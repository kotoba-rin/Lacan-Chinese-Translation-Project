# 知识库与研讨班语料检索

把检索分成四层。每层先产生候选，再阅读全文判断；不要把关键词得分或共享标签直接当作语义结论。

## 1. 先建立模糊查询词组

从用户问题提取并扩展：

- 中文主词、别译、简称和旧译；
- 法文原词、重音差异、单复数、动词与名词变体；
- 人名、作品名及原语言拼写；
- 上位概念、近邻概念和容易混淆但必须区分的词；
- 只有在结果噪声过高时才加入研讨班号、作者或年代等限定。

先提取至少两个稳定词核，再允许中间出现少量不同字符：

- “四话语”用 `四.{0,2}话语` 覆盖“四种话语”；
- 术语有“被假定知道的主体／假定知道主体”等差异时，用 `假定.{0,3}知道.{0,3}主体`；
- 人名同时搜索常见汉译、稳定尾部或姓氏片段、拉丁字母原名，例如 `鲍德里亚|博德里亚|Baudrillard|德里亚`；
- 不把单个“拉”“爱”“话”等高频字当作模糊模式，至少用两个词核或另加 TAG 限定。

记录实际使用的查询词和模糊正则。零命中时换同义词、原文词形或理论邻词再搜，不要直接下“没有相关内容”的结论。

## 2. 关键词召回

先用模糊正则搜知识库：

```bash
rg -n -i -C 2 --glob '知识库/*.md' \
  -- '词核1.{0,3}词核2|别译|外文词|人名变体' 知识库
```

再把同一组词扩展到全部已有译文：

```bash
rg -n -i -C 2 --glob 'texts/*/translation/*.md' \
  -- '词核1.{0,3}词核2|别译|外文词|人名变体' texts
```

同时 grep TAG；TAG 可能比正文更稳定：

```bash
rg -n -i --glob '知识库/*.md' \
  -- '^  - .*(稳定词核|外文名|概念词)' 知识库
```

优先读取完整卡片或完整分段。行号上下文只用于定位，不能代替上下文理解。

## 3. TAG 与链接图扩展

对关键词命中的卡片，先直接查看 TAG 与 `## 关联`：

```bash
rg -n -- '^(tags:|  - |## 关联$)|^\[\[(知识库|texts)/' \
  '知识库/命中的卡片.md'
```

再做反向链接检索：

```bash
rg -l -F '知识库/命中的卡片.md' 知识库 --glob '*.md'
rg -l -F '#s17-01-0051|' 知识库 --glob '*.md'
```

第一条寻找指向该知识卡的其他卡片，第二条寻找共享同一译文分段的卡片。随后用命中卡的高辨识度 TAG 再 grep 一轮，形成“模糊关键词 → TAG → 链接文件 → 共享分段”的闭环。

运行：

```bash
python3 .agents/skills/maintain-lacan-knowledge-base/scripts/search_local_corpus.py \
  --repo-root . \
  --query '关键词' \
  --tag '概念/精确标签'
```

可组合的种子：

- `--query`：在知识卡正文和全部译文中作字面召回；可重复；
- `--card`：以卡片标题、文件名或路径为种子；可重复；
- `--tag`：精确标签或标签层级前缀；可重复；
- `--segment`：分段 ID 或 `路径#分段ID`；可重复；
- `--include-originals`：用全部 `--query` 搜索所有研讨班法语原文；
- `--json`：输出机器可读结果。

脚本默认启用模糊召回：忽略空格和标点，允许中文短语少量插字，并对标题、TAG 和卡名容忍轻微译名差异。只有排查误报时才加 `--exact`。模糊得分只决定候选顺序，不证明两个词或人名相同。

按以下优先级解释图关系：

1. 显式知识卡双向链接；
2. 共享同一译文分段；
3. 知识卡与译文分段的正向／反向关联；
4. 共享人物、作品、概念等高辨识度 TAG；
5. 共享领域或研讨班标签，只作为弱线索。

脚本会把旧的单向卡片链接按双向边遍历，也会为尚未补互链的旧卡推导候选。回答时标明哪些是显式链接，哪些只是 TAG 或共享分段推导。

## 4. 法语原文与互联网补检

把查询词转换成法语词族后搜索整个原文语料：

```bash
rg -n -i -C 3 --glob 'texts/*/original/*.md' \
  -- 'terme|variante|forme-fléchie' texts
```

命中后读取：

- 命中 ID 的完整段落；
- 前后相邻段落；
- 同课译文对应 ID；
- 该研讨班 `original/README.md`；
- 已关联知识卡及其来源。

互联网检索使用概念词、原文词、作者和作品名组成多语言查询。优先原典、权威词典、同行评审研究、正式出版信息、图书馆和机构页面。若网页提供拉康引文，尽量在本地法语原文中重新定位；没有找到时明确说明。

## 返回结果

按证据层级组织：

1. 直接关键词命中的知识卡和译文分段；
2. 显式卡片互链及译文反向链接；
3. TAG 或共享分段推导出的相关卡；
4. 全项目法语原文命中；
5. 外部来源：标题、URL、语言和支持范围；
6. 语义判断与仍未解决的证据缺口。

本地引用优先给出卡片路径或 `[[texts/...#分段ID|分段ID]]`。把“没有字面命中”“存在相关概念但不是同一术语”“证据不足”分别表述。
