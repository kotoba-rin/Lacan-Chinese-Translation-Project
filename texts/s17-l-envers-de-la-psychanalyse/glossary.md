# 翻译术语对照表

适用范围：`S17 L'envers de la psychanalyse`

本表用于统一第十七研讨班译文。正文以“统一中文译名”为准；备注用于区分近义词、普通义与本课的特殊语境。已有法文新造词或双关若没有可靠的单一汉译，正文保留原词，并在首次出现处加译注，不以顺口的解释性意译替代原词。

## 四种话语及其位置

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| discours | 话语 | 指无需等同于实际说话、由稳定关系构成的结构；与 *parole*“言说”区分。 |
| discours sans parole | 无言说的话语 | 保留 *discours* 与 *parole* 的概念差异，不简化为“无言的话”。 |
| quatre discours / quatre discours radicaux | 四种话语 / 四种根本话语 | 指由四个要素依次作四分之一转而形成的结构。 |
| discours du Maître | 主人的话语 | 四种话语之一；*Maître* 在这一结构名中统一译“主人”。 |
| discours de l'hystérique | 癔症者的话语 | 四种话语之一；不在同一篇中改作“歇斯底里话语”。 |
| discours universitaire | 大学话语 | 四种话语之一。 |
| discours de l'analyste | 分析家的话语 | 四种话语之一；与普通形容词结构 *discours analytique* 区分。 |
| discours analytique | 分析话语 | 泛指精神分析所开启或运作的话语；若明确指四公式之一，则依上下文译“分析家的话语”。 |
| discours capitaliste / discours du Maître capitaliste | 资本主义话语 / 资本主义主人的话语 | 本研讨班尚未把它稳定写成独立的“第五种话语”，不要擅自补入后来的公式。 |
| discours scientifique / discours de la science | 科学话语 | 与大学话语有关但不自动等同。 |
| dominante | 主导项 / 主导位置 | 指四话语公式左上方；谈元素时用“主导项”，谈格位时用“主导位置”。 |
| agent | 施动者 | 四话语公式左上位置的功能名；不译“代理人”。 |
| autre | 他者 | 四话语公式右上位置；普通语境可译“另一个人/另一个”。 |
| travail | 劳作 / 劳动 | 作为四话语右上位置的功能时译“劳作”；政治经济语境可译“劳动”。 |
| vérité | 真理 | 四话语公式左下位置，同时也是全书反复讨论的真理功能。 |
| production | 产出 | 四话语公式右下位置；避免与一般工业“生产”机械混同。 |
| quart de tour | 四分之一转 | 四个要素在四个位置间轮换的结构操作。 |
| appareil | 装置 | 指四话语的书写装置或结构装置；普通器具义另按语境处理。 |
| articulation | 衔接 / 结构性联结 | 侧重能指或位置之间的结构关系，不泛化为“表达”。 |
| impossible | 不可能 / 不可能性 | 四话语中关系无法写成之处；与 *impuissance* 区分。 |
| impuissance | 无能 / 无能性 | 指既定话语结构内部的不能，不能与“不可能性”互换。 |
| pouvoir des impossibles | 诸种不可能之权能 | 第十三课回指“治理、教育、分析”等不可能职业时的反讽说法。 |

## 知识、语言与真理

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| savoir | 知识 | 指能指网络及其运作；与 *connaissance* 区分，不逐处括注法文。 |
| non-savoir | 非知识 | 保留它同“知识”的构词关系；不自动等同于一般的“无知”。 |
| connaissance | 认识 / 认知 | 依语境处理；不得无差别地并入 *savoir*。 |
| savoir-faire | 技艺性知识 | 第一课奴隶掌握的实践技艺语境；普通固定语可译“本领/技艺”。 |
| savoir du Maître / savoir de Maître | 主人的知识 | 不是说主人亲自拥有全部知识，而是知识被主人话语抽取和编排。 |
| savoir absolu | 绝对知识 | 黑格尔语境。 |
| tout-savoir | “全是知识” | 拉康明确把它同 *savoir de tout*“万事皆知”区分；正文首次出现须保留法文并说明。 |
| savoir de tout | 万事皆知 | 与 *tout-savoir* 对举。 |
| épistémè / ἐπιστήμη | 知识（epistēmē） | 第一课强调可传授、可理论化的主人知识时，首次保留希腊文。 |
| désir de savoir | 求知欲望 | 不简化为“好奇心”；拉康强调它与知识本身没有直接关系。 |
| langage | 语言 | 作为结构与体系；与 *parole*、*discours* 区分。 |
| parole | 言说 | 不译“话语”，以免与 *discours* 混同。 |
| énoncé | 陈述 | 指被说出的陈述及其结构地位。 |
| énonciation | 言说行为 | 指发出陈述的行为与位置。 |
| sens | 意义 | 普通“方向”义另按上下文处理。 |
| signification | 意指 / 含义 | 依句法选择；与 *sens* 不机械合并。 |
| vérité | 真理 | 原文的重复、限制和否定均须保留，不能改写成概括性“真相”。 |
| affect | 情动 | 精神分析概念语境统一译“情动”；动词 *affecter* 仍依句法译“影响/赋予/使受作用”。 |
| être parlant | 说话存在者 | 保留“存在”与“说话”的双重构造，不缩写为“人”。 |
| mi-dire | 半说 | 真理只能“半说”；不在各课间轮换为“半言”。 |
| énigme | 谜语 | 与“半说”相联系；必要时可译“谜面/谜语”。 |
| citation | 引文 / 引用 | 第二课把引用视为一种“半说”。 |
| interprétation | 解释 / 阐释 | 分析技术语境优先“解释”；文本解释学语境可用“阐释”。 |
| lecture / lisible | 阅读 / 可读的 | 第十三课将可读性同主人能指联系起来；不得把 *à dormir debout* 误解为“让人昏昏欲睡”。 |
| falsum | 假 / falsum | 首次保留拉丁词，说明它兼涉“虚假”与“落下/坠落”的词语联想。 |
| mensonge | 谎言 | 与“真理”并置时不弱化为“错误”。 |
| inconscient | 无意识 |  |
| ça parle | 它在说话 | 保留非人格主语和口语力度，不补成“无意识在表达自己”。 |
| désêtre | 去存在 | 指意义或主体被剥离其自明存在地位；首次出现可保留法文，不与“存在之缺”混同。 |
