# 翻译术语对照表

适用范围：`S25 Le moment de conclure`

本表用于统一第二十五期研讨班译文。拉康的言说术语依句法区分；拓扑术语则按本期关于环面、链环、针织物、莫比乌斯带与辫结的实际操作语境处理。原文中证据不足以消除的谐音或转录疑点保留在各课译注中，不在术语表内擅自定义。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Le moment de conclure | 作结的时刻 | 本期研讨班标题；*conclure* 保留作出结论、结束以及“结”的回响。 |
| dire / dit / parler | 说、说的行动／所说／说话 | 依句法区分正在发生的“说”、已经说出的内容与一般说话行为。 |
| parole / langage / discours | 言说／语言／话语 | 三者不混译；*langage* 指语言能力或语言系统，*discours* 指结构化话语。 |
| lalangue | *lalangue* | 保留拉康合写形式，不拆成普通的 *la langue*“语言”。 |
| réel / le Réel | 实在／实在界 | 指三界之一时译“实在界”；普通形容词或名词依句法译“实在、现实的”。 |
| symbolique / le Symbolique | 象征的／象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 名词化且指三界之一时译“想象界”；不与 *fantasme*“幻想”混同。 |
| rapport sexuel / il n’y a pas de rapport sexuel | 性关系／性关系不存在 | 保留 *rapport* 的关系义，不补成自然互补的“两性关系”。 |
| fantasme | 幻想 | 指支撑主体与实在界之关系的结构，不泛化为普通想象。 |
| sinthome / symptôme | *sinthome*／症状 | *sinthome* 保留法文，以免抹去拉康的古拼写及其与普通“症状”的差别。 |
| la passe | 渡越 | 指拉康学派中同分析终结及分析家产生有关的制度与经验。 |
| sujet supposé savoir | 被假定知道的主体 | 第一课用来界定转移；“知道”是被假定的位置，不是实际全知。 |
| consistance | 实存性 | 指某物得以自持、取得某种身体的性质；不按一般论证语境译作“一致性”。 |
| voisinage / surface-voisinage | 邻域／曲面邻域 | 拓扑学意义上的邻域；第一课把它同实存性相连，第五课用曲面邻域比较两个圆。 |
| ex-sister | 外—存在 | 保留 *ex-* 的“在外”构词作用，指由在外而获得支撑。 |
| écriture | 书写 | 本期反复与切割、结和实在界的显现相联系，不缩减为普通记录。 |
| nœud borroméen | 博罗米结 | 指任一组成环被切开时其余各环均释放的结式结构。 |
| chaîne / chaîne borroméenne | 链环／博罗米链环 | *chaîne* 在链结理论语境译“链环”，以同单一的 *nœud*“结”区分。 |
| chaîne à 2 / à 3 / à 4 | 二元／三元／四元链环 | 数字表示组成环数量；第五课把三元链环与生成元、二元链环与退化的单位元情形类比。 |
| rond de ficelle / cercle | 绳圈／圆环 | 前者强调作为材料被操作的绳圈；后者依几何或链环语境译“圆、圆环”。 |
| tore / toricité | 环面／环面性 | *tore* 不译作普通圆环；*toricité* 指环面结构所具有的性质。 |
| retournement / inversion | 翻转／反转 | *retournement* 指环面内外翻换等操作；*inversion* 在针织与上下穿越语境译“反转”。 |
| trouage / coupure | 开孔／切割 | *trouage* 指造出可供穿越的孔；*coupure* 可沿圆继续切开曲面，二者在第五、八、九课严格对举。 |
| âme / axe du tore | 环面的芯环／环面轴线 | 翻转操作中二者可以互换；*âme* 在此是环面内部的核心圆，不按普通词义译“灵魂”。 |
| cercle réductible / non réductible | 可缩圆／不可缩圆 | 前者在曲面上可连续缩为一点，后者不可；第八课据此区分开孔与切割。 |
| cercle méridien / cercle longitude | 子午圈／经圈 | 环面上的两类基本圆周方向。 |
| surface avec bord | 有边界曲面 | 指切割或开孔后出现边界的曲面。 |
| bande de Mœbius | 莫比乌斯带 | 保留单面带的拓扑含义；不写成普通带环。 |
| bande de Mœbius triple / triple bande de Mœbius | 三重莫比乌斯带 | 本期指具有三次半扭转、从中间切开会产生三叶结的带。 |
| demi-torsion / torsion complète | 半扭转／完整扭转 | 两次半扭转构成一次完整扭转。 |
| nœud à 3 | 三叶结 | 本期图示中指具有三个交叉点的 trefoil knot。 |
| enlacement / emboîtement | 相扣／嵌套 | 第五课区分两类链环或环面的结合操作；不把二者合并为笼统的“连接”。 |
| générateur / élément neutre | 生成元／单位元 | 第五课把三元链环类比为 1 和生成元，把二元链环类比为 0 与单位元情形。 |
| tricot torique / tricotage | 环面针织物／针织 | 第七至九课借针织结构表示环面上的上下穿越与内外面。 |
| maille à l’endroit / maille à l’envers | 正针／反针 | 平针织物的两种针目与两个表面；在反转中彼此转换。 |
| ligne de mailles / ligne de rangées | 针目线／横列线 | 第七课讨论两类线彼此从上方或下方经过；转录中的重复另在译注说明。 |
| tresse / tresse borroméenne | 辫结／博罗米辫结 | 第十二课用腰带演示可解开的三股编结结构。 |
| bande de Slade | 斯莱德带 | 一种三股编带；保留专名 *Slade*。 |
| étoffe / tissu | 质料／织物 | 第三、十、十二课既取布料、材料义，又借二者讨论思想与精神分析的“质料”及实在界；不把两个法文词完全抹平。 |
| la Chose | 原物；词物双关处作“物” | 指弗洛伊德—拉康意义上的 *das Ding*；第一、四课与 *mot / chose*（词／物）的双关相连时保留“物”，并与一般复数 *les choses*“物、事物”区分。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
