# S12 翻译术语对照表

适用范围：`S12 Problèmes cruciaux pour la psychanalyse`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| sens | 意义 | 与 *signification*“意指”区分；普通“方向”义另按语境处理。 |
| signification | 意指 | 指能指运作所产生或承载的意指；普通“含义、重要性”可依句法处理，但不与 *sens* 机械合并。 |
| non-sens / nonsense | 非意义 | 第一课明确说明它不等于“没有意指”（*sans signification*）；保留其作为意义朝向所指一侧的拒绝面。 |
| signifiant / signifié | 能指／所指 | 保留二者在 $S/s$ 公式中的区分；不得把 *signifiant* 泛化成“意义”。 |
| représenter / représentant / représentation (*Vorstellung*) | 代表／代表项／表象 | 拉康公式中的动词 *représenter* 译“代表”，*représentant* 译“代表项”；弗洛伊德的心理表象或一般名词 *représentation* 才按语境译“表象”，三者不可机械合并。 |
| chaîne signifiante | 能指链 | 指能指按组合关系形成的链条。 |
| syntagme | 组合段 | 第一课把它界定为从要素接合方面考察的能指链。 |
| sujet | 主体 | 概念性用法统一译“主体”；语法主语或受试者义按上下文处理。 |
| Autre | 大他者 | 大写 *Autre* 保留同普通他者的区分。 |
| référent | 指涉对象 | 不同于 *signifié*“所指”；第一课将它同实在及意指的迂回联系起来。 |
| dénotation / connotation | 指称／涵义 | 第一课区分能指相对于指涉对象的两种用法。 |
| réel | 实在 | 拉康三界概念用法；普通“现实、真实”义按上下文处理。 |
| sexe / sexuel / différence sexuelle | 性／性的／性差异 | 指性及其结构性差异，不以当代社会身份意义上的“性别”替代；语法上的 *genre* 仍按语境译“性”。 |
| praxis | 实践 | 指以主体为枢轴的精神分析实践，不改写成一般操作技术。 |
| épicatathète / épanathète / épamphithète | 前置修饰语／后置修饰语／同位修饰语 | 第一课引用达穆雷特与皮雄对形容词位置及意义效应的区分。 |
| signifiance | 能指性 | 指能指结构及其产生效应的性质，不等同于已经固定的“意义”。 |
| pas de sens | 意义之不／意义之步 | *pas* 同时承载否定词“不／没有”和名词“步”的双关；关键处并列保留两层。 |
| surface / face / bord | 曲面／面／边界 | 第二课拓扑语境中的区分；*surface* 不泛译为日常“表面”。 |
| homologie / homologue | 同型关系／同型的 | 指形式、位置或结构上的对应，不预设共同起源；只有在明确的数学同调语境中才译“同调”。 |
| tore / cross-cap / bande de Möbius / huit intérieur | 环面／交叉帽／莫比乌斯带／内八字 | 第二课用于说明能指链、主体及里面与外面的拓扑关系。 |
| nom propre | 专名 | 第二课强调专名的功能不能被化约为对个体的指示。 |
| métalangage / langage-objet | 元语言／对象语言 | “不存在元语言”否定一种能站到语言原初使用之外并穷尽它的层级；不否定局部形式化。 |
| sujet supposé savoir | 被假定知道的主体 | 指知识被假定于主体的结构位置，不表示某人实际拥有全部知识。 |
| ἀτοπία / atopia | 不可定位 | 第二课指苏格拉底无法被安置于既定位置的特征，并同作为主体在场之能指的非意义相连。 |
| fausse monnaie / bon aloi | 假币／成色合乎标准 | 第二课用货币隐喻区分对术语的悄然篡改与经请求确认的合宜用法。 |
| belle âme | 美丽灵魂 | 黑格尔语境中指借世界失序维持自身纯洁位置的意识形态姿态。 |
| idéal du moi | 自我理想 | 不同于“理想自我”；第三课拒绝把分析家培养的终点简单规定为对此功能的认同。 |
| bouteille de Klein | 克莱因瓶 | 第三课以其单面、闭合而内外连通的结构说明语言、主体与宇宙论的关系。 |
| point de capiton | 绗缝点 | 软垫工意象；能指结构在此发生缝合，同时打开决定性的孔洞。 |
| microcosme / macrocosme | 小宇宙／大宇宙 | 第三课批判灵魂与宇宙逐项对应、彼此包裹的宇宙论图式。 |
| acosmique | 非宇宙性的 | 指现代科学以打破主体—宇宙平行关系为条件，不表示简单否定宇宙存在。 |
| Heimlich / Unheimlich | 熟悉而隐秘的／令人不安的陌异 | 第三课强调二者在否定关系中的连续性，并把它连接到梦的“另一场景”。 |
| autre scène | 另一场景 | 梦与无意识的场所；现实在此显出如布景般被构成的性质。 |
| Verliebtheit | 爱恋状态 | 既锚定在实在与快乐调节中，又具有根本的自恋性；首次关键处保留德文。 |
| moi idéal | 理想自我 | 与 *idéal du moi*“自我理想”严格区分。 |
| trait unaire | 一元特征 | 指认同所依托的单一刻痕；不译作一般的“统一特征”。 |
| objet(a) / objet a | 客体(a) | 保留字母与括号；指欲望原因及从结构中掉落的剩余位置，不泛化为一般客体。 |
| désir | 欲望 | 与 *demande*“要求”和 *besoin*“需要”区分。 |
| demande | 要求 | 拉康概念性用法统一译“要求”；日常请求义可按语境处理。 |
| transfert | 移情 | 包括移情关系、移情要求与知识被假定的位置，不译作一般“转移”。 |
| identification | 认同 | 主体结构与临床语境统一使用；普通身份识别义按上下文处理。 |
| privation / frustration / castration | 剥夺／挫折／阉割 | 三种欠缺操作严格区分，不相互替换。 |
| subsomption / assignation / suture | 归摄／指派／缝合 | 用于主体、能指及分类功能的逻辑—拓扑关系。 |
| Einverleibung | 合并／摄入 | 首次关键处保留德文；指口腔性纳入，不简化为一般内化。 |
| Nom-du-Père | 父之名 | 保留大写术语同现实父亲、想象父亲的区分。 |
| sommation | 传唤 | 法律与结构性双重语境；普通求和义按上下文处理。 |
| effet de signification | 意指效应 | 指能指运作产生的效应，不改写为“意义效果”。 |
| anaclitique | 依附性的 | 弗洛伊德式对象选择语境；首次关键处可保留原词。 |
| fantasme | 幻想 | 指支撑欲望并把主体与客体关系搬上舞台的结构；不同于日常空想。 |
| refoulement | 压抑 | 与 *forclusion*“拒斥”、*dénégation*“否认”区分。 |
| forclusion | 拒斥 | 精神病结构中的概念性用法；不得同压抑合并。 |
| voix / regard | 嗓音／凝视 | 作为部分客体或客体(a)时采用此译；日常声音、观看义按语境处理。 |
| jouissance | 享乐 | 与 *plaisir*“快感”区分。 |
| objet partiel | 部分客体 | 指相对于要求与欲望占据同源结构位置的客体。 |
| λεκτόν / lekton | 可说之物 | 斯多葛派术语；指言说中可读、可表达的非物体层面。 |
| ὄνομα / onoma | 名称 | 与 *ῥῆσις*“言说／陈述”的功能相对。 |
| ῥῆσις / rhésis | 言说／陈述 | 指句子、命题与述说功能；依具体句法选“言说”或“陈述”。 |
| Wortbrücke | 词桥 | 弗洛伊德文本中由词语连接形成的联想通道。 |
| différence exquise | 精微差异 | 指身体感受中不可还原、被能指标记的微小差异。 |
| sonorité (phonologie) | 响音度 | 音系学中指音段在音节组织中的相对层级，不等同于声学音量；*degré / échelle de sonorité* 分别译“响音度／响音度阶梯”。 |
| Sinn / Bedeutung | 意义／指称 | 弗雷格语境中的对举；*Bedeutung* 不与法语 *signification*“意指”合并。普通德语标题语境可依句法处理。 |
| Wahrheit | 真理 | 第二十二、二十三课三元结构中的德语项；与 *Sinn*、*Zwang* 并列时首次保留德文。 |
| Zwang / Entzweiung / Spaltung | 强迫／分裂为二／裂分 | 保留三者差异：*Zwang* 突出强制，*Entzweiung* 突出一分为二，*Spaltung* 指主体的结构性裂分。 |
| non-être | 非存在 | 《智者篇》语境中与“存在”相对又由“他者”生成的形式位置，不译作日常“没有”。 |
| être sexué | 性化存在 | 指处在性之结构关系中的存在，不化约为生理性别身份。 |
| la Chose | 原物 | 弗洛伊德—拉康意义上的 *das Ding*；与普通 *chose*“东西、事物”区分。 |
| τυγχάνον / tugkanon | 情势 | 第十七课斯多葛派三元关系中的术语，指包含行动者并支撑事件流的动态语境，不简化为静态“指涉对象”。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
