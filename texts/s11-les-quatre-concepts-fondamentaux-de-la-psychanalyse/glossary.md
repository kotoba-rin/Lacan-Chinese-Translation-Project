# 翻译术语对照表

适用范围：S11 Les quatre concepts fondamentaux de la psychanalyse

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Les quatre concepts fondamentaux de la psychanalyse | 精神分析的四个基本概念 | 第十一期研讨班标题；与第一课所说的 *fondements de la psychanalyse*“精神分析的基础”区分。 |
| fondements de la psychanalyse | 精神分析的基础 | 第一课公布的新讲题；*fondement* 依上下文还带有“底部、底下”的文字游戏，不改写成“四个基本概念”。 |
| concept fondamental | 基本概念 | 第一课末明确列出无意识、重复、转移和驱力四项。 |
| praxis | 实践 | 指由人筹划、通过象征处理实在的行动；不缩减为理论的普通应用。 |
| réel / le Réel | 实在 / 实在界 | 指三界之一时可用“实在界”；第一课“通过象征处理实在”依句法使用“实在”，与 *réalité*“现实”区分。 |
| symbolique / le Symbolique | 象征的、象征 / 象征界 | 第一课谈实践时取“象征”这一操作层次；明确指三界之一时用“象征界”。 |
| imaginaire / l’Imaginaire | 想象的、想象 / 想象界 | 第一课谈实践中介入的想象成分时不机械补写“界”。 |
| psychanalyse didactique / analyse didactique | 训练分析 | 指分析家资格训练中的个人分析，以及分析家培养所提出的问题。 |
| formation des psychanalystes | 精神分析家的培养 | 指研讨班与训练分析所参与的分析家形成过程。 |
| désir de l’analyste | 分析家的欲望 | 第一课把它规定为分析家培养不能排除的问题，不改写成分析家的个人愿望。 |
| herméneutique / interprétation | 诠释学 / 解释 | 第一课区分诠释学对意指的不断追寻与精神分析的解释；分析技术语境中的 *interprétation* 统一译“解释”。 |
| signification | 意指 | 与 *signifiant*“能指”区分；不按一般措辞统一改成“意义”。 |
| inconscient | 无意识 | 第一课列出的四个基本概念之一。 |
| répétition | 重复 | 第一课列出的四个基本概念之一。 |
| Durcharbeiten / Durcharbeitung / working through | 修通 | 指分析中对阻抗材料反复工作的过程，不是一次性的“加工”或一般文本处理。 |
| transfert | 转移 | 第一课列出的四个基本概念之一。 |
| pulsion | 驱力 | 第一课列出的四个基本概念之一；不译“本能”。 |
| signifiant | 能指 | 第一课末把对能指本身的参照规定为涵盖四个概念、显示其操作价值的更普遍功能。 |
| sujet | 主体 | 概念性用法统一译“主体”；普通“题目、议题”义依上下文处理。 |
| instance | 审级；心理审级 | 精神分析地形学中指一个发挥特定功能、可同其他层次区分的系统或层次；不按日常行政含义译作“机构”。 |
| objet | 对象 | 用于科学对象、分析对象及主体真理所处的对象；不统一改写成“客体”。 |
| analysé | 被分析者 | 原文以过去分词身份指接受分析的人；不与主动言说的 *analysant* 混同。 |
| analysant | 分析者 | 强调正在分析中言说者的主动位置；与“分析家”区分。 |
| Henri / Henry Ey | 亨利·埃伊 | 法国精神病学家；原文第一课拼作 Henry Ey。 |
| Pierre Duhem | 皮埃尔·迪昂 | 法国物理学家、科学史家与科学哲学家；正文可简称“迪昂”。 |
| objet(a) / objet (a) | 对象(a) | 驱力围绕其绕行、并作为欲望原因发挥作用的部分对象；不改写成完整的经验对象。 |
| objet partiel | 部分对象 | 其“部分”指结构位置，不预设它最终整合成完整对象。 |
| pulsion partielle | 部分驱力 | 弗洛伊德意义上的驱力均为部分驱力；不把它们合成为天然的生殖器总体。 |
| désir / demande / besoin | 欲望 / 要求 / 需要 | 三者严格区分；要求经由能指提出，欲望在要求与需要的差异中定位。 |
| désir de l’Autre | 大他者的欲望 | 保留“属于大他者的欲望／以大他者欲望为参照”的结构张力。 |
| sujet supposé savoir | 被假定知道的主体 | 转移的结构性支点；不表示分析家实际拥有被假定给他的知识。 |
| mise en acte de la réalité de l’inconscient | 将无意识的现实付诸行动 | 转移的规定；不缩减为对过去关系的简单重复。 |
| réalité sexuelle | 性现实 | 与 *réalité*“现实”及 *réel*“实在”区分；不用“性爱现实”作为并行译名。 |
| sexualité / sexe / désir sexuel / libido | 性、性这一维度 / 性、性别 / 性欲 / 力比多 | *sexualité* 在本期常指构成性的“性”或“性这一维度”，不能机械译成欲望意义上的“性欲”；第八课并列 *sexualité* 与 *sexe* 时须保留二者层次差别。 |
| jouissance / plaisir / satisfaction | 享乐 / 快乐 / 满足 | *jouissance* 不译作一般快感；三项不可互换。 |
| principe de plaisir / principe de réalité | 快乐原则 / 现实原则 | 现实原则不被写成对快乐原则的最终取消。 |
| aliénation | 异化 | 指主体在能指选择与大他者关系中的结构性异化，不弱化为普通疏离感。 |
| séparation | 分离 | 异化之后的第二项操作；主体以自身缺失回应大他者话语间隔中显出的缺失。 |
| vel de l’aliénation | 异化之 vel（或） | 一种特殊的排除性选择；选中一项时，另一项必然连同部分所选项一起丧失。 |
| manque / manque-à-être | 缺失 / 存在缺失 | *manque-à-être* 指主体结构中的存在缺失，不改写成一般匮乏感。 |
| Vorstellungsrepräsentanz | 表象占位者 | 本期强调它“代替表象”；第17课拆词论证处保留“表象的代表”这一字面层次，不译成“表象性的代表”。 |
| Vorstellung / Repräsentanz | 表象 / 占位者、代表 | 依第17课的外交代表类比，*Repräsentanz* 与个人意义相对，突出能指性代表功能。 |
| Verdrängung / Unterdrückung | 压抑 / 压到下方、压制 | 前者指压抑机制；后者突出能指被压至下方，不能不加区分地合并。 |
| Urverdrängung | 原压抑 | 指使二元能指坠入下方、成为其他压抑吸引点的原初结构。 |
| aphanisis / ἀϕάνισις / fading | 消失 / 主体淡出 | 本期把琼斯的“欲望消失”移到主体层面；保留原词时依上下文注明主体的消失或淡出。 |
| trait unaire / einziger Zug | 一元特征 | 最简的能指标记，也是自我理想与认同的重要支点。 |
| idéal du moi / moi idéal | 自我理想 / 理想自我 | 前者是从大他者处取得的象征性视点，后者是镜像中令人满意的理想形象。 |
| regard / œil / vision | 凝视 / 眼睛 / 视觉 | 凝视是对象(a)的功能，不等同于观看器官或视觉知觉。 |
| écran / tache / mimétisme | 屏幕 / 斑点 / 拟态 | 观看场域中的三个相关词；斑点与凝视先于主体对图像的自觉掌控。 |
| scoptophilie / pulsion scopique | 窥视欲 / 观看驱力 | 观看驱力的对象是凝视，不是作为器官的眼睛。 |
| voyure | 窥看 | 拉康在观看场域中使用的罕见造词，保留同 *voyeur*（窥视者）相呼应的窥视意味；不泛化成中性的“观看”。 |
| lamelle / hommelette | 薄片 / 人薄片 | 拉康用以神话化力比多及有性繁殖所失落生命部分的造词，不改写成解剖实体。 |
| Sexualstrebung / ganzen Sexualstrebung | 性趋力 / 全部性趋力 | 弗洛伊德用来质疑驱力能否汇成性总体的词，不等同于任何单一驱力。 |
| Drang / Quelle / Objekt / Ziel | 推动力 / 来源 / 对象 / 目标 | 驱力的四项要素；*Ziel* 是获得满足的目标，驱力可经绕行达到它。 |
| Real-Ich / Lust-Ich | 实在自我 / 快乐自我 | 前者指趋向稳态的装置层面，后者由带来快乐的对象关系构成；不与日常人格自我混同。 |
| autoerotisch | 自体性爱的 | 指驱力回路中对象的缺席与自体回返，不等于主体封闭在自身内部。 |
| oblativité | 奉献性 | 精神分析语汇中围绕给予对象、把自己给予他者形成的概念；第15课从粪便作为礼物的肛门对象关系中推出，不译作宗教仪式意义上的“献祭性”。 |
| fils-père / fille-mère | 儿子—父亲 / 女儿—母亲（未婚母亲） | 第12课 *fils-père* 是仿照法语固定说法 *fille-mère* 临时造出的双关，必须保留亲属词之间的反常并置，不能顺译成“父亲的儿子”。 |
| τύχη / tuché | 遭遇、同实在的遭遇 | 以总可能错失的遭遇规定实在；与能指返回的 *automaton* 区分。 |
| αὐτόματον / automaton | 自动性、能指的返回 | 指能指网络中的返回、再来和坚持，不译成日常偶然。 |
| δυστυχία / dystychia | 不幸的遭逢、错失的相遇 | 指实在从起源处便来得不巧的“厄遇”；与 *eutychia* 相对。 |
| holophrase / s’holophraser | 整体句 / 整体句化 | 第18课指 S₁ 与 S₂ 之间没有间隔、第一对能指凝固成块。 |
| liquidation du transfert | 转移的清算 | 第20课质疑这一惯用说法；若“清算”有意义，只能指持续清算转移中的欺骗。 |
| traversée du fantasme fondamental | 穿越根本幻想 | 指主体相对于对象(a)重新定位并越过认同平面，不等于消除幻想内容。 |
