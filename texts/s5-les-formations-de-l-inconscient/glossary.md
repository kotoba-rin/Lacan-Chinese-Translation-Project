# 翻译术语对照表

适用范围：`S5 Les formations de l'inconscient`

本表以第五期研讨班的语境为准。其他研讨班的译名只作项目内比较；正文遇到普通词义时，仍按具体句法处理。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Les formations de l’inconscient | 无意识的形成 | 第五期研讨班标题；*formation* 在具体段落中若明确指梦、口误、症状或诙谐等产物，可依句法译“形成物”。 |
| signifiant / signifié | 能指 / 所指 | 保留索绪尔式区分；不得把 *signifiant* 改写为“意义”。 |
| chaîne signifiante | 能指链 | 指能指依差异与先后关系衔接而成的链条。 |
| sujet | 主体 | 概念义统一译“主体”；普通“主题、议题”义依语境处理。 |
| moi | 自我 | 指精神分析概念时译“自我”；普通重读代词义另按句法处理。 |
| Je | “我” | 第一课图式中指话语链里说话者的位置，不自动等同于作为概念的主体或自我。 |
| Autre / grand Autre | 大他者 | 大写 A 所标示的象征位置、语言伙伴及代码场所；与普通 *autre* 区分。 |
| autre / petit autre | 他者 / 小他者 | 小写 a 且处在想象二元关系中时译“小他者”。 |
| parole / discours / langage / langue | 言说 / 话语 / 语言 / 一门语言 | 保留言说行为、已展开的话语、语言功能与具体语种之间的区别。 |
| point de capiton | 绗缝点 | 软垫工意象；能指链与所指之流在某些点被钉合，同时仍保留一定弹性。 |
| métaphore / métonymie | 隐喻 / 转喻 | 前者以能指替代产生意义，后者沿能指组合与滑动运作；不得互换。 |
| objet métonymique | 转喻对象 | 欲望对象始终位于别处、总是另一物；不把它固定成单一经验对象。 |
| code / message | 代码 / 讯息 | 第一课图式中的两个交叉点：大他者承载代码，意义在讯息处形成。 |
| trait d’esprit / Witz | 诙谐 | 保留 *Witz* 同“才智、精神”的歧义；明确指一句话或语言产物时，可依句法写“机智语”。 |
| mot d’esprit | 机智语 | 同 *trait d’esprit* 有重叠；第一课在讨论弗洛伊德所谓语言技术时采用。 |
| le comique / le rire | 滑稽 / 笑 | 与诙谐分别构成不同问题；第一课把滑稽规定为二元关系，诙谐还需要第三方大他者的认可。 |
| famillionnaire | *famillionnaire* | *familier* 与 *millionnaire* 的压合词；正文保留法文，以保存后文对音节重叠与凝缩的分析。 |
| condensation | 凝缩 | 第一课指两条能指链在材料层面压合；不简化为内容摘要。 |
| nachträglich / après-coup | 事后性 / 事后地 | 后一时刻回溯性地规定先前成分的意义，不译成原事件当时已有完整意义。 |
| Verwerfung | 拒斥 | 与压抑、拒认和否定区分；第一课回指精神病中原初能指匮乏。 |
| vérité / réalité | 真理 / 现实 | 第一课明确区分真理层面与共同现实的话语。 |
| discours vide | 空洞言说 | 指主要循环陈套观念、很少创造新意义的话语，不等于没有任何语言材料。 |
| L’instance de la lettre dans l’inconscient | 《无意识中字母的动因》 | 拉康文章标题；第五期第一课多次回指。 |
| Der Witz und seine Beziehung zum Unbewußten / Le mot d’esprit et ses relations avec l’inconscient | 《诙谐及其与无意识的关系》 | 弗洛伊德著作；正文谈到具体“词”的技术时仍可使用“机智语”。 |
| Le séminaire sur « La lettre volée » | 《〈失窃的信〉研讨班》 | 第一课原注所指拉康文本。 |
| Ferdinand de Saussure | 费迪南·德·索绪尔 | 第一课借其能指／所指双重流图式引入绗缝点。 |
| Roman Jakobson | 罗曼·雅各布森 | 第一课援引其关于语言学分析所需最小能指组的观点。 |
| Heinrich Heine | 海因里希·海涅 | *famillionnaire* 例子的文学来源。 |
| Kuno Fischer / Friedrich Theodor Vischer / Theodor Lipps | 库诺·费舍尔 / 弗里德里希·特奥多尔·菲舍尔 / 西奥多·李普斯 | 弗洛伊德讨论诙谐时采用的三项主要理论来源。 |
| substitution / combinaison | 替代 / 组合 | 分别是能指分节的两种可能维度；隐喻在替代位置发挥作用，转喻在组合链上运作，但两组概念不得互相等同。 |
| diachronie / synchronie | 历时性 / 共时性 | 历时性关乎能指链的连续展开，共时性由每一项始终可能被另一能指替代而引入。 |
| déplacement | 移置 | 同凝缩并列为弗洛伊德所揭示的无意识机制；在具体分析中保留其沿链转移的方向。 |
| Tendenz | 倾向 | 弗洛伊德诙谐理论用语；第二课把诙谐的能指中心同其倾向及笑、滑稽等辐射现象区分。 |
| lapsus / acte manqué | 口误 / 失败行为 | *Lapsus* 依词源还可带“掉落、失落”意味；不能仅按有意识玩笑解释。 |
| association libre | 自由联想 | 使分析能够追踪无意识现象在话语中留下的能指痕迹。 |
| nom propre | 专名 | 第二课把专名置于讯息层面，并强调它不同于一个名字作为外语词的维度。 |
| substitution hétéronyme / hétéronymie | 异名替代 / 异名关系 | 指不同语言系统之间以译词互相替代，例如德语 *Herr* 与意大利语 *Signor*；替代本身不自动等于隐喻。 |
| unterdrückt / Unterdrückung | 被压下 / 压下 | 第二课用来说明绝对的 *Herr*、即死亡退出话语层面；与保持某项东西在回路中的 *Verdrängung* 区分。 |
| Verdrängt / Verdrängung | 被压抑 / 压抑 | 一股特殊力量使能指留在回路中却暂时不能重新进入；不可同一次性的“压下”混用。 |
| atterré / terre / terreur | *atterré* / 土地 / 恐惧 | 第二课的法语能指例子：*atterré* 原有“放倒在地”义，又因 *ter* 与 *terreur* 的音素接近取得恐惧色彩。正文保留法语构件。 |
| maritablement | *maritablement* | 患者把 *maritalement*（夫妻般地）与 *misérablement*（悲惨地）压合而成；语境把它判为口误，听者可在大他者位置认可其诙谐价值。 |
| Booz endormi / sa gerbe | 《沉睡的波阿斯》 / 他的禾束 | 雨果诗歌例子；“他的禾束”替代波阿斯，使迟来的父亲身份这一新意义涌现。 |
| Signorelli / Botticelli / Boltraffio / Herr / Signor | 西尼奥雷利 / 波提切利 / 博尔特拉菲奥 / *Herr* / *Signor* | 第二课专名遗忘链；保留 *Bo*、*ELLI*、*Herr*、*Signor* 等构件，才能显示组合、异名替代、压下与压抑的差别。 |
| égards aux nécessités de la mise en scène | 对场景安排之要求的顾及 | 第三课转述弗洛伊德梦工作中的第三项结构要求；与凝缩、移置并列，不简化成有意识的舞台设计。 |
| phonème | 音位 | 能指分析的基本语言学参照；第三课以辅音依托元音的最短组合说明音位操作。 |
| désir du rêve | 梦的欲望 | 第三课把它预告为意义创造之召唤所占据的 $x$；不直接等同于梦中显现的愿望内容。 |
| débris de l’objet métonymique | 对象的转喻废墟 | 隐喻创造的碎片与废余；失败隐喻中尤其显著，例如专名遗忘留下的 *Bo*、*ELLI* 等能指痕迹。 |
| énoncé / énonciation | 陈述 / 言说行为 | 第三课以“对现在的言说／言说行为的现在”区分被说出的内容与发出陈述的行为、位置。 |
| dire du présent / présent du dire | 对现在的言说 / 言说行为的现在 | 前者对应陈述，后者对应言说行为；“我、这里、现在”等指示项不能穷尽话语在讯息层面的现在。 |
| Veau d’or | 金牛犊 | 海涅与苏利耶的转喻式机智语；“小牛”先在偶像崇拜语境、再在年龄语境中运作。 |
| comte / te / con | 伯爵 / *te* 音节 / 蠢人 | 第三课极短音位诙谐；从 *comte* 中孤立 *te*，余下声音逼近粗话 *con*。正文保留法语并加译注，不另造中文笑话。 |
| métalangage / il n’y a pas de métalangage | 元语言 / 不存在元语言 | 第四课否定能够把语言现象完全数学化的单义元语言；不否定局部形式化本身。 |
| glissement du sens | 意义的滑动 | 转喻链水平展开时，意义缺少固定重心并不断延宕；不同于隐喻中的新意义涌现。 |
| valeur / sens | 价值 / 意义 | 第四课借马克思商品价值形式区分两者：一个对象成为另一对象的价值能指时，会放弃自身意义的一部分。 |
| besoin / demande / désir | 需要 / 要求 / 欲望 | 第五课的结构区分：需要经能指向大他者表达便成为要求；能指对需要的重塑及其错位产生欲望。 |
| désir de reconnaissance / reconnaissance d’un désir | 获得承认的欲望 / 对一项欲望的承认 | 前者以“承认”为欲望所求，后者是对一项欲望的承认与分节；第十三课明确并列两者，不得压缩成含混的“承认欲望”。 |
| surprise | 惊奇 | 无意识形成的根本维度；既可由形成物本身震动主体，也可在分析揭示时出现。 |
| peu de sens / dé-sens | 少量意义 / 去意义 | 指转喻链的均等化与削减使词语难以支撑完整意义；不得直接抹平成“无意义”。 |
| pas de sens | 意义之步／没有意义 | *pas* 同时是否定词与“步、间距、山口”；第五课以此双关说明隐喻越过需要、向意义迈出一步。 |
| autre scène psychique | 另一个心理场景 | 第六课沿用弗洛伊德从费希纳借来的表述，强调无意识法则相对于前意识、可理解性与意指领域的异质性。 |
| trésor métonymique / trésor des métonymies | 转喻宝库 | 大他者作为通行用语、固定搭配、意象与隐喻意涵的象征储存场所；诙谐要求听者能够调用这套共有代码。 |
| Hemmung / inhibition | 抑制 | 诙谐的“准备”把听者的对立、防御固定在某处，从而为机智言说在别处通过留出道路。 |
| façade du mot d’esprit | 诙谐的门面 | 由无意义、滑稽、淫秽等前奏构成的注意力诱饵；同诙谐真正通过的能指道路区分。 |
| naïf / comique / rire | 天真 / 滑稽 / 笑 | 第七课把天真放在诙谐与滑稽的接合处；笑同想象界的捕获及意象释放紧密相关，但不等同于滑稽本身。 |
| Ça / Es | 本我 | 第七课指欲望在语言网络中得到加工之后、在极限上呈现的原初倾向存在；不把普通代词 *ça* 机械译成本我。 |
| Nom du Père | 父之名 | 作为能指介入母亲欲望的位置；专名式概念保留“之名”，不泛化为经验父亲的姓名。 |
| père réel / père symbolique / père imaginaire | 实在父亲 / 象征之父 / 想象父亲 | 第九课依施事者、欠缺与对象三层表格区分；“象征之父”在论述其结构功能时采用，表格中可压缩为“象征父亲”。 |
| métaphore paternelle | 父亲隐喻 | 父亲能指替代母亲能指，由此重新规定母亲欲望之所指；不能改写成父亲使用的修辞比喻。 |
| castration / frustration / privation | 阉割 / 挫折 / 剥夺 | 分别须结合象征、想象、实在三个层次判断；不可仅按日常受挫或失去来互换。 |
| phallus / pénis | 阳具 / 阴茎 | *Phallus* 指结构中的象征或想象功能，*pénis* 指身体器官；两者严格区分。 |
| forme prégnante / forme prévalente | 凸显形式 / 占优形式 | *Prégnante* 在形态／完形心理学语境中指强力凸显于知觉、容易形成稳定完形，不是“孕育性的”；第二十一课中米勒本仅保留后一项。 |
| idéal du moi / surmoi | 自我理想 / 超我 | 第九课把俄狄浦斯的规范化出口同父亲成为自我理想联系起来；不得与超我混同。 |
| complexe d’Œdipe inversé | 反向俄狄浦斯情结 | 指对父亲的爱及可能形成的被动位置；不是把家庭角色作经验性倒置。 |
| agent / manque / objet | 施事者 / 欠缺 / 对象 | 阉割、挫折、剥夺三层表格的固定列名。 |
| assujet / assujettissement | 受制主体 / 受制 | *Assujet* 是拉康以 *sujet* 与 *assujetti* 构成的临时词，指儿童作为主体初成时受制于母亲任性；正文首次保留法文。 |
| loi de la mère / parole du père | 母亲的法则 / 父亲的言说 | 前者是言说母亲之欲望对儿童构成的、尚不受控制的法则；父亲功能的效力取决于母亲同父亲言说的关系，不只取决于父母的经验性关系。 |
| être le phallus / avoir le phallus | 成为阳具 / 拥有阳具 | 第十课三个逻辑时刻的关键过渡；前者属于母子想象认同，后者经父亲的剥夺、法则与认同而确立。 |
| message sur un message / message sur le code | 关于讯息的讯息 / 关于代码的讯息 | 第十一课把父亲禁令界定为前者；施雷伯的“基本语言”幻觉则以新代码本身为讯息内容，属于后者。 |
| injet / adjet | 内投物 / 附加物 | 拉康仿照 *objet*、*sujet* 临时构词：*injet* 强调阳具作为被置入母亲体内并具有本能功能的对象；*adjet* 强调它在想象层面被给予或从母亲那里欠缺。正文首次保留法文。 |
| aimer, c’est donner ce qu’on n’a pas | 爱，就是给予自己没有的东西 | 与“赠予自己拥有的东西”区分；不能改写成牺牲、无条件付出等一般伦理命题。 |
| processus primaire / processus secondaire | 初级过程 / 次级过程 | 第十二课把二者同快乐原则、现实原则联系起来，但不视为完全等同；初级过程仍须从凝缩、移置等能指结构来把握。 |
| principe de plaisir / principe de réalité | 快乐原则 / 现实原则 | 两者的联系与对立共同构成各自位置；不把现实原则简化为挫折带来的经验学习。 |
| satisfaction hallucinatoire | 幻觉性满足 | 拉康质疑把它视为需要自行复制的满足，强调幻觉回应从起源处就在能指领域、同对象缺席相联系。 |
| phantasy / playing | 幻想 / 游戏 | *Phantasy* 保留克莱因学派与温尼科特语境；首次出现标出英文拼写，*playing* 指幻想世界在成人经验中的游戏性展开。 |
| Urbild | 原型 | 镜像阶段中自我的最初虚拟意象与掌握形式；首次出现保留德文，不同于一般意义的典范或理想。 |
| Ein Kind wird geschlagen / On bat un enfant | 《一个孩子挨打》 / 一个孩子挨打 | 弗洛伊德文章标题与核心幻想；法语无人称 *on* 不指定打人者，不能先行改写为“我打孩子”或“父亲打孩子”。 |
| fusion / défusion des pulsions | 驱力融合 / 驱力去融合 | 生命驱力与死亡驱力的原初结合及其分离；第十三课转述弗洛伊德 1923 年以后受虐狂理论。 |

| Ichspaltung | 自我分裂 | 弗洛伊德晚期概念：面对驱力要求与现实危险，自我同时否认并承认现实，留下不会愈合的裂口。 |

| enfant désiré | 被欲望的孩子 | 指孩子在出生前后占据母亲欲望中的象征位置；不同于经验上是否得到满足或照料。 |
| comédie / comique | 喜剧 / 滑稽 | 喜剧是共同体中人同言说、法律和享乐之关系的舞台结构；滑稽是其中可能产生的效应，二者不能直接等同。 |
| féminité comme mascarade / Womanliness as a Masquerade | 女性气质作为假面 | 琼·里维埃的命题：女性气质可被佩戴以掩藏对男性位置的占有并避开报复；不预设假面背后另有一种可分离的“真正女性气质”。 |
| phase proto-phallique / phase deutéro-phallique | 初次阳具期 / 再次阳具期 | 欧内斯特·琼斯对阳具期的分析性划分：前者尚未在意识中遭遇性差异冲突，后者围绕阉割观念形成防御性妥协。 |
| auto-érotisme / allo-érotisme | 自体情欲 / 他体情欲 | 前者把满足主要安置在自身身体，后者朝向另一身体或客体；琼斯用二者区分阳具防御与早期接受、穿透愿望。 |
| combined parent concept | 合体父母概念 | 梅兰妮·克莱因术语；指婴儿幻想中尚未彼此分离、在交媾中融为一体的父母形象。 |
| demande signifiée / désir signifié | 被表明的要求 / 被表明的欲望 | 要求或欲望经由能指进入可表达结构后的形态；不得把 *signifié* 在这里泛化为主体已经清楚理解。 |
| moi idéal / idéal du moi | 理想自我 / 自我理想 | 前者是主体在想象认同中形成的理想化自我形象；后者由能指性徽记和象征认同构成观察、衡量自我的位置。 |
| insignes du père | 父亲的徽记 | 主体在认同中取得的能指性标记；不是模仿父亲全部经验特征，也不同于父亲的生物属性。 |
| signifiant du désir / phallus comme signifiant du désir | 欲望的能指 / 阳具作为欲望的能指 | 第二十一课把阳具同欲望客体区分：阳具作为能指标出大他者欲望及其欠缺，不是可直接取得的生物学客体。 |
| demande d’amour | 对爱的要求 | 要求仅凭得到分节便召唤大他者的在场或缺席；它所要求的不是任何特定需要的满足。 |
| inconditionné / condition absolue | 无条件之物 / 绝对条件 | 对爱的要求处在无条件层面；欲望则把取自特定需要的材料提升为相对于大他者的绝对条件，二者不得混同。 |
| oblativité | 忘我性 | 第十八课既有译法；第二十一课讽刺用这种道德化的给予理想掩盖性欲望同对爱的要求之间的困难。 |
| objet partiel / objet total / totalement objet | 部分客体 / 完整客体 / 彻底成为客体 | 第二十一课反转从部分客体进展到完整客体的成熟叙事：欲望中的他者并非成为完整客体，而是作为欲望工具彻底成为客体。 |
| acting out | 行动呈现 | 主体以行动把某种东西展示给大他者；第二十三、二十七课尤其用它标示分析中没有得到解释、转而在行动中显现的内容，不泛化为普通“付诸行动”。 |
| Verneinung / dénégation | 否定 | 欲望或被压抑内容得到表述，却同时被加上“不”的符号；同 *Verwerfung*“拒斥”严格区分。 |
| Penisneid | 阴茎嫉羡 | 弗洛伊德术语；第二十八课批评把阳具能指在不同结构位置上的功能一概还原成同男人竞争或渴望拥有阴茎。 |
| demande de mort / mort de la demande | 死亡要求 / 要求之死 | 第二十八课的关键区分与等价关系：前者是一项在大他者场所得到衔接的要求；它指向大他者时也使要求自身的衔接熄灭，因而导向后者。 |
| commandement / Dix Commandements | 命令 / 十诫 | 第二十八课用同一法语词连接强迫症主体收到的命令、言语法则与宗教诫命；正文依语境写“命令”或“诫命”，但保留其结构连续性。 |
| parole pleine | 充实言说 | 话语在大他者场所得到衔接并使主体在返回的讯息中承担自身真理；不同于内容较多或句法完整的日常言语。 |
| Wo Es war, soll Ich werden | 本我所在之处，自我应当到来 | 第二十七、二十八课以此标示主体在能指链中抵达自身位置的理想完成；不简化为自我占领或取代本我。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译；本期第二十八课同时出现真正的 *topologie*，尤其需要保持这一区分。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
