# 翻译术语对照表

适用范围：`S1 Les écrits techniques de Freud（1953—1954）`

本表以第一期研讨班的具体语境为准。后期研讨班的稳定译名只作比较；尤其是 *Autre*、*réel*、*symbolique* 与 *imaginaire*，不得仅凭后期形式化写法反向覆盖本期尚在形成中的用法。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| sens | 意义 | 普通“方向、感觉”义另按语境处理。与 *contresens*、*non-sens* 的词语呼应须保留。 |
| sens / contresens / non-sens | 意义 / 误义 / 无意义 | 第一课并列出现；*contresens* 指误读、错解形成的意义，不改写成逻辑上的“反义”。 |
| scientisme / scientiste | 科学主义 / 科学主义的 | 指把自然科学方法提升为唯一有效知识范式的立场，不等同于一般“科学的”。 |
| inconscient | 无意识 |  |
| ego / moi | 自我 | 指精神分析概念时译“自我”；普通重读代词或日常“我”义按句法处理。原文刻意对举拉丁语 *ego* 与法语 *moi* 时保留原词，避免中文译名抹平问题。 |
| id / Ça / Es | 本我 | 首次出现不同语言写法时可保留原词；不得把普通代词 *ça*、*es* 机械译成本我。 |
| super ego / surmoi / Über-Ich | 超我 | 首次出现德文时可保留 *Über-Ich*。 |
| sujet | 主体 | 概念义统一译“主体”；普通“题目、议题”义按上下文处理。 |
| subjectivité | 主体性 | 不等同于日常所谓“主观意见”。 |
| vérité du sujet / réalisation de la vérité du sujet | 主体的真理 / 主体真理的实现 | 第三课以此区别分析经验与通常客观化科学研究；*vérité* 不得改写成 *réalité*“现实”。 |
| science du particulier | 关于个别者的科学 | 拉康据分析经验每一次实现的独特性作出的界定；*particulier* 不译成泛泛的“特殊科学”。 |
| singulier / singularité | 独特的 / 独特性 | 第三课强调弗洛伊德首创分析时“提升到平方”的独特性；普通语境中的“单数”义另行处理。 |
| désir | 欲望 | 精神分析概念义统一译“欲望”。 |
| pulsion | 驱力 | 不译“本能”；与 *instinct* 区分。 |
| transfert | 转移 | 沿用项目既有译名，不改作“移情”。 |
| contre-transfert | 反转移 |  |
| Übertragungsphänomene | 转移现象 | 第五课校正法译：*die Bezwingung der Übertragungsphänomene* 是“制服转移现象”，不能译成“战胜阻抗”。 |
| résistance de transfert / Übertragungswiderstand | 转移阻抗 | 为阻抗战术性选中的内容未必具有特殊致病意义；不得把该内容在当下受到激烈防守，反推成主体历史中最根本的病因。 |
| idée de transfert / Übertragungsidee | 转移观念 | 情结中可转到医生身上的部分所产生的“下一个念头”；它优先进入意识，恰因同时满足阻抗。 |
| actualisation de la personne de l'analyste | 分析家本人的当下化 | 第五课把转移同分析家本人突然成为当下在场联系起来；不等于分析家现实人格的全部事实。 |
| sentiment de la présence | 在场感 | 主体在话语突然转折时意识到分析家的在场；这是亲历现象，不先行化约成普通人际注意。 |
| bascule de la parole vers la présence | 言说向在场的翻转 | 第六课对第五课阻抗时刻的概括：主体朝向真理的言说中断，并转向作为听者、见证人的分析家之在场。 |
| activisme de l'analyste | 分析家的行动主义 | 指把“你是否在想同我有关的事”自动化为现成介入；它会使话语凝结为朝向分析家的异化形式。 |
| névrose de transfert | 转移神经症 | 既可指转移中形成的临床结构，也可指弗洛伊德分类中同自恋性神经症对举的类别；依具体语境判断。 |
| résistance | 阻抗 | 精神分析技术概念用“阻抗”；物理阻力或一般抵抗按语境译“阻力／抵抗”。第四课的 *résistance de l'objet ou de la matière* 译“对象或材料的阻力”。 |
| refoulement / Verdrängung | 压抑 | 弗洛伊德术语；与 *répression*“压制”区分。 |
| verdrängt / unterdrückt | 遭压抑的 / 遭压制的 | 第五课明确提出两者是否相同仍待区分；不得沿早期法译把 *unterdrückt* 软化成 *étouffé*“被闷住的”，也不得先行并入 *verdrängt*。 |
| Verwerfung / verwerfen | 拒斥 / 拒斥 | 第五课借《狼人》明确同 *Verdrängung*“压抑”区分，并以 *rejet / refus* 说明；此处保留弗洛伊德原句的否定判断，不把本期用法无条件反投为后来已经形式化的 *forclusion*。 |
| Urteil / kein Urteil über | 判断 / 未就……作出判断 | 第五课说明，原初经验中首先发生的是拒斥，而不是主体已经对阉割作出否定判断；*Urteil* 只在后来出现。 |
| défense / refoulement / résistance | 防御 / 压抑 / 阻抗 | 第三课报告依据《癔症研究》作出功能区分：力量同本能冲动斗争时称防御，取消其记忆时称压抑，反对回忆时称阻抗。第四课拉康随即提醒：这套和谐的三分分类并未以此形式直接出现于弗洛伊德笔下。二次校验须保留“报告者概括／拉康纠正”的证据边界。 |
| association libre | 自由联想 | 第四课指要求主体放任自己说出联想到的内容；与“基本规则”相关，但两者在每一处不必机械互换。 |
| Einfall / nächster Einfall | 念头（联想）/ 接下来出现的念头（联想） | 第五课纠正法译 *l'association qui surgit*：*nächster* 保留“最邻近／接下来”的次序关系。 |
| expérience originelle traumatique | 原初创伤经验 | 第五课《狼人》讨论中指主体尚未就阉割作出判断时的原初经验；不等于分析中后来重建出的完整事件叙事。 |
| processus du rêve / Traumvorgänge | 梦过程 | 指梦的形成与运作过程；与醒后的梦叙述区分。 |
| oubli du rêve | 梦的遗忘 | 第五课指出，它本身构成梦过程的一部分，不能只当作梦形成之后偶然遗失的信息。 |
| pensées du rêve / pensées à la base du rêve | 梦的思想（梦思）/ 构成梦之基础的思想 | 指弗洛伊德分析所重建的梦思链条，不按普通心理学改写为做梦者当时有意识的想法。 |
| désir de qui / de quel manque | 谁的欲望 / 出自何种缺失 | 第五课借梦与西尼奥雷利遗忘追问欲望的主体位置及其缺失；*manque* 不应误接成“缺失的欲望”。 |
| Witz | 诙谐（机智） | 第五课以“从崇高到可笑只有一步”及 *pas / Pas-de-Calais* 的词语接合为例；依语境也可译“笑话、妙语”，但须保留其能指操作。 |
| pas / Pas-de-Calais / canal de la Manche | 一步（否定词 *pas*）/ 加来海峡 / 英吉利海峡 | 第五课的地名—语词游戏把“仅一步之遥”同 *Pas-de-Calais* 及海峡水道相接；译文需保留法文词形，不能只留下地理信息。 |
| faute de langage | 语言错误 | 西尼奥雷利例中指名称替代所显露的言语失误；不缩减为发音错误。 |
| pensées refoulées | 遭压抑的思想 | 第五课说明替代名字并非无关材料，而与未说出的、遭压抑的思想保持可追踪的联系。 |
| étiologie | 病因 | 医学和临床语境；*étiologie du symptôme et de l'hystérie* 译“症状与癔症的病因”。 |
| psychothérapeute | 心理治疗师 | 第四课谈精神分析名称尚未稳定时的角色用语；不要在讲者明确区分处提前改成“分析家”。 |
| psychanalyse / psychoanalyse | 精神分析 | 第四课提到 *psychoanalyse* 一词在1896年法文文章中已经出现；保留讲者“可能首次出现”的不确定语气。 |
| suggestion | 暗示 | 弗洛伊德逐步放弃的干预方式；不得同“解释”或日常建议混同。 |
| hystérie hypnotique de rétention / hystérie de défense | 催眠性滞留癔症 / 防御性癔症 | 第三课底本中的早期分类对举；保留历史用语，不以现代诊断术语改写。 |
| hypnose / hypnotisable | 催眠 / 可被催眠的 | *ne pas pouvoir* 与 *ne pas vouloir être hypnotisé* 的对举须保留为“不能／不愿意被催眠”。 |
| méthode cathartique | 宣泄法 | 从催眠通向自由联想的早期方法；通过唤回并言说致病记忆使相关情感得到处理。 |
| règle fondamentale | 基本规则 | 指要求被分析者说出脑海中出现的一切、不因其无关紧要或令人不快而删减的分析规则。 |
| Arbeit / Fortsetzung / stören / Widerstand | 工作 / 继续 / 干扰（中断、破坏）/ 阻抗 | 第四课重译《梦的解析》公式：*Was immer die Fortsetzung der Arbeit stört, ist ein Widerstand.* 重音在“工作之继续”，不是法译本所写的“解释的障碍”。 |
| Behandlung | 处理 / 治疗 | 第四课区分：可指像处理对象那样让材料经过过程，也可能被理解为治疗或治愈；《梦的解析》关键公式实际写 *Arbeit*“工作”，并非 *Behandlung*。 |
| processus secondaire | 次级过程 | 弗洛伊德心理过程概念；第四课强调《梦的解析》并未表明阻抗完全或专门来自次级过程。 |
| idée pathogène | 致病观念 | 第三课用语；不得泛化为生物医学意义的“病原”。 |
| remémoration / se remémorer | 回忆 / 重新记起 | 指使未能进入意识的材料成为可回忆内容；依句法也可译“被回忆起来”。 |
| maniement de la résistance | 阻抗的处理 | *maniement* 强调分析过程中对阻抗的处置和运用，不仅是理论上的“解释”。 |
| assurances | 保证 | 《癔症研究》中分析者向主体保证其知道、记忆将会浮现的早期技术；不是保险或一般安全感。 |
| imposition / pression des mains | 把手压在额头上 / 双手施压 | 弗洛伊德从催眠过渡到对话的中间技术；正文按具体动作调整措辞。 |
| working through | 修通 | 保留英文首次出现并标注中文；指材料在时间中的反复重历、加工和重新阐发。第十六课用 O 与 O′ 之间反复转动的“磨盘”图像说明：必须多次重做，图像、欲望与言语才可能在关键时刻结合。 |
| interprétation | 解释 | 第三课先区分“对内容的解释”与“对阻抗的解释”；不得在文本尚未作此区分处笼统合并。 |
| analyse du discours / analyse du moi | 话语分析 / 自我分析 | 第七课标题中的对举；用来取代“材料分析／阻抗分析”的经典二分，并把分析推进指向主体的象征结构化。 |
| analyse du matériel / analyse des résistances | 材料分析 / 阻抗分析 | 第七课所称经典对立；不等于前者只解释内容、后者只处理自我防御。 |
| interprétation de la défense / interprétation du contenu | 对防御的解释 / 对内容的解释 | 第四课指出弗洛伊德并不总作现代式区分；在其病例中，对内容的解释可以发挥对防御作解释的作用。 |
| interprétation d'ego à ego / d'égal à égal | 自我对自我的解释 / 平起平坐的解释 | 第四课以法文近音作文字游戏；这种解释停留在二人对称关系中，其机制无法同投射区分。 |
| projection | 投射 | 第四课明确说“投射”不等于“错误投射”；在二人关系中，情感的相互性会使这类解释自动得到验证。 |
| relation duelle / interprétation duelle | 二元关系 / 二元解释 | 第七课批评分析家在自我层面把患者防御直接理解成针对自身的攻击，并以母女关系原型过早解释转移。 |
| reproduction d'une situation | 某种情境的再现 | 若只说转移重演旧情境、却不说明该情境如何得到结构化，公式仍然不完整。 |
| champ intersubjectif | 主体间场域 | 指分析家与被分析者之间实际形成的关系场；不能因此把分析经验缩减为只有两个自我的关系。 |
| troisième terme | 第三项 | 自我对自我的防御解释至少必须加入第三项；第四课同时强调“至少”仍然不够。第七课又指分析家在迪克与其幻想—现实的未分化状态之间介入，并通过赋予言词打开分化。 |
| forçage du sujet | 强制主体 | 指分析家介入把主体逼入预设位置的危险；第四课认为它在某些“现代”技术中比在弗洛伊德那里更现实。 |
| mauvaise foi / mauvaise volonté fondamentale | 自欺 / 根本性坏意愿 | 第四课明确否定把两者合并：前者牵涉认识秩序中的含义，后者才是被批评的意志主义预设。 |
| volontariste | 意志主义的 | 第四课指把主体设想成蓄意“不愿知道”、不断发明防御的技术倾向。 |
| force / ruse / interprétation | 强力 / 机巧 / 解释 | 安齐厄对阻抗处理方式的递进概括；*ruse* 指转移、绕开阻抗的迂回办法。 |
| noyau pathogène / noyau refoulé | 致病核心 / 压抑核心 | 在《癔症研究》的分层模型中居于中央；相邻话语之线越接近核心，径向阻抗越强。 |
| complexe pathogène / Komplexstoff | 致病情结 / 情结材料 | 情结的表现可以明显或不显眼；不得把“表现是否明显”错误移接为“情结本身是否明显”。 |
| Vertretung im Bewussten | 在意识中的表征 | 第五课以德文校正法译 *manifestation dans le conscient*；*Vertretung* 在这里不只是一般“表现”。 |
| valeur tactique / importance pathogénique | 战术价值 / 致病重要性 | 小教堂与农舍比喻所作的区分；转移阻抗争夺某一要素，只能直接证明其当场战术价值。 |
| sens longitudinal / sens radial | 纵向 / 径向 | 第三课说明文件束比喻中的两个进入方向；这里 *sens* 指方向，不译作“意义”。 |
| liasse / faisceau / dossier | 一捆文件 / 束 / 卷宗 | 言说物质化比喻中的相关词群；*faisceau de preuves* 在第三课译“一束证据”，以保留 *faisceau* 同文件束、话语束之间的词语呼应。 |
| matérialisation de la parole | 言说的物质化 | 指以手稿、印刷纸页、文件束、乐谱等具体载体来呈现言说，不等于神经学式的生物实体化。 |
| discours historique | 历史性话语 | 第四课指催眠与分析中围绕主体历史展开的话语；它是否被戏剧化、是否显得“重新亲历”，仍不能替代主体对其意义的承担。 |
| reviviscence du trauma / revécu | 创伤的再现 / 重新亲历 | 早期催眠技术把创伤再现视为直接的治疗因素；第四课质疑仅凭戏剧化和情感强度就断言主体已经重新亲历。 |
| état second hystérique / hypnotique | 癔症第二状态 / 催眠第二状态 | 指主体在催眠或癔症性改变状态中说出话语、醒后却不记得的状态。 |
| assomption par le sujet de son propre vécu | 主体承担自己的亲历经验 | *assomption* 强调主体把经验认作自身历史的一部分，不只是情感性重演。 |
| sujet du discours | 话语的主体 | 第四课结尾保留的根本问题；不得提前改写成“话语的主题”，也不能预先假定它等同于说话者的自我。 |
| coordonnées symboliques | 象征坐标 | 同帘中面孔的想象性认出相交；即使内容显得琐碎，仍为认出提供结构条件。 |
| détermination symbolique / constellation symbolique | 象征决定 / 象征星丛 | 分析家必须承认自身对主体结构定位的无知；主体无意识中的象征星丛始终具有复杂的组织结构。 |
| pacte / contrat analytique | 分析契约 | 《精神分析纲要》把分析情境表述为患病自我承诺坦率、分析家承诺保密并提供解释经验的契约。 |
| inaccessibilité de l'inconscient | 无意识的不可及性 | 第三课把它作为尚待提出的元心理学问题；底本所在句句法未完，译文保留悬置。 |
| présence / présences | 在场 / 种种在场 | 第五课强调世界的亲历一致性依赖我们默默计入各种在场，而把在场本身明确实现出来会显露其奥秘。 |
| dégradation de la parole | 言说的降格 | 第五课以西尼奥雷利遗忘说明：当主体未能把真实言说说到底，言说便整体倒向抓住他者的一侧，并只留下残骸与落下物。 |
| aveu de l'être | 对存在的坦承 | 指主体把关乎其存在真理的言说推进到底；不是司法意义的口供，也不等同于一般信息披露。 |
| expression / révélation | 表达 / 揭示 | 第五课明确说弗洛伊德的发现朝向“揭示”而非“表达”；无意识不是一个预先完整、随后被直接表达的内在内容。 |
| déformation / Entstellung / distorsion / transposition | 变形 / 歪曲 / 扭曲 / 换位 | 第五课并列说明无意识只能经这些变换得到揭示；二次校验不得为了行文顺滑把四项合并为一个词。 |
| médiation / réalisation de l'autre | 中介 / 他者的实现 | 言说作为主体与他者之间的中介，同时使他者在中介本身中得以实现；“实现”不等于验证他者的现实人格。 |
| prise à témoin | 请……作证 / 把……当作见证人 | 言说已经偏折但仍较高的一项功能；比主体真理的充分实现更依赖把分析家捕获到特定位置。 |
| parole pleine / parole vide | 充实言说 / 空洞言说 | 前者实现主体的真理，后者使主体迷失于语言与文化参照系统；两者之间存在一整套实现层次，不是内容“丰富／贫乏”的量化对比。 |

| moi fort / moi faible | 强自我 / 弱自我 | 第七课对自我心理学及预先再教育立场提出质疑；两个说法在此不是未经讨论即可采用的治疗指标。 |
| niveaux différents | 不同层面 | 分析方法在亲历形式、行为与分析关系内部寻找同一关系图式；不是把不同层面直接同一化。 |
| complexe de castration | 阉割情结 | 第五课以《狼人》为例讨论其在主体结构化中的特殊功能关系。 |
| complexe d'Œdipe | 俄狄浦斯情结 | 第七课把它视为象征关系秩序的最初细胞；不能缩减为对母亲的性吸引与同父亲竞争这一整块三角形。 |
| relation narcissique ou imaginaire / relation symbolique / relation réelle ou résiduelle | 自恋性或想象性关系 / 象征关系 / 实在的或残余的关系 | 第七课区分主体同父亲关系的不同层次，以显示俄狄浦斯结构并非单一二元关系。 |

| Liebesregungen | 爱欲冲动 | 《转移的动力学》结尾所说被隐藏、被遗忘而由转移变为当下和显明的冲动。 |

| Besetzung / Libidobesetzung | 投注 / 力比多投注 | 第五课所引弗洛伊德原文中指力比多依照既有版型转向医生；沿用项目对 *Besetzung* 的统一译名，不改作一般“投入”。 |

| Erwartungsvorstellung | 期待表象 | 能够进入意识和被扣留或无意识的期待表象都可能参与转移的形成。 |

| Introversion / Regression | 内倾 / 退行 | 第五课所引弗洛伊德原文明确把两者的界限列为尚待澄清的问题；不得机械互换。 |
| Ambivalenz / Bipolarität | 矛盾情感 / 两极性 | 布洛伊勒与施特克尔对相关现象的不同命名；高度矛盾情感使神经症者能够让转移服务于阻抗。 |
| Agieren / agieren | 付诸行动 | 第五课所引弗洛伊德原文与“认识、回忆”对举；在本处先保留动词性含义，不自动扩大为后来技术语境中一切“行动化”。 |
| Gegenwärtigkeit / Realität | 当下性 / 现实性 | 无意识冲动被唤醒后，患者赋予其结果以当下性和现实性；后者不得误写成 *Real*“实在界”。 |
| Zeitlosigkeit / Halluzinationsfähigkeit des Unbewussten | 无意识的无时间性 / 无意识产生幻觉的能力 | 解释无意识冲动为何不愿被回忆、而力求再现自身。 |
| masse idéationnelle | 观念团块 | 第三课借《癔症研究》讨论自我；保留 *masse* 的组织性和体量感，不扁平化为若干孤立“观念”。《癔症研究》德文原句为 *herrschenden Vorstellungsmasse des Ich*，标准英译作“构成自我的、占支配地位的观念群”；拉康现场明确说自己记不起德文，并以法文 *masse idéationnelle* 重述。正文据法文层保留“观念团块”，不静默改成仿德文的“自我中占支配地位的表象群”。 |
| système idéationnel | 观念系统 | 指患者自我中由确信、信念、坐标和参照组成的组织，可在局部语境简称“系统”。 |
| somme des préjugés de l'analyste | 分析家偏见的总和 | 第三课用来界定分析家自我功能在反转移中的一个要素。 |
| somme de silence | 沉默之总和 | 位于主体自我的观念团块所形成的言说边界；在其后，另一种有待从无意识中重新夺回的言说出现。 |
| élaboration théorico-technique | 理论—技术建构 | 同时包含分析理论与技术的历史展开，不拆成彼此无关的两条发展线。 |
| hic et nunc | 此时此地 | 第四课讨论安妮·赖希及英国学派部分技术取向；指分析课次当下的言说意图与对话关系。第二十三课批评把全部转移处理压缩到当前行为：主体抱怨杂货商时仿佛在痛骂分析家，这仍可能退化成现实教育。首次出现可保留拉丁文。 |
| interlocution présente | 当下的对话 | 指分析家与主体正在发生的言说交换；不缩减成一方的内心意图。 |
| cupido / libido | 欲求 / 力比多 | 第四课以拉丁词作区分：两个弗洛伊德未必属于同一种 *cupido*，即便属于同一种 *libido*；正文首次出现保留原词。 |
| dénégation（普通用法） | 否认 | 第一课指弗洛伊德对自身治疗者位置的否认，并非在此处直接命名 *Verneinung* 机制。 |
| dénégation / Verneinung（术语） | 否定 | 沿用项目对弗洛伊德术语及篇名的统一译名；不得由普通动词性“否认”自动升级为术语。第六课显式讨论法语 *dénégation / négation* 之别时，正文分别标作“否认式否定／一般否定”，以保存论证。 |
| dénégation / négation（法语对举） | 否认式否定 / 一般否定 | 伊波利特认为 *Die Verneinung* 应以前者而非后者译入法语；中文不能用同一个“否定”抹平这场术语辨析。 |
| Urteil verneinen / déjugement | 否定判断 / 取消判断 | 伊波利特区分“判断内部的否定”与作为态度的否定，并以自造法语 *déjugement* 指后者对判断的撤回。首次出现保留法语。 |
| Aufhebung / aufheben | 扬弃 / 扬弃、取消、提起 | 第六课保留黑格尔词的多义：否定、取消、保存与提起；“取消订阅”和“提起石头”说明其日常义。不得只留下抽象哲学标签。 |
| fonction intellectuelle / processus affectif | 智性功能 / 情感过程 | 《否定》原句所作的分离；正文概括性名词 *l'intellectuel / l'affectif* 可译“智性方面／情感方面”，但不得改成思想内容与情绪内容的二分。 |
| négation idéale / négativité réelle | 观念性的否定 / 真正的否定性 | 伊波利特借黑格尔以能够悬置毁灭的观念性否定取代欲望中的毁灭冲动；*réelle* 此处强调真正成立的否定性，不是同“观念性”对举的经验现实。 |
| Bejahung / affirmation | 肯定 | 第六课把肯定追溯到 *Vereinigung*“结合”；与后来才出现的否定符号之间存在不对称。 |
| Bejahung / assomption par le moi / oui | 肯定 / 由自我作出的承担 / “是” | 第七课追问分析推进究竟要求哪一种肯定；消解否定或完成否定之否定，仍不自动等于主体已经作出这种承担。 |
| Vereinigung | 结合 | 属于厄洛斯的原初结合；*Bejahung* 是它的 *Ersatz*“替代物”。不因日常语境改译为组织统一。 |
| Ausstoßung / expulsion | 驱逐 | 第六课明确纠正法译 *rejet*：原文不是 *Verwerfung*“拒斥”，而是把坏的、异己的东西逐出外部的驱逐操作。 |
| jugement attributif / jugement d'existence | 属性判断 / 存在判断 | 前者决定一物是否具有某属性，后者决定一个表象是否在现实中存在；其原初形式分别追溯到内摄／驱逐和表象／知觉关系。 |
| introjection / expulsion | 内摄 / 驱逐 | 快乐原则支配下的两种原初操作；塑造内部与外部，尚不是已经形成的判断。 |
| mécanismes de répression | 压制机制 | 第七课报告者沿用底本 *répression*；不得自动改写成 *refoulement*“压抑”。这里指驱逐自身施虐性以及摧毁危险对象。 |
| représentation / perception | 表象 / 知觉 | 存在判断要求把当前表象同曾经的原初知觉相对照，并检验能否在现实中重新找到对象。 |
| Ersatz / Nachfolge | 替代物 / 后继 | 伊波利特批评法译把两者译成同一种关系：肯定是结合的替代物，否定是驱逐的后继。 |
| Destruktionstrieb / instinct de destruction | 毁灭驱力 / 毁灭本能 | 德文引句按 *Trieb* 译“驱力”；伊波利特的法文评注明确写 *instinct* 时译“本能”，不得机械统一。 |
| symbole de la négation / Verneinungssymbol | 否定符号 | 它使判断功能得以运作，使思想首次在一定程度上摆脱压抑结果与快乐原则的强制。 |
| principe du plaisir / Lustprinzip | 快乐原则 | 第六课中既调节内摄与驱逐，也同毁灭倾向的技术问题相连。 |
| parole | 言说 | 指说话行为及其象征条件；与 *langage*、*discours* 区分。 |
| langage | 语言 | 指语言体系或一般语言条件；具体说法仍按语境处理。 |
| discours | 话语 / 论述 | S1 尚未形成后期“四种话语”的公式；一般论述语境可译“论述”。 |
| semblable | 相似者 | 第六课指主体最初相对于其而形成自我的另一个人；与概念性的 *autre*“他者”相关，但不可机械互换。 |
| fonction imaginaire | 想象功能 | 自我在分析中的动力性构成条件；不同于普通心理学把自我界定为综合功能。 |
| méconnaissance / fonction de méconnaissance | 误认 / 误认功能 | 第六课把自我的防御与拒绝放在其根本误认功能中理解；不弱化为一般“不了解”。 |
| méconnaître | 误认 / 没有认识到 / 忽视 / 不承认 | 指结构性的错认时可译“误认”；在 *ne peut pas méconnaître*、*on ne saurait méconnaître*、*méconnaître que...* 等普通动词句式中，常表示“不能忽视”“没有认识到”或“不承认”，不得机械套用“误认”。 |
| système symbolique / fonction symbolique | 象征系统 / 象征功能 | 语言符号通过整体、汇流和对立性多重决定彼此交织；儿童早期言语也不能仅由运动掌控解释。 |
| stade sadique-oral / stade du symbolisme | 口腔—施虐阶段 / 象征作用阶段 | 第七课概述克莱因的问题：儿童如何从内摄—驱逐循环进入能在自身身体与外部对象间建立多重等同的阶段。 |
| symbolisme | 象征作用 | 在克莱因语境中指建立身体部分、母亲身体内容与外部对象之间的等式；不译作艺术思潮意义的“象征主义”。 |
| équation symbolique | 象征等式 | 第七课报告强调尽可能多地建立等式；弗洛伊德的肛门结构图式写作“孩子＝菲勒斯＝排泄物”。 |
| enfant = phallus = excréments | 孩子＝菲勒斯＝排泄物 | 肛门结构中的等同图式；保持等号关系，不改写成彼此具有一般相似性。 |
| situation anxiogène | 致焦虑处境 | 焦虑源于儿童自身施虐性及其对摧毁爱欲对象和自身的恐惧。 |

| quantité optimum d'anxiété | 焦虑的最优量 | 报告者概括为：焦虑过少便不会向外分布，过多又超出自我容忍与掌控能力；这一量化模型在发言中受到保留。 |

| fantaisie / fantasme | 想象活动 / 幻想 | 第七课同句并列使用二词；前者强调能够自由展开的想象活动，后者保留精神分析意义的幻想，二次校验时不得为了顺滑而抹去并列。 |

| verbalisation | 赋予言词 / 言语化 | 描写克莱因向迪克说出解释并由此分化象征与实时，译“赋予言词”；拉康批评她把主体粗暴塞入解释话语时，依动作结果译“言语化”。 |

| signal d'anxiété | 焦虑信号 | 焦虑不是构成对象时等待分配的能量，而是随认同涌现的信号、性质与主体性色彩。 |

| béant / béance | 敞裂的 / 裂隙 | 第七课以人的起源状态本质上的“敞裂”说明迪克面对的空洞；不得弱化为一般空缺或尚未学会命名。 |
| destructionnisme | 毁灭主义 | 指毁灭在人的现实构成中所具有的结构功能；同本课法文 *instinct de destruction*“毁灭本能”及第六课德文 *Destruktionstrieb*“毁灭驱力”区分。 |

| oral / muscular / urethral / anal sadism | 口腔 / 肌肉 / 尿道 / 肛门施虐性 | 克莱因英文原文列举对母亲身体发动幻想性攻击的不同施虐来源；保留并列及其逐步加入的时间关系。 |

| phantasy-life / symbol-formation | 幻想生活 / 符号形成 | 迪克针对毁灭冲动的防御同时使二者停滞；前者是幻想得以展开的生活，后者是建立象征等式的过程，不能合并。 |
| play-technique / symbolic representations | 游戏技术 / 象征性表征 | 儿童分析可以循游戏和一般行为细节中的象征性表征进入焦虑与罪疚；迪克的困难在于这类表征尚未发展。 |
| affect / emotional contact / emotional rapport | 情感 / 情感接触 / 情感联系 | 克莱因英文病例以情感缺失和无法建立情感接触描述迪克；斜体 *rapport* 保留“联系”义，不译作治疗同盟。 |
| inhibition of ego-development / regression | 自我发展受到抑制 / 退行 | 诊断部分的关键区分：迪克的问题被描述为发展未能展开，而典型儿童精神分裂症病例通常在达到一定阶段后退行。 |
| dementia praecox / schizophrenia / psychosis | 早发性痴呆 / 精神分裂症 / 精神病 | 保留克莱因论文中的历史诊断层次：福赛思使用“早发性痴呆”，克莱因在扩展儿童期精神病概念后主张归入精神分裂症；不得以现代术语一律回写。 |
| negativistic behaviour / automatic obedience / perseveration | 违拗行为 / 自动服从 / 持续现象 | 早发性痴呆临床图景中的并列症状；“持续现象”指言语或动作的病理性延续，不等于一般坚持。 |
| psychotic traits / differential diagnosis | 精神病性特征 / 鉴别诊断 | 克莱因认为儿童期精神病性特征比完整精神病更常见，并把精确鉴别不同疾病列为儿童分析理论工作的目标。 |
| fixation-point / narcissistic stage | 固着点 / 自恋阶段 | 克莱因分别把暴力攻击与下毒攻击阶段设为早发性痴呆和妄想症的固着点，并将两者放在弗洛伊德所说的自恋阶段中比较。 |
| sadistic appropriation / exploration of the mother's body | 对母亲身体的施虐性占有 / 探索 | 这一过程同时扩展到被视为广义母亲身体的外部世界；过早防御使其停滞，并中止同环境及现实的象征关系。 |
| l'imaginaire, le symbolique et le réel | 想象界、象征界与实在 | 第八课把三者明确称为理解分析技术与弗洛伊德经验所不可缺少的三个参照系统；排印与句法尚未要求时，不机械给“实在”补写“界”。 |
| refus de compréhension / compréhension analytique / interpréter | 拒绝理解 / 分析性理解 / 作出解释 | 拉康把文本评注类比于分析：先标出无法理解之处，不让套话替主体话语补足意义；“作出解释”同“想象自己已经理解”恰好相反。 |
| stade du miroir / Urbild du moi | 镜像阶段 / 自我之原型 | 镜像阶段不只是发展的历史时点，也以光学方式示范主体同自身图像的关系；*Urbild* 首次出现保留德文。 |
| lieu psychique / appareil psychique / représentation auxiliaire | 心理地点 / 心理装置 / 辅助性表象 | 《梦的解析》的光学比喻把心理地点置于装置中图像形成的观念性位置；辅助性表象是脚手架，不是解剖定位或建筑本身。 |
| image réelle / image virtuelle / objet virtuel（光学） | 实像 / 虚像 / 虚对象 | 光学术语：会聚光线形成的实像可如对象般再次产生虚像；此处 *réelle* 不译作三界概念“实在的”。 |
| espace réel / espace imaginaire（光学） | 现实空间 / 想象空间 | 光学结构假设要求现实空间中每一点在想象空间中有且只有一个对应点；二者可重合，但必须被思考为不同空间。 |
| miroir sphérique / expérience du bouquet renversé | 球面镜 / 倒置花束实验 | 布阿斯实验以隐藏花束的实像同真实花瓶组合；拉康随后交换花瓶与花束的位置，把它用作镜像阶段的小型替代模型。 |
| accommodation / parallaxe / impression de réalité | 调焦 / 视差 / 现实印象 | 眼睛对实像与花瓶在同一平面调焦而获得现实印象；观察距离增加、横向位移造成的视差减小时，幻觉更完整。 |
| imaginaire primitif / Ur-Ich / Lust-Ich | 原初想象界 / 原自我 / 快乐自我 | 第八课把自身身体图像的把握，同原初自我在内外、纳入与排除之间的构成联系起来；德文首次出现保留。 |
| contenant / contenu | 容器 / 内容物 | 花瓶与所盛花束为原初自我形成中的内外划界提供隐喻；*contenu* 在这里指被容纳之物，不是文本“内容”。 |
| moi imaginaire / inclusion / exclusion | 想象自我 / 纳入 / 排除 | 自我诞生以前主体中的最初纳入—排除游戏，相对于想象自我得到定位；不得改写成成熟自我的有意识选择。 |
| entification des instincts | 本能的实体化 | 把本能当作独立实体的理论建构；拉康以其最终使任何一项本能都无法成立来显示这种构想的悖谬。 |
| incorporation imaginaire / introjection symbolique | 想象性并入 / 象征性内摄 | 前者在母亲身体、咬噬与摧毁对象的镜像关系中运作；后者始终伴随象征性命名，是对他者之言说的内摄。两者不得都扁平化成“内化”。 |
| expulsion / réintrojection / projection / réabsorption | 驱逐 / 重新内摄 / 投射 / 重新吸收 | 象征等式诞生时交替运作的想象机制；对象从母亲身体这一总体容器被逐出，又以较中性的等值物重新纳入。 |
| imaginification | 想象化 | 拉康临时造词，指外部世界通过对象等值与换位初步取得想象形式；正文首次出现保留其试探性口吻。 |
| transposition imaginaire / valeur de Gestalt / Umwelt | 想象性换位 / 格式塔价值 / 周围世界 | 想象等式的扩展使对象在人的周围世界中被作为形式分离并获得价值；德文 *Gestalt*、*Umwelt* 首次出现保留。 |
| appel / appel parlé / appel verbalisé | 呼唤 / 用言语说出的呼唤 / 言语化的呼唤 | 迪克已有语言系统却不发出呼唤；克莱因的象征化以后，他第一次询问保姆，呼唤才在言说层面出现并包含回应。 |
| négativisme / dénégation | 否定主义 / 否认式否定 | 迪克会故意歪曲已经掌握的词语，使语言失去交流用途；这种否定主义不同于伊波利特讨论的 *dénégation / Verneinung*。 |
| énoncé / appel / communication（Karl Bühler） | 陈述 / 呼唤 / 交流 | 第八课转述比勒的语言三阶段：陈述显出主体性质，呼唤由语调赋值，交流把所说内容同整体情境联系起来；不得反投为拉康后来成熟的“陈述／言说行为”对举。 |
| langage / parole（第八课） | 语言 / 言说 | 迪克已能掌握并否定主义地使用语言，但尚未在言说层面发出呼唤和定位自身；二者在此被明确说成“并不相同”。 |
| surmoi / ego idéal | 超我 / 理想自我 | 第八课把真正而本真的超我说成相对于理想自我功能的次级象征性内摄；不把 *ego idéal* 误作“自我理想”。 |
| l'inconscient est le discours de l'autre | 无意识是他者的话语 | 第八课借迪克病例把克莱因的话语视为最初象征化的来源；拉康随即断言主体内部“没有任何一种无意识”，二次校验不得把它软化成克莱因发现了某个既存的隐藏内容。 |
| inertie moïque / symbolisations brutales | 自我性惰性 / 粗暴的象征化 | 克莱因的话语把俄狄浦斯象征结构嫁接到迪克尚未进入人的现实的处境上；“粗暴”保存拉康对介入方式的判断。 |
| système de substitution des objets | 对象替代系统 | 迪克从昏暗门道、洗手池到电暖器逐步建立等值关系，使容纳／不容纳的对象世界获得更多层次。 |
| champ de l'appel / possibilité du refus | 呼唤场域 / 拒绝的可能性 | 呼唤并不必然包含拒绝，却在言说内部打开拒绝可能性，并同依赖关系的形成同时显现。 |
| relations préverbales / postverbales | 前言语关系 / 后言语关系 | 病例中语言之前与之后的关系系列各自发挥作用；外部现实世界只有在符号引入的正确位置关系中才得到人化。 |
| véritable parole / acte de parole | 真正的言说 / 言说行动 | 真正的言说甚至可以由治疗者带入暂时形成的对子；其象征效力来自同既有象征系统及俄狄浦斯位置的协调，而非词句本身。 |
| transfert dans l'imaginaire | 想象界中的转移 | 第八课末预告的转移面向；后续必须同“在不同层面上研究的转移”一并区分，不能把一切转移都还原为想象关系。 |
| fonction symbolique / fonction de la parole | 象征功能 / 言说功能 | 第九课明确说，在本课词汇中二者“完全是一回事”；它们构成弗洛伊德文本处处指示却未直接命名的分析经验核心领域。 |
| Erinnern, Wiederholen und Durcharbeiten / Remémoration, répétition et élaboration | 回忆、重复与修通 | 弗洛伊德1914年技术论文；*Durcharbeiten* 沿用项目“修通”，不因法译 *élaboration* 改成一般理论阐发。第二十三课把修通同“理解时刻”的铺展相连：主体需要时间使重复取得自身持续时间、象征价值与概念维度。 |
| Bemerkungen über die Übertragungsliebe / Observations sur l'amour de transfert | 对转移之爱的观察 | 弗洛伊德1915年技术论文；同《回忆、重复与修通》一起构成本课为《论自恋：一篇导论》定位的两端。 |
| Zur Einführung des Narzißmus | 论自恋：一篇导论 | 弗洛伊德1914年论文；沿用项目其他研讨班既有题名，不按底本法译另造“自恋概念导论”。 |
| Drei Abhandlungen zur Sexualtheorie / Trois essais sur la sexualité | 性学三论 | 弗洛伊德1905年著作；第十课以其中的原初自体性欲观念说明力比多投注与对象构成。 |
| Wandlungen und Symbole der Libido / Métamorphoses et symboles de la libido | 力比多的变形与象征 | 荣格1912年著作；第十一课把它置于《论自恋》之前，作为统一心理能量构想同弗洛伊德力比多理论冲突的历史背景。 |
| Metapsychologische Ergänzung zur Traumlehre / Complément métapsychologique à la doctrine des rêves | 梦学说的元心理学补充 | 弗洛伊德1917年论文；第十课底本又说法文译作《梦的学说》，正文保留这一题名差异。 |
| The Nature of the Therapeutic Action of Psycho-Analysis | 精神分析治疗作用的性质 | 詹姆斯·斯特雷奇1934年论文；第十课借其“寄生性超我”假设讨论分析效力，原注中的英、德、法文版本信息须完整保留。 |
| amour de transfert / amour-passion | 转移之爱 / 激情之爱 | 第九课强调弗洛伊德不回避二者在心理结构上的等同性；不得把转移之爱软化成非现实的象征替代。 |
| ressort énergétique du transfert | 转移的能量机制 | 弗洛伊德所谓转移现象的根本能量动力；拉康随后以转移之爱具体命名，不能只理解为技术阻抗。 |
| Introversion der Libido / introversion de la libido | 力比多内倾 | 《论自恋》德文术语。第九课法文转录误作 *introjection de la libido*“力比多内摄”，正文据同页德文校正并加译注，不得与象征性内摄混同。 |
| Paraphreniker / paraphrénique | 妄想痴呆患者 | 弗洛伊德用来同癔症及强迫神经症患者对举的历史类别；其力比多从外界对象撤回而不立即以幻想对象替代。 |
| fonction de l'imaginaire dans la névrose et la psychose | 想象界在神经症与精神病中的功能 | 神经症者在幻想中保存、替代或混合对象关系；精神病中的想象世界重建则被说成一种次级的治愈尝试。 |
| enfant-loup / le loup | 狼孩 / 狼 | 罗贝尔整天呼喊“狼”，并以狼和碎奶瓶表象自身的摧毁原则；后续“治疗者成为狼”表示坏东西被投射到持续在场者身上。 |
| principe de destruction | 摧毁原则 | 地点、房间和照料者不断变更在罗贝尔那里形成的关系模式，并标记摄入、排泄、门和奶瓶场景；不等同于抽象的死亡驱力。 |
| permanence du thérapeute / permanence du corps | 治疗者的持续在场 / 身体恒存 | 前者使罗贝尔能够在倒空与装满之间引入延迟；后者以带回空便盆为标志，指身体排出内容物后仍继续存在。 |
| dialectique contenus-contenants / ego-body | 内容物—容器辩证法 / 自我—身体 | 罗贝尔必须先成为治疗者的内容物并确认她作为未来容器，才开始完成从未形成的身体建构；*ego-body* 首次出现保留英文。 |
| mère phallique castratrice / mère féminine | 阉割性的菲勒斯式母亲 / 女性母亲 | 共生阶段的两种母亲位置；治疗问题在于使罗贝尔能够接受食物，而不因同母亲认同便体验为遭受阉割或变成女孩。 |
| symbiose mère-enfant | 母婴共生 | 口腔建构阶段中的原始关系；正文同时保留性别与阉割冲突，不能把它写成无差别的安全依恋。 |
| patterns de comportement | 行为模式 | 罗贝尔既有的激动、自我摧毁与分离反应；新建构形成后并未立刻消失，受挫时仍可能返回。首次出现保留英文 *patterns*。 |
| fantasmes devenus réalité / la réalité impose les fantasmes | 幻想变成现实 / 现实强加幻想 | 罗贝尔的口腔—施虐性幻想被饥饿、无麻醉手术、强饲与反复转移等经历实际化；不得把“现实”误写成单纯主观确信。 |
| zwingen / bezwingen / Zwang / Bezwingung | 强迫 / 制服、克服 / 强迫 / 制服、克服 | 伊波利特以德文区分被狼强制并产生焦虑，同能够扮演狼从而克服焦虑；*Bezwingung* 在第五课“制服转移现象”的译法由此得到回照。 |

| figure féroce | 凶猛形象 | 超我同主体过早而原始的创伤经验中最具破坏力、最能攫住人的形象认同；不把它柔化为一般严格权威。 |
| délire hallucinatoire / psychose hallucinatoire chronique | 幻觉性妄想 / 慢性幻觉性精神病 | 朗医生仅以类比方式提出诊断；拉康认为它同罗贝尔病例的共同点，是患者把某种东西承担为实在的现实感，而非已经符合成人疾病分类。 |

| parole à l'état nodal | 处于结点状态的言说 | “狼”既不是罗贝尔也不是别人，却使任何可命名之物都能取得位置；言说虽停在残干状态，仍成为他定位和建构自身的起点。 |
| moi comme fonction imaginaire / fonctions de synthèse du moi | 自我作为想象功能 / 自我的综合功能 | 第九课把自我本身列为想象功能，同时用抓取、注意与睡眠的裂口讨论自我综合；二者不是彼此独立的两套同质心理机构。 |
| atypie du sommeil / retard sur le plan imaginaire | 睡眠的非典型性 / 想象界层面的发育迟缓 | 罗贝尔能够呼唤、做梦以后，运动和睡眠障碍同时缓解；拉康据此考察想象发展同看似低级的感觉—运动功能之间的依存。 |
| maîtrise imaginaire / adaptation sensorio-motrice | 想象性掌控 / 感觉—运动适应 | 抓取动作、距离判断等不只取决于锥体系统和器官完整性，也取决于主体对身体及空间的想象性整合。 |
| diagnostic analogique / cas de démonstration | 类比诊断 / 示范病例 | 罗贝尔没有已经确立的精神分裂症状态或相应症状，只呈现某种关系结构和可能的精神病性走向；疾病分类不能被当作预先完备的孔位。 |
| fonction du narcissisme | 自恋功能 | 第九课末把精神病与转移中的爱连接在同一想象功能之弧上，并以此引入《论自恋：一篇导论》对分析技术的作用。 |
| don de la parole / locuteur / allocutaire | 言说的给予 / 说话者 / 受话者 | 第十课以言说被给予后双方位置的改变界定充实言说；*allocutaire* 是言说所朝向者，不泛化为一切听众。 |

| illusion de réalité / illusion réelle（光学） | 现实幻觉 / 实像幻觉 | 球面镜装置中，前者指图像足够清晰而产生的现实效果；后者指实像恰在其被看见之处形成的特殊幻觉。不得译成“实在幻觉”或同镜中虚像混同。 |

| relation mortelle / anéantissement réciproque | 致死关系 / 相互消灭 | 欲望熄灭与客体消失构成想象性关系的两个深渊；这里的 *mortelle* 强调结构上的消灭，不弱化成一般“危险关系”。 |
| dialectique du maître et de l'esclave | 主奴辩证法 | 黑格尔语境。第十九课以它显示：为纯粹威望冒死的想象性僵局，只有借劳动、法与规则的象征延伸才会展开为历史。 |
| raisons de pur prestige / risque de la mort / enjeu | 纯粹威望的理由 / 死亡的风险 / 赌注 | 主奴神话并非由生物性的死亡恐惧奠基；死亡首先是想象性的，风险则已被一项游戏规则构造成赌注。 |
| jouissance et travail / règle du jeu | 享乐与劳动 / 游戏规则 | 奴隶为主人的享乐劳动时，工时、法和规则使行动进入象征界；一切构造人类行动的主体间关系都隐含某种游戏规则。 |
| théorie des jeux / structuration numérique | 博弈论 / 数值结构 | 博弈论作为数学理论从一开始就在象征层面；主体间场域必然通向三、四等数值结构，不能只保留每个主体为中心的想象性复多。 |
| holophrase / fragmentation symbolique | 整体句 / 象征性碎分 | 指不可继续分解、却指称一个整体情境的表达。第十九课明确反对把它当作动物整体把握向人类语言过渡的发生学中介，而把它放在象征组合的边界与周缘。二次校验须结合外部语言学通行译名复核“整体句”。 |
| auto-symbolisme（Silberer）/ phénomène figuratif | 自我象征作用 / 具象现象 | 疲倦或半睡眠时，正在进行的思想可在最初入睡前意象中立即获得形象；西尔伯勒只标示形象化出现的转折，并未否认冲突、超我与主体历史的意义。 |
| mensonge / méprise / ambiguïté | 谎言 / 误认 / 歧义 | 第十九课“言说三角”的三个顶点。*méprise* 指主体在言说中认错、听错或错取其所指的具体失手，故译“误认”；它同 *erreur*“错误”有别，也不无条件并入自我结构性的 *méconnaissance*“误认”。福雷斯特英译相应区分为 *mistake / error / ambiguity*，正文据语境保存三项差别。 |
| parole mensongère / ce qui n'est pas et ce qui est | 撒谎的言说 / 不存在之物与存在之物 | 言说能把不存在之物作为谎言引入现实，因而也能引入存在之物；在言说以前，现实中尚无真／假与是／非的划分。 |
| vérité creusée dans le réel / béance de l'être | 在现实中挖出的真理 / 存在的裂口 | 第十九课在尚未完全形式化的语境中说，言说把真理及存在的凹空引入现实纹理；此处 *réel* 依句法译“现实”，不得仅因后期术语而自动改成“实在界”。 |
| chattering / parole qui engage | 为了什么也不说而说个不停 / 使人负责的言说 | 巴林特病例中，患者以空洞闲谈避免进入劳动与成人契约；转折不在把闲谈还原为童年情境，而在一封推荐信使她必须对自身言说负责。 |
| pacte symbolique / lois et contrats | 象征性契约 / 法与契约 | 言说以契约功能把主体彼此约束并联结进人类行动；转移围绕象征关系的确立、延伸与支撑展开，不等于情感从一个客体移置到另一个客体。 |
| au-delà / en-deçà de la parole | 言说的彼岸 / 此岸 | 言说无法再把自身奠立为言说时抵达的彼岸属于言说自身；若去表情、痉挛等心理—情感相关项中寻找，它相对于言说反而只是此岸。 |
| acte de la parole / approfondissement de l'acte de la parole | 言说行动 / 深化言说行动 | “本我所在之处，自我应当到来”不指自我扩大并占领本我，而指自我与本我之间真正的翻转、移位和位置变换；其意义须从言说行动的构成作用把握。 |
| Wort / Ort | 言词 / 地点 | 安格鲁斯·西莱修斯对句所利用的德语近音双关；二次校验与知识卡片均须保留原词，不能只留下中文释义。 |
| émotion / affect | 情感 / 情感 | 第二十课的法文报告在相邻理论层面交替使用两词，未形成可稳定对应“情感／情动”的术语二分。中文均译“情感”，首次关键出现分别附原词 *émotion*、*affect* 以保存差异；不为追求表面区分而把其中一项系统改成“情动”。作者争论的是情感能否自主倒转或移置，不能把它先验当成中性能量。 |
| Need / Trend / instinct / pulsion | 需要 / 倾向 / 本能 / 驱力 | 伊沙姆文章的术语混乱正是讨论对象：*Trend* 被摇摆地解释为驱力或本能，*need* 又被当作心理客体。正文不得替作者提前整理成稳定体系。 |
| objet mental / motivation d'objet | 心理客体 / 客体动机 | 伊沙姆认为情感的调制与启动来自有意识或无意识、现实或心理的客体，并主张以“客体动机”替代“可移置的情感”；这是报告中的理论命题，不是拉康直接采纳的术语。 |
| perception endopsychique | 内心知觉 | 对情感作为内部需要之感觉性知觉的说法；拉康讽刺它常在理论僵局中成为最后诉诸，不把它写成已证实的心理机制。 |
| meaning / meaning form / Meinung | 意义、含义、意见 / 意义形式 / 意见、所指之意 | 格拉诺夫强调英语 *meaning* 的多义，并同德语 *Meinung*、*Was meinen Sie?* 相连；没有脱离语境的单一固定译法，须从用法之和确定。 |
| actual / actualisation / actuality / réalisation | 现实的 / 现实化 / 现实性 / 实现 | 贝尼特的英语词组由格拉诺夫保留，拉康随即把 *actualisation* 释为 *réalisation*。不得同第五课“分析家本人的当下化”机械统一，亦不得把 *actuality* 误作日常“时事”。 |
| symbolisation du fait / factualisation du symbole | 事实的象征化 / 象征的事实化 | 贝尼特所谓存在的最终过程；梦在事实层面退行、在象征层面前进。这是被讨论的文章命题，拉康随后把问题转向象征用法和言说。 |
| emploi / somme des emplois | 用法 / 用法之和 | 一个词的意义只能从其全部语境用法中把握；*main*、*main-d'œuvre*、*mainmise*、*mainmorte* 说明意义不靠指向语言以外的单一事实来奠基。第二十一课把“用法”扩展到词组、固定表达与句法形式，又指出完整句子本身没有同样意义上的“用法”，由此区分两个意义区域，并引向语言／言说之别。 |
| métaphore / invocation symbolique / soleil de mon cœur | 隐喻 / 象征性祈唤 / 我心中的太阳 | 隐喻不是先完成“你像太阳”的比较再作缩写；祈唤本身使新的存在关系涌现，并同时带入温暖、生命、眩目与阴影等尚未逐项说出的意义。 |
| parole comme moyen d'être reconnu / faire croire | 作为获得承认之手段的言说 / 使人相信 | 奥德修斯伙伴变猪的寓言把言说同机械交流区分：关键不在咕噜声表达何种情感，而在说话者想使听者相信什么，并要求自己仍作为人得到承认。 |
| communication / parole | 交流 / 言说 | 机械运动也能传递信息；只有当发出者要求听者相信并承认某种主体位置时，交流才进入言说层面。动物语言只在有人能够理解它的意义上存在。 |
| readiness / aptitude au transfert | 转移的准备状态 | 农贝格用来区别现实地要求分析家符合某一原初图像与严格的转移；拉康借其案例反对把转移简单化为图像同当前现实的幻觉性混淆。 |
| concept / temps de la chose / identité dans la différence | 概念 / 物的时间 / 差异中的同一性 | 黑格尔命题“概念是物的时间”说明：概念在物缺席处使物在场；正因它是物的纯粹时间，才能在任意物质载体中、仿佛处于时间之外地再现物。 |
| automatisme de répétition / modulation de temps | 重复自动症 / 时间调制 | 旧言说与当前言说的等值，不要求过去满足或情感当下在场；二者被置入同一种时间形式，重复首先在言说维度中发生。 |
| dernier mot / dernier sens / Tu es celui qui... | 最后一句话 / 最后意义 / 你是那个……的人 | 逐层解释之后抵达的仍是一项言说及其时间形式，而不是言说背后现成的心理情感。第二十一课继续展开“你是那个……”的构成性形式。 |
| Übertragung（Traumdeutung）/ transfert du sens | 转移（《梦的解析》）/ 意义的转移 | 日间残余作为已撤去自身欲望投注的能指材料，被无意识欲望重新组织以表达新意义；第二十课据此把 *Übertragung* 的首要结构规定为语言现象，而非两个人之间情感的搬移。 |
| matériau signifiant / alphabet et phonématique des restes du jour | 能指材料 / 日间残余的字母表与音素系统 | 音素、象形文字等形式在失去自身意义后可被重新编排，使不可直接翻译的无意识欲望在梦中得到表达。 |
| discours apparent / discours masqué / parole persécutée | 表面话语 / 隐蔽话语 / 遭迫害的言说 | 一套隐蔽话语能够占据另一套表面话语；梦中无意识话语利用日间残余，政治压迫下也可借表面反驳传递受迫害的言说。后者是拉康借列奥·施特劳斯作出的类比，不把两种语境直接等同。 |
| sémantème / polyvalence des emplois | 语义单位 / 用法多价性 | 第二十一课把 *sémantème* 规定为总是指向整个语义系统和多种用法、因而始终具有多重意义的单位。当时语言学可用该词指承载词汇意义的语言单位；本课并非后来的最小义素分析，故定译“语义单位”，不译“义素”。 |
| signifiant / signifié / signifiable / significabilia | 能指 / 所指 / 可意指者 / 可意指者 | 能指是可在对立系统中辨认的可听材料，所指是意义而非被意指的事物；*signifiable / significabilia* 指可由符号指称、自己却不是符号的对象。不可把后三者合并成同一个“所指”。 |
| phonème / matériel audible / phonétique | 音位 / 可听材料 / 语音学 | 音位不是任意物理声音，而是同另一声音相对立、在一组对立关系中可被区分的声音单位；第二十一课的速记打字例说明语境可消除符号歧义。 |
| phrase sans emploi / deux zones de la signification | 句子没有用法 / 两个意义区域 | 贝尼特报告之后，拉康把词和词组的用法同完整句子区别开来，并把两个区域作为语言／言说之差的入口；这里“没有用法”是研讨班提出的理论界限，不是说句子不能被使用。 |
| locutio / oratio / sententia plena | 言说 / 话语 / 完整陈述、完整句子 | 第二十一课明确指出 *sententia plena* 只指主语与动词齐备的完整句子，绝不是拉康的 *parole pleine*“充实言说”。*locutio* 与 *oratio* 依奥古斯丁文本和讨论语境区分，不机械套用后期术语。 |
| docere / discere / per commemorationem | 教 / 学 / 通过唤回记忆 | 《论教师》开篇把提问理解为使两套言说及两种语言达成一致，因而使教与学彼此缠结；*commemoratio* 在拉康评述中对应 *remémoration*，附录普通叙述仍可按句法译“唤起记忆、重新想起”。 |
| signum / verbum / nomen | 符号 / 言词 / 名称 | 《论教师》的层级并不等同于三个同义词：*signum* 是能够意指某物者，*verbum* 是接合并发出的言语符号，*nomen* 则可指称事物或其他符号。涉及词类时 *verbum* 可按语境译“词、动词”，不能把拉丁语多义性抹平。 |
| signa facere / signa facimus / significare | 制造符号 / 我们制造符号 / 意指 | 奥古斯丁对话借“说话就是制造符号”连接 *signa facere* 与 *significare*；正文保存这项文本内部的构词说明，不把它写成已经得到现代词源学确认的结论。 |
| nomen（lecture de Lacan）/ symbole / totalité signifiant-signifié | 名称（拉康的解读）/ 象征 / 能指—所指的总体 | 拉康把 *nomen* 的功能放在承认、契约与共识层面，并解释成研讨班意义上的象征。此项属于拉康对奥古斯丁论证的结构性读取，不等同于奥古斯丁每次使用 *nomen* 时都已提出成熟的象征理论。 |
| nomen / numen / noscere / cognoscere / agnomen | 名称 / 神意、神圣者 / 认识 / 认识 / 附加名 | 第二十一课并用雨果的 *nomen—numen* 文字游戏和 *noscere / cognoscere / agnomen* 的词形关联，说明名称、认识与承认的交错。正文保留拉丁词形；二次校验须区分诗性双关、研讨班解释与历史词源事实。 |
| signes impuissants à enseigner / vérité intérieure / Maître intérieur | 符号无力教导 / 内在真理 / 内在教师 | 《论教师》附录主张：若已知事物，符号只唤回记忆；若未知事物，符号本身也不能给予认识，真正的教导来自内在真理。拉康借这次翻转返回言说与真理的辩证法，并未无条件接受其神学结论。 |
| méprise / erreur / ambiguïté | 误认 / 错误 / 歧义 | 第二十一课结尾把奥古斯丁的辩证法概括为三个极点，并由此引向 *Verneinung / Verdichtung / Verdrängung*。*méprise* 继续同一般 *erreur* 区分，也不无条件并入 *méconnaissance*。底本 *vérité d’un créé* 语法与语义不稳，米勒整理本删去该句；正文按字面保留并加译注，不擅改为“非受造的真理”或“造物主的真理”。 |
| dialectique du transfert imaginaire / transfert en miroir / troisième terme | 想象性转移的辩证法 / 镜像式转移 / 第三项 | 从投射、客体关系到转移—反转移，若仍停留在双体心理学，就只能维持自恋性的镜像转移；第二十二课把言说规定为使这一结构能够推进的第三项。 |
| dimension de la vérité / mensonge / erreur | 真理维度 / 谎言 / 错误 | 言说即使要欺骗，也必须把自身断言为真，并随谎言扩展而更严密地掌握有待遮蔽的真理；错误则把自己提出并传授为真理。这里不是把真／假理解为黑白两项的静态对立。 |
| erreur comme incarnation de la vérité / voies d'erreur | 错误作为真理的化身 / 错误的道路 | 第二十二课称真理在完整揭示以前以错误形式传播，并把“真理的道路”说成从本质上经过错误；这是言说现象学中的命题，不等于认可任何经验错误都是真的。 |
| contradiction dans le discours / savoir absolu / non-contradiction | 话语中的矛盾 / 绝对知识 / 无矛盾 | 词项可因约定不同而系统性换名，只有话语继续展开并抵达矛盾，错误才得到揭示；拉康据此概括黑格尔的绝对知识为话语在完全无矛盾中闭合并自我说明的理想。 |
| langue bien faite / langage sans parole | 完善语言 / 没有言说的语言 | 科学的象征系统越趋向形式完善，越可能被设想成失去“声音”或言说参照的语言；拉康随即指出，该系统仍不能脱离其自身运动不断参照的真理维度。 |
| la vérité rattrape l'erreur au collet dans la méprise | 真理在误认中揪住错误的衣领 | 第二十二课对弗洛伊德发现的公式：日常话语在错误、误认与否认式否定中展开，而口误、失误行为、梦与症状让真理从背后追上错误。*méprise* 在这条公式中不与 *méconnaissance* 或 *erreur* 换用。 |
| parole au-delà du discours / sujet discourant / sujet parlant | 话语彼岸的言说 / 论述主体 / 说话主体 | 无意识言说超出主体作为有意识论述者的界限，却仍处在他作为说话主体的界限中；它不是藏在灵魂地下室的一套更真实实体，也不能以荣格式原型来保证真理。 |
| discours discourant | 推演性话语 | 本课以它指普通错误语域中连续推进、以矛盾检验真假的话语；梦、症状、口误与诙谐所揭示的言说则服从另一套组织法则。“推演性”保留 *discourant* 的展开、推进之意，并同“论述主体”区分；不将它泛化为一切话语。 |
| l'inconscient ne connaît ni contradiction ni temps / suspension du principe de contradiction | 无意识不知道矛盾与时间 / 矛盾原则的悬置 | 第二十二课明确限制这项公式：它不是说无意识构成不受现实位置制约的神秘实体，而是说经解释揭示的无意识言说，不按普通话语直到矛盾才暴露错误的方式运作。 |
| Verdichtung / Verneinung / Verdrängung（第二十二课） | 凝缩 / 否认式否定 / 压抑 | 本课把三者画入话语彼岸言说的三个面：凝缩显示意义的多价交叉，否认式否定显示象征—事物不重合的负面，压抑则以话语中断为根本标志。底本说压抑在话语语域中“*préférable*”，米勒整理本作“*référable*”；正文据后者译为“可以在话语语域中得到参照”并加译注。不得把压抑、重复与否认式否定混同。 |
| refoulement / interruption du discours / parole suspendue | 压抑 / 话语中断 / 悬置的言说 | 植物学专著之梦被读作日间言说未能走到坦承、事物与存在的底部；压抑在本课不是一般遗忘，而是本来有待推进的言说停住。 |

| silence dans le transfert / présence de l'autre | 转移中的沉默 / 他者的在场 | 过强转移可使想象性结晶过早靠近关键点，并以沉默表现最尖锐的阻抗；若时机恰当，同一沉默又可成为言说彼岸的积极时刻，让主体最尖锐地把握他者在场。 |
