# Seminar VIII 译文格式样例

以下格式取自 `texts/s8-le-transfert/translation/` 中已完成的课次，并按当前“一段一 ID”要求整理。复制结构，不复制示例措辞。

## 1. 文件头

```markdown
---
translation_progress: 100
translation_progress_label: 100.00%
untranslated_count: 0
max_segment_id: 94
---
# Leçon 13 | 08 Mars 1961

<!-- source-original: texts/s8-le-transfert/original/Leçon-13.md -->

<!-- seminar: s8 -->

<!-- lesson: 13 -->
```

完成后由项目逻辑或编辑过程更新进度字段；仍有未译段落时不得伪写 100%。

## 2. 普通的一对一段落

```markdown
<!-- id: s8-13-0001 -->

这里写与该原文 ID 严格对应的完整译文。

<!-- id: s8-13-0002 -->

这里写下一段译文。
```

不要把上一段末句移到下一 ID，也不要为了中文连贯把两个 ID 合并。

## 3. 原文编号注释

原文可能在正文中使用 `[^173]`，并在文件末尾给出定义。译文按本课出现顺序改为：

```markdown
<!-- id: s8-13-0003 -->

……通常没有平面图反倒也不碍事[注1]。可是反过来却不成立……

> [注1] 这里写 `[^173]` 的完整中文译文，包括续行、出处与页码。
```

编号采用本课局部顺序，不沿用源文件的全书脚注号。

## 4. 同段同时存在原注和新增译注

正文里必须同时出现两个引标，段后先原注、后译注：

```markdown
<!-- id: s8-14-0008 -->

……原文所引的说法[注2]在这里还有一层双关[注]。

> [注2] 原文脚注的完整译文。

> [注] 译者补充的出处、双关或理解说明。
```

不要把新增译注混入 `[注2]`，也不要漏掉正文 `[注]`。

## 5. 义译后保留直译

```markdown
把话说明白吧（直译：把 i 上的点点出来）。
```

只用于字面与自然中文差距明显、而字面形态又有解释价值的地方。

## 6. 多义或句法不确定

```markdown
……他成了这个坏客体的病人/承受者（原文：*patient*）[注]。

> [注] *Patient* 既可指接受分析的病人，也可指被动承受某种作用的人；这里保留两义。
```

若问题来自残缺转录：

```markdown
……仍会这么说/这么想（原文：*nous dirons dans une pensée…*）[注]。

> [注] 原句句法不完整，可能有转录或标点问题；证据不足以排除任一读法。
```

## 7. 新增典故或双关译注

```markdown
……扮演桥牌里的“明手”（*le mort*，直译“死人”）[注]。

> [注] 法语桥牌称明手为 *le mort*。这里同时调用桥牌术语和“死亡”的字面义。
```

## 8. 润色后无法避免的信息损失

只有确实无法在中文正文中同时保留语义和形式时才使用译注。例如法语语音双关：

```markdown
……人们不再赞颂爱，而要赞颂另一个人[注]。

> [注] 原文以 *l’Amour*（爱）与 *l’autre*（另一个人）的近音关系完成转场。中文正文保留了论证方向，但无法同时保留这层语音双关。
```

若能通过调整正文准确保留信息，就直接改正文，不要用译注替代修正。译注应明确指出保留了什么、损失了什么及损失原因。

## 9. 图片

引用原文资源，不把图片复制到译文目录：


原注中的图片放在对应 `> [注N]` 块内，并保留引用层级。
