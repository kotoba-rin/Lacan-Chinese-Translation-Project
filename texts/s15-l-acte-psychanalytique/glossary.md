# 翻译术语对照表

适用范围：`S15 L’acte psychanalytique（1967—1968）`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| L’acte psychanalytique | 精神分析行动 | 本期研讨班标题；讨论的不是一般分析技术，而是使分析者任务得以开始、并在终点使分析家承担对象(a)位置的行动。 |
| acte | 行动 | 指能指事实及其使主体发生分裂、变异的后果；不按日常语境泛译为“行为”或“动作”。 |
| acte de naissance | 出生文书 | 常规法律义为出生记录或出生证明；本期又借 *acte* 的“文书／行动”双义追问精神分析的诞生。 |
| acte psychanalytique | 精神分析行动 | 分析家授权并支撑分析者任务的行动；它预先押注被假定知道的主体，而自身结果又将否认这一押注。 |
| action / agir / faire | 活动／行动、起作用／“做” | 与 *acte* 严格区分；尤其不能把分析家所“做”的事情自动等同于精神分析行动。 |
| mise en acte / mettre en acte | 行动实现／使……在行动中实现 | 指使某物在行动中呈现或取得现实性；与 *passage à l’acte*〔付诸行动〕、*acting out*〔行动化〕严格区分。 |
| tâche psychanalysante | 分析者任务 | 指分析者在分析中完成的言说与主体化行程；同授权这项任务的精神分析行动区分。 |
| acte manqué | 失败行动 | 弗洛伊德术语，亦常译“失误行动”；本期反复利用 *manqué* 与“成功”的悖论，故统一译“失败行动”，而非一般意义的行动失败。 |
| passage à l’acte / acting out / sublimation | 付诸行动／行动化／升华 | 本期用四边形比较几项操作位置；三者不得混译，也不能按行为严重程度排列。 |
| psychanalyste / analyste | 精神分析家／分析家 | 指承担分析功能者；简写“分析家”只在语境不会同分析者混淆时使用。 |
| psychanalysant / analysant | 分析者 | 强调正在分析中言说并完成任务的主动位置，不译成被动的“受分析者”。 |
| analysé | 受分析者 | 原文以过去分词身份指已经接受分析者；本期又明确质疑把它实体化为固定身份。 |
| qualification / identification / formation du psychanalyste | 精神分析家的资格／认同／培养 | 三项问题彼此相关但不等同；制度准入规则本身不能回答精神分析家是什么。 |
| analyse didactique / training analysis | 训练分析 | 指精神分析家培养中的个人分析；本期追问它的终点、进入方式及其同普通分析是否相同。 |
| la passe | 通行 | 分析者转到分析家位置的制度性与结构性“跃迁”；不按普通语义译为“通过考试”。 |
| sujet | 主体 | 概念性用法固定译“主体”；普通“题目、议题”义依句法处理。 |
| sujet divisé / sujet barré / S barré | 分裂主体／被划杠的主体／被划杠的 S | 主体由能指效应构成并不可还原地分裂；公式中保留 S 的横杠。 |
| effet de sujet | 主体效应 | 言语在语言中产生的分裂效应；不能预设一个先于能指而完整自足的主体。 |
| signifiant / signifié / signification | 能指／所指／意指 | *signifiant* 不译为“意义”；*signification* 指意指作用或形成的意指。 |
| un signifiant représente un sujet pour un autre signifiant | 一个能指为另一个能指代表一个主体 | 本期反复采用的主体公式；不得改写成能指对既成主体的外部描述。 |
| répétition | 重复 | 重复使主体效应返回，并在 S₁ 与 S₂ 之间造成对象(a)的丧失；不只是经验事件重现。 |
| objet(a) / objet petit(a) | 对象(a) | 主体分裂的剩余与欲望成因；分析家在行动中承担其位置，不把它实体化为完整经验对象。 |
| cause du désir | 欲望成因 | 对象(a)的结构功能；与作为目标、被有意识追求的欲望对象区分。 |
| objet partiel | 部分对象 | “部分”指结构位置，不预设其最终整合为一个完整总体。 |
| sein / scybale / regard / voix | 乳房／粪块／凝视／声音 | 本期列举的对象(a)形态；凝视同眼睛或主动观看严格区分。 |
| transfert | 转移 | 由被假定知道的主体支撑；转移的枢轴不在分析家的个人属性，而在他承担的结构位置。 |
| sujet supposé savoir | 被假定知道的主体 | 分析开始与转移的结构性支点；不表示分析家事实上拥有被假定给他的知识。 |
| sujet supposé demande | 被假定要求的主体 | 最后一课同被假定知道的主体并置；分析介入的是两者之间的间隔，而不是只回应表面要求。 |
| désêtre | 去存在 | 被假定知道的主体在分析终点的坠落；分析家以对象(a)的形式给这种坠落赋予支撑。 |
| vérité / savoir | 真理／知识 | 真理在主体拒绝知道之处以症状显现；知识则经大他者承认而得到分节，二者不能总体化为分析家的知识。 |
| savoir refusé | 遭拒知识 | 主体拒绝知道、却在症状和言说中产生效应的知识；不等于分析家预先掌握的隐秘内容。 |
| impuissance du savoir | 知识的不可能／无能 | 指知识无法穷尽主体分裂和对象(a)；依句法在“不能”与“无能”之间处理。 |
| Autre / grand Autre | 大他者 | 言语前来取得位置的场所，也是传统、知识积累与能指储备的场所；不同于经验中的另一个人。 |
| parole / discours / langage | 言语／话语／语言 | 语言不是主体的行动；话语在特定条件下才可能构成主体行动，三者不可互换。 |
| l’inconscient est structuré comme un langage | 无意识像语言一样被结构起来 | 只断言可说的无意识具有语言结构；不等于“语言像无意识一样被结构起来”，也不表示说话者已掌握无意识。 |
| énoncé / énonciation | 陈述／言说行为 | 区分已经说出的内容与发出陈述的行为、位置及过程。 |
| sujet de l’énoncé / sujet de l’énonciation | 陈述主体／言说行为主体 | 前者写在陈述中，后者占据言说行为的位置；量化逻辑无法轻易清除二者的裂隙。 |
| conséquence | 后果 | 首先指话语分节中的逻辑续接和蕴涵；动力学效应只有进入能指链后才在分析中“牵出后果”。 |
| fantasme | 幻想 | 主体同对象(a)之间的结构性关系；分析家的幻想也可能成为使分析者言语“解冻”的撞击来源。 |
| castration / -φ | 阉割／负 φ | 标示主体与性行动中不可总体化的欠缺；不是经验身体的普通残缺。 |
| acte sexuel / copulation | 性行动／交媾 | 性行动涉及能指、重复和主体变异；不能同生物性交或生殖功能直接等同。 |
| il n’y a pas d’acte sexuel / le sexe n’est pas tout | 不存在性行动／性并非全部 | 前者不等于一切性经验都彻底失败；后者指出性结合不能形成预设的“全部”。 |
| désir / demande / jouissance | 欲望／要求／享乐 | 三者严格区分；主体不知道自己要求什么，也不会因此要求自己所知道的东西。 |
| désir du psychanalyste | 分析家的欲望 | 分析行动与解释得以运作的关键，不还原为分析家的个人愿望或善意。 |
| tout / universel / particulier | 所有、全部／全称／特称（特殊者） | 依语境区分量词、总体幻象与命题类型；“全部”之幻象以对象(a)的省略为原则。 |
| universelle affirmative / universelle négative | 全称肯定命题／全称否定命题 | 亚里士多德命题方阵及本期量词讨论中的固定译法。 |
| particulière affirmative / particulière négative | 特称肯定命题／特称否定命题 | 由存在量化与否定关系得到；不能仅凭“并非全部”便草率推出一个事实存在。 |
| quantificateur / quantification | 量词／量化 | ∀ 与 ∃ 的逻辑运算；本期借其考察全称、存在、否定与言说行为主体的裂隙。 |
| double négation | 双重否定 | 在本期并不总能消解成普通肯定；它可建立全称命题，也暴露两项否定并非同一层次。 |
| pas sans | 并非没有／无……不…… | 作为否定形式的名称译“并非没有”；展开为 *il n’y a pas de X sans Y* 时译“没有不带 Y 的 X”，不可拆成条件句。 |
| contradiction / principe de non-contradiction | 矛盾关系／非矛盾律 | 命题方阵中的“矛盾命题”同 A 不可能在同一方面既是 A 又是非 A 的原则区分。 |
| Begriffsschrift | 《概念文字》／概念书写 | 弗雷格的形式书写系统；本期用来区分命题内容、判断线、量化与谓词函数。 |
| fonction / argument | 函数／自变量 | 弗雷格语境中的固定术语；“是智慧的”作为函数，“人”作为进入函数的自变量。 |
| Sinn / Bedeutung | 意义／指称 | 沿用弗雷格术语边界；*Bedeutung* 不泛译成普通“意义”。 |
| οὐσία / ousia | 所是 | 亚里士多德术语；本期专门质疑把它轻率译成“实体”。 |
| ὑποκείμενον / hypokeimenon | 基底、主体性支撑 | 亚里士多德式承载位置；最后用来说明分析家必须成为分析话语的支撑并承担自身分裂。 |
| trait unaire | 一元特征 | 可把异质对象计作同一集合成员的最小能指标记；同重复、计数与主体定位相连。 |
| Verneinung / dénégation | 否定 | 弗洛伊德术语；主体在说出真理时又以否定形式同它保持距离。 |
| Verleugnung / déni | 否认 | 同主体分裂及分析家押注被假定知道的主体、却由行动否认这一押注相关；不得同拒斥混译。 |
| Verwerfung / forclusion | 拒斥 | 精神病结构中从象征界被拒斥者在实在界返回；与 *Verleugnung*〔否认〕严格区分。 |
| Spaltung | 分裂 | 弗洛伊德术语；指主体不可还原的分裂，不译成普通意见分歧。 |
| méconnaissance / dé-connaissance / connerie | 误认／去认识／愚蠢 | 本期借 *déconnaissance / déconner* 的声音关系展开文字游戏；三者不可归并成一般“不知道”。 |
| sub-logique / sublogique | 亚逻辑 | 把逻辑要求带入精神分析行动场域的名称；不是低等逻辑，也不意味着放弃严格性。 |
| indécidable | 不可判定之物／不可判定性 | 量词逻辑中不能由预定算法对所有命题统一裁决真假的结构性结果。 |
| hommelette / lamelle | 人薄片／薄片 | 拉康以 *homme* 与 *omelette* 构造的名称；指力比多及对象(a)的神话形象，不改写成解剖实体。 |
| self / false self / true self | 自身／假性自身／真实自身 | 温尼科特语境；保留 *self* 与拉康式主体、自我之间的概念差异。 |
| vie privée | 私人生活 | 第十五课同时利用 *privée* 的“私有／被剥夺”含义；分析经验使其不再是维持性关系规范的封闭虚构。 |
| il n’y a pas de dialogue | 不存在对话 | 指主体同大他者的关系本质上不对称；不否认经验层面存在交谈。 |
