# 翻译术语对照表

适用范围：`S14 La logique du fantasme（1966—1967）`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| La logique du fantasme | 幻想的逻辑 | 本期标题；*logique* 指对幻想结构的逻辑化表述，不把幻想还原为想象性内容。 |
| fantasme | 幻想 | 不译“幻觉”；公式按原文写作 $\bar S \mathbin{\lozenge} a$。 |
| logique | 逻辑 | 依语境可指形式逻辑、逻辑关系或对结构作逻辑化表述；不泛化成日常“道理”。 |
| métalangage / langage-objet | 元语言／对象语言 | 第二课以“没有元语言”质疑用一个外在语言层级包裹对象语言的设想；不否认实际存在的语言分层操作。 |
| sujet | 主体 | 概念义固定译“主体”；普通“题目、议题”义依语境处理。 |
| S barré / sujet barré / division du sujet | 被划杠的 S／被划杠的主体／主体的分裂 | 公式中写作 $\bar S$；“划杠”标示主体由无意识与能指结构所造成的分裂。 |
| objet(a) / objet (a) / objet petit(a) | 对象(a) | 沿用相邻 S13 的记法；进入公式时写作 $a$，不改写成经验中的完整对象。 |
| poinçon / ◊ | 菱形符号／◇ | 幻想公式中连接 $\bar S$ 与 $a$ 的符号；同时可按横向或纵向切分呈现双重关系，不译为普通“冲头”。 |
| signifiant / signifié / signification | 能指／所指／意指 | 不把 *signifiant* 译成“意义”；*signification* 指意指作用或形成的意指。 |
| lettre | 字母 | 能指的最低限度书写形态；本期强调字母的重复并不自动保证自我同一，且字母可作为被排除或欠缺之物运作。 |
| trésor du signifiant | 能指宝库 | 位于大他者场所，不局限于词典所收词语，而涵盖陈述得以产生的能指资源。 |
| point de capiton | 绗缝点 | 软垫工意象；在流动的意指秩序中暂时固定能指与意指关系。 |
| Autre / grand Autre | 大他者 | 大写 A 的能指场所；与普通 *autre*“他者／另一个”区分。 |
| autre / petit autre | 他者／小他者 | 小写时可指镜像同类、另一个人或公式中的小写项；依上下文辨别。 |
| désir / réalité / réel | 欲望／现实／实在界 | 本期把欲望与现实表述为同一织物的两面；*réel* 仍同“现实”严格区分。 |
| endroit / envers | 正面／反面 | 兼具织物两面与拓扑曲面定向的含义；不能直接等同于现实／欲望。 |
| étoffe du désir | 欲望的织物 | 欲望与现实构成无切口、无缝线的同一织物；切割随后使主体与对象(a)的结构显现。 |
| prêt à le fournir / prêt à le porter | 现成可供出它／现成可承载它 | 后一说法借 *prêt-à-porter*“成衣、现成可穿”的固定表达，连接对象(a)、幻想的承载面与框架。 |
| Symbolique / Imaginaire / Réel | 象征界／想象界／实在界 | 作为三种语域时使用“界”；普通形容词依句法译“象征的／想象的／实在的”。 |
| répétition | 重复 | 不是简单找回同一之物，也不必然意味着无限反复。 |
| écriture | 书写 | 指文字铭写、公式化及其结构功能时译“书写”；具体作品依语境译“文字／著作”。 |
| discours / Univers du discours | 话语／话语宇宙 | 本期命题“没有话语宇宙”指能指总体不能构成一个封闭且包罗一切的集合。 |
| graphe | 图式 | 指拉康分层构造的欲望图式；用来排列语言场域、言语功能与能指通道中的关系。 |
| mot d’esprit / non-sense | 妙语／非意义 | 妙语的 *non-sense* 不是普通“荒谬”，而是陈述被非意义性切割后在接收层面产生的作用。 |
| énoncé / énonciation | 陈述／言说行为 | 区分已经说出的内容与发出陈述的行为、位置或过程。 |
| existence de fait / existence logique | 事实存在／逻辑存在 | 前者关涉说话存在者的经验存在，后者关涉逻辑与能指操作中主体的成立。 |
| inclusion / implication | 包含／蕴涵 | 第一课在菱形符号的逻辑拆分中并置；保留集合关系与命题关系的差别。 |
| si et seulement si | 当且仅当 | 双条件关系；原转录偶作 *si et si seulement*，正文按标准逻辑表达译出。 |
| moi / non-moi | 自我／非我 | *moi* 指想象性自我；“非我”不是可在原初结构中同自我互补的既成项。 |
| Urverdrängung / refoulement originaire | 原初压抑 | 指一个能指为另一个能指表征主体的原初结构，不并入一般压抑。 |
| Verneinung | 否定 | 弗洛伊德术语；本期强调它相对于原初结构的次生地位。 |
| plaisir / déplaisir | 快乐／不快 | 第一课指出二者的分裂不是 *Verneinung* 最初发生的层面。 |
| Dasein | 此在 | 保留海德格尔术语层次；第一课把原初的此在定位于异化形态的对象(a)。 |
| Sinn / Bedeutung | 意义／指称 | 弗雷格语境中的对举；原转录在 *Bedeutung* 后括注 *signification* 时，正文仍保留“指称”的术语边界。 |
| fort-da | “走了—在这儿”游戏 | 弗洛伊德所述儿童线轴游戏；本期指出在场／缺席并未穷尽能指入场的结构。 |
| bande de Mœbius | 莫比乌斯带 | 一面一边的拓扑曲面；其正反面无需越过边界即可连续。 |
| plan projectif / cross-cap / mitre | 射影平面／交叉帽／主教冠 | *cross-cap* 是射影平面的浸入模型；*mitre* 保留“主教冠”的形象。 |
| bouteille de Klein | 克莱因瓶 | 无定向闭曲面；同射影平面、莫比乌斯带及环面区分。 |
| tore | 环面 | 中央孔洞属于其在三维空间中的外在呈现，须同曲面内在性质区分。 |
| bulle | 泡状曲面／气泡 | 第一课用作欲望与现实之共同曲面的形象；不是普通心理内容的容器。 |
| coupure / bord | 切割／边界 | 切割使主体与对象(a)的结构显现；边界标出从正面跨到反面的不可能性。 |
| fonction du bord | 边界功能 | 边界不可被实体化成给话语流动加上的外框；被边界所限定之物也可能反过来进入划界功能。 |
| réunion / intersection | 并集／交集 | 欧拉圆及集合论语境中的两项运算；第一课以交集定位对象(a)。 |
| cercles d’Euler | 欧拉圆 | 用两个相交圆表征主体、大他者与对象(a)的关系；图像只是一项不充分但可与逻辑运算结合的工具。 |
| vel / aut | “或”／“非此即彼” | 拉丁语析取形式；异化结构中的 *vel* 不是两个完整项间的普通自由选择，*aut* 则强调排斥性的二选一。 |
| aliénation | 异化 | 指主体在能指选择和大他者关系中形成的结构性异化，不弱化为一般疏远感。 |
| métaphore / substitution signifiante | 隐喻／能指替代 | 隐喻源于一个能指在能指链上替代另一个能指；不能把四项关系误读成普通比例或类比。 |
| langage réduit | 缩减语言 | 第一课所批评的神话：假定存在一个可以缩减并形成封闭能指总体的语言。 |
| l’inconscient est structuré comme un langage | 无意识像语言一样得到结构化 | 按字面保留“像语言一样”的结构命题，不缩减为无意识只是使用语言表达内容。 |
| axiome de spécification | 分离公理（模式） | 集合论中按某一性质从既有集合分离出子集的公理模式；原文用 *spécification*。 |
| ensemble / membre | 集合／成员 | 集合论术语；“能指集合”不能成为自我封闭、包罗一切的总体。 |
| classe / ensemble / sous-ensemble | 类／集合／子集 | 第二课明确说三者的运作不能直接叠合；罗素式自指问题必须按各自的规定原则处理。 |
| trait unaire | 一元特征 | 在异质元素上逐一施加的单一标记；使集合构成，并同计数、认同和重复相连。 |
| paradoxe de Russell | 罗素悖论 | 第一课以“不包含自身的所有目录之目录”说明集合无法按该规定完成封闭。 |
| Un / 1 comptable | 大写的“一”／计数的 1 | 前者不同于总体性，后者只有至少重复一次并回到自身时才作为 1 成立。 |
| signifiant en plus / un en plus | 多出来的能指／多出来的一 | 链条闭合时涌现、却无法在链内被计数或抓住的额外单位；同重复、环面与一元特征相连。 |
| pur signifiant / signifiant purifié | 纯粹能指／经过纯化的能指 | 第二课明确区分二者；“绝对之书”设想依靠把能指同一切所指区分开的纯化操作，但意指无法真正从话语宇宙中被清除。 |
| Livre absolu | 绝对之书 | 马拉美式诗性幻想：一部涵盖全部能指链的书；本期借它检验书写闭合与意指无法彻底纯化之间的张力。 |
| algèbre de Boole | 布尔代数 | 第三课从 $X^2=X$ 考察意指、同一律与矛盾律；公式的逻辑解释不得同普通算术计算混为一谈。 |
| loi de la signification / équation fondamentale de la pensée | 意指规律／思想之根本方程 | 布尔对 $X^2=X$ 的命名；第三课借它指出意指中的加倍，同时考察该方程所排除的 $+1$ 与 $-1$。 |
| redoublement / reduplication | 加倍／再复制 | 指一个元素在意指中向自身意指自身时发生的双重化；不得同主体分裂直接等同。 |
| un par excès / un par défaut | 因过多而有的一／因欠缺而少的一 | 分别从 $+1$ 与 $-1$ 标示同一结构位置；二者相对于意指、现实与总体形成同一项排除。 |
| réflexion / réflexivité | 反思／反身性 | *réflexivité* 在第三课先取集合论定义：无限集合可同自身真子集一一对应；再借此分析意识与主体。 |
| liaison biunivoque | 一一联结 | 整体每个元素同部分中的一个元素建立双射式对应；是第三课讨论无限集合与斯宾诺莎式反思的形式模型。 |
| conscience thétique / non-thétique / positionnelle / non positionnelle | 设定／非设定意识；定位／非定位意识 | 萨特语境中的区分；第三课据此考察不经再复制而同自身发生关系的意识点。 |
| théorie des types | 类型论 | 罗素为限制自指悖论而建立的层级规定；第三课把它同“我说谎”及主体分裂联系起来。 |
| réseau / treillis / lattice | 网络／格 | 第四课用联想线的覆盖、交叉、汇聚与再次出发说明弗洛伊德式解释；*treillis* 取序理论中的“格”，不译作普通篱笆。 |
| table de vérité | 真值表 | 以真、假取值规定命题联结词的运作；本期同时追问把 V、F 写成可操持能指是否合法。 |
| conjonction / disjonction / implication / équivalence | 合取／析取／蕴含／等值 | 命题逻辑的基本联结；*implication* 不直接等于因果关系。 |
| protase / apodose | 前件／后件 | 斯多葛蕴含中的两个命题环节；前件只是被设置为真，不表示说话者相信它。 |
| Ex falso sequitur quodlibet | 从假可以推出任意命题 | 假前件既可蕴含真后件，也可蕴含假后件；不是说假与真本身没有差别。 |
| sujet de l’énonciation / sujet de l’énoncé | 陈述行为的主体／陈述主体 | 前者指实施言说行为的位置，后者指陈述中被写出或被指称的主体位置；二者的双重性不能在书写中被无条件抹平。 |
| négation complémentaire / mé / pas sans | 补集否定／*mé*（误认之“不”）／“并非没有” | 第四课开始区分否定层次：集合补集、原初误认式排斥与蕴含反转中的“并非没有”不可视为同一运算。 |
| extension / compréhension | 外延／内涵 | 谓词逻辑中的传统对举；第四课强调，逻辑朝“内涵”推进时仍依靠外延方式操作。 |
| groupe de Klein | 克莱因四元群 | 由四个元素构成的群；第五课以三个对合操作 $a,b,c$ 及其复合关系组织后续对 *cogito* 的变换。 |
| opération involutive | 对合操作 | 同一操作连续施行两次回到原状态；不应简单改说成“两次否定等于肯定”，因为起点未必是肯定。 |
| Unterdrückt / refoulé / retour du refoulé | 被压制者／遭压抑者／遭压抑者的返回 | 第五课借 *sub-situer* 的文字拆分强调：被替代者不是消失，而是被置于下方；遭压抑者只在其返回层面被写出。 |
| S(\bar A) | 大他者中欠缺的能指 | 第五课把它同“多出来的一”以及“欠缺的能指”相连；第九课进一步强调横杠表示“大他者受标记”，不只是一句泛泛的“大他者不存在”。 |
| effet de vérité / vérité de l’interprétation | 真理效果／解释的真理性 | 解释可以产生真理效果，并不等于解释本身已经可被判定为真或假。 |
| cogito ergo sum / dubito ergo sum | 我思故我在／我疑故我在 | 本期从书写、蕴含与主体构成考察笛卡尔公式；不把 *ergo* 自动缩减为普通实质蕴含。 |
| voix moyenne / diathèse moyenne | 中间语态／中间语态配置 | 主体不是外在行动者，而由行动本身受到根本决定；第五课以 *loquor*、*sequor* 和献祭动词说明。 |
| loi de De Morgan / différence symétrique | 德·摩根律／对称差 | 书写否定与集合图示中的操作；图像只作辅助，不代替逻辑公式本身。 |
| opération Ω / aliénation | 欧米伽操作／异化 | 第六课暂以 $\Omega$ 标示一种真值操作：只有“真—真”组合为假，其余组合为真；它将被用来区分异化之“或”与普通 *vel*、*aut*。 |
| résistance / défense | 阻抗／防御 | 第六课明确二者不重合；防御圈定并保存“我不在”，不能把一切临床阻碍统称为阻抗。 |
| Wo es war, soll Ich werden | 它曾在之处，我必须来临 | 此处 *Ich* 取主体位置，不等同于第二地形学的 *das Ich*（自我）；逗号的去留关系到公式的主体结构。 |
| appréhension diagonale | 对角把握 | 康托尔式对角步骤借从既有列举中突然脱离，构造无法由该列举命名的新项，并据此区分不同的无穷。 |
| Poros / Penia | 机巧或资源／贫乏 | 《会饮》中的寓言人物；第六课借二者对举精神分析与大学的位置，并延续“哲学的爱欲”讨论。 |
| principe de dualité | 对偶原理 | 集合论公式中同时交换全集／空集与并集／交集，已成立的真值仍被保留；第七课借它变换 *cogito*。 |
| ensemble vide / sujet de l’énonciation | 空集／陈述行为的主体 | 第七课把空集视为陈述行为主体在集合定义中的被遮蔽支撑；“没有成员”不等于没有逻辑位置。 |
| pas-je | 非“我” | 本我不是 *moi* 的坏版本，也不是普通“非我”；*pas-je* 指被否定的第一人称位置，须同 *moi / non-moi* 区分。 |
| Es / Ça / inconscient | 本我／本我／无意识 | 德语 *Es* 与法语 *Ça* 指同一弗洛伊德术语，但二者都不等于无意识；第十课 *Cogito, ergo Es* 还利用拉丁语 *es* 与德语 *Es* 的近似同音。 |
| d(être)itus / détritus | 嵌入“存在”的废弃物／废弃物 | 第七课把 *être* 嵌入 *détritus*，说明遭象征界拒斥的“人的存在”如何以废余形态在实在界返回。 |
| Sachvorstellung / Das Ding | 事物表象／物 | 无意识由可表述的事物表象构成；这不等于不可言说的 *Das Ding*，也不妨碍无意识像语言一样得到结构化。 |
| Ein Kind wird geschlagen / Ein Kind ist geschlagen | 一个孩子正挨打／一个孩子已经挨打 | 弗洛伊德 1919 年论文的题名与幻想公式作过程被动态 *wird geschlagen*；第二十三课底本与 J.L. 速记稿误作结果状态 *ist geschlagen*，译文据弗洛伊德原文统一从前者。幻想公式把“我”排除在显式陈述外，驱力的倒置与反转依靠语法装配运作。 |
| occultation / éclipse | 遮掩／隐没 | 本我与无意识两个场域重合时彼此遮蔽的操作；两个方向分别显露对象(a)与性差异无法被指称充分覆盖的裂隙。 |
| sui-pensée / Selbstbewusstsein | 自思／自我意识 | 第八课以法语新词 *sui-pensée* 模拟德语复合词的构造，讽拟笛卡尔式思想仿佛对自身透明；“自思”不等于已经成立的统一自我。 |
| Traumgedanken / Trauminhalt / Traumarbeit | 梦思想／梦内容／梦工作 | 梦思想以语言和语法关系得到重构；梦内容则是经凝缩、移置等机制形成的能指总体，二者不得混用。 |
| structure grammaticale | 语法结构 | 大他者坠落后留下的“非‘我’”之结构补集；窥视驱力、施虐—受虐驱力及“一个孩子正挨打”都借语法位置展开。 |
| Verwerfung / verworfen | 拒斥／遭到拒斥 | 固定译“拒斥”：从象征界遭拒斥者在实在界返回；第十一课明确要求同 *Verleugnung*［否认］区分，不译成普通排除或法律术语。 |
| réalité sexuelle / rapport des sexes / Bedeutung sexuelle | 性现实／两性关系／性的指称 | 语言不能支配性现实，也不能以指称充分表述两性关系；阉割标示这项语言欠缺，不把它心理化为经验中的残缺感。 |
