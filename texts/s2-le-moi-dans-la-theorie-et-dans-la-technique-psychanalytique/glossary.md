# 翻译术语对照表

适用范围：`S2 Le moi dans la théorie et dans la technique psychanalytique`

本表以第二研讨班的具体语境为准；其他研讨班术语表只作比较证据。条目随逐课翻译与第二次语义回校补充。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| moi / ego | 自我 | 精神分析概念统一译“自我”；普通重读代词按句法处理。原文刻意对举 *ego* 与 *moi* 时保留外文，避免中文抹平问题。 |
| je | 我（je） | 指言说中以第一人称出现的“我”；同 *moi / ego*“自我”对举时首次保留法文。 |
| sujet | 主体 | 概念义统一译“主体”；普通“题目、议题”义按上下文处理。 |
| individu | 个体 | 指作为有机体或社会单位的人；不得同 *sujet*“主体”互换。 |
| subjectivité | 主体性 | 第一课既指弗洛伊德开启的主体维度，也指主体性随历史发生的变化；不等同于主观意见。 |
| conscience / inconscient | 意识 / 无意识 | 第一课批判“自我＝意识”的等价关系，并区分无意识中以 *je* 发言之物与自我领域。 |
| autre | 他者 / 另一个人、别的东西 | 概念义译“他者”；普通指称按语境译“另一个人／别的东西”。大小写若在后续课次形成结构性区分，再据原文补充。 |
| semblable / prochain | 相似者 / 邻人 | 第一课列举“他者”的不同可能含义；不得把二者机械并入概念性的 *autre*。 |
| idéal de je | 我之理想 | 第一课底本写作 *idéal de je*，不是已定型的 *idéal du moi*“自我理想”；保留其特殊说法。 |
| fonction du moi / champ du moi | 自我功能 / 自我领域 | 前者指自我的作用，后者指主体把自己认作自我的确定性范围。 |
| décentrement du sujet / excentrique | 主体的去中心化 / 偏心的 | 弗洛伊德发现的核心：主体不同于个体，不与智力和适应功能处在同一轴线上。 |
| Je est un autre | 我是一个他者 | 兰波《通灵者书信》的著名反语法公式；正文首次出现同时保留法文。 |
| vérité / savoir / méconnaissance | 真理 / 知识 / 误认 | 第一课讨论真理沉淀为知识以后，知识自身的惰性如何导致对其意义的误认。 |
| ἀρετή / aretè | 卓越 | 柏拉图语境中也含德性、优异与完善；第一课根据拉康紧随其后的法文释义取“卓越”。 |
| psychologie générale | 普通心理学 | 第一课指前分析的、人人习以为常的心理学；不译作“普遍心理学”。 |
| technique psychanalytique / technique de la psychanalyse | 精神分析技术 | 包含方法、介入与分析关系的导向，不缩减为操作技巧。 |
| amour-propre | 自爱 | 拉罗什富科语境中的自我关切；其新意不在一般利己主义，而在这种自爱具有欺骗性和非本真性。 |
| théorie « physique » de l'amour | “物理的”爱理论 | 第一课沿用底本的经院哲学术语 *physique* 并保留法文，不把它静默改写成一般意义的“自然之爱”。 |
| plaisir / bien | 快乐 / 善 | 第一课回顾从苏格拉底到功利主义的论证；*bien* 作名词时译“善”，具体个人利益按语境处理。 |
| libido / instinct sexuel | 力比多 / 性本能 | 第一课把二者并置为弗洛伊德真理闯入时的名称；不因此预设二者在后续论证中完全同义。 |
| processus primaire | 初级过程 | 与弗洛伊德元心理学中的次级过程相对。 |
| métapsychologie / métapsychologique | 元心理学 / 元心理学的 | 弗洛伊德从动力、经济与地形学等角度阐发心理过程的理论层次。 |
| le Moi / le Surmoi / le Ça | 自我 / 超我 / 本我 | 第一课列举弗洛伊德1920年后引入的新地形学概念；*Ça* 不译成普通代词“它”。 |
| ego autonome / autonomous ego / autonomus ego | 自主自我 | 哈特曼自我心理学的概念；第一课以 *autonomus ego* 的讽刺性写法批判其被当作现成给予。 |
| moi fort / moi faible | 强自我 / 弱自我 | 第一课把这组概念视为回避神经症理解与技术运用问题的方式，不作为未经检验的治疗指标。 |
| entification | 实体化 | 把自我或某种属性当作独立实体；不同于仅仅“命名”。 |
| Au-delà du principe de plaisir | 超越快乐原则 | 弗洛伊德1920年著作；第一课把它列为最后一个元心理学时期的枢纽文本。 |
| Psychanalyse collective et analyse du moi | 群体心理学与自我分析 | 弗洛伊德著作，底本用法文题名。 |
| Das Ich und das Es | 自我与本我 | 弗洛伊德著作；正文首次出现保留德文。 |
| instinct de mort | 死本能 | 第一课底本确切使用 *instinct*；不得静默改成 *pulsion de mort*“死驱力”。 |
| fonction symbolique / système symbolique | 象征功能 / 象征系统 | 第三课中，符号一旦涌现便蕴含人类事物的总体；不把它实体化为集体灵魂。 |
| ordre symbolique / registre symbolique / plan du symbolique | 象征秩序 / 象征层面 / 象征层面 | *ordre* 强调组织法则，*registre / plan* 强调分析中的区分层次；依原文保留差异。 |
| univers symbolique / monde symbolique | 符号宇宙 / 符号世界 | 第三课明确说符号有机体构成宇宙并使宇宙不同于世界；二词不得机械互换。 |
| symbolique / imaginaire / réel | 象征界 / 想象界 / 实在 | 三个分析参照层面；第三课尚会按句法写“象征层面、想象层面”。不因 *réel* 出现就把普通 *réalité* 改成“实在”。 |
| le moi comme fonction imaginaire et comme symbole | 自我作为想象功能与符号 | 自我在其本质面向上是一项想象功能，却只作为符号介入精神生活。 |
| complexe d'Œdipe | 俄狄浦斯情结 | 第三课一方面讨论其在想象层面的暴烈在场，另一方面称其因纯粹象征性而既普遍又偶然；两层不可合并。 |
| prohibition / interdiction de l'inceste | 乱伦禁令 | 指组织联姻的象征禁令；第三课反对把它直接奠立在自然恐惧上。 |
| exogamie / endogamie | 外婚制 / 内婚制 | 列维-斯特劳斯亲属关系讨论中的制度术语。 |
| ordre / orientation préférentiel(le) | 优先秩序 / 优先导向 | 积极的联姻偏好同时规定必须避免的负面关系。 |
| structures élémentaires / structures complexes de la parenté | 亲属关系的基本结构 / 亲属关系的复杂结构 | *élémentaire* 在此同“复杂”对举，不译“原始”。 |
| Les Structures élémentaires de la parenté | 亲属关系的基本结构 | 克洛德·列维-斯特劳斯著作。 |
| compensation / surcompensation / formation réactionnelle | 补偿 / 过度补偿 / 反应形成 | 安齐厄把社会制度语言同个体心理机制类比；拉康随后指出具体例子的“补偿”可能只有统计学价值。 |
| automatisme de répétition | 重复自动症 | 弗洛伊德技术语境中的重复机制；第五课将法语译名同德语 *Wiederholungszwang* 对读，不弱化为一般重复习惯。 |
| inconscient collectif | 集体无意识 | 第三课明确拒绝将象征功能实体化为共同灵魂或人类这一“大动物”。 |
| finalité / causalité | 目的性 / 因果性 | 第三课指出目的性会以潜伏形式进入因果概念，但不能据此给社会实体化出一个灵魂。 |
| mécanisme / mécanisme ancien | 机制、机械论 / 旧机械论 | 具体运作译“机制”；作为生命解释立场时译“机械论”。 |
| machine / machinisme / cybernétique | 机器 / 机械主义 / 控制论 | 第三课强调机器概念从能量模型到控制论正在变异，并以可变参数重新讨论自由。 |
| L'Homme-Machine | 人是机器 | 拉·梅特里著作；第三课借此讨论十八世纪机械论仍受旧范畴支配。 |
| nature / culture / institution | 自然 / 文化 / 制度 | 第三课质疑三者的经典对立，但没有因此允许正文任意互换。 |
| contingent / nécessaire | 偶然的 / 必然的 | 偶然性首先同必然性对立；不得用“普遍”替代任一项。 |
| universel / générique / général | 普遍的 / 类属的 / 一般的 | 符号系统依其权利而具有普遍性；两臂两腿等遍见特征属于类属，不因此成为普遍形式。 |
| formalisation mathématique / forme gestaltiste | 数学形式化 / 格式塔形式 | 前者由约定、定理与结构法则展开，后者是自洽而孤立的良好形式。 |
| signatura rerum / asymétrie pseudo-significative | 万物的符记 / 具有伪意指作用的不对称 | 自然提供形式差异；人把它们相互关联并赋予象征价值与功能。 |
| un réel / un donné | 一种实在 / 一种既定之物 | 第三课讨论自然不对称时的说法；保留 *réel* 与 *donné* 的差异。 |
| transfert / fonction de la parole | 转移 / 言说功能 | 若不从言说的创造性、奠基性功能出发，转移只剩由松散纽带联系的事实集合。 |
| Trois essais sur la théorie de la sexualité | 性学三论 | 弗洛伊德著作；第三课底本简写为 *Essai sur la théorie de la sexualité*。 |
| Totem et Tabou | 图腾与禁忌 | 弗洛伊德著作。 |
| résistance / analyse des résistances | 阻抗 / 阻抗分析 | 第四课反对把阻抗分析等同于劝服、暗示、强化自我或同自我的“健康部分”结盟。 |
| contrôle（clinique） | 督导 | 指分析家向资深分析家报告病例并讨论工作的临床督导，不译作一般“控制”。 |
| texte / matériel analytique | 文本 / 分析材料 | 第四课批评把主体带来的言说不恰当地只称作“材料”；回答必须落在其历史与命运所处的层次。 |
| dialogue intermoïque | 自我间对话 | 分析家以自身自我替代主体自我而展开的正常化对话；可能产生心理治疗效应，却不因此成为分析。 |
| der Kern unseres Wesen | 我们存在的核心 | 弗洛伊德《梦的解析》用语；拉康把它同初级过程及自我所误认的主体联系起来。 |
| le moi comme objet / fonction imaginaire | 自我作为对象 / 想象功能 | 自我不是无意识“我”的局部真理或不完整形式，而是主体经验内部履行想象功能的特殊对象。 |
| illusions de la conscience / transparence de la conscience à elle-même | 意识的幻觉 / 意识对自身的透明性 | 第四课批判意识作为受造物顶峰并直接保证自我统一的现代公设。 |
| conscience thétique / conscience non-thétique | 设定意识 / 非设定意识 | 第四课底本在描述笛卡尔如何处理二者的谓语位置缺文；译名只保留可见对举。 |
| phénomène de conscience | 意识现象 | 第四课用镜面、摄影机和机器寓言说明，意识现象不必已经被某个自我感知或反思。 |
| image réelle / image virtuelle | 实像 / 虚像 | 光学术语；不得将 *réelle* 误译为三界意义的“实在界”。 |
| espace réel / espace imaginaire | 现实空间 / 想象空间 | 光学中的成像空间区分；同一般主观/客观区分不重合。 |
| illusoire objectif / objectivable | 客观的、可对象化的幻觉之物 | 想象性和幻觉性并不自动等于主观。 |
| area striata | 纹状区 | 枕叶视觉皮层的历史称谓；第四课把其点对点成像功能同镜面类比。 |
| stade du miroir | 镜像阶段 | 身体倾向的支离破碎状态同提前把握的异化、虚拟统一之间的辩证关系。 |
| unité aliénée / unité virtuelle | 异化的统一 / 虚拟的统一 | 主体在镜像中首次把自己认识为统一，但这一统一来自外部图像并带有惰性。 |
| aveugle et paralytique / serpent et oiseau | 盲人与瘫子 / 蛇与鸟 | 第四课说明自我图像的引导、迷住与锁死功能的两组图像。 |
| homéostase | 稳态 | 自动机模型中通过反馈维持的状态；不泛化为一般心理平衡。 |
| jalousie-sympathie | 嫉妒—同情 | 对象构成中自我与他者彼此悬系、竞争同一对象的辩证法。 |
| connaissance / reconnaissance | 认识 / 承认 | 自我与他者对对象的竞争属于认识层面；象征第三项与交换系统介入后才可能出现承认。 |
| message reçu de l'autre sous une forme inversée | 从他者那里以颠倒形式接收的讯息 | 第四课借“我欲望这个／你欲望这个”说明人的讯息结构。 |
| intersubjectivité symbolique / subjectivité cosmique | 象征性的主体间性 / 宇宙主体性 | 机器与记录的连续性不要求实体化出宇宙灵魂。 |
| ex machina / machina ex Deo | 从机器中 / 从上帝中抽出机器 | 第四课调换拉丁短语，悬置机器与上帝谁从谁而来的问题。 |
| behaviourisme / behaviourisme molaire | 行为主义 / 整体行为主义 | 后者把完整行为作为一个场中的总体来观察；拉康仍批评“行为”概念排除了主体间关系。 |
| personne | 人 / 无人 | 第五课利用法文兼有“人”和否定代词“无人”的歧义，把无法实体化的主体称作 *personne*；相关段落保留“无人”并首次附法文。 |
| idolâtrie / idolification | 偶像崇拜 / 偶像化 | 前者指对形象化公式的崇拜倾向，后者指把主体或大他者凝固成偶像的操作；不同于一般宗教史描述时按语境处理。 |
| se compter soi-même | 把自己计算在内 | 第五课的机器模型与弗洛伊德无意识论的连接点；既指组合系统把自身列入计算，也指主体在无意识中以症状、梦和随机数字把自己算进去。 |
| système conscience | 意识系统 | 弗洛伊德心理装置中的特殊系统；第五课强调它在动力学上不能简单等同于自我，也不能直接放入其他三个心理系统的相互作用。 |
| investissement / désinvestissement | 投注 / 撤回投注 | 能量学表述中，心理系统获得或失去心理能量的过程。 |
| Verneinung | 否认 | 弗洛伊德术语；第五课反对把无意识理解为只需将自我陈述“变换符号”即可读出的反面。 |
| analyse du matériel / analyse des résistances | 材料分析 / 阻抗分析 | 第五课追问二者是否真能互为反面或等价物；后者不得译成一般性的“抵抗分析”。 |
| égologie | 自我学 | 指新地形学之后以自我组织及阻抗为技术中心的取向；第五课以批判口吻使用。 |
| Rid Principle | 摆脱原则 | 第五课援引《精神分析季刊》中的英文标题，以 *to rid / to rid of* 说明把自我功能理解为避开、清除未整合刺激的倾向。 |
| principe du plaisir / principe de réalité | 快乐原则 / 现实原则 | 第五课把现实原则界定为延迟的快乐原则，同时追问重复现象为何不能由同一平衡定律穷尽。 |
| réalité psychique | 心理现实 | 与无生命现实中力量和能量的自由流通相对，指生物通过内部组织和调节维持的现实。 |
| principe d'inertie / principe d'homéostase | 惯性原则 / 稳态原则 | 第五课指出弗洛伊德早期用“惯性”描述后来可称作“稳态”的调节，但该词容易与物理惯性混淆。 |
| processus primaire / processus secondaire | 初级过程 / 次级过程 | 两套法则结构不同，但第五课追问它们是否仍受同一快乐原则和释放定律支配。 |
| fonction restitutive | 恢复性功能 | 心理组织在刺激或扰动后恢复平衡的作用；必须同主体不断再现某物的 *fonction répétitive*“重复性功能”区分。 |
| Wiederholungszwang / compulsion à la répétition | 重复强迫 | 德语 *Zwang* 强调强迫性；第五课以“坚持性”说明它对快乐原则造成的扰动，并同法语译名“重复自动症”对读。 |
| insistance | 坚持性 | 第五课为说明无意识系统产物持续返回、不能被平衡原则消解而采用的日常词；不泛译成意志上的坚持。 |
| fonction répétitive | 重复性功能 | 主体在行为、幻想、性格、自我或转移中不断再现某物的功能；第五课将其同快乐原则的恢复性功能对立。 |
| symbolisable | 可象征化的 | 第五课末尾关于主体本性的开放问题之一；不得预先等同于“可以完全命名或把握”。 |
| Autre | 大他者 | 大写时译“大他者”；第五课由勒克莱尔明确提出偶像化是否被转移到 *l'Autre* 一侧，区别于小写 *autre*。 |
| principe de constance / principe de nirvana | 恒常原则 / 涅槃原则 | 第六课明确反对把二者同快乐原则无差别地等同；恒常原则维持一定能量水平，涅槃原则则被置于“超越快乐原则”的问题中。 |
| instinct de vie | 生命本能 | 与 *instinct de mort*“死本能”对举；第六课讨论二者的组成部分如何在爱与攻击性中结合或分离。 |
| tendance restitutive / tendance répétitive | 恢复性倾向 / 重复性倾向 | 第六课用来拆分 *Wiederholungszwang* 中彼此交织的两条线索；前者回归平衡，后者在恢复以后仍坚持返回。 |
| partie saine du moi / sphère sans conflit | 自我的健康部分 / 无冲突领域 | 自我心理学把二者设为分析联盟的支点；第六课批判这种世界之外的阿基米德支点并不存在。 |
| maîtrise / maître / esclave | 支配 / 主人 / 奴隶 | 黑格尔讨论中，*maîtrise* 既是掌控的逐步建构，也保留主奴辩证法中“主人功能”的含义；不可只译作普通技能。 |
| savoir absolu / non-savoir | 绝对知识 / 非知识 | 第六课讨论绝对知识是历史终点还是每一经验阶段的内在场，并追问非知识在黑格尔那里的功能。 |

| intersubjectivité duelle | 二元主体间性 | 主体不得不通过自身思想推断他者，却不能据此稳定翻译对方的个体差异；它既根本又充满幻象。 |
| transfert comme signification | 转移作为意义 | 爱与恨等情感本身并不是转移；转移是使这些材料能够被解释为一门不完整无意识语言的意义结构。 |
| efficacité symbolique / inertie symbolique | 象征效力 / 象征惰性 | 前者使机器或仪式从序列中提取结构，后者指无意识主体在自认为随机的选择中仍留下的个人重复公式。 |
| détermination symbolique / détermination réelle | 符号规定 / 实在规定 | 第十七课用随机正负序列说明符号的句法约束先于每次实际抽取；不可把机器的计算规则同机械装置混同。 |
| insistance de la chaîne signifiante | 能指链的坚持 | 重复自动症的原则；能指链的要求即使悬置也持续生效，并由此规定主体的行动、命运、盲目与际遇。 |
| surdétermination signifiante | 能指过度决定 | 弗洛伊德式过度决定被定位于符号法则，而非实在中多重物理原因的简单叠加。 |
| caput mortuum du signifiant | 能指的死头 / 残渣 | 组合系统必然排除的可能性；炼金术拉丁语原指无法再提取任何东西的残渣。 |
| ex-sistence / place excentrique | 外存在 / 离心的位置 | 无意识主体的位置在既成 ego 之外；保留 *ex-* 所强调的外部站位。 |
| forclusion / refoulement / dénégation | 拒斥 / 压抑 / 否认 | 分别对应 *Verwerfung / Verdrängung / Verneinung*；三者都追随能指的移置，不得互换。 |
| lettre | 信 / 字母 | 第十七课持续利用 *lettre* 同时指书信、字母与文字学养的多义；须依句法保留双关，不一律压成“信件”。 |
| message / texte de la lettre | 讯息 / 信的文本 | 讯息可以已经抵达收件人，信却仍在主体间回路中流转；文本、意义与物质载体不具有同一命运。 |
| quotient / reste | 商 / 余项 | 两次窃信行动像运算一样产生“商”与未入账的“余项”；用数学措辞标示信在主体间位置中的结构作用。 |
| lettre en souffrance | 滞留待领的信 | 邮政用语兼有“受苦”意味；信的迂回延长时，受苦的是被它规定的主体。 |
| nullibiété / le réel est toujours à sa place | 无处性 / 实在总在其位置上 | 只有符号之物能从自身位置上缺失；实在无论如何翻覆都携带自身位置。 |
| purloined / détourné | 被转移路径的 / 遭迂回的 | *The Purloined Letter* 不只表示被偷，还强调被搁到一旁、延长或改变行程；同波德莱尔的 *volée* 区分。 |
| trois regards / trois places | 三次凝视 / 三个位置 | 三个逻辑时间分别由“什么也没看见”“看见前者没看见”“看见隐藏物仍暴露”支撑，人物会随信的位移接替位置。 |
| automaton / tychē | 自动发生 / 相遇 | 亚里士多德对偶然的两个术语；第十七课用前者标示能指规则的自动运作，用后者标示掷骰与运气的相遇。 |
| l'émetteur reçoit du récepteur son propre message sous une forme inversée | 发送者从接收者那里以颠倒形式收到自己的讯息 | 主体间沟通公式；《失窃的信》的回路把行动者自己的讯息从他者处返还。 |
| une lettre arrive toujours à destination | 一封信总会抵达它的目的地 | 第十七课的结论；“目的地”由能指行程及主体位置构成，不等于经验上每封邮件都准时送达。 |
| insistance répétitive / insistance significative | 重复性的坚持 / 意指性的坚持 | 第十八课把 *Wiederholungszwang* 从机械自动性重新表述为某种意义在能指链中的持续作用。 |
| désir de rien / innommable | 对无的欲望 / 不可命名者 | 欲望并非可列成驱力清单的既定对象；经符号来到存在之物尚不能命名，并由此同死亡发生回声。 |
| satisfaction substitutive / satisfaction symbolique | 替代满足 / 符号满足 | 前者可由受阻动物行为突然切换到另一回路说明；后者不能用“伪装”隐喻或行为回路直接解释。 |
| désir de dormir / moi vigilant | 睡眠欲望 / 保持警觉的自我 | 自我通过维持睡眠而介入梦；同一章也首次引入无意识幻想，显示自我、白日梦与幻想功能的复杂关系。 |
| fantasme inconscient / rêverie | 无意识幻想 / 白日梦 | 白日梦在自我层面提供想象性满足；无意识幻想则只能经由自我这一迂回被外推为“没有自我的白日梦”。 |
| déverbalisation | 去言语化 | 第十八课争论是否应撤回主体的现成言说；拉康主张把话语推进到辩证严密性的终点，而非退回无言经验。 |
| chosification | 物化 | 把慷慨、怯懦等概念当成固定事物的倾向；认真对待概念并不必然等于把概念物化。 |
| maître mort | 死去的主人 | 强迫症者等待主人死亡，却已异化于一个早已死去的主人；他的赠予与享用仍被这个位置占据。 |
| tables de présence | 临场表 | 借培根式术语说明：标示某物临场已经以其可能不在为背景，属于符号涌现而非实在的简单复制。 |
| manque d'être | 存在之匮乏 | 第十九课用来界定欲望主体的生存条件：主体不是缺少某个现成对象，而是在自身存在的匮乏中体验欲望。 |
| résistance de l'analyste | 精神分析家的阻抗 | 主体当下的言说并非需要被强推越过的客观障碍；把自己的抽象解释当作现成对象，才构成分析家的阻抗。 |
| nomination / faire passer le désir à l'existence | 命名 / 使欲望进入存在 | 解释不是指认一个已知性对象，而是通过言说使尚处于“存在之前”的欲望获得名字与存在。 |
| masochisme primordial / réaction thérapeutique négative | 原初受虐狂 / 负性治疗反应 | 不能还原为倒转的施虐狂或力比多平衡的受挫；它们标示生命并不凭自身趋向痊愈与进步。 |
| vie conjointe à la mort | 与死亡相结合的生命 | 《超越快乐原则》的生命图式：生命是被外部刺激拖入更长迂回的暂时肿胀，其根本趋势仍与死亡相结。 |
| symbolisme / Merken symbolisant | 象征作用 / 象征性标记 | 象征作用不由某个自然象征单独构成；它通过标记与组合使原本不存在之物进入世界，如骰子六面的符号秩序。 |
| autre (a) / Autre (A) | 他者（*a*）/ 大他者（A） | 第二十课明确区分：小写 *a* 是自我与镜像同类；大写 A 是言说所指向的真实主体位置，不可一律译为“他者”。 |
| mur du langage | 语言之墙 | 共同语言把自我与同类当作客体化对象；主体说话时指向大他者，却通常只经由墙面反射到小写 *a* 的影子。 |
| réponse inattendue / mensonge | 意外回答 / 谎言 | 真正回答不是刺激—反应系统中的可预期输出；主体能够说谎，是大他者具有主体间现实性的决定性证据。 |
| champ unifié / réduction au langage | 统一场 / 还原为语言 | 牛顿式句法使行星成为可计算的沉默现实；言说与语言由此区分，精神分析不应把人的回答同样封闭为统一场。 |
| miroir vide / absence du moi de l'analyste | 空镜 / 精神分析家自我的缺席 | 分析家不应作为“活镜”把自己的自我特征投射给主体；空镜是分析家培训所指向的理想极限。 |
| réduction du transfert | 转移的还原 | 并非消除一种情感实体，而是使主体逐步把自己经由语言之墙所指向的真实大他者关系承担起来。 |
| aliénation imaginaire du moi | 自我的想象性异化 | 把分析终点设为球形、整合、相信自我的主体，会把治疗推向与偏执狂同质的异化；精神分裂症被明确排除于这一同一机制之外。 |
| ego central / ego libidinal / internal saboteur | 中央自我 / 力比多自我 / 内部破坏者 | 费尔贝恩的内在心理图式把自我实体化并裂分为三个组织；第二十一课借此批判对象关系论对主体辩证法的封闭。 |
| exciting object / rejecting object | 激发性对象 / 拒绝性对象 | 前者被规定为激起欲望的对象，后者却已暗含对象对主体的拒绝与不承认；两项其实不在同一逻辑层面。 |
| object-seeking / pleasure-seeking | 寻求对象 / 寻求快乐 | 费尔贝恩以力比多“寻求对象”反对弗洛伊德式“寻求快乐”；拉康指出其论据暗中以爱替换了力比多。 |
| internalisation / introjection | 内化 / 内摄 | 坏对象因需被主体掌控而内化；若分析被简化为由分析家的“好自我”纠正坏内摄，分析家的想象世界便成为正常性尺度。 |
| relation duelle / rapport ternaire | 二元关系 / 三元关系 | 想象性对象关系若只以分析家自我为模型，便停留在二元层面；象征秩序则通过另一个主体、命名和法则引入根本的三元关系。 |
| présence / absence / nomination | 在场 / 缺席 / 命名 | 对象的在场只有以缺席为背景并经命名才能在缺席中得到维持；它有别于对象的物质现实性。 |
| irrationnel / incommensurable | 无理的 / 不可公度的 | 第二十一课借正方形对角线与《美诺篇》说明：无理数激活想象性构形，而问题的解依赖先行的符号操作。 |
| capitonnage des images | 意象的缝合固定 | 意象在主体历史话语的某些点被固定并取得符号功能；它们的分析价值不来自孤立形象，而来自所嵌入的话语文本。 |
| sosie / identité imaginaire | 替身 / 想象性身份 | 两个不同实在对象可以在意象中显得相同；第二十一课以此预告《安菲特律翁》对自我幻象性质的展开。 |
| pacte symbolique du mariage / parole donnée | 婚姻的符号契约 / 已经许下的诺言 | 婚姻纽带超越个体的想象性变迁；诺言即使轻率许下，仍在无意识中延续其后果。 |
| femme comme objet d'échange / ordre androcentrique | 女人作为交换对象 / 男性中心秩序 | 第二十二课沿用列维-斯特劳斯的联盟论，说明女人在亲属交换中的不对称位置；这是对该历史理论框架的转述。 |
| fides | 信义 / 已经许下的诺言 | 《安菲特律翁》的拉丁语用法；拉康强调它不是内在信念，而是主体对言说契约的承担。 |
| miraginaire | 镜幻性的 | 拉康把 *mirage* 与 *imaginaire* 压合的造词；指自我及其同类在镜像幻象中彼此反射的性质。 |
| mort imaginaire / mortification de l'obsédé | 想象性的死亡 / 强迫症者的自我僵死 | 强迫症者紧附自我、把自己的欲望呈现为另一个人的欲望，并由此在主人和享用对象面前取消自身。 |
| objet du désir / objet d'amour | 欲望对象 / 爱情对象 | 第二十二课指出两者在强迫症关系中自动分裂；若只在二元关系中加强自我，这种分裂反而会被延续。 |
| Penisneid / phallus | 阴茎嫉妒 / 阳具 | 阴茎嫉妒并非自然事实；在男性中心的象征秩序中，可见且可勃起的阴茎取得阳具的符号使用价值。 |
| langage / code | 语言 / 编码 | 语言中的能指多义且句子意义不能被词典穷尽；编码则原则上使每个符号单义，混淆只作为错误发生。 |
| message / communication | 讯息 / 传播 | 讯息可以在尚未抵达或未被理解时流转；传播强调发送与接收建立的关系，两者不自动等同于主体的言说。 |
| discours universel concret | 具体的普遍话语 | 自时间起源以来实际被说出并持续展开的全部话语；主体出生前就已被铭写、规定并安置在其中。 |
| langage constitué / parole constituante | 被构成的语言 / 构成性的言说 | 语言提供完整符号系统，言说则在具体主体间关系中奠基、揭示，并使一种含义通过行动获得有效性。 |
| monde de vérité sans subjectivité | 没有主体性的真理世界 | 数学符号的性质独立于具体主体而成立；主体性的历史进展则不断重新发现已寓于符号秩序中的真理。 |
| temps pour comprendre / hâte | 理解的时间 / 急迫 | 三囚犯诡辩中，主体经他人的不行动完成相互推理，并必须在真理因延迟而失效之前骤然作出断言。 |
| affirmation symbolique | 符号性断言 | “我是白色”不是静态演绎的末句，而是一次以行动见证自身真理、并由其时间位置保证有效性的言说。 |
| In principio erat verbum / logos | 起初有言词 / 逻各斯 | 第二十三课以 *verbum* 与 λόγος 追问开端处是语言还是言说；拉康借其歧义区分永恒符号法则与历史中的创造行动。 |
| création symbolique / réminiscence | 符号创造 / 回忆 | 柏拉图式想象序列把认识视为既有理念的倒影与回忆；符号行动则能承担过去并开启不可还原为倒影的新后果。 |
| sciences exactes / sciences conjecturales | 精确科学 / 猜想科学 | 前者以仪器和可复现位置把实在联结于句法；后者研究人的行动、相遇、空位及其组合，构成控制论的历史前提。 |
| hasard / déterminisme sans intention | 偶然 / 无意图的决定论 | “偶然”既可指没有意图，也可指服从法则；决定论断言一切有因，却不把意图放进原因。 |
| exactitude / rencontre de deux temps | 精确性 / 两种时间的相遇 | 自然之钟与人造钟必须对时；科学精确性不是实在的裸露属性，而由仪器、恒星日和校准关系建立。 |
| place vide / calcul des chances | 空位 / 机会计算 | 帕斯卡式概率计算并非给偶然附加实体原因，而是计算在一连串断句回合中，某物出现或不出现于位置的可能性。 |
| ordre binaire / présence-absence | 二元秩序 / 在场—缺席 | 0 与 1 把缺席和在场写入组合表，使符号序列能够独立于主体性在实在装置中运作。 |
| porte / circuit / feed-back | 门 / 回路 / 反馈 | 门把通行与闭合交叉成符号；电路的反复开闭产生振荡和断句节奏，使二元句法能够自行运行。 |
| disjonction / conjonction / addition modulo 2 | 析取 / 合取 / 模 2 加法 | 三类二元真值运算分别对应“或”“与”和恰有一个输入为 1；后者即异或式运算。 |
| incarnation transsubjective du symbole | 符号的跨主体具身 | 控制论使组合链在装置中运作；装置只是承载物，真正持续的是独立于个体主体的符号游戏。 |
| syntaxe avant la sémantique | 句法先于语义 | 机器先依符号次序和变换规则运作，具体语言的歧义、情感与人类含义随后进入；精确科学同样把实在联结于句法。 |
| bonne forme / cycloïde | 良好形式 / 摆线 | 圆作为格式塔属于想象性良好形式；滚动圆上一点画出的摆线却是符号操作的发现，并支撑等时摆钟。 |
| du non-être à l'être | 从非存在到存在 | 被压抑之物因未获表达而尚不存在，却坚持要求在承认中进入存在；言说使这种过渡成为可能。 |
| davar / memra / va’omer | *davar* / *memra* / *va’omer* | 第二十五课的语文学争论不把三者简化成同一个“言词”：*davar* 被追问其律法性、诱引性用法，阿拉姆语 *memra* 被提出为约翰 λόγος 的可能背景，*va’omer* 则是《创世记》“于是他说”的动词形式；正文保留转写。 |
| triangularité / ternarité | 三角性 / 三元性 | 三角性关乎三角形这一形式能否被机器识别，横跨想象性形式与符号关系；三元性则指 0、1 及其后继所构成的第三项功能，是控制论机器结构的符号原则。 |
| circuit A–S / circuit A–m–a–S | A–S 回路 / A–m–a–S 回路 | 前者标示大他者与主体之间的奠基性话语，后者标示经由自我与镜像他者的想象性迂回；神经症、阻抗与转移须依两条回路的交叉定位。 |
| Überlegenheit / Spiegelung | 优越性 / 映照 | 弗洛伊德关于转移神经症的原句：分析情境中的现实须凭一定的 *Überlegenheit* 被反复认作被遗忘过去的 *Spiegelung*；拉康提示前一词可能含文字游戏，后一词同镜像功能相联。 |
| l'instinct de mort comme masque de l'ordre symbolique | 死本能作为象征秩序的面具 | 第二十五课的收束公式：尚未在主体承认中实现的象征秩序是沉默的，却以坚持要求存在的方式在无意识中运作；这里保留底本的 *instinct*“本能”。 |
| La Pythie / Charmes | 《皮提亚》/《魅力集》 | 保罗·瓦莱里诗作及其所属诗集；第五、七、十四课引用同一末节，统一篇名与书名。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
