# 翻译术语对照表

适用范围：`S26 La topologie et le temps`

本表用于统一第二十六期研讨班译文。拓扑术语按本期图示与操作语境处理；第九、十课来宾发言中的弗洛伊德德语、逻辑学术语和自拟分类保留必要的外文，以免把不同机制压成同一中文词。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| La topologie et le temps | 拓扑学与时间 | 本期研讨班标题。*temps* 依句法也可译“时刻、时间阶段”，复数 *les temps* 不抹去其多重性。 |
| sujet | 主体 | 概念义固定译“主体”。 |
| sujet de l’inconscient / sujet effet du signifiant | 无意识主体／作为能指效果的主体 | 第十课把主体定位在说的行动、由一个能指为另一个能指所作的代表，以及链中的消隐之间。 |
| Autre / autre | 大他者／他者、另一个 | 大写 *A* 指能指场所；普通小写依句法处理。 |
| moi / moïque | 自我／自我的、自我层的 | 不同于 *sujet*“主体”。 |
| Ça / Es | 本我 | *Ça* 是法语对弗洛伊德德语 *Es* 的概念译名；第一课同时利用普通代词 *ça*“这／它”与大写 *Ça*“本我”的同音双关。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 改写成一般“意义”。 |
| dit / dire / parole | 所说／说、说的行动／言说 | 第九、十课反复区分已经说出的内容、说这一行动与言说。 |
| L’étourdit | 晕眩言说 | 拉康文本标题；第一、十课均用此译名，并保留法文。 |
| savoir inconscient | 无意识知识 | 无意识作为能指连接所构成的知识，不人格化为某人实际拥有的全知。 |
| sujet supposé savoir | 被假定知道的主体 | 第十课指主体同整条能指链相同化时的结构位置。 |
| parlêtre / être parlant | 说话之在 | 保留言说与存在的复合关系，不直接简化为“人”。 |
| objet petit (a) / objet (a) | 小对象 $a$ | 进入公式时写作 $a$；在孔洞、废余、幻想与主体坠落的位置中出现。 |
| Nom-du-Père / signifiant du Nom du Père | 父之名／父之名能指 | 第九课讨论其并入、隐喻化及向实在界坠落的不同命运。 |
| métaphore paternelle | 父亲隐喻 | 同父之名能指有关，不泛化成普通父亲形象。 |
| réel / le Réel | 实在／实在界 | 指三界之一时用“实在界”；普通句法依语境用“实在”。 |
| symbolique / le Symbolique | 象征的／象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 名词化且指三界之一时译“想象界”。 |
| R.S.I. | R.S.I.／实在界—象征界—想象界 | 正文保留缩写；需要展开时依原字母顺序说明。 |
| jouissance | 享乐 | 与普通快乐、满足区分。 |
| rapport sexuel / il n’y a pas de rapport sexuel | 性关系／性关系不存在 | *rapport* 保留“关系”义，不补写成自然互补的“两性关系”。 |
| phallus / signifiant phallique / fonction phallique | 阳具／阳具能指／阳具功能 | 与解剖学阴茎区分；正文大写 *Phallus* 时仍按概念译“阳具”。 |
| troisième sexe | 第三种性别 | 第四至七课的试探性命题；保留拉康随后的撤回、迟疑与自我修正。 |
| possible / ce qui cesse de s’écrire | 可能者／停止被书写的东西 | 第四课沿拉康模态公式使用；不改写成一般概率。 |
| initiation / anti-initiation | 入门仪式／反入门仪式 | 第五课称精神分析为反入门仪式，并把入门同升向阳具联系起来。 |
| bande de Mœbius / surface de Mœbius | 莫比乌斯带／莫比乌斯曲面 | 依原文名词区分；不写成普通“环”。 |
| bande triple / bande à trois / bande à un | 三重带／三重带／单重带 | 第一课环面与莫比乌斯带的图示用语。 |
| bande enveloppante | 包覆带 | 第一课以虚线标出、用于覆盖三重带的带子。 |
| doublure | 衬带／替身 | 第一课的拓扑结构译“衬带”；第四课 *doublure d’Ève* 取普通“替身”义，不强行统一。 |
| tore | 环面 | 不译作普通圆环；第九课“环面翻转”与第十课曲面操作均沿用。 |
| rond de ficelle / cercle | 绳圈／圆环 | 前者强调可操作的绳圈，后者依图示译圆环。 |
| nœud borroméen / chaîne borroméenne | 博罗米结／博罗米链 | 依原文 *nœud / chaîne* 区分。 |
| borroméen généralisé | 广义博罗米结构 | 指切去指定数量圆环后，其余圆环全部自由的推广结构；作形容词时可译“呈博罗米式”。 |
| bande de Slade | 斯莱德带 | 一种三股编带；本期第六课沿用上一期名称，保留专名 *Slade*。 |
| homotopie / homotopique | 同伦／同伦的 | 第八课指同一根绳子可经自身穿越而完成的连续变形。 |
| consistance | 实存性 | 指绳圈、曲面或结构作为一项得以自持的性质；不与普通“观点一致性”混同。 |
| ex-sistence / ex-sister / ex-siste | 外—存在／外—立 | 第十课按拆写保留“在链以外、却相对于链而存在”的结构。 |
| surmoi | 超我 | 第九课来宾发言进一步区分三种超我形态。 |
| surmoi médusant / fascinant / sidérant | 美杜莎式超我／迷摄性超我／震慑性超我 | 分别对应不许说出一个词、凝视的局部迷摄，以及 *Che vuoi?* 所造成的彻底惊愕。 |
| censure / censeur | 审查／审查者 | 《梦的解析》语境；第九课把审查者同君主及“不上当者”相联系。 |
| Che vuoi ? | 你要什么？ | 欲望图中的问题公式；保留意大利语并附中文。 |
| signifiant de haute valeur / haute intensité psychique | 具有高心理价值／高心理强度的能指 | 第九课转录在 *valeur* 与 *intensité* 之间变换；译文保留两种限定，不擅自统一底本。 |
| sidération / sidérant / Verblüffung | 震慑／震慑性的／惊愕 | 第九课围绕雷鸣、闪电、哑口无言与“震慑—照亮”展开；*Verblüffung* 首次出现保留德文。 |
| persévération / persévérance | 持续重复／坚忍 | 第九课有意从第二次说出的重复固着，推进到第三次说出时承担欲望的坚忍；二词不得合并。 |
| incorporation / introjection | 并入／内摄 | 前者涉及对象、言说、凝视及父亲的并入；后者在《否定》文本讨论中另译“内摄”。 |
| suppléance / suppléer | 替补／起替补作用 | 指某物在结构性欠缺的位置上代行功能，并不表示把欠缺补成完整；第四、九、十课统一如此处理。 |
| Versagung | 满足的被拒与落空 | 第九课同时涉及大他者不予象征承认、赠礼缺失及满足未发生；保留德文，以免压成一般主观“受挫感”。 |
| Bejahung / Ausstossung | 肯定／驱逐 | 《否定》及原初并入语境中的一对操作。 |
| Verwerfung / forclusion | 拒斥／拒斥 | 同 *Verdrängung*“压抑”严格区分。 |
| Verdrängung / refoulement / refoulement originaire | 压抑／压抑／原初压抑 | 第九课区分拒斥与压抑，并把各次并入的命运同原初压抑联系起来。 |
| Werfen / Werfung | 抛出／抛出操作 | 第九课用来讨论一种未必排除可逆返回的彻底排除；转录同段另有非常规拼法 *Verfen*，正文已注明证据边界。 |
| aphanisis / fading | 消隐／主体淡出 | 第十课把琼斯的“欲望消隐”移到主体层面，并区分重复中的消隐与幻想中的遮蔽。 |
| surface de Riemann | 黎曼曲面 | 第十课以复解析多值函数的层页结构类比主体与能指链。 |
| feuillet / feuilletage / espace feuilleté | 层页／层页化／层页空间 | 保留上下叠置与多值对应；不把它直接实体化为主体的固定层级。 |
| zéro de Frege / suture | 弗雷格的零／缝合 | 第十课借零既指不可能对象又在数列中计作一，说明主体被排除却仍由能指代表。 |
| machine de Turing / bande-machine | 图灵机器／机器带 | 第十课把读写头、机器状态与无扭转的线性带，同莫比乌斯带、结和链对照。 |
| bande bipartite / carrefour de bande | 二分带／带交叉口 | 瓦普罗绘图中使用的曲面操作名称。 |
| compacité / faille compacte | 紧致性／紧致裂口 | 拓扑学术语；不按日常词义译作“密实”。 |
| pas-tous | 非全 | 第十课谓词演算与模型理论语境；不改写成简单的“并非每个人”。 |
| nodalité | 结性 | 指链与结所显示、不能由观看或无限增殖模型穷尽的结构效应。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”；本期第九课来宾发言明确将它同 *topologie* 对举，用来批评“情感出现以前必已在某处”的位置设想。 |
