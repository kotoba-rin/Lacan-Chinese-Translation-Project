# 翻译术语对照表

适用范围：`S24 L’insu que sait de l’une-bévue s’aile à mourre`

本表用于统一第二十四期研讨班译文。正文以“统一中文译名”为准；标题音链、新造词及书写变形保留必要的法文或德文，以免把拉康依靠语音、字母与切分推进的论证压平。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| L’insu que sait de l’une-bévue s’aile à mourre | 保留法文标题 | 整个标题以连续音链牵出 *l’insuccès*、*Unbewußt / une-bévue*、*c’est l’amour* 与 *la mourre*；不以一个流畅汉译替代其多重切分。 |
| L’insu que sait | 知道着的不知情 | 字面把“不知情／未被知道的东西”同“知道”叠合，并在语音上牵出 *l’insuccès*“失败”。 |
| Unbewußt / une-bévue / l’Une-bévue | 无意识／一桩—失误 | *une-bévue* 是拉康对德语 *Unbewußt* 的近音重译；连字符和“一桩”保留偶发失误的单次性，不把它重新等同于一般“无意识”。 |
| inconscient / inconscience / conscience | 无意识／无知觉、不省人事／意识 | 第一课明确利用 *inconscient* 在理论概念与失去意识之间的歧义；依句法区分。 |
| la mourre | 猜指游戏；标题中保留法文 | 双方同时伸指并猜总数的游戏；标题中还同 *l’amour*“爱”发生语音勾连。 |
| lalangue | *lalangue* | 拉康把冠词与 *langue* 连写的新造词；正文保留法文，不同一般“语言”合并。 |
| parlêtre / parle-être | 说话之在 | 保留言说与存在的复合关系，不直接简化为“人”。 |
| parêtre / par-est / parest | 似—在 | 把 *paraître*“显现”改写为 *par-être / par-est*，让显现同存在在书写中错接。 |
| semblant / s’embler / s’emblant | 假象／显似 | 普通概念义用“假象”；第八课拆写 *s’embler* 时用“显似”并保留法文。 |
| savoir y faire / savoir-faire | 懂得如何在其中周旋／会做、技艺 | 前者强调懂得如何同症状等对象打交道，不能并入一般技能意义的 *savoir-faire*。 |
| langage / métalangage / métalangue | 语言／元语言／元语 | “元语言并不存在”；*métalangue* 则在第八、十二课指一门新语言或语言之间的翻译性操作。 |
| linguisterie / polylinguisterie | 语言学术／多重语言学术 | 拉康用来标记自己借精神分析支撑的语言工作；正文首次出现保留法文。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 译成一般“意义”。 |
| sens / signification | 意义／意指 | 第九课明确对举：充实言说“充满意义”，空洞言说“只有意指”；两词不得机械合并。 |
| sujet / sujet barré | 主体／被划杠主体 | 被划杠主体写作 $\bar S$。 |
| clivage / division | 劈裂／分裂 | 第六课在同一句中对举二者：*clivage* 是用来避开 *division* 的操作性切开，不得机械合并为同一个“分裂”。 |
| Autre / grand Autre / Autre barré | 大他者／被划杠大他者 | 普通小写 *autre* 依句法译“他者／另一个”；被划杠大他者写作 $\not A$。 |
| sujet supposé savoir | 被假定知道的主体 | 正性转移中的归属位置；不等于分析家实际拥有知识。 |
| sujet supposé entendre | 被假定聆听的主体 | 第三课来宾发言中由音乐作品构成、把听者指派到回答位置的大他者。 |
| objet petit (a) / objet (a) | 小对象 $a$ | 进入公式时写作 $a$；同主体分裂、分离及分析家占据的假象位置有关。 |
| trait unaire | 一元特征 | “全体”唯一共有的特征；同“一”的逻辑相连。 |
| S(A barré) | $S(\not A)$ | 大他者中欠缺的能指；不同于单独的被划杠大他者 $\not A$。 |
| S barré poinçon D | $\bar S \lozenge D$ | 被划杠主体同要求的菱形公式；第六课亦称主体淡出的位置。 |
| réel / le Réel | 实在／实在界 | 指三界之一时用“实在界”；其他语境依句法译“实在”。 |
| symbolique / le Symbolique | 象征的／象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 名词化且指三界之一时译“想象界”。 |
| nœud borroméen / chaîne borroméenne | 博罗米结／博罗米链 | 依原文 *nœud / chaîne* 区分；任一环断开后其余各环全部分离。 |
| rond de ficelle / tore | 绳圈／环面 | *tore* 不译作普通圆环；本期反复以环面翻转、打孔和链结展开身体与三界结构。 |
| bande de Mœbius / bouteille de Klein | 莫比乌斯带／克莱因瓶 | 依曲面类型固定译名，不改写成一般“环”。 |
| tresse / quatresse | 辫式／四股辫 | *quatresse* 是由 *quatre* 与 *tresse* 构成的新造词；保留四股编织结构。 |
| nodal | 结性的 | 指博罗米结中由环面功能支配的“结性”因素，不译作病理或解剖意义的“结节”。 |
| consistance / ex-sistence / trou | 实存性／外—存在／洞 | 三项须区分：作为一环得以自持、从外部相对于某物而在，以及结构中的孔洞。 |
| la passe / passant / passeur | 渡越／渡越者／传递者 | 同时涉及分析经验及学派制度；普通 *passer* 仍按句法译“经过／通过”。 |
| jury d’agrément | 认可评审团 | 接收传递者见证并决定是否认可渡越的制度性位置。 |
| désêtre / manque à être | 去存在／存在之缺 | 第六课严格区分主体的去存在位置与在 $S(\not A)$ 中共同经历的存在之缺。 |
| aphanisis / fading | 消隐／主体淡出 | 第六课把主体消隐同精神病位置、幻想公式及去存在区分。 |
| Urverdrängung / refoulement originaire | 原初压抑 | $S_2$ 被定位为原初压抑的能指；不与后续压抑机械合并。 |
| Verneinung / Bejahung | 否定／肯定 | 第十一课沿弗洛伊德《否定》说明：写下否定以某种先行肯定为前提。 |
| forclusion | 拒斥 | 指根本排除机制；与一般“排除”及 *refoulement*“压抑”区分。 |
| sinthome / symptôme | 圣状／症状 | “圣状”标记 *sinthome* 的古拼写与拉康式重写；普通 *symptôme* 固定译“症状”，两者不互换。 |
| discours analytique / discours de l’analyste | 分析话语／分析家话语 | 泛指精神分析的言说结构时用“分析话语”；明确指四话语公式时用“分析家话语”。 |
| articuler / articulation | 依句法译“表述／阐述／构成／衔接” | 言说、理论或命题用“表述／阐述”，结构的组成方式用“构成”，只有明确的连接关系才用“衔接”；不机械统一。 |
| parole pleine / parole vide | 充实言说／空洞言说 | 第九课分别界定为充满 *sens* 与只有 *signification*，不是内容多少的量化区别。 |
| rapport sexuel / il n’y a pas de rapport sexuel | 性关系／性关系并不存在 | 指不可被写成关系公式，不补写成自然互补的“两性关系”。 |
| jouissance / plus-de-jouir / jouissance de l’Autre | 享乐／剩余享乐／大他者的享乐 | 与 *plaisir*“快乐／快感”区分。 |
| tout / pas-tout / pas-toutes | 全体／非全／并非全体 | *pas-tout* 标记全称量词无法封闭，不表示从一个完整集合中简单排除部分成员。 |
| possible / contingent / nécessaire / impossible | 可能／偶然／必然／不可能 | 保留本期模态书写：可能“停止被书写”，不可能“不停地不被书写”。 |
| L’étourdit | 晕眩言说 | 拉康文章标题；第八课保留法文。 |
| Bozef | 博泽夫 | 第六、七课来宾发言所用的假定名称，用来承载绝对知识、异端者及渡越位置的拓扑推演。 |
| varité / vérité / variété | *varité*／真理／多样性 | 第十课把 *vérité* 与吞掉一个 *é* 的 *variété* 压缩成新词 *varité*；正文保留法文。 |
| élangue / s’élonger | *élangue*／拉长 | 第十课把 *é.l.a.n.g.u.e* 同语言在互译中的拉长相连；不并回一般 *langue*。 |
| famillionnaire | *famillionnaire* | *familier* 与 *millionnaire* 的缩合造词；保留法文以显示机智语的揉皱和操作效果。 |
| pouate / pouate assez | “噗哇特”／还不够噗哇特 | *poète*“诗人”的变音，并同 *pas poète assez*“不够诗人”叠合；第十二课借此改写亲缘关系。 |
| automatisme mental / écho de la pensée | 精神自动症／思想回声 | 第十二课克莱朗博语境；拉康把它从纯粹病理标签重新放回多语言与自言自语的滑动中。 |
