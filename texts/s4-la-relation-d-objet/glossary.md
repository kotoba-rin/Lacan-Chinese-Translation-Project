# 翻译术语对照表

适用范围：`S4 La relation d'objet（1956—1957）`

本表以第四期研讨班的具体语境为准。其他研讨班的译名只作比较；本卷围绕 *objet* 展开论证，必须保留一般“对象”、理论名称“客体关系”以及 *objectivité / objectalité* 的层次差别。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| relation d'objet / relation objectale | 客体关系 | 作为理论名称及本研讨班标题统一译“客体关系”；不因此把正文中一般的 *objet* 全部译作“客体”。 |
| objet | 对象 | 一般概念统一译“对象”；固定理论名称、复合术语或刻意讨论 *objectalité* 时依条目处理。 |
| sujet | 主体 | 概念义统一译“主体”；普通“主题、议题”义按语境处理。 |
| moi | 自我 | 指精神分析概念时译“自我”；普通重读代词义按句法处理。 |
| Autre / grand Autre | 大他者 | 大写 A 并承担象征位置时译“大他者”；与普通 *autre*“他者／别人”区分。 |
| signifiant | 能指 | 与 *signifié*“所指”区分。 |
| symbolique / imaginaire / réel | 象征界／象征的 / 想象界／想象的 / 实在界／实在的 | 依名词或形容词用法选择；普通“真实、现实”义不机械译作“实在”。 |
| relation imaginaire | 想象关系 | 第一课指 *a ↔ a′* 轴上自我与相似者之间的关系。 |
| relation duelle | 二元关系 | 第一课批判把主体—对象关系物化为无裂隙的两项关系。 |
| méconnaissance | 误认 | 指结构性的错认，不弱化为一般“不知道”。 |
| stade du miroir / relation en miroir | 镜像阶段 / 镜像关系 | 镜像阶段不只是儿童认出自身形象的历史时点，还关涉内在张力、形象统一与异化认同之间的距离。 |
| principe de plaisir / principe de réalité | 快乐原则 / 现实原则 | 二者相互蕴含，却仍由一道裂隙分开；与 *jouissance*“享乐”区分。 |
| objet perdu / retrouver l'objet | 失落对象 / 重新找到对象 | 第一课保留 *perdu / retrouver / retrouvaille* 的词语链，以显示寻找从一开始就是不可能的重复；其他研讨班“丧失的对象”只作比较。 |
| objet génital / relation d'objet génitale | 生殖器对象 / 生殖器期客体关系 | 与前生殖器期对象和关系相对；不把它预设成自然适配的完满对象。 |
| prégénital / génital | 前生殖器期的 / 生殖器期的 | 指人物类别时译“前生殖器期者／生殖器期者”。 |
| objet significatif | 重要对象 | 第一课同时追问 *significatif*“重要”未经解释、缺少区分的问题，不擅自改成“能指性对象”。 |
| moi auxiliaire | 辅助自我 | 指承接最初对象之情感价值、借移置或象征化维持客体关系的替代对象。 |
| objectivité / objectalité | 客观性 / 客体性 | 第一课明确批判把现实建构的“客观性”同完满客体关系意义上的“客体性”混为一谈。 |
| pulsion / instinct | 驱力 / 本能 | 原文明确使用 *pulsion* 时译“驱力”；*instinct / instinctuel* 译“本能／本能的”，不机械合并。 |
| phobie / objet phobique | 恐怖症 / 恐怖症对象 | 恐怖症对象被构成为抵御焦虑的前哨，不能直接等同于给对象染色的原始恐惧。 |
| fétiche / fétichisme | 恋物 / 恋物癖 | 临床及性倒错语境使用；马克思主义 *fétichisme de la marchandise* 译“商品拜物教”，保留相近而非同义的差别。 |
| angoisse de castration | 阉割焦虑 | 第一课把恐怖症对象与恋物都放在这一焦虑背景上，同时要求区分二者的功能。 |
| objet-écran / souvenir-écran | 屏幕对象 / 屏幕记忆 | 保留 *écran* 的词语呼应；屏幕既遮蔽，也参与主体过去与现实的构成。 |
| objet halluciné | 幻觉对象 | 第二课指初级欲望系统在令人焦虑的现实背景上产生的对象；与分析实践中被缩减为“实在”的对象观对照。 |
| système primaire / système secondaire | 初级系统 / 次级系统 | 弗洛伊德心理装置的两种运作秩序；不改写成一般的先后阶段。 |
| réciprocité imaginaire | 想象的相互性 | 主体同时占据对象关系各项的位置，并以对对象的认同为根底。 |
| petit autre / alter ego | 小他者 / 另一个自我 | 小他者处在想象轴线上，是主体的分身；与象征位置的大他者区分。 |
| phallus / pénis | 阳具 / 阴茎 | 阳具首先作为想象功能中的特权对象出现；阴茎则是具有实在功能坐标的器官，二者不得混同。 |
| phallus imaginaire / phallicisme / période phallique | 想象阳具 / 阳具主义 / 阳具期 | 第二课由阳具主义争论引出想象界范畴；后文若出现象征阳具，必须另行区分。 |
| Wirklichkeit / Wirkung | 现实效力（Wirklichkeit）/ 作用（Wirkung） | 第二课借德语词形强调“现实”作为能够产生效果的机制；*Wirklichkeit symbolique* 译“象征的现实效力”，不还原为底层有机物质。 |
| Stoff | 原初物质 | 第二课批判把原初物质、冲动或流动同分析现实中由冲突和结构化产生的效力混为一谈；首次出现保留德文。 |
| organicisme / postulat organiciste | 有机主义 / 有机主义公设 | 指把分析效果最终安置在某种有机现实中的保证性假设；拉康在此把它称作分析视角中的迷信残余。 |
| objet transitionnel / phénomène transitionnel | 过渡性对象 / 过渡现象 | 温尼科特概念；对象既不能归到幻觉一侧，也不能归到实在对象一侧，拉康在本课把它命名为想象对象。 |
| manque de l'objet | 对象欠缺 | 不是消极的空无，而是主体同世界之关系的动力；必须分别考察欠缺、对象与施事者所属的象征、想象、实在层次。 |
| castration | 阉割 | 对象欠缺三分之一：欠缺属于象征性债务，所涉及的对象是想象阳具。 |
| frustration | 挫折 | 对象欠缺三分之一：欠缺是想象损害，所欠缺的是实在对象；与一般不快或现实困难区分。 |
| privation | 剥夺 | 对象欠缺三分之一：欠缺是实在的洞，所欠缺的是由法则规定“本应在其位置上”的象征对象。 |
| dam imaginaire | 想象损害 | 第二课用来规定挫折的欠缺性质；*dam* 保留伤害、损失义，不译作象征性债务。 |
| dette symbolique | 象征性债务 | 第二课把阉割归入这一范畴；法则、制裁与惩罚共同规定其象征结构。 |
| agent | 施事者 | S4 对象欠缺三分中的第三维度；指造成挫折、剥夺或阉割的作用位置，不预先等同于经验中的某个个人。 |
| image du corps | 身体意象 | 第三课讨论多尔托的临床材料；它不是对象，本身也不能成为对象，但可在分析对话中作为能指发挥作用。 |
| résidu | 余项 | 科学解释未能吸收的剩余；第三课以儿童对狮子的恐惧及恋物种类的有限性为例，要求不要把余项偷偷抹去。 |
| libido | 力比多 | 像能量一样是建立异质表现之共同尺度的抽象概念，不固定于某个化学或物质载体。 |
| libido du moi / Ich-Libido | 自我力比多 | 作为蓄水池及客体力比多的构成来源；与客体力比多具有共同尺度而不取消结构差异。 |
| libido d'objet / Objektlibido | 客体力比多 | 指向对象的力比多；固定复合术语沿用“客体”，不改变一般 *objet* 译“对象”的规则。 |
| Es / ça | 本我 | 第三课把本我界定为主体中能够成为“我”的东西；它已经像能指一样得到组织和衔接，不是未经结构的原始自然。 |
| signifié | 所指 | 与能指区分；分析现象要求承认所指在能指之下、能指在所指之上的持续滑动。 |
| glissement du signifié sous le signifiant | 所指在能指之下的滑动 | 某物的能指可随时成为另一物的能指；主体可被分析把握的欲望与力比多都带着能指印记。 |
| Lust | 快乐／想要 | 第三课保留德语双义：快乐原则既指向回归静止，又同“想要”、欲望的勃起相联系。 |
| demand | 要求 | 第三课保留英语；同时唤起食欲、索求与要求的原始表达，仍受能指法则标记。 |
| instinct de mort | 死亡本能 | 原文确切使用 *instinct*，故不静默替换成 *pulsion de mort*“死亡驱力”；指能指以取消亲历整体及死亡界限为背景的运作。 |
| théories sexuelles infantiles | 儿童性理论 | 儿童对性交和生殖的误解会给两性关系史留下印记；不预设男女之间有自然的预定和谐。 |
| phase phallique | 阳具期 | 俄狄浦斯充分发展前的第一次生殖器成熟；想象层面只有勃起阳具这一种原始表象，与阉割构成二择。 |
| ordre symbolique | 象征秩序 | 不是孤立主体从自身产生的秩序；第三课追问挫折如何把主体引入其中。 |
| auto-érotisme | 自体性欲 | 第四课保留弗洛伊德意义：尚未构成他者、也不必预设自我与非我的区分；不等于主体同外部乳房毫无实在关系。 |
| primary love | 原初之爱 | 爱丽丝与迈克尔·巴林特的术语；他们设想母亲与孩子的需要完美互补，拉康以临床中的根本不相合加以批判。 |
| position dépressive | 抑郁位置 | 克莱因术语；第四课把重点从“整体母亲对碎片对象”的简单对立移到主体明确表达的“在场—缺席”结构。 |
| présence-absence | 在场—缺席 | 儿童在母亲缺席时呼唤她，在她在场时又以同一发音语域将她推开；这一节拍是象征秩序的开端和条件，但单凭正负对立尚不足以构成完整序列。 |
| jeu de gage | 罚物游戏 | 一种以物品作“罚物”、由输者接受指定任务的儿童游戏；不是金融意义上的抵押。 |
| mère symbolique / mère réelle | 象征母亲 / 实在母亲 | 母亲依呼唤在场或缺席时处于象征施事者位置；当她只按自身意愿回应时变成实在力量。 |
| objet de satisfaction / objet de don | 满足对象 / 赠礼对象 | 母亲成为实在力量以后，乳房等对象不只满足需要，还象征母亲力量的有利赠予。 |
| toute-puissance maternelle | 母亲全能 | 第四课把原初全能归于能够给予或拒绝一切的母亲，而不是归于孩子自己的思想全能。 |
| mère-enfant-phallus | 母亲—孩子—阳具 | 孩子作为实在可象征母亲的想象阳具需要；父亲功能维持三项间距，使孩子不必以自身填补它。 |
| mère symbolique / enfant réel / phallus imaginaire | 象征母亲 / 实在孩子 / 想象阳具 | 第四课用于说明同一关系中三个不同层次；三者不能压缩成自然互补的母子二元组。 |
| aphallicisme / a-pénienne | 无阳具状态 / 无阴茎的 | 前者标示孩子发现自身不具有阳具的状态，后者是观察中对女孩缺少阴茎的说法；不把阳具与阴茎混同。 |
| objet fétiche | 恋物对象 | 第四课结尾预告其作为前俄狄浦斯期客体关系的一种解决方式；与一般“物神”及商品拜物教区分。 |
| anaclitique / Anlehnung | 依托型 / 倚靠、支撑 | 弗洛伊德的两种对象选择之一；第五课强调德语 *Anlehnung* 所含“倚靠、支撑”义，并批判把成人的依托型关系简单当作婴儿依赖的残存。 |
| narcissique | 自恋型 | 与依托型相对；对象以主体自身的自恋性意象为模型，但不能因此把两种关系压缩为单纯的主动与被动。 |
| oblatif | 奉献型 | 第五课用另一套分析词汇反讽性地描述弗洛伊德赋予自恋者的“去爱之需要”；不等同于无私奉献的道德评价。 |
| passage à l'acte | 诉诸行动 | 指主体从象征性编排中跃出、在行动中实现某种短暂汇聚的时刻；第五课的窥视行为必须同一般“付诸实践”区分。 |
| mère phallique / mère aphallique | 阳具母亲 / 无阳具母亲 | 第五课病例批判分析家把铠甲男人解释为“阳具母亲”，并指出治疗把主体推向观察女人之无阳具状态。 |
| bundling | 同床禁触习俗 | 一种以同床而不发生身体接触为条件的款待和求偶习俗；第五课借此讽刺把分析情境还原为两具真实身体间距离调节的技术。 |
| homosexualité féminine | 女性同性恋 | 第六课把它作为女性主体之象征道路、停顿与对象选择的典范问题；不把临床结构化讨论压缩为现代身份标签。 |
| assomption phallique | 阳具性承担 | 指主体在象征关系中承担阳具位置或功能；不是简单承认自己是否具有阴茎。 |
| après-coup | 事后 | 早期经验只有在后来的象征事件中才取得新的意义和效力；不弱化为一般的“后来”。 |
| phallophore | 阳具携带者 / 阳具携带的 | 指在象征回路中承担或代表阳具位置的要素；第六课特指完整家庭中父亲、继父或兄长等男性项。 |
| don | 赠礼 | 挫折辩证法中来自大他者之物；要求得到满足时，对象退居次位，重要的是赠予者的爱及其背后的象征链条。 |
| niederkommen | 坠下 / 分娩、降生 | 第六课保留弗洛伊德病例的德语双关：少女从桥上“坠下”，同时以象征行动实现孩子的“降生”。 |
| amour courtois | 宫廷爱情 | 把欠缺制度化为侍奉、克制与象征参照的爱情形式；第五、六课借它说明理想爱情并不以对象满足为目标。 |
| « la perversion est le négatif de la névrose » | “倒错是神经症的负片” | 保留摄影“负片”的结构比喻；第七课反对把它简化成神经症中被压抑之物在倒错里直接暴露。 |
| pulsion partielle / pulsion génitale | 部分驱力 / 生殖器驱力 | 第七课批判把倒错理解成未经俄狄浦斯加工、原封不动残存的部分驱力。 |
| « On bat un enfant » / « Ein Kind wird geschlagen » | “一个孩子被打” | 弗洛伊德击打幻想的终极公式；同“父亲打我憎恨的孩子”和“我被父亲打”两个重构阶段区分。 |
| désubjectivation / objectivation | 去主体化 / 对象化 | 倒错幻想把完整主体间场景缩减成静止图像和纯粹能指，使主体只剩旁观之眼。 |
| symbolique du don | 赠礼的象征体系 | 阳具作为想象要素，把主体引入正负、在场缺席及交换的象征辩证法；不等同于生物学的生殖器成熟。 |
| frustration de l'amour / frustration de la jouissance | 爱的挫折 / 享乐的挫折 | 前者牵涉来自大他者的爱与主体间关系，后者至多重新发动欲望，不能单独产生现实或对象世界。 |
| Wiederholungszwang | 重复强迫 | 移情首先体现象征链条本身的坚持；即使梦在同分析家的想象关系中带有欺骗性，也仍可承载重复的无意识公式。 |
| donner ce qu'on n'a pas | 赠出自己没有的东西 | 第八课规定爱的赠礼：对象只作为爱的标志才有价值，最大的赠礼来自主体自身的欠缺，而非财物的充盈。 |
| potlatch | 夸富宴 | 原初赠礼交换的竞争性形式；主体通过献祭超出其所有物的东西，使赠礼获得象征价值。 |
| métonymie / métaphore | 转喻 / 隐喻 | 第八课以女同性恋病例说明倒错的转喻功能，以朵拉病例说明神经症和症状的隐喻功能；两者不得互换。 |
| phallus réel / phallus imaginaire / phallus symbolique | 实在阳具 / 想象阳具 / 象征阳具 | 第九课明确区分：恋物不是实在阴茎，而是把女人所没有的象征阳具作为缺席呈现；想象阳具则属于意象与认同层面。 |
| voile / rideau | 面纱 / 帷幕 | 缺席投射并被意象化的表面；恋物写在面纱上，既宣告对象位于彼岸，也随时面临帷幕掀起、幻觉崩溃。 |
| Verleugnung | 拒认 | 恋物关系中一面承认女人遭阉割、一面以恋物否认其阳具丧失的机制；保留德文以同 *Verneinung*“否定”和 *Verdrängung*“压抑”区分。 |
| splitting de l'ego | 自我分裂 | 恋物癖中阉割的承认与拒认并存；不把两项压缩成单一的错误信念。 |
| Glanz auf der Nase / glance at the nose | 鼻上的光泽 / 看一眼鼻子 | 弗洛伊德恋物病例中的德英跨语双关；说明历史链条可把被遗忘语言中的整句固定到恋物意象上。 |
| « le fétichisme est une défense contre l'homosexualité » | “恋物癖是抵御同性恋的一种防御” | 第九课以认同女人与认同想象阳具的两极摇摆说明二者间距极窄；不等同于现代性取向身份判断。 |
| transvestisme / transvestiste | 易装 / 易装者 | 第十课把易装规定为恋物位置的对称项：主体认同于面纱后缺少阳具、同时遮蔽这项缺失的对象。涉及固定临床分类时可依语境译“易装癖”。 |
| scoptophilie / se donner à voir | 窥视癖 / 让自己呈现给观看 | 不把窥视癖简化为“看／被看”的镜像对偶；反身或中间语态强调主体把某种不同于展示内容的东西交付给观看。 |
| identification / choix d'objet | 认同 / 对象选择 | 弗洛伊德坚持二者有别：对象位于主体一侧、成为认同支撑，不等同于对象作为被投注和爱恋的选择对象。 |
| introjection / incorporation / projection | 内摄 / 并入 / 投射 | 第十课反对把内摄与投射想成内外移动的简单对称；“并入”保留口腔隐喻，并可扩展到言语与早期超我的形成。 |
| Verliebtheit | 爱恋状态 | 弗洛伊德讨论对象占据自我或自我理想位置时的术语；首次或关键处保留德文，不泛化为普通“恋爱”。 |
| idéal du moi / moi idéal | 自我理想 / 理想自我 | 二者须严格区分；第十课先突出对象、面纱与自我理想之间的关系，后文依具体图式继续校准。 |
| Versagung | 废止／撤回承诺 | 第十一课强调其不等于简单需要受挫；词义可跨越“承诺”与“违背承诺”，指向象征关系中承诺的撤销。关键处保留德文。 |
| triade frustration-agression-régression | 挫折—攻击—退行三联式 | 拉康反对把三项当作不证自明的自然因果链；退行须界定为实在对象及把握活动对受挫象征要求的替代。 |
| anorexie mentale / se nourrir de rien | 神经性厌食 / 以无为食 | 儿童不是只在行动层面说“不”，而是在对象层面用作为象征对象的“无”倒转对母亲全能的依赖。 |
| phallus comme signifiant | 作为能指的阳具 | 阳具的优先地位不能由生理构造推导；它属于超越个体发展的象征秩序，并在想象辩证法中组织母亲的欲望。 |
| aphanisis | 消隐（欲望的消失） | 琼斯用以改写阉割情结的希腊语术语；指主体恐惧自身欲望熄灭。第十二课批判其预设过度反思和高度主体化的位置。 |
| père symbolique / père imaginaire / père réel | 象征父亲 / 想象父亲 / 实在父亲 | 三者不可混同：象征父亲是能指世界不可还原的构造性项；想象父亲承载攻击、认同与理想化；实在父亲以具体介入把法则和阉割带入游戏。 |
| Penisneid | 阴茎嫉羡 | 作为母亲—儿童关系的恒定参照项时保留德文；不把它同阳具作为能指的功能或单纯器官欠缺混为一谈。 |
| Verwerfung | 拒斥 | 把象征父亲能指排除在外的机制；同 *Verleugnung*“拒认”、*Verneinung*“否定”、*Verdrängung*“压抑”严格区分。 |
| Wiwimacher / fait-pipi | 撒尿器 | 小汉斯对自己、母亲、父亲及动物是否拥有阴茎的儿童用语；关键处保留德文，避免过早替换为理论术语“阳具”。 |
| père mort / père tué | 死去的父亲 / 遭到杀害的父亲 | 《图腾与禁忌》的神话建构把唯一父亲置于历史以前；杀父使父亲作为不可杀死的象征位置得到保存。 |
| angoisse / phobie | 焦虑 / 恐怖症 | 小汉斯病例中二者依次发生而不可混同：恐怖症对象在焦虑背景上承担组织和替补功能。 |
| Schutzbau / Vorbau | 防护构筑 / 前筑、门廊 | 第十六课借弗洛伊德的建筑比喻规定恐怖症：它是在危险点前方搭起的防护设施，也把主体限制在界限以内。关键处保留德文。 |
| Durcharbeitung / working through | 修通 | 指分析中沿能指链反复工作的过程；不弱化为一般“想通”或一次性解释。关键处可保留德文或英文。 |
| fonction du mythe / mythe individuel du névrosé | 神话的功能 / 神经症者的个体神话 | 神话不是对既定情感内容的装饰，而是在起点与终点的双重僵局之间，通过能指置换和中介重新组织所指。 |
| Krawall | 喧响、骚动 | 小汉斯用语；既涉及马倒下时的踩踏噪声，也可同母亲或安娜的喊叫发生能指联结。关键处保留德文，不预先固定为单一所指。 |
| Lumpf / Strumpf | Lumpf（粪团／排便用语）/ 长袜 | *Lumpf* 由 *Strumpf* 变形而来；它把粪便、黑色衣物、遮蔽屏幕与欠缺阳具的追问连在一起，不能直接等同于肛门排便。 |
| fomentation mythique | 神话酝酿 | 指幼儿性理论中能指星丛的繁生、重组和转化；它有自身动力与法则，不是虚浮的幻想附属物。 |
| ambocepteur | 双向接合器 | 第十八课用来概括马可套上、解开、联结并协调两端的性质；强调能指的语法中介功能，而非马固定代表某个人。 |
| métaphore paternelle / Nom-du-Père | 父亲隐喻 / 父之名 | 父亲能指替代母亲欲望的位置，由此引入阉割及象征中介；“父之名”是象征父亲的能指位置，不等同于经验父亲的姓名或人格。 |
| castration maternelle / castration paternelle | 母亲阉割 / 父亲阉割 | 前者以被母亲吞没、咬噬的想象危险出现；后者作为象征性替代，虽然同样可怕，却为主体提供能够展开的出口。 |
| logification | 逻辑化 | 第二十三课指神话要素经过充分游戏、交换和置换后形成可操作的整体；不是把临床材料外加成一套抽象形式逻辑。 |
| Verarbeitung | 加工 | 第二十四课指分析进程中神话化材料的动态组织与结晶；保留德文，并同 *Durcharbeitung / working through*“修通”区分。 |
| phallus dentatus | 有齿阳具 | 小汉斯病例中由石头浮现的凝固想象对象；男性进攻会撞伤在它上面，不能按惯常的 *vagina dentata*“有齿阴道”替换。 |
| sublimation | 升华 | 第二十四课借列奥纳多说明：它不是“本能去本能化”或对象变高尚，而牵涉大他者的自然化、想象认同以及以幻象关系容纳根本他异性。 |
| moi-isation | 自我化 | 第二十四课结尾的造词；同升华、心理学化和异化并列，指过程向想象自我组织，并开放主体在想象自我中遗忘自身位置的可能。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
