# 翻译术语对照表

适用范围：`S23 Le sinthome`

本表用于统一第二十三研讨班译文。正文以“统一中文译名”为准；拉康的新造词、同音双关及乔伊斯式拼写无法由单一汉译穷尽时，保留外文并在首次出现处说明。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Le sinthome / sinthome | *Le sinthome*／*sinthome* | 标题与核心新造词保留法文斜体；它既承接 *symptôme*，又牵连英语 *sin*、*saint homme*、*sint-home* 等音形游戏，不压平为单一中文词。 |
| symptôme | 症状 | 与本研讨班特意改写的 *sinthome* 区分；原文在论证中互换或比较时保留差别。 |
| sin / saint homme | 罪／圣人 | 第一课用来展开 *sinthome* 的英语和法语谐音。 |
| sinthome madaquin / madaquinisme | *sinthome madaquin*／阿奎那主义 | 把 *saint Thomas d’Aquin* 压缩进 *sinthome* 的造词；保留原形并说明构词。 |
| sint-home Rule / sinthome-roule | *sint-home Rule*／*sinthome-roule* | 分别牵连爱尔兰 *Home Rule* 与 *roule*“滚动”；不改写成普通政治术语或一般动作。 |
| réel / le Réel | 实在／实在界 | 指 RSI 三界之一时译“实在界”；作为不可能、无意义或“一截实在”时依句法译“实在”。 |
| réalité | 现实 | 与 *Réel*“实在”严格区分。 |
| symbolique / le Symbolique | 象征的／象征界 | 指 RSI 三界之一时用“象征界”。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 指 RSI 三界之一时用“想象界”。 |
| sens / orientation | 意义或方向／定向 | 第八、九课利用 *sens* 兼有“意义／方向”的歧义；拓扑学的 *orientation* 统一译“定向”。 |
| vrai / vérité | 真／真理 | *le vrai* 多译“真”；指话语中的真理功能时译“真理”，不与现实或实在混同。 |
| Echt | 真正的／本真的 | 保留德文；米勒编后说明释为 *authentique / véritable*，并联系海德格尔，但不直接等同于术语 *Eigentlichkeit*。 |
| énonciation / énoncé | 陈述行为／陈述内容 | 前者是说出一句话的行为及其主体位置，后者是所陈述出来的内容；不得都压平为“陈述”。 |
| nœud borroméen / chaîne borroméenne | 博罗米结／博罗米链 | 拉康反复强调所谓博罗米“结”严格说是一条链；依原文称呼保留两种说法。 |
| nœud bo | bo 结 | 拉康对 *borroméen* 的缩写，并同 *mont Neubo*“尼波山”形成音形游戏。 |
| chaîne / link / chaî-nœud | 链／*link*／链—结 | *chaî-nœud* 把 *chaîne* 与 *nœud* 压合，正文保留法文。 |
| nœud à trois / nœud de trèfle | 三叶结 | 指三交叉的 trefoil knot；与三环博罗米链区分。 |
| nœud à quatre / nœud à cinq | 四交叉结／五交叉结 | 数字指结图的最小交叉数，不是叶片数；分别包括本课所称利斯廷结与“拉康结”。 |
| rond de ficelle / cercle / anneau | 绳圈／圆／圆环 | 依实体绳圈、抽象圆与环形构件的语境区分。 |
| droite infinie / tore | 无限直线／环面 | 无限直线以一个点位于无限远处而同圆等价；*tore* 译“环面”。 |
| faux-trou / vrai trou | 假洞／真洞 | 两个圆共同围出的中间洞为“假洞”；由直线或圆穿过而得到证实时成为“真洞”。 |
| consistance | 实存性 | 指绳圈、身体或作品作为一体而自持的性质；与 *ex-sistence* 区分。 |
| ex-sistence / ex-sister | 外—存在／外—立 | 保留“在外部坚持、相对于他者而存在”的拆词结构。 |
| coinçage | 绞卡 | 指各环彼此卡住并由此维系或确定场域。 |
| lévogyre / dextrogyre | 左旋／右旋 | 用于结的手性与定向。 |
| parlêtre | 说话之在 | 保留言说与存在的复合关系，不简化为普通“人”。 |
| lalangue / lalanglaise | *lalangue*／*lalanglaise* | 拉康连写的新造词；后者把 *lalangue* 与 *anglaise*“英语的”叠合。 |
| parole / dire / dit / discours | 言说或话语／说／所说／话语 | 依作为发声的言说、作为事件的“说”、其结果“所说”及结构性话语加以区分。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 改写成一般“意义”。 |
| phonation / identité phonatoire | 发声／发音同一性 | 第五至七课讨论声音效果、书写与能指时使用。 |
| jouissance / plaisir | 享乐／快乐或快感 | 保留拉康概念中的享乐与快乐原则层面的 *plaisir* 之别。 |
| objet petit a / objet (a) | 小客体 a | 公式中写作 $a$；普通 *objet* 依语境译“客体／对象”。 |
| semblant / faire semblant de l’objet petit a | 假象／充当小客体 a 的假象 | 分析家以小客体 a 的形态占据分析话语的假象位置；不按戏剧角色扮演译成“假扮小客体 a”。 |
| S₁ / S₂ / S(Ⱥ) / Φ | **S₁**／**S₂**／**S(Ⱥ)**／**Φ** | 分别为主人能指、知识、被划杠大他者的能指与阳具功能；不彼此替代。 |
| savoir / savoir-faire | 知识／能会（*savoir-faire*） | *savoir-faire* 指乔伊斯对能指和书写“知道怎样做”的技艺；首次保留法文。 |
| artifice / artificier / artiste | 人为构造／造作师／艺术家 | 第四、八课把“能会”同三者连缀；*artificier* 的通常义还有烟火师、机关制作者，正文保留法文以免抹去词形滑动。 |
| Nom-du-Père / noms du père | 父之名／诸父之名 | 单复数依语境区分。 |
| forclusion / Verwerfung | 拒斥 | 与一般排斥、法律除权区分；第九课还提出“实在的定向对意义的拒斥”。 |
| père-version / perversion | 父亲—版本／倒错 | 保留 *version vers le père*“朝向父亲的版本”与 *perversion* 的音形关系。 |
| carence paternelle / démission paternelle | 父职匮乏／父职辞任 | 用于乔伊斯之父未能承担父亲功能，以及乔伊斯以专名和艺术进行补偿的论证。 |
| ego / moi | 自我 | 第十一课把乔伊斯的 *ego* 规定为修正缺失想象关系的第四环；必要时保留英文 *ego*。 |
| rapport sexuel | 性关系 | “性关系不存在”指它无法作为关系被写出；第七课又从 *sinthome* 的不等价讨论其有限支撑。 |
| tout / pas-tout | 全体或全部／不全 | *pas-tout* 不译作经验数量上的“不完整”，而指全称量词不能封闭女人一侧。 |
| ravage | 蹂躏 | 第七课用于男人对一个女人可能成为比 *sinthome* 更糟的东西。 |
| lapsus / faute / erreur | 漏误／过错／错误 | 在结的书写中分别保留无意识漏误、带有罪责回响的过错及拓扑穿越错误。 |
| paroles imposées | 强加之言 | 第七课病例用语；指主体感到话被强加，而不是一般外部命令。 |
| télépathie | 心灵感应 | 区分“接收型”与病例所谓“发射型心灵感应”；露西娅段落保留乔伊斯自己的归因。 |
| épiphanie | 显现 | 乔伊斯术语；第十一课把它重读为借过错使无意识与实在打结。 |
| dit-mension / mensionge | 说—维／*mensionge* | 前者把 *dit*“所说”嵌入 *dimension*；后者把 *mension*、*mensonge*“谎言”与 *je* 叠合。 |
| appensée | 倚思 | 由 *appui*“支撑”与 *pensée*“思想”构成，指倚着能指而思考；首次保留法文。 |
| osbjet | 骨—客体 | 把 *os*“骨”与 *objet*“客体”压合，并由小客体 a 标记。 |
| art-dire / ardeur | 说的艺术／热情 | 第八课由 *art-dire* 滑向 *ardeur*；正文保留法文以呈现音形关系。 |
| évidement / évidence | 掏空／显明 | 第八、十一课反复利用两词近音，说明结被掏空因而并不显明。 |
