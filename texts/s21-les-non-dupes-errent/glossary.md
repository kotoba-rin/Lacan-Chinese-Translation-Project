# 翻译术语对照表

适用范围：`S21 Les non-dupes errent`

本表用于统一第二十一研讨班译文。正文以“统一中文译名”为准；拉康的新造词、同音双关及无法由单一汉译穷尽的表达，首次出现时保留法文并加译注。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Les non-dupes errent | 不上当者会犯错 | 标题与 *Les Noms du Père* 完全同音；*errer* 还牵涉游荡、失路及 *erre* 的余势。首次出现加注，后文依具体论证分别保留“犯错／游荡”等义。 |
| dupe / non-dupe | 上当者／不上当者 | 指是否甘愿受无意识与话语结构蒙骗；不把 *dupe* 一律心理化为缺乏判断力的“傻瓜”。 |
| erre / errer / errance / erreur | 余势／犯错或游荡／游荡／错误 | 第一课明确把 *errer* 同 *error-erreur*、*iter*、*iterare* 及行进余势相互勾连，正文按论证层次区分。 |
| Nom-du-Père / Noms du Père | 父之名 | 保留概念地位；复数形式依句法译“父之名／诸父之名”。 |
| forclusion / Verwerfung | 拒斥 | 指根本能指未进入象征秩序并在实在中返回；不同于法律语境的“除权”，也不与一般 *rejet*“排斥”混同。 |
| la passe | 渡越 | 分析经验及拉康学派制度中的概念；首次出现保留法文，相关双关中的普通 *passer* 依句法另译。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分。 |
| jouissance phallique / jouissance du corps / jouissance de la femme | 阳具享乐／身体享乐／女人的享乐 | 后半期把阳具享乐规定为从身体享乐中分出的寄生性、符号学享乐；“女人的享乐”不还原为器官类型。 |
| discours | 话语 | 指由稳定关系构成的结构；与 *parole*“言说”区分。 |
| discours analytique / discours de l’analyste | 分析话语／分析家话语 | 泛指精神分析开启或运作的话语时用“分析话语”；明确指四公式中 $a/S_2 \to \bar S/S_1$ 的结构时用“分析家话语”。 |
| discours scientifique | 科学话语 | 指科学凭自身数学结构划定事实可进入范围的话语，不简化成科学家的个人观点。 |
| discours du maître / discours universitaire | 主人话语／大学话语 | 四种话语中的两种结构。 |
| sujet | 主体 | 概念义固定译“主体”。 |
| Autre / grand Autre | 大他者 | 大写 *A* 的结构性他者；普通 *autre* 依语境译“他者／另一个”。 |
| objet petit (a) / objet (a) | 小对象 $a$ | 公式中写作 $a$。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 改写成“意义”。 |
| savoir / connaissance | 知识／认识 | 保留能指所衔接的知识与认识活动之间的区别。 |
| savoir inconscient / savoir dans le Réel | 无意识知识／实在界中的知识 | 前者是能指连接所构成的失谐知识；后者不因此被人格化为保障秩序的主体或上帝。 |
| sujet supposé savoir / savoir supposé sujet | 被假定知道的主体／被假定给主体的知识 | 第十一课有意把通常公式倒写为后者；两种语序不可互换。 |
| chiffrage / déchiffrage | 编码／解码或破译 | 第二课以梦的编码承载 *Lustgewinn*；按语境把对已编码文本的读取译“解码／破译”。 |
| Deutung / Deutbarkeit | 意义或解释／可解释性 | 第二课按拉康对弗洛伊德德文的拆解，把 *Deutung* 的“意义”层同解释活动联系起来；不机械统一成一个中文词。 |
| Beziehung / Verhältnis | 关系／可书写的关系 | 第二课把近似的一般联系同能够衔接、铭写为数学式的关系区分；性的 *Verhältnis* 正是在可写性上失灵。 |
| Lustgewinn / plus-de-jouir | 享乐收益／剩余享乐 | 拉康把弗洛伊德的 *Lustgewinn* 重读为 *plus-de-jouir*；与普通效用收益区分。 |
| rapport sexuel | 性关系 | 否定命题统一译“性关系不存在／无法被写出”。 |
| fonction phallique / Φ | 阳具功能／Φ | 性化公式中的函数；同作为器官表象的阳具区分。 |
| tout / pas-tout / pas-toutes | 全部／非全部／并非所有女人 | *pas-tout* 不是集合外的例外，而是全称量词不能封闭女人一侧。 |
| inconscient | 无意识 | 指弗洛伊德—拉康意义上的无意识结构。 |
| lalangue | *lalangue* | 拉康把冠词与 *langue* 连写的新造词；正文保留法文，避免同一般“语言”混同。 |
| parlêtre / être parlant | 说话之在 | 保留说话与存在的复合关系，不直接简化为“人”。 |
| réel / le Réel | 实在／实在界 | 指三界之一时用“实在界”；其他语境依句法用“实在”。 |
| symbolique / le Symbolique | 象征的／象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 名词化且指三界之一时译“想象界”。 |
| dit-mension | 言说—维度 | 拉康把 *dit*“所说”嵌入 *dimension*“维度”的写法；首次出现保留法文。 |
| nœud borroméen | 博罗米结 | 三环相扣且任一环断开后三环全部分离的结结构。 |
| nœud olympique | 奥林匹克结 | 三环中仍有成对相扣；切断一环时另两环不一定分离，用来同博罗米结对照。 |
| rond de ficelle / tore | 绳圈／环面 | 闭合绳圈在拓扑上是环面；它使结在不被解开的情况下能够得到区分。 |
| coinçage | 绞卡 | 指绳圈相互卡住并由此确定点的拓扑操作。 |
| consistance | 实存性 | 指绳圈等作为一环得以自持的性质；与 *ex-sistence*“外—存在”区分。 |
| ex-sistence / ex-sister | 外—存在／外—立 | 按拉康拆写保留“从外部坚持、相对于某物而在”的结构；不与 *consistance* 混同。 |
| coupabilité | 可切断性 | 拉康从 *couper*“切断”造词，并使它同 *culpabilité*“有罪性”近音。 |
| lévogyre / dextrogyre | 左旋／右旋 | 用于结及 R.S.I. 字母序列的两种取向。 |
| mode / mode d’être | 模态或方式／存在方式 | 第三课联系模态逻辑使用；“只有方式之存在”不把所区分的秩序实体化。 |
| naming / nomination | 专名命名／命名 | 英语 *naming* 强调给予专名；同一般命名行为区分。 |
| connerie | 蠢 | 保留口语与粗俗强度；不美化成一般的认知局限。 |
| moi-ïté / moitié | 我性／一半 | 第三课以近音把自我式“我性”坠入由两个“一半”组成的二。 |
| vérité | 真理 | 指话语中的真理位置或功能时不改写为“真相”。 |
| mi-dire | 半说 | 真理只能被“半说”。 |
| dire vrai / rainure | 说真／沟槽 | 第七课把“说真”比作承载无意识知识的沟槽；它不同于实在界的科学。 |
| dit / dire / parole | 所说／说／言说或言语 | 第四课把作为事件的“说”同一般言语及已经说出的内容区分；不把三者统一成“话语”。 |
| événement | 事件 | “说”与爱情作为改变结构位置的发生；不缩减为认识中的一个时刻。 |
| amour / amour divin / amour courtois | 爱情／神圣之爱／宫廷爱情 | 第四课按三界各自充当中项的位置区分；不把三者归并为同一种情感。 |
| heur / bonheur | 机缘／幸福 | 保留 *bon-heur* 中“好的机缘”及偶然相逢的构词关联。 |
| l’(a)mur | 爱／$a$—墙 | 把小对象 $a$ 与 *mur*“墙”嵌入 *l’amour* 的同音写法，强调爱情构成界限并堵住知识的实在关系之洞。 |
| masochisme | 受虐 | 第四课把实在界作为中项、联结享乐与身体的配置；不自动等同死亡驱力。 |
| pulsion | 驱力 | 与生物学本能相区分。 |
| soma / germen | 躯体／种质 | 魏斯曼生物学中可死亡的躯体系列与延续生殖谱系的种质；*soma* 不译作个人禀赋意义的“体质”。 |
| troumatisme | 洞—创伤 | 由 *trou*“洞”与 *traumatisme*“创伤”合成；指性关系缺失处形成的洞。 |
| nommer-à | 任命去 | 第十课把社会性的“任命去做某事”同父之名的命名功能对照；保留不自然的动向结构。 |
| désêtre / dé-suis | 去存在／去—是 | 第十一课对分析家位置的拆词；不改写为一般的“不存在”。 |
| sème / sémiosis | 义素／符号过程 | 第十五课中的义素是 *lalangue* 中“构成意义”的材料；其符号过程被规定为附加于身体的寄生性运作。 |
| signans / signatum | 能指／意义（所指） | 第十五课沿斯多葛派—索绪尔脉络使用的拉丁词；保留原词以区别一般中文用法。 |
| anagramme | 变位词（字母易位） | 以同一组字母重新排列成另一词句；不同于按行首、行尾等位置藏字的“离合诗”。 |
| animation / âme / anima | 赋生或搅动／灵魂 | 第十五课借共根关系先唤起“赋予生命/灵魂”，继而以寄生物造成的翻搅、搔痒、狂怒重释 *animation*。 |
| dysharmonie / dysharmonique | 失谐／失谐的 | 无意识知识扰乱身体与环境之间被假定的自然和谐。 |
| pathétique | 痛苦情态 | 第十四课由“我们受苦”来规定分析实践所介入的情态；不只译作修辞性的“悲壮”。 |
| impudence / impudeur | 放肆／不知羞耻 | 第十五课明确区分二者，并把女人享乐同“言说之放肆”联系起来。 |
| horreur de savoir | 对知识的恐怖 | 第十一、十二课明确同 *désir de savoir*“求知欲”对置；*horreur* 的强度高于一般“恐惧”。 |
| homologie / ressemblance | 形式对应／相似性 | 第十四课指身体之间被假定的对应或相似，不预设生物学上的共同起源。 |
| occulte / occultisme | 神秘现象／神秘学 | 第二课利用 *occulte* 兼有“神秘学的”与“隐匿的”两义，并把它同 *caché*“隐藏的”区分；正文依语境分别译出。 |
| télépathie | 心灵感应 | 弗洛伊德把其信息事实同梦的编码机制分开处理。 |
| initiation | 入门仪式 | 指古代秘仪及身体技术所涉及的、通向享乐知识的渐进入门过程。 |
| Sacher-Masoch | 萨赫尔-马索克 | 奥地利作家 Leopold von Sacher-Masoch；不得误写成“萨德-马索克”。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
