# 翻译术语对照表

适用范围：`S20 Encore`

本表用于统一第二十研讨班译文。正文以“统一中文译名”为准；拉康的新造词、同音双关及无法由单一汉译穷尽的表达，首次出现时保留法文并加译注。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Encore | 还要／再来 | 标题同时牵涉“仍然、又一次、更多”以及爱的要求“还要”；正文依句法处理，标题保留法文。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分；法律语境中的 *jouir de* 依句法译“享用”。 |
| jouissance phallique | 阳具享乐 | 不改写成生理快感。 |
| jouissance de l'Autre | 大他者的享乐 | 依句法也可译“大他者之享乐”；与阳具享乐区分。 |
| jouissance supplémentaire | 补充享乐 | *supplémentaire* 不译“互补”；它不补成一个总体，恰恰须与 *complémentaire* 区分。 |
| hainamoration | 恨—恋 | 把 *haine*“恨”与 *énamoration*“陷入爱恋”叠合；不用一般心理学的“矛盾情感”抹平。 |
| âme / âmour / âmer | 灵魂／魂—爱／魂爱 | 第八、九课把 *âme* 强行作动词并同 *amour* 相叠；依具体构词保留法文。 |
| autre satisfaction | 另一种满足 | 第六课指由语言支撑、在无意识层面得到满足的东西；不等同于需要的满足。 |
| principe de plaisir / Lustprinzip | 快乐原则 | 与“享乐”区分；第六课质疑把减轻刺激造成的痛苦径直理解为快乐。 |
| rapport sexuel | 性关系 | 否定命题统一译“性关系不存在”。 |
| pas-tout / pas-toute | 非全 | 逻辑位置上的“并非全部受阳具函数管辖”，不等于部分统计命题。 |
| discours | 话语 | 指由稳定关系构成的结构；与 *parole*“言说”区分。 |
| discours analytique | 分析话语 | 泛指精神分析所开启或运作的话语；明确指四公式之一时译“分析家话语”。 |
| discours du maître | 主人话语 | 四种话语之一。 |
| discours de l'hystérique | 癔症者话语 | 四种话语之一。 |
| discours universitaire | 大学话语 | 四种话语之一。 |
| discours de l'analyste | 分析家话语 | 四种话语之一。 |
| analysant | 分析者 | 强调正在分析中言说者的主动位置，不译“受分析者”。 |
| psychanalyste / analyste | 精神分析家／分析家 | 不译“分析师”。 |
| sujet supposé savoir | 被假定知道的主体 | 转移的结构性支点。 |
| transfert | 转移 | 沿用项目既有译名，不改作“移情”。 |
| sujet | 主体 | 概念义固定译“主体”。 |
| sujet barré / sujet divisé | 被划杠的主体／分裂主体 | 公式依原文保留。 |
| Autre / grand Autre | 大他者 | 大写 *A* 的结构性他者；普通 *autre* 依语境译“他者／另一个”。 |
| S(Ⱥ) / S(\bar A) | $S(\bar A)$／被划掉的大他者之能指 | 标示大他者中没有能够保证其完整一致的最终能指，即“不存在大他者的大他者”。 |
| objet petit (a) / objet (a) | 小对象 $a$ | 公式中写作 $a$。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 改写成“意义”。 |
| un signifiant représente un sujet pour un autre signifiant | 一个能指为另一个能指代表一个主体 | 固定公式；*représenter* 表示能指所承担的代表关系，不译成心理意义的“表象”。 |
| signifiance | 能指性 | 指产生所指作用的能指运作，不等同于已经固定的“意义”。 |
| S1 / S2 | $S_1$／$S_2$ | 分别表示主人能指与知识；保留下标。 |
| lalangue | *lalangue* | 保留拉康的连写，不拆成 *la langue*，也不径译为一般“语言”；首次说明时可提示其“语言物”意味，但不把提示固定成普通名词。 |
| linguisterie | 语言学术 | 拉康在第二十研讨班第三课中为自己的工作所造之词，用来同雅各布森的“语言学”划界；首次出现保留法文并加注。 |
| parlêtre / être parlant | 说话之在 | 保留说话与存在的复合关系，不直接简化为“人”。 |
| semblant | 假象 | 指话语中的结构位置或在该位置起作用之物。 |
| plus-de-jouir | 剩余享乐 | 保留同“剩余价值”的构词关联。 |
| réel / le Réel | 实在／实在界 | 指三界之一时用“实在界”；其他语境依句法用“实在”。 |
| symbolique / le Symbolique | 象征的／象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l'Imaginaire | 想象的／想象界 | 名词化且指三界之一时译“想象界”。 |
| vérité | 真理 | 指话语中的真理位置或功能时不改写为“真相”。 |
| savoir / connaissance | 知识／认识 | 保留能指所衔接的知识与认识关系之间的区别。 |
| énoncé / énonciation | 陈述／言说行为 | 区分已经说出的陈述内容与说出它的行为或过程；具体句法中 *énonciation* 可译“言说／言说过程”。 |
| être / étant | 存在／存在者 | 哲学论证中保持二者区别。 |
| l’êtrernel | 存—永恒者 | 第五课把 *être*“存在”、*éternel*“永恒者”叠合，并可能唤起 *lettre*“字母”；首次出现保留法文并加注。 |
| par-être | 旁—存在 | 由 *para*“在旁”与 *être*“存在”构成，并与 *paraître*“显现”相对；不译成普通“表象”。 |
| l'Un / il y a de l'Un | 一／有一 | 概念性使用时保留其公式地位。 |
| fonction phallique | 阳具函数 | 公式写作 $\Phi(x)$。 |
| phallus | 阳具 | 指能指或函数位置，不译作解剖学的“阴茎”。 |
| castration | 阉割 | 指由能指及阳具函数刻画的结构，不缩减为生理解剖事件。 |
| ex-sister / ex-sistence | 外—存在／外—存在 | 保留“在结构之外站立”的构词关系。 |
| dit / dire | 所说／说 | 具有概念地位时区分已说出的内容与“说”的事件。 |
| signe | 符号／征兆 | 与 *signifiant*“能指”严格区分；实验或符号学语境译“符号”，症候性语境可译“征兆”，动词依语境译“示意”。 |
| l’écrit / écriture | 所写之物／书写 | 前者侧重已经写成、可被阅读的文字或文本；后者侧重书写行为、形式或记法。 |
| mi-dire | 半说 | 真理只能被“半说”。 |
| nécessaire / impossible / contingent / possible | 必然／不可能／偶然／可能 | 分别对应“不断被写下／不断不被写下／停止不被写下／停止被写下”。 |
| mathème | 数学元 | 拉康仿 *phonème* 等构成的术语，指能够完整传递、可供教学的形式化书写；不泛化为任意数学公式。 |
| compacité | 紧致性 | 拓扑学术语；不按日常词义译“密实性”。 |
| l'(a)mur | 爱／$a$—墙 | 与 *l'amour* 同音，并把小对象 $a$ 与 *mur*“墙”并置。 |
| representamen | *representamen* | 保留皮尔士术语，不用一般“表象”覆盖其专门地位。 |
| interprétant | 解释项 | 皮尔士符号学三项关系之一。 |
| section de prédicat | 谓词切分 | 保留 *section* 的切割义，以衔接 *sexion*、边界和裂口的论证。 |
| prédicat / prédication | 谓词／述谓 | 区分谓词项与述谓行为、关系。 |
| substance | 实体 | 波尔-罗亚尔逻辑及哲学语境中的 *substantia*；与日常“物质”区分。 |
| substance jouissante | 享乐实体 | 指身体作为“自行享乐之物”的实体维度，不等同于笛卡尔的思维实体或广延实体。 |
| corporiser | 身体化 | 使某物取得身体或实体一致性；第三课强调身体只有以能指方式被身体化才会享乐。 |
| compréhension / extension | 内涵／外延 | 波尔-罗亚尔逻辑和集合论语境中的成对术语。 |
| intension / extension（逻辑语境） | 内涵／外延 | 第十课米尔内报告中的逻辑区分；*intension* 不按日常 *intention* 译作“意图”。 |
| dénégation / non radical | 否认／根本的“不” | 第二课的逻辑论证中，*dénégation* 指先行于述谓操作的根本否认；不与一般 *négation* 混同。 |
| ordinal | 序数 | 与基数区分；雷卡纳蒂把它论作“名字的名字”。 |
| identification de l’objet（逻辑语境） | 对象的身份认定 | 雷卡纳蒂讨论对象在重复中如何取得同一性时使用；不按精神分析中的主体“认同”来译。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
