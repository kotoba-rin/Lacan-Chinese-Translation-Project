# 翻译术语对照表

适用范围：`S22 R.S.I.`

本表用于统一第二十二研讨班译文。正文以“统一中文译名”为准；拉康的新造词、同音双关、拓扑术语及无法由单一汉译穷尽的表达，首次出现时保留法文并按需加译注。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| R.S.I. / Réel, Symbolique, Imaginaire | R.S.I.／实在界、象征界、想象界 | 法语字母 R、S、I 连读时近似 *hérésie*“异端”；作为三种语域时使用“界”，普通名词或形容词依句法译“实在／实在的、象征／象征的、想象／想象的”。 |
| symptôme | 症状 | 第一课把症状归于实在界；第二课把它规定为象征界在实在界中的效应。后续与 *sinthome* 并见时须保留词形与结构差异。 |
| sens / effet de sens / équivoque | 意义／意义效应／歧义 | 第二课明确区分意义与歧义：分析家由意义出发，却通过缩减意义并运用象征界的歧义来操作。普通“方向”义另按句法处理。 |
| rapport sexuel / non-rapport | 性关系／非关系 | 否定命题译“性关系不存在”；第三课指出语言不是填补非关系的塞子，非关系本身在语言中得到铭写。 |
| tout / pas-tout | 全部／非全 | *Pas-tout* 不是集合外的例外或残缺总体；第三课用它把上帝同“宇宙”这一全体观念区分。 |
| nécessité / ne cesse pas de s’écrire | 必然性／不停地被写下 | 模态定义；与“停止被写下、不停止不被写下”等后续公式严格区分。 |
| discours | 话语 | 指由稳定关系构成的结构；与 *parole*“言语”区分。 |
| discours analytique / discours de l’analyste | 分析话语／分析家话语 | 泛指精神分析开启或运作的话语时用“分析话语”；明确指四公式之一时用“分析家话语”。 |
| discours du maître / discours universitaire / discours scientifique | 主人话语／大学话语／科学话语 | 保留不同话语结构的名称。 |
| psychanalyste / analyste | 精神分析家／分析家 | 正式身份与一般简称依语境区分；不译“分析师”。 |
| sujet | 主体 | 概念义固定译“主体”；普通“议题、题目”义依句法处理。 |
| Autre / grand Autre | 大他者 | 大写 $A$ 的结构性他者；普通 *autre* 依语境译“他者、另一个、他异的”。 |
| Tout-Autre | 全然他者 | 第三课指不可能被完整说出的大他者；不改写成“全部的大他者”。 |
| la passe | 渡越 | 指分析经验及拉康学派制度中的位置转换与见证程序；首次出现保留法文。 |
| ensemble / élément / série | 集合／元素／序列 | 第一课追问分析家能否构成集合并形成序列；*ensemble* 的普通副词义仍依句法译“共同、一起”。 |
| imbécile / imbécillité | 痴愚者／痴愚 | 第一课借旧精神病理分类追问分析话语中的判准；与口语而粗俗的 *connerie*“蠢”严格区分。 |
| connerie | 蠢 | 保留口语和粗俗强度；不得与 *imbécillité*“痴愚”合并。 |
| débilité mentale | 心智低能 | 第二课由身体表象与意义效应推出的结构性命题；与第一课旧精神病理分类中的 *imbécillité*“痴愚”区分。 |
| topique / seconde topique | 局部论／第二局部论 | 指弗洛伊德精神装置中各系统或审级的位置关系；不是 *topologie*“拓扑学”。 |
| Verneinung / Bejahung | 否定／肯定 | 弗洛伊德术语；主体在说出某项内容时又以否定形式同它保持距离。第九课指出，被否定的真理与得到肯定的真理具有同样的想象界分量。 |
| nœud borroméen / borroméaniser | 博罗米结／博罗米化 | 三环是下限；切断任一环后其余各环全部分离。第二课把它就三这个数而言归入想象界。 |
| rond de ficelle / tore | 绳圈／环面 | 闭合绳圈在拓扑上按环面处理；不得把 *tore* 误作普通圆环。 |
| consistance | 实存性 | 指绳圈、直线或平面作为一个环或面得以自持的性质；与 *ex-sistence*“外—存在”区分。 |
| ex-sistence / ex-sister | 外—存在／外—立 | 保留“从外部站立、相对于某物而在”的拆写关系；不与 *consistance* 合并。 |
| mise à plat / coinçage | 平面化／绞卡 | 前者把结投射并缩减到二维图示；后者指各环、直线或平面相互卡住并由此规定点。 |
| point / dimense | 点／维量 | 第二课以三条具有实存性的直线或三个平面来规定点；*dimense* 是由 *dimension* 改成的动词。 |
| dit-mension | 言说—维度 | 把 *dit*“所说”嵌入 *dimension*“维度”，并同 *mention du dire*“对说的提及”相连；首次出现保留法文。 |
| crossing-over / under-crossing | 上越／下穿 | 平面结图中一条线从另一条线上方越过或下方穿过；不是现实空间中的支配关系。 |
| lévogyre / dextrogyre | 左旋／右旋 | 用于结的取向；第四课指出把图翻面并不会自动变成镜像或改变其左旋性。 |
| objet petit (a) / objet (a) / petit (a) | 小对象 $a$ | 公式中写作 $a$；第二课将其标在博罗米图的中央点。 |
| jouissance / jouissance de l’Autre（génitif objectif） / jouissance phallique | 享乐／以大他者为对象的享乐／阳具享乐 | 第三课明说 *jouissance de l’Autre* 使用客体属格，不得写成仿佛大他者自身享有的享乐；图中以 $J_A$、$J_\Phi$ 标示相关场域。 |
| inhibition / angoisse | 抑制／焦虑 | 与“症状”组成弗洛伊德三元标题；第二课分别从想象界侵入象征界、实在界侵入想象界的结结构来定位。 |
| Urverdrängung / urverdrängt | 原初压抑／原初被压抑 | 指不可还原、使“不可能”范畴得以出现的原初结构；不并入一般 *refoulement*“压抑”。 |
| l’Urverdrängte / refoulé originaire | 原初被压抑物／原被压抑物 | 第四课把它定位为永远无法被拥有的洞；与“原初压抑”这一过程或结构区分。 |
| pulsion phallique / pulsion génitale | 阳具驱力／生殖器驱力 | 第三课明确说前者不是后者，并否定男性生殖器驱力具有自然性。 |
| parlêtre / être parlant | 说话之在 | 保留说话与存在的复合关系；不直接简化为“人”。 |
| modèle / substance | 模型／实体 | 第三课拒绝把博罗米结称为普通数学模型：模型在想象界中以实体为预设，而结的三个环作为纯粹实存性彼此维系。 |
| réalité / principe de réalité / réalité psychique | 现实／现实原则／心理现实 | 三者不得同 *Réel*“实在界”混同；第四课把弗洛伊德的心理现实作为结起 R.S.I. 的第四项。 |
| complexe d’Œdipe | 俄狄浦斯情结 | 第四课把它等同于弗洛伊德用作第四项的“心理现实”，同时主张它已隐含在最低限度的三环结中，并非应被抛弃。 |
| sentiment de culpabilité | 罪疚感 | 第四课把它写成无意识会计式的算账及迷失；与一般的后悔或 *faute*“过错、罪责”区分。 |
| universel / existence | 普遍者／存在 | 第四课区分“普遍性不蕴含存在”与更严重的“把存在说成蕴含普遍性”，并以 *ex* 的外部性重写存在。 |
| pathétique | 痛苦情态 | 第四课援引克尔凯郭尔来规定外—存在；不只译作修辞性的“悲壮”。 |
| Les non-dupes errent / dupe / non-dupe | 不上当者会犯错／上当者／不上当者 | 呼应第二十一研讨班标题；*errer* 还包含游荡、失路之义，整句又与 *Les Noms du Père*“父之名”同音。 |
| nœud-trèfle / forme triviale | 三叶结／平凡形式 | 第五课用三叶结说明严格意义上不能连续变形成绳圈的结；“平凡形式”则指闭合绳圈本身。原文同时保留英语 *clove hitch*。 |
| trivision | 三分视 | 第五课新造词；仿 *division*“划分”，同时叠入 *tri-*“三”与 *vision*“观看”，用来指三种实存性的三分。 |
| Un de sens / 1 de signifiant | 意义的一／能指的一 | 第五课严格区分二者：前者是被无意识特定化并相对于身体外—存在的存在；后者只有在可以指示任意所指时才运作。 |
| cause du désir / objet du désir | 欲望的原因／欲望的对象 | 小对象 $a$ 是引起欲望的原因，却不是欲望的直接或间接对象；不得把“原因”顺译成“所欲求的对象”。 |
| Verwerfung / rejet | 弃绝／排斥 | 第五课谈后代对父亲的弃绝；作为拉康精神病结构术语时保留德文，并与一般的拒斥或排斥区分。 |
| père-versement / père-version / (a)-cueille / mi-Dieu / mi-Dieure | 父—倒错地／父亲版本／收—纳 $a$／半—神／半—神—说 | 第五课围绕父亲的症状函数形成的连续造词；分别在 *perversement*、*perversion*、*accueille* 以及 *Dieu/dire* 的声音中嵌入父亲、$a$、上帝和“说”。正文首次出现保留法文。 |
| croire à / y croire / le croire / la croire | 相信其存在／相信它存在／相信它所说的话／相信她 | 第五课用法语代词结构区分神经症与精神病，并把“相信她”同爱相连；中文正文须显出“相信存在”与“相信其言说内容”的差异。 |
| parole / dire / dire silencieux | 言语／说／沉默之说 | 第六课区分受分析者加工的言语与能够“结成结”的说；分析家的解释不必然采取一次言说行为，沉默也可能承担一种说。 |
| effet de sens réel / effet de fascination | 实在的意义效应／迷醉效应 | 分析话语所要求的意义效应既非想象的也非象征的，而必须是实在的；不得把它同艺术常借助的迷醉效应混同。 |
| emploi / jaculation | 使用／迸射 | 第六课追问意义效应来自词语的日常使用，还是能指被突然“投掷、射出”；*jaculation* 同短促祈祷及射出的身体意涵相连，首次出现保留法文。 |
| correspondance / fonction / équivalence | 对应关系／函数／等价关系 | 第六课依次提高论断强度；不得在拉康明确保留时提前把“对应”改写为“等价”。 |
| racine / racine imaginaire | 根／虚根 | 以无实根方程为例说明：即使根“不存在”，书写仍能使虚根外—存在并产生结果。 |
| Nom-du-Père / Noms-du-Père / fonction du Père / suppléance | 父之名／父之名（复数）／父亲函数／替补 | 第六课把父之名视为可能把彼此分离的 R.S.I. 结起的第四项；遇到单复数对举或研讨班题名时必须明标“复数”，不得把 *Les Noms-du-Père* 静默并入单数 *Le Nom-du-Père*。 |
| consistance – ex-sistence – trou / Imaginaire – Réel – Symbolique | 实存性—外—存在—洞／想象界—实在界—象征界 | 第七课提出并暂时确定的对应：实存性属于想象界，外—存在属于实在界，而洞是否属于象征界仍带问号；不得把这组三项改排成 R.S.I. 的字母顺序。 |
| nœud mental / mens | 心智之结／心智 | 结不因心智是否能表示它才外—存在；拉康借拉丁语 *mens* 强调心智对把博罗米结“心智化”的抵抗。 |
| savoir dans le Réel / matériel signifiant | 实在界中的知识／能指质料 | 第七课否定把世界运转直接当作实在界具有内在知识的证据；知识只在同象征界、同作为质料而体现的能指发生关系时才被假定。 |
| symptôme social / symptôme particulier | 社会症状／特殊者的症状 | 第七课从马克思所定位的社会症状转向每一主体由其无意识及其享用无意识的方式规定的特殊症状；不把 *particulier* 泛化成一般“个人问题”。 |
| jouir de l’inconscient | 享用无意识 | 第七课对症状的界定：症状是每个人享用无意识的方式，而无意识同时规定这个人。 |
| acte manqué | 失误动作 | 指行动在意图层面“失败”却使另一无意识意向显现；第七课称死亡对强迫症者而言是一项失误动作。 |
| une dénombrable / La femme | 可数的一个个女人／那个女人 | 第七课收束处说女人们以可数的“一个个”存在，而不以全称单数的“那个女人”存在；须保持 *une* 与 *La* 的层级差异。 |
| dit-mansion / dit-mension | 所说—宅邸／言说—维度 | 第八课的 *dit-mansion* 由 *dit*“所说”与英语 *mansion*“宅邸”构成，指所说之物安顿的地方；它与第二课出现的 *dit-mension* 声音相近，但构词与论证功能不同。 |
| plus-de-jouir | 剩余享乐 | 第八课把传统的“多与少”按作为产品的剩余享乐来判断；保留它与剩余价值的构形关系，不泛译为“更多快乐”。 |
| mot d’esprit / comique | 机智语／滑稽 | 第八课明确说阳具属于滑稽而非机智语；滑稽又总是一种悲伤的滑稽，两者不得合并。 |
| nommer / donner nom / Naming | 命名／给予名字／命名 | 命名不同于交流或闲聊；父之名的根本函数被缩减为给事物一个名字，而 R.S.I. 作为最初的父之名也因命名而取得意义。 |
| lalangue | 语词 | 指先于规范语言系统、由声音与享乐沉积构成的特异语言材料；第八课把意义界定为语词作用于理念或想象界的效应。 |
| expulsé du sens / impossible / l’aversion – la version du sens | 被意义驱逐之物／不可能／对意义的厌弃—意义的版本 | 第八课对实在的连续界定；*l’aversion* 与 *la version* 同音相叠，并继续分岔为反意义与前意义。 |
| trou du Symbolique inviolable | 象征界的洞不可侵犯 | 第八课把上一课仍带问号的对应推进为肯定命题：三环结之所以是博罗米结，正在于象征界围绕这个不可侵犯的洞转动。 |
| ordre / orientation / équivalence des nœuds | 次序／定向／诸结的等价关系 | 第八课明确区分三者；翻面或交换着色可能改变 R.S.I. 的识别，却不必改变未着色结的等价类。 |
| aphligé / aphliction | 被阳具折磨—阳具化／阳具—困扰 | 把 *affligé/affliction* 中的词形改写为提示 *phallus*；用来指阳具实在阻隔男人享用大他者身体，首次出现保留法文。 |
| pathème du phallus / sujet pathématique | 阳具的受动情态／受动情态主体 | *Pathème* 由“承受、受影响”的词根构成；第八课指主体作为能指交媾的产物，由能指“一”从根本上分裂。 |
| pareil / même / homogénéiser | 相似／相同／同质化 | 第九课借 ὅμοιος 区分“相似”与“相同”：同质化强调三环在实存性上的相似，但证明结的同一性还必须把各个着色或定向情形还原。 |
| nœud colorié / nœud orienté | 着色结／定向结 | 着色使各环保持可识别，定向则为每一环赋予方向；第九课接受苏里的展示，即定向博罗米结仍只有一个等价类。 |
| xRy / impossibilité d’écrire le rapport sexuel | $xRy$／性关系不可写 | “性关系不存在”不是说没有身体接触，而是说不存在能经逻辑化、数学化并经得起检验的关系式 $xRy$。 |
| é-vider / évidence | 挖空／不证自明 | 第九课把 *évider* 拆回 *vide*“空”，并同源于“看”的 *évidence* 区分；R.S.I. 要被挖空，而不是被宣称为显然。 |
| noumène / phénomène / trou | 本体／现象／洞 | 第九课把客观性问题移向结的外—存在，并指出与现象对置的本体最终只能唤起洞的隐喻。 |
| tore-boyau / sphincter | 肠—环面／括约肌 | 把数学环面带回身体的肠管与括约肌；用来说明身体实存性同想象界的关系，以及抽象球面图像的限度。 |
| Réel à partir de 3 / Imaginaire et 2 | 实在从三开始／想象界牵涉二 | 第九课以三重点和结为依据：一切配对归于想象界，而二只作为从实在中被抹去的剩余相对于实在外—存在。 |
| nommer / n’hommer | 命名／不—使成男人 | 同音拆写；第九课借它指出“说”作为行动会增加一个平面化维度，命名同时触及父之名与性化。 |
| identification imaginaire / symbolique / réelle à l’Autre réel | 对实在大他者的想象界／象征界／实在认同 | 分别对应癔症者对大他者欲望的认同、单一特征认同、以及父之名层面的认同与爱。 |
| sphère et croix / Imaginaire engluant | 球与十字／黏人的想象界 | 第十课以圆形球面截面和十字说明身体想象如何把思虑扣留在封闭图形中，同时遮蔽其中可能形成的博罗米结。 |
| vérité mi-dite / mi-dire | 被说一半的真理／说一半 | 真理不可能被完整说出，只能被“说一半”；不得顺译成含混的“委婉表达”。 |
| trait une-erre / trait unaire | 一—漂特征／单一特征 | *Trait une-erre* 与 *trait unaire* 近乎同音；前者把认同的单一划痕改写成无终点的漂行。 |
| transhumant / transit / transcendance / transfert / transitoire | 迁徙—人／过渡／超越／移情／过渡性 | 第十课把一系列 *trans-* 词串成声音链。Staferla 在一处作 *transi*，ALI、Gaogoa、Chollet 对勘本及米勒整理本的德译均支持 *transit*；正文据多数见证采用 *transit*，译注保留异文。 |
| inter-dit / refoulé | 间—说／受压抑者 | 把 *interdit*“被禁止的”拆为 *dit entre*“在中间被说”；受压抑者在行间被说，而非绝对无言。 |
| droite infinie / cycle / jeu | 无限直线／循环／游隙 | 二者在结的效能中等价，但无限直线在漂行中外—存在，循环则以洞为中心；差异位于从一者到另一者的游隙与行程。 |
| homologue au cercle | 与圆相应 | 第十二课谈无限直线与圆时，各主要见证本及米勒整理本都保留 *homologue*，并未使用 *isomorphe*；正文避免用会预设特定代数结构的“同构”，译注说明其射影／拓扑语境。 |
| gyrie / dextrogyre / lévogyre | 旋性／右旋／左旋 | 两种旋性可以区分，但无法仅凭一则信息无歧义地指定何者为左、何者为右；一个不可定向或被着色的环使两个定向结显现。 |
| père-vers / a-père-itive | 父—向／趋—父式 | 分别以 *pervers* 与 *apéritive* 的声音把“父亲”及“朝向”嵌入倒错和享乐的开启；正文首次出现保留法文。 |
| viologie / biologie | 暴力学／生物学 | *Viologie* 把 *biologie* 的词首换成 *violence* 的开头，以“暴力之学”取消生命和谐发展的想象。 |
| non-rapport de couple / nœud en chaîne | 配对关系不存在／链式结 | 第十一课以两两不相结却共同成结来支撑性非关系；两个环面直接套成链只能表示要求与欲望的配对式纽带。 |
| hainamoration | 恨—爱迷恋 | 由 *haine*“恨”、*amour*“爱”与 *énamoration*“迷恋”压合而成；爱在结所规定的界限处转向他人福祉的反面。 |
| inconscient comme Réel troué / signifiant comme trou | 作为被穿洞之实在界的无意识／作为洞的能指 | 第十一课谨慎推进的命题：象征界借能指构成洞，无意识由此不是结的表象模型，而是结的实在支撑。 |
| réalité opératoire / réalité psychique | 操作性现实／心理现实 | 前者以言语在分析中的实际效力为判准；后者会重新引入心灵与上帝的整套假定，二者不得混同。 |
| désir de dormir / besoin de dormir | 睡眠的欲望／睡眠的需要 | 弗洛伊德命题是梦保护前者，而非笼统地保护睡眠或满足后者。 |
| Père comme Nom / Père comme Nommant | 父亲作为名字／父亲作为命名者 | 父之名不只是一项既定名称；它还指从象征界之洞吐出名字的命名功能。 |
| plus-une / cartel | 加一／卡特尔小组 | 小组从三加一开始，四为最低数目；“加一”作为可被抽走的实在的一，使群体结的博罗米性质可受检验。 |
| triskèle / triskel | 三曲枝图 | 三支旋臂或三条腿构成的循环对称符号；本身不是结，只书写三种实存性，父之名作为第四项才使其成结。 |
| montrer / démontrer | 展示／证明 | 第十二课把前者归于想象界、后者归于象征界；实在界作为不可能者必须得到证明，不能只靠图形展示。 |
| nombre noué | 相结的数 | R.S.I. 的意义由三这个数规定；一旦数进入结，它是否仍只是数，成为第十二课向四、五、六过渡的问题。 |
| condition nécessaire et suffisante | 必要且充分条件 | 博罗米性质要求弄断任一元素都使其余元素彼此自由；仅“看起来像”或满足必要条件并不足够。 |
| deux cercles non noués / non-rapport | 两个彼此不相结的圆／非关系 | 两性各自转圈而不直接相结；第三项恰恰由于前两项不相结而把它们结起。 |
| groupe fondamental / trajet | 基本群／路径 | 结的结构不由摊平图中区域的表面数目决定，而由若干路径之间的关系规定。 |
| nomination imaginaire / réelle / symbolique | 想象界命名／实在界命名／象征界命名 | 第十二课末分别以抑制、焦虑、症状作为三种候选形式；这是留待下一年展开的问题，不得写成已经封闭的最终分类。 |
| référent / description russellienne | 指称对象／罗素式摹状词 | 指称对象瞄准实在界，而不只是被思想为身体支撑的个体；以“《威弗利》的作者”为例讨论命名的逻辑位置。 |
