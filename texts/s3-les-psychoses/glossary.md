# 翻译术语对照表

适用范围：`S3 Les psychoses`

本表以第三研讨班的具体语境为准；其他研讨班术语表只作比较证据。条目随逐课翻译及法文回校补充。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Daniel Paul Schreber / Président Schreber | 丹尼尔·保罗·施雷伯 / 施雷伯主席 | 弗洛伊德精神病个案研究的主人公；正文依称谓分别处理。沿用第一研讨班译名。 |
| Flechsig | 弗莱希希 | 施雷伯两次发病初期的主治医生，后来成为其迫害妄想的核心人物；全册统一此译名。 |
| technique psychanalytique / technique analytique | 精神分析技术 / 分析技术 | 指方法、规则与介入方式，不缩减为操作技巧；依原文是否带 *psychanalytique* 区分译法。 |
| interprétation | 解释 | 指精神分析解释时不译作一般性的“阐释”；具体文本释义语境再依上下文处理。 |
| retour à Freud | 回归弗洛伊德 | 指重新回到弗洛伊德文本与发现的结构意义，不等于恢复一种历史上的旧式做法。 |
| anhistorisme foncier | 根本的非历史主义 | 第六课用来刻画美国新理论的特有维度；保留其对历史化意义的否定，不弱化为“忽视历史”。 |
| signification historisante de l’analyse | 精神分析的历史化意义 | 指精神分析使主体经验进入历史化的意义维度；不只表示编写客观历史。 |
| La chose freudienne | 弗洛伊德之物 | 拉康文章题名；保留 *chose* 的“物”这一概念措辞。 |
| psychose / névrose | 精神病 / 神经症 | 保留两种结构层面的区分；不得把 *psychose* 泛化成一般心理异常。 |
| paranoïa / paranoïaque | 偏执狂 / 偏执狂患者、偏执狂的 | *paranoïaque* 依名词或形容词句法处理；同一般“多疑”性格区分。 |
| schizophrénie | 精神分裂症 | 历史疾病分类术语；不以当代诊断标准静默改写五十年代语境。 |
| paraphrénie / paraphrénique | 妄想痴呆 / 妄想痴呆患者 | 弗洛伊德用来命名偏执狂之外的精神分裂症领域；依本期文本保留其历史分类位置。 |
| démence | 痴呆 | 第一课同 *psychose* 明确区分；不把所有精神病都译作痴呆。 |
| clinique / nosographie | 临床 / 疾病分类学 | 前者指临床观察与结构，后者指疾病命名和分类体系。 |
| constitution paranoïaque | 偏执型体质 | 法国精神病学的历史术语；第一课批判把偏执狂还原为连续发展的性格异常。 |
| délire / délirer | 妄想 / 陷入妄想 | *délire* 指形成体系或言说的妄想时统一译“妄想”；不与 *hallucination*“幻觉”混同。 |
| délire d’interprétation | 解释妄想 | 塞里厄与卡普格拉的临床分类；不是“对妄想作解释”。 |
| automatisme mental | 精神自动症 | 克莱朗博术语；主体全部行动被空洞、中性的内在评注持续伴随，语言仿佛自行思考。它不等于一般机械动作，也不只按神经病学“释放现象”类比。 |
| anidéïque | 非观念性的 | 克莱朗博用来强调现象不依照观念序列发生；第一课同时质疑把“观念连续性”当作可理解性尺度。 |
| psychogenèse | 心理发生 | 第一课所批判的是用连续的“理解关系”说明精神病；不把该词弱化为一般心理发展史。 |
| relation de compréhension / compréhensibilité | 理解关系 / 可理解性 | 雅斯贝尔斯《普通精神病理学》的方法概念；拉康批判把临床意义等同于常识上“能够理解患者”。 |
| symbolique / imaginaire / réel | 象征界 / 想象界 / 实在 | 三种分析参照域；*réel* 不与 *réalité*“现实”混同。依句法也可写“象征的、想象的、实在的”。 |
| ordre symbolique / registre symbolique | 象征秩序 / 象征层面 | *ordre* 强调组织法则，*registre* 强调区分层面；不机械抹平。 |
| sujet | 主体 | 概念义统一译“主体”；普通“题目、议题”义按上下文处理。 |
| moi / ego | 自我 | 精神分析概念统一译“自我”；同 *sujet*“主体”严格区分。 |
| Autre / autre | 大他者 / 小他者、另一个人 | 大写 *Autre* 译“大他者”；小写形式依结构图式或普通句法处理。 |
| a / a′ | a / a′ | 第一课沿用前期图式，标示两个自我及其想象性关系；保留符号，不改写成普通代词。 |
| intuition délirante | 妄想直觉 | 某物突然取得最大意指，却不必已有可说明的具体意义；第一课以红色汽车为例。 |
| phénomène élémentaire | 初级现象 | 精神病临床中的基本现象；其“现实感”不能还原为知觉误差。 |
| hallucination / hallucination verbale | 幻觉 / 言语幻觉 | 后者可用第三人称复述主体的活动；不与 *délire*“妄想”混同。 |
| langue fondamentale | 根本语言 | 施雷伯对自身特殊语言的称呼；弗洛伊德由能指链重构其规则。 |
| Unbewusst / non conscient | 无意识 / 非意识 | 第一课强调无意识的效力不只来自“不是意识”这个否定特征。 |
| Spaltung | 分裂 | 指主体同自身语言及言说位置的结构性分裂，不弱化为一般意见分歧。 |
| Bejahung / affirmation primordiale | 肯定 / 原初肯定 | 在象征层面接纳某物、使其得以进入象征秩序的原初操作；它本身可能缺失。 |
| Verwerfung | 拒斥 | 同精神病结构有关；把某物排除于象征秩序，不与 *Verdrängung*“压抑”或 *Verneinung*“否定”混同。 |
| Verdrängung / refoulement / refoulé | 压抑 / 压抑 / 被压抑者 | 受压抑者会在症状等现象中以得到表述的方式返回；不同于遭拒斥者在实在中重新出现。 |
| Verneinung / dénégation | 否定 / 否认 | *Verneinung* 为弗洛伊德文本及其操作名称；法语 *dénégation* 指话语中一面呈现、一面否认的形式。 |
| ce qui est refusé dans l’ordre symbolique reparaît dans le réel | 在象征秩序中遭拒斥的一切，都会在实在中重新出现 | 第一课由狼人病例提出的结构公式；“实在”不是一般外部现实。 |
| sentiment de réalité | 现实感 | 精神病初级现象的根本特征；指现象带着不可撤销的现实确信出现。 |
| relation d’objet | 对象关系 | 第一课警告：在分析初期把想象关系当真、以想象承认替代象征承认，可能触发精神病。 |
| folie raisonnante | 推理性疯病 | 塞里厄与卡普格拉的历史表述；“推理”不表示妄想因而符合正常理性，而是标出其表面可理解性。 |
| délire de relations | 关系性妄想 | 韦尼克术语；主体把外部关系读作指向自身的意指，不与普通人际关系问题混同。 |
| délire de revendication | 诉求妄想 | 激情性精神病的一种形式；主体围绕损害、补偿和诉讼性诉求形成辩证惰性的核心。 |
| psychose passionnelle | 激情性精神病 | 克莱朗博分类；表面上更接近正常情感，但其激情性核心不再进入辩证变化。 |
| moment fécond | 丰产时刻 | 偏执狂发病之初的断裂或突发阶段；反驳妄想只依内因隐匿、连续发展的定义。 |
| phénomène élémentaire / force structurante | 初级现象 / 结构化力量 | “初级”不是因果链上的原始小核；同一结构化力量在局部初级现象与整个妄想中重现。 |
| déduction idéique | 观念推演 | 克莱朗博用语；指从人人可理解的观念连续性中推出妄想，不足以说明初级现象的结构。 |
| inaffectivité | 情感淡漠 | 第二课借早发性痴呆患者积攒石头的病例，批判用相反行为都可证明同一诊断特征的循环说明。 |
| signification | 意指 / 意义 / 含义 | 在能指—所指结构、妄想确定性等技术语境中译“意指”；普通的“重要性、说明力、词义或用途”按上下文译“意义”“含义”或“能说明问题”，不机械统一。 |
| inertie dialectique | 辩证惰性 | 某个核心可以表面上完全可理解，却不接受提问、回答、重新定位或价值翻转。 |
| hallucination psychomotrice verbale / hallucination psychique verbale | 言语性精神运动幻觉 / 言语性精神幻觉 | 塞格拉发现患者会亲口说出自己声称听见的话；但发送者同时也是接收者，单凭内外定位仍不能解开幻觉。 |
| mentisme | 思维奔逸 | 思想不受意志控制地连续涌现；第二课列作施雷伯复发初期现象之一。 |
| Nervenanhang | 神经附接 | 施雷伯“根本语言”中的德语词，指神经在交换中发生附着并进入依赖关系。 |
| rayons divins / nerfs divins | 神圣射线 / 神圣神经 | 施雷伯妄想体系的结构要素；既构成解释网络，也由主体切身体验。 |
| investissement / désinvestissement | 投注 / 撤回投注 | 力比多经济术语；第二课将其结构同施雷伯神圣射线理论的运作比较。 |
| Des sens opposés dans les mots primitifs / Über den Gegensinn der Urworte | 原始词语的相反意义 | 弗洛伊德1910年文章；第二课同时保留本维尼斯特后来从语言学角度提出的批评边界。 |
| dire psychotique | 精神病性言说 | 第三课用来替代把妄想只当作静态“内容”的说法；同时追问其意指与主体进入精神病的机制。 |
| signifiant / signifié / signification | 能指 / 所指 / 意指 | 能指按语言材料把握；所指不等于现实对象，意指始终指向另一意指。 |
| néologisme | 新词 | 妄想语言中同共同语言发生物质性不协调的词；其重量和诊断“署名”不能先被现成意义消解。 |
| galopiner | *galopiner*（加洛皮内） | 第三课女患者使用的新词；保留法文和音译，不预先归并为“挫折”等普通概念。 |
| endophasie | 内言语 | 主体内部的言语现象；第三课在其最充实的新词一极与最空洞的叠句一极之间分析妄想意指。 |
| ritournelle | 叠句 | 妄想传讯中刻板、反复而不再指向其他意义的空洞公式；同充实的“关键词”一极相对。 |
| langage / parole / discours | 语言 / 言说 / 话语 | 语言提供共同材料；言说建立主体间关系；话语的经济和意指秩序使妄想结构显现。 |
| schizophasie / schizographie | 精神分裂性言语 / 精神分裂书写 | 拉康早期分析精神病言语与书写结构的术语；不缩减为一般语句混乱。 |
| sémantème / taxième | 语义单位 / 句法关系单位 | 前者指承载词汇意义的语言单位；后者指组合或句法关系层面的单位。第三课借二者说明话语可在不同层面呈现结构。 |
| écho de la pensée | 思想回声 | 主体把自己的思想体验为稍后从外部或另一通道返回的回声；纯脑内延迟模型仍预设一个享有特权的观察点。 |
| endoscopie | 内窥 | 器质发生论为了说明主体察觉脑内不协调而不得不预设的自我观察功能；拉康以此揭示其隐含的“灵魂”。 |
| chronaxie / altération chronaxique | 时值 / 时值改变 | 克莱朗博式模型用神经通道兴奋时间差解释思想回声；不能独力消除主体位置问题。 |
| le sujet reçoit son message de l’Autre sous une forme inversée | 主体从大他者那里以颠倒形式接收自己的讯息 | 言说结构公式；奠基性承诺与可能的佯骗从两面显示它。 |
| fides | 信义 / 已经许下的言说 | “你是我的妻子／主人”这类言说同时奠定两个主体的位置，并从大他者处返回承诺的确定性。 |
| feinte | 佯骗 | 对方可以说真话使你相信反面；这种不可最终判定的可能标志着主体对主体关系。 |
| parole fondatrice / parole trompeuse | 奠基性言说 / 欺骗性言说 | 前者通过承诺建立主体位置，后者通过说谎或佯骗显露大他者作为未知者。 |
| connaissance paranoïaque | 偏执狂式认识 | 一切对象认识都从同类竞争、嫉妒和镜像认同中取得根源；不是说一切认识都构成临床偏执狂。 |
| transitivisme | 传递主义 | 幼儿把自己的行动体验并说成同类者的行动，显示自我与小他者位置可以相互翻转。 |
| corps morcelé | 碎裂身体 | 自我是欲望的不连贯集合；最初的整体综合来自外部小他者图像，因而从根本上异化。 |
| le moi humain comme tel c’est l’autre | 人的自我本身就是小他者 | 第三课公式；小他者图像赋予欲望主体最初统一，也使对象首先成为小他者欲望的对象。 |
| témoignage / testis | 见证 / *testis* | 拉康借拉丁语“见证”与睾丸的词形回响，强调见证始终包含主体及身体的投入和潜在斗争。 |
| dialectique du maître et de l’esclave | 主奴辩证法 | 主人夺取奴隶欲望的对象与享乐，却仍依赖奴隶的承认；奴隶则为获得有效承认持续斗争。 |
| aliénation invertie / divertie / convertie | 颠倒的异化 / 转向的异化 / 转换的异化 | 第三课分别对应嫉妒妄想、情爱妄想和迫害妄想中讯息位置的变化；三者不可笼统归为同一种投射。 |
| délire de jalousie / érotomanie / délire de persécution | 嫉妒妄想 / 情爱妄想 / 迫害妄想 | 弗洛伊德从“我爱他”的不同否定形式区分；拉康进一步追问讯息、见证与异化结构。 |
| projection | 投射 | 不得把神经症式把自身不忠归给伴侣，同精神病性嫉妒妄想中的位置颠倒视为同一机制。 |
| perte de réalité / remplacement de la réalité | 现实丧失 / 现实替代 | 弗洛伊德区分神经症与精神病的两步过程：不仅考察转离现实，也考察幻想怎样提供替代材料。 |
| Unterdrückung | 抑制 | 指一项内部感觉受到压制；第四课明确同 *Verdrängung*“压抑”及其象征性返回区分。 |
| projection psychologique / « projection » psychotique | 心理学投射 / 精神病性“投射” | 前者可见于正常心理与神经症；后者只是遭拒斥者从外部返回的描述，不得用自我—小他者机制解释其发生。 |
| injure / allusion | 辱骂 / 暗示 | “母猪”病例中，主体以暗示谈及自身，而辱骂在小他者处于实在中返回；重点不是先行“理解”隐喻内容。 |
| Autre absolu | 绝对大他者 | 超出一切可知内容、其作为主体的存在担保言说承认价值的大他者；同现实中的经验性伙伴区分。 |
| jeu des quatre / S, A, a, a′ | 四方游戏 / S、A、a、a′ | S为主体，A为大他者，a与a′为镜像关系中的两个小他者；精神病回路可排除A而封闭于a—a′。 |
| matériel signifiant / ensemble synchronique / discours diachronique | 能指材料 / 共时整体 / 历时话语 | 语言作为结构性对立的同时体系提供材料，具体话语则按时间序列展开。 |
| érotisation du signifiant | 能指的爱欲化 | 某些词突然孤立、加重并负载特殊意指，打破能指体系的通常分布；第四课以施雷伯根本语言为例。 |
| âme / assassinat d’âme | 灵魂 / 灵魂谋杀 | 施雷伯把“灵魂谋杀”确定为妄想的决定性枢纽，却仍把它呈现为谜；不得先用家庭情感叙事消解其形式特征。 |
| certitude délirante | 妄想确定性 | 主体可承认幻觉不具共享现实性，却根本确信现象涉及自身；它不同于正常主体围绕证据保持的不确定。 |
| Versöhnung | 和解 | 施雷伯把自身定位为上帝的女人与人神中介后形成的体系性解决；平静和稳定不自动等于临床治愈。 |
| écrivain / poète / témoignage objectivé | 作家 / 诗人 / 客体化见证 | 施雷伯能够写出完整体系，却未像诗性创造那样让读者进入一项主体承担的新象征关系；第七课以此限定其见证性质。 |
| acting-out | 行动化 | 第七课将“吃新鲜脑子”作为分析家过早在现实层面介入后出现的回应；某物自行显现，不等于主体已理解解释。 |
| propriété symbolique | 象征的私有产权 | 第七课剽窃病例强调符号属于所有人；分析问题不是先从现实查证产权，而是词语为何取得“显现或不显现”的特殊重量。 |
| Verwerfung primitive | 原初拒斥 | 逻辑上先于神经症辩证法：象征化的一部分可能不发生；未被象征化者随后在实在中显现。 |
| Verdichtung / loi du malentendu | 凝缩 / 误解的法则 | 一项言说可同时承载多个方向，使主体在象征关系中满足不同位置；同压抑造成的链间冲突区分。 |
| jugement d’existence / retrouver l’objet | 存在判断 / 重新找到对象 | 现实检验不是第一次找到自然适配的对象，而是尝试重寻已经丧失、起初以幻觉形式出现的满足对象。 |
| principe de plaisir / principe de réalité | 快乐原则 / 现实原则 | 两者在弗洛伊德那里不可分开；现实原则使主体以不同对象回应需要，却永远不能重新取得原对象本身。 |
| phénomène psychotique | 精神病现象 | 一项从未进入象征化的巨大意指在现实中浮现，无法同既有链条联结，并可威胁主体的整套世界结构。 |
| procréation | 生殖 | 第七课把施雷伯未整合的女性功能推进到象征意义上的“生殖”，不缩减为去势、女性化或怀孕幻想。 |
| prolifération imaginaire | 想象增殖 | 主体无法恢复同大他者的象征契约时，以镜像性的群集和增殖取代象征中介；根本语言仍保留能指要求的痕迹。 |

| paraphrase / métaphrase | 释义 / 逐语转述 | 第十九课区分围绕同一意义重新表述与沿词语逐项搬移；用来说明能指排列怎样约束意义，不把语言理解成思想的透明包装。 |
| lien positionnel / lien propositionnel | 位置联系 / 命题联系 | 前者由词在链中的位置、邻接与句法建立，后者表现为已完成的判断内容；精神病话语可保留前者而使后者变得不稳定。 |
| langage comme métalangage / traduction | 作为元语言的语言 / 翻译 | 每一种语言都可用自身说明、改述或翻译另一段语言；这不预设一个脱离能指的纯意义层。 |
| « le névrosé habite le langage / le psychotique est habité par le langage » | “神经症者居住在语言中 / 精神病者被语言居住” | 第二十课的结构性对照；后一句也带“被语言占据、附身”的意味，不译成一般表达能力差异。 |
| neutralité idéique | 观念上的中性 | 克莱朗博说明精神自动症的机制不由先在思想内容或情感意义发动；“中性”不表示现象对主体没有分量。 |
| parole révélatrice / refrain | 揭示性言说 / 叠句 | 前者以充实形式向主体带来新意义；后者是“天空之鸟”机械复诵的空壳、残余。两者构成施雷伯声音的不同层次。 |
| migration / recul / dérobade du sens | 意义的迁移 / 后退 / 闪避 | 意义从近处声音移向越来越遥远的背景，并以自身缺失为特征；不能只按内容贫乏描述。 |
| continuité du signifiant / phrase achevée | 能指的连续性 / 完成的句子 | 句中各元素的地位须在结尾闭合后回溯确定；施雷伯的中断句利用的正是这种预期与补全。 |
| point de capiton | 绗缝点 | 能指与游移的意义物质在此钉合，使前后成分获得回溯性与前瞻性定位；第二十一课以《阿达莉》的“敬畏”说明。 |
| crainte de Dieu | 对上帝的敬畏 | 不是无数经验性恐惧中的一种；作为主要能指，它把阿布纳游移的害怕和可疑的热忱转化为勇气与忠实。 |
| personnaison / dépersonnalisation du discours | 人称化 / 话语的去人称化 | 主体怎样借“我、你、他”及动词词尾在话语中取得位置；精神病中某些绗缝点崩开时，话语可显得不再属于主体。 |
| pronom conjoint / pronom disjoint | 非重读代词 / 重读代词 | 法语人称系统中附着动词的形式与独立、重读形式；对应关系不能简化成主体与自我的自然区分。 |
| voix moyenne / sequor | 中间语态 / *sequor* | 中间语态表示主体在动词过程或状态中构成自身；拉丁语“我跟随”用来说明“跟随”怎样牵涉说话者的“我”。 |
| grand-route / petits chemins / écriteaux | 大路 / 小路 / 标牌 | 大路作为能指先于并极化沿线意义；父亲能指缺失时，零散小路及其路边标牌类比精神病中的言语幻觉。 |
| « être père » / signifiant de la procréation | “成为父亲” / 生育能指 | 性交与孩子出生的经验相加，并不会自然产生父职；只有文化中已取得地位的能指，才把男性主体铭入生育与世代。 |
| « tu » comme ponctuation / hameçonnage | 作为标点、下钩方式的“你” | “你”不必指一个具体受话者，也可引入地点、时间或条件；它在意义波流中钩住并固定大他者。 |
| copule / ostension / invocation | 系词 / 指示 / 召请 | “是”的纯粹系词和“正是你”的指示把悬置的“你”提升一个层次；“你就是那个……”的最高形式则召请构成主体的全部能指、神祇与恶魔。 |
| suis / tu es / tues / tutoiïté（斯塔费拉：tutoïté） | “是／跟随” / “你是／你杀死” / “你性” | *suis* 同时属于 *être* 与 *suivre*；*tues* 在字母上可拆看成 *tu + es*；*tutoiïté* 则把第二人称造为性质名词。这条能指游戏揭示想象认同的极限：我或你、一个或另一个，不能同时占据同一位置。 |
| Nom-du-Père / signifiant du père | 父之名 / 父亲能指 | 不等于父亲意象、生殖者或权威人物；它为父职、亲属关系和世代差异引入象征排序，并把阳具—母亲—儿童三角维系起来。 |
| forclusion / Verwerfung | 拒斥 | 第二十五课正式提出以法语 *forclusion* 固定 *Verwerfung*，取代不够精确的 *rejet*；指根本能指未进入象征秩序，后在实在中返回。 |
| cataclysme imaginaire | 想象灾变 | 主体遭遇无法接收的能指后，象征调节失效，与小他者的致命二元关系失去限制，继而能指装置与所指分离并自行展开。 |
| anneau comme signifiant | 作为能指的环 | 环并非女性器官的“自然象征”；圆、重复、婚姻等意义之所以能够凝结，是因为环已先作为能指存在。 |
| « c’est cela » / nomination du météore | “就是这个” / 气象现象的命名 | “就是这个”把本来无处安放的显现定位并命名，且已蕴含“只不过是这个／不是这个”的后续追问；彩虹说明命名先于因果化约。 |
| triangle phallus-mère-enfant / père comme anneau | 阳具—母亲—儿童三角 / 作为环的父亲 | 父亲不只是父—母—子图中的第三个经验人物；作为能指，他像环一样维系想象交换，并把自然生殖改写成有代际切分的谱系秩序。 |
