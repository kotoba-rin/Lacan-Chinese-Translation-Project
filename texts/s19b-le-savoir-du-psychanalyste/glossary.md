# 翻译术语对照表

适用范围：`S19B Le savoir du psychanalyste`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Le savoir du psychanalyste | 精神分析家的知识 | 研讨班标题；*psychanalyste* 不译“分析师”。 |
| savoir / connaissance | 知识 / 认识 | *savoir* 主要指由能指 articulé 出来、与无意识相关的知识；*connaissance* 指认识关系或已知内容，依语境可译“认识／知识”。 |
| ignorance / docte ignorance / non-savoir | 无知 / 博学的无知 / 非知 | 保留“无知”与主动承担的“非知”之间的差别。 |
| psychanalyste / analyste | 精神分析家 / 分析家 | 前者在正式身份语境用“精神分析家”，后者依上下文简称“分析家”；不译“分析师”。 |
| analysant | 分析者 | 指正在分析中言说的人，避免“被分析者”抹去其主动位置。 |
| psychique / psychiques | 精神的 | 作定语时依汉语搭配使用“精神”构词，如“精神因果性”；不译“心理的”。*Psychologie* 仍译“心理学”。 |
| discours | 话语 | 指由稳定关系构成的结构；与 *parole*“言说”区分。 |
| discours du maître | 主人话语 | 四种话语之一。 |
| discours de l’hystérique | 癔症者话语 | 四种话语之一。 |
| discours universitaire | 大学话语 | 四种话语之一。 |
| discours de l’analyste | 分析家话语 | 四种话语之一；与泛指的 *discours analytique* 区分。 |
| discours analytique | 分析话语 | 泛指精神分析所开启或运作的话语；若明确指四公式之一，则译“分析家话语”。 |
| signifiant / signifié | 能指 / 所指 | 不能把 *signifiant* 依日常语义改写成“意义”。 |
| signifiant-maître | 主人能指 | 与主人话语中的 $S_1$ 相连。 |
| S1 / S2 | $S_1$ / $S_2$ | 分别表示主人能指与知识；保留下标。 |
| sujet barré / grand Autre barré | 被划杠的主体 / 被划杠的大他者 | 公式依正文写作 $\not S$、$\not A$；不写成普通字母。 |
| inconscient structuré comme un langage | 无意识像一门语言那样被结构 | 不简化为“无意识就是语言”。 |
| lalangue | *lalangue* | 保留拉康的连写，不拆成 *la langue*，也不径译为一般“语言”。 |
| parlêtre / être parlant | 说话之在 | 保留说话与存在的复合关系，不直接简化为“人”。 |
| vérité | 真理 | 指话语中的真理位置或真理功能时，不改写为日常意义的“真相”。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分。 |
| plus-de-jouir | 剩余享乐 | 保留同“剩余价值”的构词关联；不译“剩余快感”。 |
| semblant | 假象 | 指话语中的结构位置或在该位置发挥作用之物，不等于一般“假装”或“拟真”。 |
| rapport sexuel | 性关系 | 否定命题统一译“性关系不存在”。 |
| transfert | 转移 | 沿用项目既有译名，不改作“移情”。 |
| objet (a) / petit a | 小对象 $a$ | 保留小写及公式性质，不写成“对象(a)”或“小客体”。 |
| réel / le Réel | 实在 / 实在界 | 指三界之一时用“实在界”；指作为不可能者起作用的层面或性质时依句法用“实在”。 |
| symbolique / le Symbolique | 象征的 / 象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l’Imaginaire | 想象的 / 想象界 | 名词化且指三界之一时译“想象界”。 |
| fonction phallique | 阳具函数 | 公式写作 $\Phi(x)$；不译“菲勒斯功能”。 |
| l’Universelle / l’Universel | 全称命题 / 普遍者 | 阴性形式通常省略了 *proposition*，指“全称命题”；阳性形式指逻辑上的“普遍者”。不译作“周延项”或“广延项”。 |
| pas-tout / pas-toute | 非全 | 不等同于否定全称命题，也不改写成“并非一个也没有”。 |
| Yad’lun / il y a de l’Un | 有一 | 保留拉康的缩合写法及其断言结构。 |
| trait unaire | 一元特征 | 不与单纯“一条线”或 *unien* 混同。 |
| monade / dyade / triade / tétrade | 单子 / 二元组 / 三元组 / 四元组 | 依集合和数的上下文使用。 |
| nade | 无元 | 拉康仿照 *monade* 等构造的词，指零项。 |
| mathème | 数学式 | 指能够传递、可供教学的形式化书写，不泛化为一般“数学”。 |
| lettre d’a-mur | 爱／a—墙之信 | 保留 *amour*、$a$ 与 *mur* 的复合双关。 |
| ex-sistence | 外存在 | 保留词中的断开，表示置身结构之外而坚持存在。 |
| forclusion | 拒斥 | 拉康精神病理论术语，不泛化为“排除”。 |
| mi-dire | 半说 | 真理只能被“半说”。 |
| dire / dit | 言说 / 所说 | 保留言说行为与已经说出的内容之间的差别。 |
| psychiatrerie | *psychiatrerie* | 保留拉康的贬义造词；首次出现可在正文说明其戏谑意味。 |
