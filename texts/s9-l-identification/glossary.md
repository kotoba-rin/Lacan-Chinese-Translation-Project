# 翻译术语对照表

适用范围：`S9 L'identification`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| identification | 认同 | 指主体借他者或能指形成自身位置的精神分析概念；不译作一般身份“识别”。 |
| identification de signifiant / identification imaginaire | 能指性认同／想象性认同 | 第二课明确对举；前者依能指的差异与重复成立，后者依同类形象的同化效应成立。 |
| identification primaire / régressive / hystérique | 原初认同／退行性认同／癔症性认同 | 第五课重述弗洛伊德三种认同：吞食—同化的双价认同；失去对象后借一道单一特征发生的部分认同；经由欲望同他者发生的认同。 |
| identité | 同一性 | 逻辑与主体问题中的 identity；与 *identification*“认同”区分。 |
| même / le même | 同一、相同／同一者 | 第一课讨论 *idem*、*même* 与“我自己”的词源时，依句法分别处理。 |
| Un / un | “一”／1 | 作为能指功能讨论时加引号；不把它预先解释成总体、统一体或普罗提诺的“一者”。 |
| unité / unification | 单位／统一化 | 索绪尔语境中的 *unité* 是由差别构成的语言单位；第三课明确说认同不等于统一化。 |
| monas / nombre | 单子、单位／数 | 第五课依欧几里得定义：每个存在者凭单位被称作“一”，数则是由多个单位组成的多。 |
| sujet | 主体 | 概念性用法统一译“主体”；不在正文逐处附法文。 |
| moi | 自我／我 | 精神分析结构中的 *moi* 译“自我”；代词或词源讨论中的 *moi* 译“我”。 |
| autre / Autre | 小他者／大他者 | 大写 *Autre* 统一译“大他者”；必要时依原文明确大小写。 |
| signifiant / signifié | 能指／所指 | 不把 *signifiant* 改写成“意义”。 |
| signification | 意指 | 指能指运作产生意义的过程或结果；依句法需要时可译“意义”。 |
| batterie du signifiant | 能指库 | 指能够彼此替换并组成链条的一整组能指。 |
| signe / image | 符号／图像 | 与 *signifiant*“能指”区分；第二课把图像界定为两个系统间的一一对应安排。 |
| signe / signifiant | 符号／能指 | 第四课的公式：符号为某个人代表某种东西；能指为另一个能指代表主体。 |
| lettre | 字母 | 指能指可书写、可重复的物质支撑；汉字语境也按此译名处理，不等同于一般“书信”。 |
| L'instance de la lettre dans l'inconscient | 《无意识中字母的动因》 | 拉康文章标题；第五课用它说明独一循环由可编号的字母支撑。 |
| diachronie / synchronie | 历时性／共时性 | 第二课进一步区分事实上的历时性与结构上成立的历时性。 |
| symbolique / imaginaire / réel | 象征界／想象界／实在界 | 用作三界范畴时加“界”；普通形容词用法依语境处理。 |
| vérité / vrai / réel | 真理／真、真实之物／实在、实在界 | 第三课明确区分把“真”带入实在界与从实在中找到真实之物，不把三项混同。 |
| la Chose | 原物 | 指弗洛伊德—拉康意义上的 *das Ding*，与一般“东西”区分。 |
| parole / discours / langage / langue | 言说／话语／语言／一门语言 | 保留言说行为、已展开的话语、语言功能与具体语言系统之间的区别；*langue* 还可依第三课双关译“舌头”。 |
| préverbal | 前语言 | 第三课借动物言说与人类语言的差别讨论；不等同于完全没有声音或交流。 |
| imago | 意象 | 指分析经验中具有凝结与俘获力量的想象性形成物；不泛化为普通视觉图像。 |
| Gestalt cristallographique / anthropomorphique | 晶体学格式塔／拟人化格式塔 | 前者探索自然形成与能指组合结构的连接；后者把分析经验退回宏观宇宙—微观宇宙的古老类比。 |
| phonème / occlusion / occlusive | 音素／闭塞／塞音 | 第三课以 *ap/pa* 说明闭塞中的无声时刻；不把 *occlusive* 泛译为一般“封闭”。 |
| transfert | 转移 | 主体在言说中把分析家置于大他者层面的结构性关系；不缩减为普通情感转嫁。 |
| parler babyish / pidgin | 儿语式说话／皮钦语 | 第三课从两个语言领域之间的不对称接触说明二者的结构近似。 |
| participation mystique / mentalité prélogique | 神秘参与／前逻辑心态 | 列维-布留尔的分类名称；正文保留拉康对其解释力的明确质疑。 |
| énonciation / énoncé | 言说行为／陈述 | 第一课借“我说谎”区分说出的行为层面与所说内容层面。 |
| sujet supposé savoir | 被假定知道的主体 | 指知识被假定于某个主体的结构位置，不表示该主体实际拥有全部知识。 |
| sujet de l'énonciation | 言说行为的主体 | 与陈述中的语法人称区分；第二课指出它可由第三人称显现。 |
| savoir absolu | 绝对知识 | 第一课在黑格尔现象学语境中使用。 |
| trait unique / ein einziger Zug | 单一特征 | 第二课所用表述；作为始终同一的一道特征支撑能指链。后文若出现 *trait unaire*，另译“一元特征”，不自动混同。 |
| trait unaire | 一元特征 | 第四课以集合论术语 *unaire* 取代 *unique*；其同一性来自标示纯粹差别，不来自各道笔画质性相似。 |
| différence qualitative / différence signifiante | 质性差别／能指差别 | 前者依形态相似与属性判断；后者由能指不是其他能指、也不与自身相同而成立。 |
| trace d'un pas / pas de négation | 脚步痕迹／否定词 *pas* | 第四课借同音词把在场痕迹与否定的抹除放在能指链两端。 |
| effacement / effaçons | 抹除／抹除方式 | *effaçons* 是把 *effacement* 与 *façons* 叠合的造词；指能指从事物关系被抹除的不同方式中出现。 |
| idéal du moi | 自我理想 | 指主体从大他者位置取得的象征性参照点；与 *moi idéal*“理想自我”区分。 |
| être-pour-la-mort | 向死而在 | 海德格尔式术语，不缩减为一般“走向死亡”。 |
| forclusif / discordantiel | 排除项／不一致项 | 达穆雷特—皮雄对法语否定成分的区分；前者完成排除，后者标示言说同陈述间的不一致。 |
| acting out | 行动化（acting out） | 首次出现保留英文，以区别一般行动与付诸行动。 |
| passage à l'acte | 付诸行动 | 第二课用于刻画笛卡尔开创性进程；与 *acting out*“行动化”区分。 |
| automatisme de répétition | 重复自动症 | 关键不在“总是同一件事”，而在没有生物需要的黏着性重复为何发生。 |
| Vorstellungsrepräsentanz | 表象代表 | 第六课把它界定为被压抑的“第某号行为”之丢失号码；保留德文时首次附中文。 |
| nom propre / noun / name | 专名／名词／专名 | 第六课依英语区分语法上的 *noun* 与命名功能的 *name*；后者即 *nom propre*。 |
| écriture / marque / idéogramme | 书写／标记／表意符号 | 书写材料最初作为区别性标记产生；表意符号越抹除图像性，越能作为能指运作。 |
| phonétisation / usage phonétique | 语音化／表音用法 | 书写并非由口语直接复制而来，而是在既成标记被命名、语音化之后承载声音。 |
| peu de sens | 少量意义 | 转喻公式中的效应；不得直接抹平成“无意义”。 |
| névrosé obsessionnel | 强迫症者 | 指主体的神经症结构位置，不缩减为日常“有强迫行为的人”。 |
| hystérique / pervers / psychotique | 癔症者／倒错者／精神病者 | 作为结构位置时统一使用这些译名；具体临床病人语境可依原文使用“患者”。 |
| inconscient / préconscient / conscient | 无意识／前意识／意识 | 保留弗洛伊德系统中的层次区分；形容词用法依句法处理。 |
| identité de perception / identité de pensée | 知觉同一性／思想同一性 | 第七课区分初级过程所追求的知觉同一性与次级过程中的思想同一性。 |
| Urverdrängung / l’Urverdrängte | 原初压抑／原被压抑之物 | 前者指原初压抑这一过程或结构，后者指其结果；不并入一般压抑。 |
| lexis / phasis | 词项／言说 | 逻辑命题中是否有对象可取的词项层面，与作出全称断定的言说层面；第二十六课原注指出拉康口误颠倒二者。 |
| objet (a) / petit(a) | 客体(a)／小客体(a) | 公式中保留括号；普通论述可依原文写“客体a”，但不把 *a* 解释成一般对象编号。 |
| fantasme / fantasme fondamental | 幻想／根本幻想 | 指以 S◇a 形式化的主体与欲望客体关系；不泛译成随意想象。 |
| demande / désir | 要求／欲望 | *Demande* 是经能指重复并指向大他者的要求；与不能由满足填平的 *désir* 区分。 |
| pulsion / Trieb | 驱力 | 不译作本能；第二十二课把它界定为要求效应下实在向主体的第一次变更。 |
| objet du désir / objet de la castration | 欲望客体／阉割的客体 | 后者是第二十六课对小客体(a)的逻辑规定；不得同剥夺或挫折的客体混同。 |
| objet partiel | 部分客体 | 其“部分”不等于物理残片；第二十六课以丧失所标示的压抑点规定其功能。 |
| phallus / pénis | 阳具／阴茎 | *Phallus* 指能指与结构功能，*pénis* 指身体器官；不得互换。 |
| Einheit / Einzigkeit | 统一性／独一性 | 第十一课的德语区分：前者指统一为一，后者指不可替代的唯一。 |
| Einverleibung / incorporation | 并入／并入 | 指主体同身体及父亲一侧的结构关系；依具体吞食语境可译“吞食式并入”。 |
| intuition pure / Sinnlichkeit / Beharrlichkeit | 纯粹直观／感性／持存 | 康德语境中的术语组；*Beharrlichkeit* 不泛译为一般恒常。 |
| privation / frustration / castration | 剥夺／挫折／阉割 | 三项必须分开；后两课分别从类逻辑、满足匮乏与客体(a)的结构规定展开。 |
| ens privativum / ens rationis | 缺失之有／理性之有 | 保留“有”的本体论层次；不平写成“缺少的东西／想出来的东西”。 |
| Verwerfung / verworfen | 拒斥／遭拒斥之物 | 指精神病结构中的排除机制及其结果；与一般否认、压抑区分。 |
| jouissance | 享乐 | 拉康概念用法；不按普通快乐或享受改写。 |
| tore | 环面 | 只指二维拓扑表面，不把它写成有厚度的实心圆环体。 |
| homologue / homologique / homologie | 对应的、同构的／对应关系、同构 | 图式、能指与拓扑语境中指位置或功能上的对应，不译作共同来源的“同源”；胚胎学语境可译“同源结构”。 |
| se recouper / recoupement（拓扑） | 自相交／自相交 | 指线或表面穿过自身；不同于只接触而不穿越的“相切”。 |
| cercle plein / cercle vide | 实圆／空圆 | 环面上的两类特殊回路；分别涉及环面厚度与中央孔洞，不按视觉上的实线、虚线理解。 |
| vide / rien | 空缺／无 | 第二十二课明确区分：空缺支撑要求的重复；“根本之无”是欲望客体被召唤到来的孔洞。 |
| lacs | 环结 | 指由切口与回路构成的结状线；与一般链条、湖泊词义区分。 |
| cross-cap / plan projectif | 交叉帽／射影平面 | 课程在需要精确时以“射影平面”限定 *cross-cap*；图像中的穿透线不是表面的真实交线。 |
| surface de Mœbius / bande de Mœbius | 莫比乌斯表面／莫比乌斯带 | 均为单侧、只有一条边界的表面；依原文名词选译。 |
| huit inversé / huit intérieur | 倒置八字形／内八字形 | 前者主要描述线形，后者作为切口能指及双环结构的名称；依原文保持区分。 |
| différence symétrique / auto-différence | 对称差／自身差异 | 集合与拓扑论证中的技术词；不泛化为一般对称或自我差别。 |
| surface orientable / non-orientable | 可定向表面／不可定向表面 | 指能否在整个表面一致规定方向；不等同于能否在三维空间中看清朝向。 |
| spécularisable / non spécularisable | 可由镜像区分／不能成为镜像对象 | 前者在本课语境中指镜像不能与原表面重合；后者指镜像功能对客体(a)失去把握。 |
| point privilégié / point-trou | 特殊点／点孔 | 射影平面伪穿透线的终点；“点孔”无维度却不可填平，是表面组织的不可还原起点。 |
| trou courant d’air / place du trou | 穿堂风孔洞／孔洞的位置 | 第二十一课以孔洞的位置而非实体内容规定表面结构。 |
| aphanisis / fading | 消隐／消隐 | 指主体在能指或欲望结构中的淡出；保留原文外文时首次附中文。 |
| esthétique transcendantale | 先验感性论 | 康德术语；不译为一般审美理论。 |
| Möglichkeit / Erwartung | 可能性／期待 | 第十八课引用弗洛伊德与康德语境时使用；保留两者逻辑和时间指向。 |
| poinçon / ◊ | 菱形符号／◇ | 指公式 S◇a 中同时承载切口、结合与双重关系的符号，不译为普通冲头。 |
| Dasein / Mitsein / In-der-Welt-sein / Sorge | 此在／共在／在世存在／操心 | 海德格尔术语组；不把 *Sorge* 缩减成一般焦虑。 |
| Weltlichkeit / Umwelt / ustensilité | 世界性／周围世界／用具性 | 第二十三课讨论海德格尔同列维-斯特劳斯“修补术”的平行进路时使用。 |
| das Ding / Sache | 原物／事情、物 | *das Ding* 采用本表既定概念译名“原物”；*Sache* 依普通语境处理。 |
| angoisse | 焦虑 | 第二十六课把它规定为对大他者在主体自身中所欲望之物的恐惧；不泛译成日常担忧。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
