# 翻译术语对照表

适用范围：`S18 D'un discours qui ne serait pas du semblant`

本表用于统一第十八研讨班译文。正文以“统一中文译名”为准；普通义、引文中的历史译法以及拉康明确制造的双关，依具体句法处理。无法由单一汉译穷尽的新造词或同音双关，首次出现时保留原文并加译注。

## 标题、假象与话语结构

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| D'un discours qui ne serait pas du semblant | 论一种并非假象的话语 | 本研讨班标题；保留 *ne serait pas* 的假设式，不改成已经存在的断言。 |
| discours | 话语 | 指由稳定关系构成的结构；与 *parole*“言说”区分。 |
| semblant | 假象 | 指话语中的结构位置、在该位置起作用之物及自然中作为起点的显现；不等于一般“假装”或“拟真”。 |
| faire semblant | 充当假象 / 装出假象 | 依句法选择；涉及话语的结构作用时优先“充当假象”。 |
| discours du Maître | 主人的话语 | 四种话语之一；*Maître* 在该结构名中译“主人”。 |
| discours de l'hystérique | 癔症者的话语 | 四种话语之一。 |
| hystérique / hystérie | 歇斯底里者 / 歇斯底里症 | 指主体、临床结构或症状史时使用；四话语的固定结构名仍译“癔症者的话语”。 |
| discours universitaire | 大学话语 | 四种话语之一。 |
| discours de l'analyste | 分析家的话语 | 四种话语之一；与泛指的 *discours analytique* 区分。 |
| discours analytique / discours de la psychanalyse | 分析话语 / 精神分析话语 | 泛指精神分析所开启或运作的话语；明确指四公式之一时用“分析家的话语”。 |
| artefact | 人工制品 | 强调话语事实由话语造成；不是用来反设一个未经话语中介的“自然”。 |
| position dominante | 主导位置 | 指四话语公式左上方的位置。 |
| vérité | 真理 | 指话语中的真理位置或真理功能时，不改写成日常意义的“真相”。 |
| effet de vérité | 真理效应 | 指话语序列所产生的效应；不等同于可由“是／否”裁定的真值。 |

## 能指、主体与知识

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| signifiant | 能指 |  |
| signifié | 所指 | 与作为指涉对象的 *référent* 区分。 |
| référent | 所指物 | 指话语所指涉之物；不得机械并入 *signifié*。 |
| signifiant-maître | 主人能指 | 保留同“主人的话语”的关系。 |
| batterie du signifiant | 能指库 | 强调诸能指已经构成可运作的集合。 |
| trait unaire | 一元特征 | 与普通的一条线或单一特征区分。 |
| sujet | 主体 | 概念义统一译“主体”；普通“议题”义依上下文处理。 |
| sujet divisé | 分裂主体 | 公式中写作 $\bar S$。 |
| Autre / grand Autre | 大他者 | 大写 A 时统一译“大他者”；与普通 *autre* 区分。 |
| objet (a) | 对象(a) | 公式中写作 $a$；不在正文逐处补法文。 |
| savoir | 知识 | 指能指网络及其运作；与 *connaissance* 区分。 |
| savoir en échec | 受阻中的知识 | 《文字域》中不是“知识的失败”，而是知识在意义之外碰壁、显出孔洞的结构状态。 |
| savoir de Maître | 主人的知识 | 指由主人话语抽取并编排的知识，不表示主人亲自掌握全部内容。 |
| sujet supposé savoir | 被假定知道的主体 | 移情结构中的位置；不等于分析家事实上掌握关于个案的一切知识。 |
| analysant | 分析者 | 指正在分析中言说的人；不译“被分析者”。 |

## 语言、逻辑与弗洛伊德术语

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| langage | 语言 | 作为结构与体系；与 *parole*、*discours* 区分。 |
| parole | 言说 | 不译“话语”，以免与 *discours* 混同。 |
| écriture | 书写 | 指书写的功能、过程或系统；与具体的 *écrit* 区分。 |
| écrit | 书写之物 / 书写 | 依句法指已经写下的文本、字形或逻辑配置；作品名 *Écrits* 仍用通行译名《文集》，首次涉及标题双关时注明原义。 |
| Lituraterre | 《文字域》（*Lituraterre*） | 拉康的造词，令 *littérature*、*litura*、*litter*、*littoral*、*littéral* 与 *terre* 彼此回响；译名只作指称，正文保留法文。 |
| littoral | 滨岸 | 指两个绝对异质而无共同尺度的领域之间所形成的边缘；不同于把同质区域分开的普通“边界”。 |
| littéral | 字面的 / 字面之物 | 《文字域》中与 *littoral* 构成音义链；作名词时译“字面之物”，不机械并入“文学”。 |
| litura / rature | 涂抹、删改 / 删划 | 指对先在痕迹的抹除及其留下的痕迹；正文依书法、文字或逻辑语境选词。 |
| ravinement | 冲沟 / 冲蚀 | 《文字域》中既指流水在土地形成的沟槽，也指书写对所指造成的实在痕迹；过程义用“冲蚀”，结果或形态用“冲沟”。 |
| lituraterrir | *lituraterrir* | 拉康把 *litura*、*terre*、*atterrir* 等压合而成的动词；正文保留造词并由上下文说明。 |
| on-yomi / kun-yomi | 音读 / 训读 | 第七课讨论日语汉字的两种读法：前者按字的音值读，后者按其所指在日语中的说法读。 |
| l'achose / a-chose | 非物（*l’achose*） | 把 *la chose*“物”改写为 *l’ + a-chose*，并牵出否定性前缀与对象(a)的位置；首次出现保留法文。 |
| Dasein / être-là | 此在 / 在此之在 | 哲学术语 *Dasein* 用“此在”；拉康拆解法语 *être-là* 的“在这里”时译“在此之在”。 |
| épokhē / ἐποχή | 判断悬置（*epokhē*） | 第五课同时按字面说明为“置于括号之中”；首次出现保留希腊文。 |
| parole pleine | 充分言说 | 第五课强调它“填满”非物的功能；保留 *pleine / remplit* 的构词回声。 |
| archi-écriture | 本原书写 | 第五课批评把书写奠基于神话式先在层面的做法；首次出现保留法文。 |
| représentation de mot / Wortvorstellung | 词表象 | 第五课明确提出“词表象就是书写”；不理解成主体脑内自行观看词语图像。 |
| topologie | 拓扑学 | 第五课强调没有书写便没有拓扑学；图式的拓扑约束不由随意口头解释决定。 |
| illisible | 不可读的 / 不可读之物 | 第六课并非赞成故意写得晦涩，而是追问不可写的性关系如何使书写在结构上成为“不可读”。 |
| papludun / papludune | 至多一个 / 至多一个女人 | *Pas plus d’un* 的口语压合；第六课把它置于书写和整数序列的起点，阴性变体 *papludune* 在正文继续保留。 |
| un en plus / Hun-en-peluce | 多一个 | *Hun-en-peluce* 是对 *un en plus* 的戏仿拼写；正文保留造词，以衔接后文的“至少一个”。 |
| hommoinzun / hommoinzin | 至少一个男人 | 把 *homme* 与 *au moins un* 压合的造词；既指阳具功能中的“至少一个”例外，也保留“男人”的读音回声。 |
| multi-unité | 多重一（*multi-unité*） | 第六课援引布劳威尔，把“一个”同可重复、可展开的多重性联结；首次出现保留法文。 |
| énoncé | 陈述 | 指被说出的陈述及其结构地位。 |
| énonciation | 言说行为 | 指发出陈述的行为与位置。 |
| libre association | 自由联想 | 第四课强调其并非无约束的自由，而受分析话语及分析设置的条件约束。 |
| demansion | *demansion*（真理的居所之维） | 拉康以 *dimension*、*demeure* 与 *mansion* 的回声造词；正文保留法文，并随句法说明为居所、住处或场所。 |
| métalangage | 元语言 | “元语言并不存在”；书写可质询语言，但不因此构成一个独立于语言的更高语言。 |
| lettre | 字母 / 文字 / 信件 | 依语境区分；《被窃的信》中首先是书信，同时保留它与字母、文字的同形关系。 |
| lettre en souffrance | 滞留待领的信 | *En souffrance* 是邮政用语，也带有“处于痛苦中”的回声；首次出现保留法文并加译注。 |
| effet féminisant | 女性化效应 | 第六课指信件的持有和流转对大臣、杜宾所处位置的结构效应；不等同于性格变得“女性化”。 |
| lapsus calami / lapsus linguae | 笔误 / 口误 | 第五课主张即便口误也以“有待写出”的程序为条件，从而把两者重新关联。 |
| mi-dire | 半说 | 真理只能被“半说”；不改写为“说一半”。 |
| implication | 蕴涵 | 逻辑关系；与一般“牵涉／意味着”依语境区分。 |
| quantificateur | 量词 | 第八至十课的 $\forall x$ 与 $\exists x$；否定横线落在量词还是函数上必须按原式区分。 |
| universelle / particulière | 全称命题 / 特称命题 | 亚里士多德三段论及现代量化逻辑语境中的命题类型。 |
| négation forclusive / discordantielle | 拒斥性否定 / 离调性否定 | 前者排除函数的书写，后者把否定置于量词一侧；不把两者都泛化为普通“不”。 |
| pas-tout | 非全 | 否定的是全称量化，而不是建立一个反向的“全不”；与“女人并不存在”及女性位置相联。 |
| touthomme | 全男人（*touthomme*） | 把 *tout homme* 压合成能指；正文首次出现保留法文，不把它当作经验上所有男人的集合。 |
| Sinn / Bedeutung | 意义 / 指称 | 弗雷格术语；第九、十课保留德文，必要时把 *Bedeutung* 的“意谓”回声并列标出。 |
| nom propre / name / noun | 专名 / 专名之名 / 语法名词 | *name* 与 *noun* 的区分服务于“名召唤人说话”；不把两者都译成无差别的“名字”。 |
| modus ponens | 肯定前件式 | 首次出现保留拉丁文并加原注。 |
| Bejahung | 肯定 | 弗洛伊德术语；第一课强调它只包含属性判断。 |
| Verneinung | 否认 | 弗洛伊德术语；第一课强调它在否认某物时已经蕴含该物的存在。 |
| refoulement | 压抑 |  |
| principe du plaisir | 快乐原则 | 与 *jouissance*“享乐”区分。 |
| répétition | 重复 | 第一课把它同超越快乐原则的享乐联结起来。 |
| fantasme | 幻想 | 主体与对象(a)之间的结构关系；公式写作 $\bar S \mathbin{\Diamond} a$，不译“幻觉”。 |
| rapport sexuel | 性关系 | 指男人与女人之间能否形成可写出的结构关系；不等于生物学的染色体组合。 |
| acte sexuel | 性行动 | 公式“**不存在性行动**”不等于否认性交或性经验，而是否定一项能把双方铭写为互补主体的行动。 |
| passage à l'acte | 付诸行动 | 指主体越出维持假象的话语边界而遭遇实在；与 *acting out* 区分。 |
| acting out | 表演行动（*acting out*） | 把假象带上舞台并使之成为展示；首次出现保留英文。 |
| identité de genre | 性别认同 | 第二课用来讨论说话存在者怎样在男人与女人之间取得位置；不得缩减为染色体组合。 |
| faire-homme | 做出男人样 | 保留 *faire* 的表演和假象维度；不把它改成静态的男性本质。 |
| phallus | 阳具 | 作为性享乐的能指及假象结构中的位置；与解剖学的“阴茎”区分。 |
| fonction phallique | 阳具功能 | 第八至十课以 $\Phi(x)$ 书写；量词和否定位置决定“所有／非全／例外”的逻辑结构。 |
| instrument phallique | 阳具器具 | 第四课明确同阴茎区分，并将其设为语言的原因而非语言的起源。 |
| loi sexuelle | 性法则 | 第四课用来标示替代性关系而起作用的法则；不同于可由数学函数写出的关系法则。 |
| être / avoir | 存在 / 拥有 | 第四课以二者的不相容说明阳具功能与阉割；不改写为可任意选择的两种生活方式。 |
| Nom-du-Père | 父之名 | 保留概念性大写与命名功能。 |
| métaphore paternelle | 父亲隐喻 | 把语言学的隐喻与无意识的凝缩连接起来；其效力涉及父之名对母亲欲望的替代。 |
| castration | 阉割 | 指能指与阳具结构中的阉割，不缩减为生理解剖事件。 |
| seconde topique | 第二拓扑学 | 弗洛伊德的第二套心理装置模型；这里不是一般空间拓扑。 |
| surmoi | 超我 | 第十课把其命令表述为“享乐吧！”；命令不可满足，并同道德良知的形成相联。 |

## 享乐与实在

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| jouissance | 享乐 | 不译“快感”；与 *plaisir*“快乐／快感”区分。 |
| jouissance féminine | 女性享乐 | 第四课用于规定阳具作为器官时与享乐的悖论关系；不得直接等同于女人的经验属性。 |
| jouissance mortelle | 致死享乐 | 第六课指自身身体的享乐在痛苦和死亡边界上的维度；性享乐借针对这一维度的禁令取得结构。 |
| plus-de-jouir | 剩余享乐 | 保留同“剩余价值”的构词关联。 |
| jouis-sens | 享乐—意义（*jouis-sens*） | 与 *jouissance* 同音，并可拆作“享用／享受意义”；首次出现保留法文并加译注。 |
| réel / le Réel | 实在 / 实在界 | 作为不可能者起作用时依句法译“实在”；明确指三界之一时译“实在界”。 |
| impossible | 不可能 / 不可能性 | 指话语效应不能被归入可能性；与一般“做不到”区分。 |
| La femme n'existe pas | 女人并不存在 | 否定的是“女人”作为全称普遍项的存在；不是否认现实中的女人。 |

## 隐喻、资本主义话语与中文参照

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| métaphore | 隐喻 | 第三课强调一切指称都以别的东西为中介；不缩减为修辞装饰。 |
| métonymie | 转喻 | 第三课把它规定为剩余享乐这一滑动对象的承托者。 |
| langage-objet | 对象语言 | 逻辑学语境中同元语言对举；首次出现保留原注。 |
| compétence / performance | 语言能力 / 语言运用 | 语言学术语；普通形容词或非术语用法可译“能力／表现”。*Performance* 也被拉康转用来指当场话语所生产的剩余享乐。 |
| discours du capitaliste | 资本主义话语 | 由主人话语的一处转动产生；与一般“关于资本主义的言论”区分。 |
| plus-value | 剩余价值 | 马克思术语；同“剩余享乐”保持构词对应。 |
| sous-développement | 欠发达 | 第三课指资本主义扩张所生产、主体相对于已发展话语所处的状态；不等于返回古老社会。 |
| symptôme | 症状 | 会向主体发出信号却不能立即被理解；不改写成一般“迹象”。 |
| lǐ 禮 | 礼 | 第三课强调“公平地回应”在场者，并将其同话语中的适当回应相联。 |
| wéi 為 | 为 / 行动 / 作为 | 第三课利用“为”兼有行动与“作为／如同”功能，说明隐喻式指涉；正文按句法保留汉字。 |
| xìng 性 | 性 / 自然 / 本性 | 第三课从中文“性”引出自然、本性与欠发达问题；正文依拉康当场说明保留多义。 |
| mìng 命 | 命 / 天命 | 第三课同“性”并置；不自动改写成心理意义的命运感。 |
