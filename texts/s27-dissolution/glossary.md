# 翻译术语对照表

适用范围：`S27 Dissolution`

本表用于统一第二十七研讨班译文。正文以“统一中文译名”为准；拉康的新造词、拆词、同音双关和版本歧义，在首次出现处保留法文并加译注。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| Dissolution / solution / la dis | 解散／解决办法／*dis* | 本期标题与核心行动。“解散”一词中包含 *solution*，拉康又把词首拆作 *la dis*；涉及文字游戏时保留法文。 |
| École freudienne de Paris (E.F.P.) | 巴黎弗洛伊德学派 | 指拉康于 1964 年创立并于 1980 年解散的学派；普通 *École/école* 依语境译“学派”。 |
| La Cause freudienne | 弗洛伊德事业 | 1980 年解散巴黎弗洛伊德学派后启动的新组织名称；*Cause* 的普通“原因”义依句法另译。 |
| École / colle / effet de colle | 学派／胶或粘团／胶粘效应 | 本期以近音把学派的群体凝固同胶粘相连；不把 *colle* 抽象化为一般“团结”。 |
| tourbillon / temporaire | 旋涡／暂时性 | 旋涡是对抗固化等级与胶粘效应的组织原则；卡特尔凭限期、解组与重新组合而运作。 |
| cartel / Plus-Un | 卡特尔／加一者 | 卡特尔由四名成员围绕一名加一者组成，工作成果属于每个人而非集体；与经济语境中的垄断联盟无关。 |
| la passe / passant | 通行／通行者 | 本期主要指学派制度及其中的作证者，故采用“通行”；其他研讨班依其语境可能使用“渡越”。首次出现保留法文。 |
| Analyste de l’École (A.E.) | 本学派分析家 | 经通行程序获得的学派称号；保留缩写 A.E.，不泛译为一般“学派里的分析家”。 |
| acte / acte psychanalytique | 行动／精神分析行动 | 指会改变主体位置并产生结构后果的行动，不按日常语境泛译为“行为”或“动作”。 |
| nœud borroméen | 博罗米结 | 至少三个环按如下方式相结：任一环离开或断开，其余各环全部分离。 |
| lévogyre / dextrogyre | 左旋／右旋 | 指结铺平后呈现的两种旋向；旋向随铺平方式而改变。 |
| consistance | 实存性 | 指绳圈等作为一环得以自持的性质；与 *ex-sistence*“外—存在”区分。 |
| réel / le Réel | 实在／实在界 | 指实在—象征—想象三界之一时用“实在界”；其他语境依句法用“实在”。 |
| symbolique / la symbolique / le Symbolique | 象征的／象征体系（或象征书写）／象征界 | 阴性名词 *la symbolique* 指一套象征体系或象征书写；阳性名词 *le Symbolique* 指实在—象征—想象三界之一。不得因中文都可写“象征”而抹去冠词和语法性别所标出的区别。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 名词化并指三界之一时译“想象界”。 |
| topique / seconde topique | 局部论／第二局部论 | 指弗洛伊德精神装置中各审级的位置关系，不译作 *topologie* 意义上的“拓扑学”。 |
| mathème | 数学式 | 指能够传递、可供教学的形式化书写；本期采用“数学式”，不泛化为一般数学公式。 |
| parlêtre / parlêtrer | 说话之在／说话—存在 | *Parlêtre* 保留说话与存在的复合关系；*parlêtrer* 是第十课由此临时造出的动词。 |
| verbe / Verbe | 言／圣言 | 第十课“言具有创造力”唤起神学中的圣言／逻各斯，但法文写小写 *verbe*，随后又将其规定为无意识和误解；正文用“言”区别于 *parole*“言说”，不提前锁定为宗教意义。 |
| Autre / Autre de l’Autre | 大他者／大他者的大他者 | 大写 *A* 标示能指与言说取得位置的结构性他者；普通 *autre* 依语境另译。第十三课“紧紧抱住我”一段存在米勒定本大写与录音校勘本小写的异文，正文保留“他者／大他者”并加注。 |
| sujet supposé savoir | 被假定知道的主体 | 支撑移情与分析中欺骗功能的位置；分析家不得把自己认同为这一主体。 |
| effet de groupe / effet de sujet / désubjectivation | 群体效应／主体效应／去主体化 | 群体效应使个体形成共时性单元；主体效应则同分析家所必需的去主体化相连。 |
| jouissance phallique / jouissance du corps | 阳具享乐／身体享乐 | 阳具享乐不等同于器官快感，也不意味着女人被归为男人；身体享乐依上下文另行区分。 |
| il n’y a pas de rapport sexuel / non-rapport | 性关系不存在／非关系 | 指性关系无法被书写并在实在界中得到认可，不等同于经验中没有性接触。 |
| pas-tout / pas de tout | 非全／没有全部 | *Pas-tout* 是不能由全称封闭的逻辑位置；*pas de tout* 在第五课又同“沙粒成堆却不构成总体”相连。 |
| lalangue | *lalangue* | 保留冠词与 *langue* 的连写，不拆成 *la langue*，也不简化成普通“语言”。 |
| dit-mension | 言说—维度 | 把 *dit*“所说”嵌入 *dimension*“维度”的写法；首次出现保留法文。 |
| ex-sister / ex-sistence | 外—存在／外—立 | 保留从结构之外站立并坚持存在的构词关系；不与 *consistance*“实存性”混同。 |
| fixation | 固着 | 欲望因进入压抑过程而获得恒存与不可摧毁性；同本期组织语境中的“胶粘”既相关又不等同。 |
| désir indestructible | 不可摧毁的欲望 | 欲望在压抑中维持恒存；与情感的流动性形成对照。 |
| malentendu | 误解／被误解 | 第十课把言、无意识、出生与身体的传递都定位为误解；不弱化成偶然沟通失误。*L’homme naît malentendu* 同时容纳“人生来就是一个误解”和“人生来便被误解”，正文并列保留。 |
| Urverdrängt | 原初被压抑者 | 指分析不能进一步解除的原初压抑核心；同梦的脐点、口误与俏皮话所围住之处相连。 |
| instinct de mort | 死亡本能 | 本期法文明确使用 *instinct*，故不静默替换成 *pulsion de mort*“死亡驱力”。 |
| Pulsions et destins des pulsions / Triebschicksale | 《驱力及其命运》／驱力的命运 | 弗洛伊德 1915 年文本及其中对驱力诸命运的表述；保留 *Trieb*“驱力”与生物学本能的区分。 |
