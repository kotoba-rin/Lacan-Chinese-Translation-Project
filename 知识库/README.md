卡片正文只保留核实后的知识，不复述原建言，也不单列核实结论。外部知识卡以人物、典故、著作、概念或论证本身为中心，保持中立；只有以拉康的概念、文本或生平为主题的卡片才在正文中讨论拉康。卡片与翻译语境的关系统一放在文末 `## 关联`。

来源不限于英语，按资料性质选用中文、法文、德文、英文和意大利文的原典、权威词典、图书馆目录、学术出版物及机构资料。涉及拉康研讨班时，优先以项目本地法语原文核对；如外部英文版本被采用，须同时寻找本地法语对应段落，并在没有找到对应内容时明确说明。

## 注释吸收原则

注释不是自动进入知识库的素材池。只有在脱离当前句以后仍能帮助读者理解人物、文本、事迹、历史背景或专业术语，并且可以由原典、权威词典、图书馆资料或可靠研究核实时，才整理为知识卡。已有卡片能够承载的新材料，补充正文、来源和关联，不另建近义卡。

下列内容原则上保留在原注释中，不单独吸收：

- 纯页码、版本、书目信息、转录异文和排印勘误；
- “参见某课／某段”一类内部导航；
- 只解决当前句的微型词义提示、一次性双关或口语笑点；
- 尚无独立证据支持的个人联想和语境性判断；
- 大段引文但没有新增背景知识的资料摘录。

## verification 属性

`verification` 记录原解读或建言中客观知识的核实情况，不表示卡片正文仍含有相应错误。当前分布为：

- `已核实`：197 张；
- `部分准确`：144 张；
- `需更正`：57 张；
- `解释性延伸`：3 张。

四种取值的含义如下：

- `已核实`：事实核心有原典或可靠研究支持；
- `部分准确`：主旨可保留，但原表述过强、角色混合或缺少必要限定；
- `需更正`：原表述含有可明确定位的名称、出处、年代或概念错误；
- `解释性延伸`：原表述超出可直接核实的文本事实或历史共识。

## 卡片结构

每张知识卡包含：

1. YAML 属性：`title`、`type`、`verification`、`tags`、`verified_at`；
2. 独立、经过核实的知识正文；
3. `## 来源`：原典或可靠研究资料，并注明资料语言；
4. `## 关联`：同时连接相关知识卡，并采用 `[[文本路径#分段ID|分段ID]]` 形式返回翻译语境。

卡片文件名和标题不使用编号，正文不再设置“知识卡”或重复标题。`tags` 用于主题与研讨班检索，不使用“知识卡片”“核实”“部分准确”等流程性标签。

相关知识卡使用 `[[知识库/文件名.md|卡片标题]]`。卡片间链接按双向关系维护：A 卡关联 B 卡时，B 卡也补入 A 卡；检索时即使遇到尚未补齐的旧单向链接，也按双向边理解。只连接知识对象、概念沿革、论证对照、人物—作品或常见混淆等实质关系，不因共享宽泛领域或同属一个研讨班就机械互链。`## 关联` 中先列相关知识卡，空一行后再列译文分段。

## 标签体系

每张卡片使用 3–5 个标签。研讨班标签保留为稳定的一级标签，其余标签按知识维度分层：

- `研讨班I`、`研讨班II`、`研讨班III`、`研讨班IV`、`研讨班V`、`研讨班VII`、`研讨班VIII`、`研讨班IX`、`研讨班X`、`研讨班XI`、`研讨班XIII`、`研讨班XIV`、`研讨班XV`、`研讨班XVI`、`研讨班XVII`、`研讨班XIX`、`研讨班XIXb`、`研讨班XX`、`研讨班XXI`：标明卡片所关联的本地语料；
- `领域/…`：学科、研究领域或知识史范围，如 `领域/哲学`、`领域/精神分析`、`领域/古典学`；
- `人物/…`、`作品/…`、`期刊/…`、`机构/…`、`团体/…`：可明确指认的实体；
- `概念/…`、`传统/…`、`体裁/…`：概念、思想传统与文类；
- `语言/…`、`地区/…`、`时期/…`：语言及必要的时空范围。

标签只保留卡片的核心检索维度，不把正文中的每一个人名或术语都做成标签。同一对象采用同一层级和名称。为确保 Obsidian Properties 与 Bases 兼容，标签只使用字母、数字、下划线、连字符和表示层级的 `/`；正文人名中的间隔号、外文撇号在标签中统一改用连字符，例如 `人物/雅克-布伦施维格`、`期刊/Cahiers-pour-l-Analyse`。索引页可以使用 `索引/…`，但知识卡本身不使用索引标签。
