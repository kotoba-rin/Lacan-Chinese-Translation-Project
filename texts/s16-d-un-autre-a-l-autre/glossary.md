# 翻译术语对照表

适用范围：`S16 D’un Autre à l’autre（1968—1969）`

本表用于统一第十六研讨班译文。正文以“统一中文译名”为准；普通义、引文中的既有译名以及拉康刻意制造的双关，依备注处理。公式中的字母、横杠、括号与大小写均具有结构意义，不以解释性中文替代。

## 大他者、集合与主体结构

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| D’un Autre à l’autre | 从一个大他者到另一个他者 | 研讨班标题；大写 *Autre* 对应 $A$，小写 *autre* 同对象 $a$ 的位置相连。 |
| Autre / grand Autre | 大他者 | 大写 $A$；指能指、知识与真理取得位置的场所，不等于经验中的另一个人。 |
| autre | 他者／另一个 | 小写普通义依句法处理；标题及 $a$ 的结构语境中译“另一个他者”。 |
| il n’y a pas d’Autre de l’Autre | 不存在大他者的大他者 | 不推出大他者是“一”；本卷借空集与集合边界说明这一点。 |
| ensemble vide / Ø / ∅ | 空集／$\varnothing$ | 大他者的极限写法；不得写成数值 $0$。 |
| Un-en-plus | 多出来的那个一 | 空集作为单元素集合之子集所显出的“额外一项”；与普通数量增加区分。 |
| un Autre / 1 Autre | 一个他者／$1$ 个大他者 | 本卷有意让冠词 *un*、数值 $1$ 与大他者发生叠合；按上下文保留文字游戏。 |
| l’en-forme du A / de a | $A$ 之内形／呈 $a$ 形 | 拉康新造构式；指大他者由 $a$ 穿孔的拓扑形式，不只表示外观相似。 |
| ensemble / sous-ensemble | 集合／子集 | 元素与只含该元素的集合不得混同。 |
| appartenance / inclusion | 隶属关系／包含关系 | 集合论语境严格区分；不得都泛译为“属于”。 |
| paire ordonnée | 有序对 | 用来形式化“从这个一到大他者”的不对称关系。 |
| identité numérique | 数值同一性 | 标记未被性质规定的纯粹差异；不同于经验认同。 |
| trait unaire | 一元特征 | 最低限度的能指标记；同重复、计数以及 $S_1$ 的生成相连。 |
| Un / un / 1 | 一／一个／$1$ | 柏拉图式的“一”、冠词或数量“一”与数值 $1$ 依大小写及语境区分。 |
| point à l’infini | 无穷远点 | 标示知识系统无法自行覆盖、却由结构纳入的界限。 |
| série de Fibonacci | 斐波那契数列 | 本卷用 $U_{n-1}/U_n$ 的极限说明 $a\approx0.618034$。 |
| réel / le Réel | 实在／实在界 | 作为三界之一时译“实在界”；本卷尤其把“无法书写的不可能”同实在相连。 |
| symbolique / le Symbolique | 象征的／象征界 | 依形容词或名词用法处理。 |
| imaginaire / l’Imaginaire | 想象的／想象界 | 依形容词或名词用法处理。 |

## 能指、话语、知识与真理

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| discours | 话语 | 指可由书写支撑的结构性关系；与 *parole*“言说”区分。 |
| parole | 言说 | 指说出的言语及言说维度；不与 *discours* 混译。 |
| langage | 语言 | 指语言结构与系统。 |
| para-langagier | 旁语言式的 | *para-* 表示“在旁、并行”，同“元语言式的”构成对照；不译“准语言的”。 |
| discours sans parole | 无言说的话语 | 本卷开篇与终课呼应的核心公式。 |
| signifiant | 能指 | 不译“意义”；能指由同其他能指的差异取得地位。 |
| signifié | 所指 | 与 *signification*“意指”区分。 |
| S1 / S₁ | $S_1$ | 为另一个能指代表主体的第一能指；亦同一元特征、主人位置相连。 |
| S2 / S₂ | $S_2$ | 另一个能指；在大他者场域中铭写，并在后期课程中明确标示知识。 |
| sujet | 主体 | 概念义固定译“主体”；普通“题目、议题”义按句法处理。 |
| sujet divisé / sujet barré | 分裂主体／被划杠的主体 | 公式写作 $\bar S$；不还原为完整自我。 |
| un signifiant représente le sujet pour un autre signifiant | 一个能指为另一个能指代表主体 | 本卷反复采用的主体公式；*pour* 所标示的代表方向不得倒置。 |
| effet de sujet | 主体效应 | 主体不是预先存在的实体，而在能指关系中作为效应出现。 |
| fantasme / S ◊ a | 幻想／$\bar S\diamond a$ | 指分裂主体同对象 $a$ 的结构关系，不译“幻觉”。 |
| savoir | 知识 | 指能指网络及其运作；与 *connaissance*“认识”区分。 |
| connaissance | 认识／认知 | 依语境处理，不并入 *savoir*。 |
| vérité | 真理 | 同知识区分；本卷把真理、欲望、主体分裂及虚构结构相连。 |
| sujet supposé savoir | 被假定知道的主体 | 转移与分析开端的结构支点；不表示分析家事实上掌握该知识。 |
| l’Autre sait, seulement il n’est pas un sujet | 大他者知道，只不过它不是主体 | 否定落在“主体”而非“知道”上。 |
| ça se sait | 那里知道着／它被知道着 | 保留中性、非人格结构；不擅自补出一个知道者。 |
| inconscient | 无意识 | 一种主体所不知道的知识；本卷明确把这一点称作范式而非单一概念。 |
| énoncé | 陈述 | 指说出的内容及其结构。 |
| énonciation | 言说行为 | 指发出陈述的行为与位置；与“陈述”区分。 |
| répétition | 重复 | 重复瞄准享乐，并使一元特征与主体代表事后涌现。 |
| après-coup / nachträglich | 事后性／事后地 | 保留弗洛伊德术语的追溯效力，不简化为普通“后来”。 |
| transfert | 转移 | 由被假定知道的主体支撑，并在分析装置中以重复的术语得到解释。 |
| interprétation | 解释 | 分析解释在既已衔接为知识之物中产生知识效应，并使其真理可感。 |
| Durcharbeitung | 修通 | 精神分析的 working-through；*durch* 与 *Arbeit* 含“穿越式工作”之意，不译“精加工”。 |
| acte psychanalytique | 精神分析行动 | 使分析者位置及分析家位置发生转换的行动；不泛译“精神分析行为”。 |
| psychanalyste / analyste | 精神分析家／分析家 | 正式身份与一般简称依语境区分。 |
| psychanalysant / analysant | 分析者 | 强调在分析中言说、劳动的主动位置。 |
| règle analytique | 分析规则 | 指让分析者说出一切从脑中经过之物的规则。 |

## 享乐、对象与政治经济

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| jouissance | 享乐 | 不译“快感”；同快乐原则、知识、身体及排除关系相连。 |
| jouir | 享乐／享用 | 动词依施事与宾语处理，保留“享用某人／某物”的关系。 |
| autre jouissance | 另一种享乐 | 本卷帕斯卡赌注、女人及主奴关系中的另一项收益。 |
| jouissance de l’Autre | 大他者的享乐 | 大写 $A$；与经验中“他人的享乐”区分。 |
| plus-de-jouir | 剩余享乐 | 拉康仿照剩余价值构造；既是享乐的结构剩余，也是赌局所押之物。 |
| Mehrlust | 剩余享乐（*Mehrlust*） | 首次出现保留德文；同 *Mehrwert* 的构词对应不得抹去。 |
| plus-value / Mehrwert | 剩余价值／剩余价值（*Mehrwert*） | 马克思术语；不得同剩余享乐互换。 |
| renonciation à la jouissance | 对享乐的放弃 | 本卷把它同话语、劳动与剩余享乐的出现相连。 |
| principe de plaisir | 快乐原则 | 构成通往享乐的屏障；不得把 *plaisir* 译成“享乐”。 |
| objet(a) / objet petit(a) | 对象（a） | 公式中写作 $a$；是主体分裂的剩余、欲望之因及知识的产物，不实体化为普通客体。 |
| cause du désir | 欲望的原因 | 对象（a）的结构功能；与欲望所追逐的目标区分。 |
| a-cause | （a）-原因（*a-cause*） | 同法语 *à cause de* 发生声音游戏，正文保留原词。 |
| perte | 丧失 | 能指重复与结构运作产生的丧失；普通损失义按语境处理。 |
| manque | 欠缺 | 只有在象征秩序与计数建立后才出现；与普通“不够”区分。 |
| travail | 劳动 | 政治经济与主奴关系中的劳动；不得把知识直接等同于劳动。 |
| production | 生产 | 本卷把知识作为生产资料及对象（a）作为知识产物加以讨论。 |
| moyen de production | 生产资料 | 资本主义中从劳动分离并取得自主地位的资料。 |
| valeur d’usage | 使用价值 | 同交换价值区分。 |
| valeur d’échange | 交换价值 | 同使用价值区分。 |
| capital / capitalisme | 资本／资本主义 | 本卷讨论剩余价值、劳动剥削、革命及知识的共谋。 |
| exploitation | 剥削 | 包括劳动剥削及对他人身体的支配；不美化为一般“利用”。 |
| Maître / esclave | 主人／奴隶 | 黑格尔、帕斯卡与政治经济语境中的结构位置。 |
| dialectique du Maître et de l’esclave | 主奴辩证法 | 本卷重写其赌注：押上的不是主人的生命，而是奴隶的生命与剩余享乐。 |
| savoir absolu | 绝对知识 | 黑格尔语境；本卷质疑主体在知识中的潜藏位置未受批判。 |

## 临床结构与对象形态

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| névrose / névrosé | 神经症／神经症者 | 神经症者质询知识之真理，并把被假定知道的主体放入自身结构。 |
| hystérie / hystérique | 癔症／癔症者 | 不固定为生理女性；其模型参照“那个女人”，并以未满足欲望维持质询。 |
| névrose obsessionnelle / obsessionnel | 强迫症／强迫症者 | 不固定为生理男性；其模型参照主人，并试图逃避享乐。 |
| phobie | 恐惧症 | 在倒错与神经症之间发挥结构中介作用；“纸老虎”不只是经验恐惧对象。 |
| perversion / pervers | 性倒错／性倒错者 | 结构语境优先“性倒错”；普通形容或上下文明确时可简称“倒错”。 |
| symptôme | 症状 | 揭露同被排除享乐的关系；神经症者本人也可成为这场质询的症状。 |
| castration | 阉割 | 能指场域中的结构欠缺，不等于经验身体残缺。 |
| phallus / Phallus | 菲勒斯 | 同 *pénis*“阴茎”严格区分；大写时保留其结构地位。 |
| signifiant phallique | 菲勒斯能指 | 作为被排除的享乐能指，处于主体的能指系统之外。 |
| pénis | 阴茎 | 指身体器官；不与菲勒斯互换。 |
| Nom-du-Père | 父之名 | 保留概念性大写与连字符关系。 |
| forclusion | 除闭 | 本卷用于象征关系中无法修订的根本排除；与一般 *rejet*“拒斥／排斥”区分。 |
| relation anaclitique / anaclitisme | 依托关系／依托性 | 指在大他者层次取得支撑的关系；本卷把它同倒错的根本结构相连。 |
| pulsion | 驱力 | 不译“本能”。 |
| sexualité / le sexuel / désir sexuel | 性／性的东西／性欲 | 三者必须区分：*sexualité* 指性或性这一维度，*le sexuel* 是名词化的“性的东西”，只有 *désir sexuel* 译“性欲”。 |
| auto-érotisme / auto-érotique | 自体性欲／自体性欲式的 | 弗洛伊德术语，指驱力尚不以外部对象为目标的结构；不泛译为“自身性欲”或带褒义色彩的“自爱”。 |
| pulsion orale | 口腔驱力 | 第二十四课以胎盘式贴附及吞噬关系重新说明。 |
| regard / voix | 凝视／声音 | 对象（a）的两种形态；凝视不等同于眼睛或主动观看。 |
| sein / excrément | 乳房／排泄物 | 对象（a）的两种要求性形态。 |
| tache | 斑点 | 视觉场域中作为孔洞、缺席及欠缺位置的结构因素。 |
| passage à l’acte | *passage à l’acte*［越入行动］ | 同 *acting-out* 区分；分析规则要求分析者避免前者。 |
| acting-out | *acting-out*［行动展示］ | 分析家承担并维持其结构位置；不与“越入行动”混译。 |

## 语义区分、新造词与特殊表达

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| sens | 意义 | 与 *signification*、*désignation*、*manifestation* 区分。 |
| signification | 意指 | 指命题或能指产生的意指关系；不机械并入“意义”。 |
| désignation | 指称 | 指名称、命题同所指对象的指向关系。 |
| manifestation | 显现 | 指言说主体、信念或欲望在命题中的显露。 |
| registre | 层面／语域／范畴 | 依论述对象处理；只有声音、音乐等语境才译“音域”。 |
| incidence | 作用／介入／影响 | 依 *incidence de / dans / sur* 的关系处理；只有光学或几何语境才译“入射”。 |
| méconnaître / méconnaissance | 未认识到／忽视／误认 | 依语境区分单纯未察觉、主动忽视与以错误形态认识，不机械固定为“误认”。 |
| gratuit / champ du gratuit | 任意的、无所凭依的／无所凭依的场域 | 形式运算与赌局语境指缺少预先根据，不是经济意义的“无偿”。 |
| positif / positivation | 实际的、实定的／实定化 | 依语境表示实际存在或取得确定位置，不机械译成带褒义的“积极”；数学、实证主义等语境另按本义处理。 |
| Vorstellungsrepräsentanz | 表象之代表 | 保留“表象”与“代表”的双层关系；不简化为“心理表象”。 |
| das Ding / Sache | 物／事物 | *das Ding* 译“物”，*Sache* 依语境译“事物”；二者在弗洛伊德文本中不得混同。 |
| extime | 外密 | 由“内密”与“外部”构成的拉康式术语，首次出现保留法文。 |
| nullibiété | 无处性（*nullibiété*） | 指被象征界排除、因而从“无处”成为“无所不在”的享乐位置。 |
| famillionnaire | *famillionnaire* | 海涅笑话中的缩合造词；正文保留法文，不用顺口意译抹去其生成方式。 |
| hommelle | *hommelle*［男人—她］ | *homme* 与女性形式的声音构造；指被塑造成未阉割、同时占据主人和知识位置的女人形象。 |
| famil | *famil*［家庭—他］ | 由 *famille* 与阳性代词的声音关系构成；用来标记家庭的隐喻功能。 |
| les quatre effaçons du sujet | 主体的四种抹法 | *effacer*“抹除”与 *façon*“方式”构成的文字游戏。 |
| self | *self*［自体］ | 保留英文学派术语，同拉康式主体及自我区分。 |
| nullibiété / utopie | 无处性／乌托邦 | 前者是本卷对享乐排除位置的特殊命名，后者按普通思想史语境处理。 |
| scapegoat | *scapegoat*［替罪羊］ | 第二十二课用来反讽分析家及其国际组织的自我保护。 |
| perinde ac cadaver | *perinde ac cadaver*［如同一具尸体］ | 指极端服从、被动顺从与彻底奴役。 |
| La Chose freudienne | 弗洛伊德之物 | 拉康文章名及真理的拟人化表达；同普通“弗洛伊德的事情”区分。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
