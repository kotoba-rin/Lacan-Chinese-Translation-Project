# 章节阅读笔记

在译文的分段 ID 旁点击“记笔记”，插件会在本研讨班的 `notes/` 目录中创建或打开对应章节的 Markdown 笔记。例如，第八期第十七课的所有段落都汇总到 `texts/s8-le-transfert/notes/s8-17.md`。

每次点击会在章节笔记末尾加入当前段落的分段 ID 标签、法语原文、中文译文、当前段落注释和当前段落建言，并留出“我的笔记”区域。合并译文段落会带上全部关联 ID 和对应的法语段落。没有注释或建言时显示“（无）”。注释与建言按站点现有规则区分：以“注”开头的引用块作为注释，含 `<!-- 建言 -->` 标记或其他引用块作为建言。

笔记是点击时的内容副本，可以直接修改、补充和整理。重复点击已收录的段落只会打开笔记，不重新导入或覆盖用户编辑的内容；其他段落继续追加到同一文件。请保留自动生成的分段 ID 或 `reading-note-segment` 标记，以便识别已收录的段落。

译文中会加入指向章节笔记相应段落的链接。旧版按段落创建的笔记和已有链接保留，不自动迁移或删除。找不到当前段落或对应法语原文时会提示错误，不生成不完整的段落笔记。

更新插件后，在 Obsidian 的第三方插件设置中重新启用 Lacan Translation Helper，即可使用新行为。
