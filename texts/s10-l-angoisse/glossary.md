# 翻译术语对照表

适用范围：S10 *L'angoisse*

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| angoisse | 焦虑 | 本卷核心术语；不同于一般恐惧。 |
| affect | 情感 | 与 *émotion*“情绪”区分；情感本身不受压抑，而会脱离系泊、移置或转化。 |
| émotion | 情绪 | 第一课置于“运动”轴；不与 *émoi* 合并。 |
| émoi | 慌乱 | 指困扰、力量跌落及运动维度中的深层失序；保留法语以提示同 *émotion* 的词源辨析。 |
| inhibition | 抑制 | 第一课矩阵中的起始项；处于运动维度。 |
| symptôme | 症状 | 与抑制、焦虑构成弗洛伊德三元标题。 |
| empêchement | 阻碍 | 第一课由 *impedicare*“落入陷阱”展开；指主体受到阻碍。 |
| embarras | 窘迫 | 第一课借 *barre*“横杠”说明被横杠标记的主体；位于困难维度的极点。 |
| sujet | 主体 | 概念义固定译“主体”；普通“题目、议题”义按上下文处理。 |
| Autre | 大他者 | 大写A；作为能指场所，并与小写 *autre* 区分。 |
| autre | 他者／小他者 | 指同类或镜像他者时译“小他者”；普通他人义按上下文处理。 |
| désir | 欲望 | 精神分析概念义固定译“欲望”。 |
| désir de l’Autre | 大他者的欲望 | 保留“属于大他者的欲望／以大他者欲望为参照”的结构张力。 |
| objet du désir | 欲望对象 | 不与认识论或科学所定义的对象混同。 |
| fantasme | 幻想 | 不译“幻觉”；公式写作 S ◊ *a*。 |
| signifiant | 能指 | 与 *signifié*“所指”区分。 |
| trait unaire | 一元特征 | 先于主体的最简能指标记。 |
| imaginaire | 想象界／想象性 | 名词性领域译“想象界”，形容词按句法译“想象性”。 |
| symbolique | 象征界／象征性 | 名词性领域译“象征界”，形容词按句法译“象征性”。 |
| symboliser / symbolisation | 象征／象征化 | 按句法译“象征着、由……象征”或“象征化”；不译“符号化”，以免同 *signe*“符号”混同。 |
| réel | 实在界／实在 | 名词性领域依语境译“实在界”或“实在”；形容词译“实在的”。 |
| réalité | 现实／现实性 | 与 *réel / le Réel*“实在／实在界”严格区分；*réalité irréelle* 译“非实在的现实”，保留词形回响而不混同概念。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分。 |
| plaisir | 快乐／快感 | 与 *jouissance*“享乐”严格区分；*L’homme du plaisir* 译“快乐之人”。 |
| manque | 缺失 | 第三课“缺失开始缺失”保留同词重复，不改写为一般缺少。 |
| castration | 阉割 | 不缩减为生理解剖事件；第三课首先表现为想象性阉割。 |
| phallus | 阳具 | 同（-φ）及镜像中的空白相连。 |
| objet a / petit (a) | 客体 (a)／小客体 (a) | 一般写“客体 (a)”；原文强调 *petit* 时写“小客体 (a)”。它是除法意义上的余数，并非镜像对象。 |
| reste / résidu | 余数／剩余 | 数学除法语境用“余数”；结构性残留依句法用“剩余”。 |
| image spéculaire | 镜像 | 与 *image réelle*“实像”、*image virtuelle*“虚像”区分。 |
| moi idéal | 理想自我 | 与 *idéal du moi*“自我理想”区分。 |
| idéal du moi | 自我理想 | 与 *moi idéal*“理想自我”区分。 |
| Unheimlich | 令人不安的陌异 | 正文保留德文；第三课把它定位为本应空缺之处出现某物。 |
| demande | 索求 | 区分于 *besoin*“需要”与 *désir*“欲望”。 |
| pulsion | 驱力 | 不译作“本能”。 |
| instinct | 本能 | 与 *pulsion*“驱力”严格区分。 |
| Hilflosigkeit | 无助状态 | 必要时保留德文。 |
| jouissance de l’Autre | 大他者的享乐 | 属格关系不简化。 |
| désir de l’analyste | 分析家的欲望 | 不译作“分析欲望”。 |
| trace | 痕迹 | 同能指链及主体轨迹相关。 |
| signe | 符号 | 与 *signifiant*“能指”区分。 |
| passage à l’acte | 付诸行动 | 首次出现时保留法文。 |
| acting-out | 行动化 | 首次出现时保留英文。 |
