# 翻译术语对照表

适用范围：`S6 Le désir et son interprétation（1958—1959）`

本表以第六期研讨班的具体语境为准。其他研讨班的稳定译名只作比较；图式、符号及尚在形成中的概念区分，均须依本期法文与上下文校准。

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| désir | 欲望 | 本期核心概念；不化约为生理“需要”或可由对象直接满足的愿求。 |
| interprétation | 解释 | 指精神分析解释及对欲望结构的解释；普通“表演、演绎”义按语境处理。 |
| besoin | 需要 | 与 *demande*“索求／要求”和 *désir*“欲望”区分。 |
| demande | 索求 / 要求 | 作为语言结构中的概念时优先译“索求”；具体请求、要求按语境译“要求”。 |
| sujet | 主体 | 概念义统一译“主体”；普通“题目、议题”义按上下文处理。 |
| moi | 自我 | 精神分析概念义译“自我”；普通重读代词按句法处理。 |
| autre | 他者 / 别人、另一个 | 概念义译“他者”；日常指称按语境处理。 |
| Autre / grand Autre | 大他者 | 大写 A 并承担语言、法则或象征位置时译“大他者”。 |
| signifiant | 能指 | 与 *signifié*“所指”区分；不能按普通形容词义机械处理。 |
| signifié | 所指 | 与 *signifiant*“能指”区分。 |
| signification | 意指 / 意义 | 指能指作用或生成关系时译“意指”；普通内容义按语境译“意义”。 |
| énoncé | 陈述 | 指已经说出的陈述及其层面；与 *énonciation* 区分。 |
| énonciation | 言说 / 言说行为 | 依句法指发出陈述的行为、位置或层面；不得与 *énoncé* 合并。 |
| parole | 言说 / 话语 | 强调说话行动时译“言说”；具体说出的话按语境译“话语”。 |
| discours | 话语 | 与一般“讲话、论述”义按语境协调，但保留其结构性用法。 |
| langage | 语言 | 与 *langue*“语言系统／具体语言”按语境区分。 |
| fantasme | 幻想 | 不译“幻觉”；公式中的关系与符号按原文保留。 |
| libido | 力比多 | 本期第一课把它界定为“欲望的精神能量”，并批判其向预定对象论的偏移。 |
| pulsion | 驱力 | 不译“本能”；与 *instinct* 区分。 |
| transfert | 转移 | 沿用项目既有译名，不改作“移情”。 |
| refoulement / Verdrängung | 压抑 | 弗洛伊德术语；与一般压制或防御区分。 |
| défense | 防御 | 第一课从“防御性神经精神病”追问防御所针对的欲望。 |
| angoisse | 焦虑 | 与一般恐惧及后文具体焦虑结构区分。 |
| symbolique / le Symbolique | 象征的 / 象征界 | 名词化且指三界之一时译“象征界”。 |
| imaginaire / l'Imaginaire | 想象的 / 想象界 | 名词化且指三界之一时译“想象界”。 |
| réel / le Réel | 实在的 / 实在（界） | 依本期三界对举程度决定；不与 *réalité*“现实”混同。 |
| plaisir / principe de plaisir | 快乐、快感 / 快乐原则 | 依语境在“快乐／快感”间取舍；理论术语统一译“快乐原则”。 |
| pleasure-seeking | 寻求快乐 | 费尔贝恩概括的力比多取向；与 *object-seeking* 对举。 |
| object-seeking | 寻求对象 | 费尔贝恩的表述；拉康借此批判把力比多朝向某个仿佛预定的对象。 |
| objet | 对象 | 一般概念义译“对象”；固定复合术语若项目已有“客体”先例，另按语境核对。 |
| phallus / pénis | 阳具 / 阴茎 | 前者指结构性、象征性或想象性功能；后者指解剖器官，二者不得混同。 |
| castration | 阉割 | 不缩减为生理解剖事件；依本期欲望、法则与能指结构理解。 |
| idéal du moi / moi idéal | 自我理想 / 理想自我 | 二者严格区分，不得互换。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分。 |
| chaîne signifiante | 能指链 | 能指依相继关系展开，同时以共时的能指组为条件。 |
| diachronie / synchronie | 历时性 / 共时性 | 第一课图式中分别标示能指在时间中的相继，以及能指组的同时存在。 |
| batterie signifiante | 能指组 | 指共时存在并由差异关系组织的能指配置；不按字面译作“电池”。 |
| Code / Message | 编码 / 信息 | 第一课图式中的 C 与 M；信息通过能指序列的追溯作用取得形式。 |
| barre entre signifiant et signifié | 能指与所指之间的横杠 | 写作 $S/s$；既标示共存，也维持二者之间的差异与不可穿透性。 |
| métaphore / métonymie | 隐喻 / 转喻 | 隐喻涉及一个能指对另一个能指的替代；转喻沿能指链展开。 |
| graphe | 图 | 指欲望图及其各阶段；依项目习惯不译作计算机语境中的“图结构”。 |
| désir de l’Autre | 大他者的欲望 | 保留“大他者欲望什么／主体欲望大他者之欲望”的结构张力，依上下文阐明。 |
| Che vuoi? | 你要什么？ | 主体向大他者追问其欲望的公式。 |
| Hilflosigkeit / détresse du sujet | 无助 / 主体的无助 | 主体面对晦暗的大他者欲望而无所凭借；焦虑作为自我中的信号被召来应对它。 |
| expérience spéculaire / Urbild du moi | 镜像经验 / 自我的原型 | 镜像经验奠定自我的原型，并使想象关系介入主体对无助的防御。 |
| fantasme / $\bar S \mathbin{\lozenge} a$ | 幻想 / $\bar S \mathbin{\lozenge} a$ | 说话主体以想象他者为参照；人的欲望根本上同幻想而非某个预定对象接合。 |
| signifiant manquant / phallus | 缺失的能指 / 阳具 | 第一课把阳具定位为从言说链抽离、承担主体同能指之关系的能指。 |
| psychische Impotenz | 精神性阳痿 | 弗洛伊德附录术语；指器官功能可保持完整，却因精神机制而出现性行动失败或快感缺失。 |
| zärtliche Strömung / sinnliche Strömung | 温情潮流 / 感官性潮流 | 弗洛伊德附录区分；二者未能会合构成精神性阳痿与爱情生活分裂的基础。 |
| Erniedrigung des Sexualobjekts | 对性对象的贬低 | 同对乱伦对象及其代替者的高估相对；不得淡化为一般“评价降低”。 |
| Besetzung | 投注 | 精神分析能量术语；指力比多对对象、表象或驱力路径的占据。 |
| Anlehnung / Anlehnung an die Ichtriebe | 依托 / 依托于自我驱力 | 性驱力最初依托维持生命的身体功能及自我驱力的评价来寻找对象。 |
| Versagung | 受挫 / 拒绝 | 第一课附录主要指现实中满足或对象选择受到阻碍；保留其不只是一种主观挫败感的范围。 |
| Introversion | 内倾 | 力比多背离现实并被幻想活动接纳；不译作“内摄”。 |
| le refoulé | 遭压抑之物 | 与 *refoulement*“压抑”这一过程区分；第二课把它同欲望、无意识分列。 |
| sujet de la connaissance / sujet parlant | 认识主体 / 说话主体 | 前者是同对象相关并被假定出来的理想主体；后者以说话行动的必然性强加自身。 |
| sujet du besoin | 需要的主体 | 主体在索求语境中的原初、尚未成形状态；需要通过能指隘口后受到结构性改变。 |
| trésor de la langue | 语言宝库 | 位于编码 A；指语言要素以共时系统存在的场所。 |
| éléments taxématiques | 组合关系要素 | 指语言宝库中依彼此差异取得价值的系统要素。 |
| toute-puissance de l’Autre | 大他者的全能 | 来自大他者支配全部能指；不得按心理学方式记在儿童或主体的能力账上。 |
| sein / seing | 乳房 / 签印 | 第二课以同音把母亲给予乳房同给予能指阐明之签印联系起来。 |
| shifter | 转换词 | “我”只能依信息行动指称每一时刻承担信息的人，不由词汇编码中的其他语义要素固定。 |
| fonction vocative | 呼格功能 | 命令、召唤与使命式言说只使受话者显现，却由被遮蔽的“我”施行。 |
| message sous une forme inversée | 以颠倒形式返回的信息 | 主体通过赋予“你”的形式收到自己的信息。 |
| appel de l’être | 对存在的呼唤 | 图式第二层的话语功能；法语 *sois* 同时带出“成为／你要存在”的命令。 |
| Wunsch / vœu | 愿望 | 弗洛伊德梦论中的得到表述、得到阐明的愿望；与本期试图定位的 *désir*“欲望”相关但不机械等同。 |
| fantasme fondamental | 根本幻想 | “我欲望你”意味着把对方卷入主体的根本幻想；幻想是欲望解释的关键点。 |
| première topique / seconde topique | 第一地形学 / 第二地形学 | 第二课把无意识—压抑系统同本我、自我、超我的进一步图式区分开来。 |
| Ça / moi / surmoi | 本我 / 自我 / 超我 | 第二地形学三项；普通代词 *ça* 或日常“我”义不机械套用。 |
| Vorstellungsrepräsentanz | 表象代表 | 指驱力在无意识中的能指性代表；压抑首先作用于这一代表，而不是直接作用于情动。 |
| Triebregung | 驱力冲动 | 指驱力运动或驱力激发；须与其表象代表及其情动命运区分。 |
| affect / sensation / sentiment | 情动 / 感觉 / 情感 | 保留三者层次差异；affect 不泛译为“感受”。 |
| association libre | 自由联想 | 分析技术中的基本规则；与联想主义的心理学解释区分。 |
| contiguïté / similitude | 邻接 / 相似 | 联想主义的两条旧原则；在雅各布森—拉康框架中分别由转喻与隐喻重新界定。 |
| élision | 省略 | 能指链中被删去、却仍通过位置或效果发挥作用的成分。 |
| fantasme de rêve / fantasme vigile | 梦中幻想 / 清醒幻想 | 分别指梦的幻想结构与清醒时的幻想；两者均可参与愿望实现。 |
| Verwerfung / Verneinung | 拒斥 / 否定 | 前者指能指从象征界根本排除，后者指在否定形式中让被压抑内容进入言说。 |
| principe de plaisir / principe de réalité | 快乐原则 / 现实原则 | 弗洛伊德两项心理运作原则；现实原则不是对快乐原则的简单取消。 |
| Entstellung | 变形 | 梦的显在形式相对于其思想内容所发生的结构性改造；不弱化为一般“失真”。 |
| Vorstellung | 表象 | 在原初过程中具有能指组织，并可经回归性再投注带来幻觉性满足。 |
| processus primaire / processus secondaire | 原初过程 / 次级过程 | 原初过程依快乐原则运作并可通向幻觉；次级过程承担现实检验并服从现实原则。 |
| régression topique | 地形学回归 | 精神装置中的兴奋从较后系统退回知觉端，使表象取得幻觉强度。 |
| Niederschrift / niederschreiben | 铭写 / 写下、铭写 | 指梦的残余及精神装置各层中的登记；强调书写与层叠关系，不只是一项记忆印象。 |
| objet à retrouver | 要重新找到的对象 | 原初过程所追索的不是全新对象，而是同最初开通相联系、要被重觅的对象。 |
| andere Schauplatz | 另一个场景 | 梦与无意识的“另一个场所”；不是另一个神经学部位，而在能指结构中定位。 |
| holophrase | 整句 | 作为不可拆分整体起作用的句子形式；第四课以“面包！”“救命！”等呼喊说明。 |
| interdit / inter-dit | 禁止 / 禁—言 | 保留拉康把“被禁止”拆作“在言说之间／由言说构成”的双关。 |
| taxième / ne explétif | 句法关系素 / 赘词式 ne | 维持陈述过程与言说过程间距的语法标记；赘词式 ne 不表达普通否定。 |
| Bejahung | 肯定 | 原初肯定；弗洛伊德把 Verneinung（否定）在逻辑上置于其后。 |
| trace / effacement de la trace | 痕迹 / 痕迹的抹去 | 能指不始于自然痕迹本身，而始于把某物设定为可以抹去；划杠使被取消者作为能指存续。 |
| forclusif / discordantiel | 排除项 / 不一致项 | 达穆雷特—皮雄对法语否定成分的区分；前者完成排除，后者标示言说同陈述间的不一致。 |
| ex-sister dans le langage | 外—存于语言中 | 主体的存在支点在其自身之外；主体必须在能指背后消隐，并由欲望对象获得支撑。 |
| objet du désir | 欲望对象 | 不是需要的对应物，而是在主体被能指抹去之处支撑其存在的对象。 |
| le souhaité | 所愿 | 愿望中作为被愿求之物得到陈述的成分；可在主体前方回溯性地规定主体。 |
| vœu secret | 秘密愿望 | 愿望因主体的结构位置成为秘密，并借诗性表达、谎言或幻想得到传达。 |
| désir indestructible | 不可摧毁的欲望 | 位于主体前方并依照过去的形象回溯性地塑造现在。 |
| douleur d’exister | 存在之痛 | 欲望不再栖居其中、只剩存在本身时的痛苦；第五课用以读取死去父亲之梦。 |
| ambivalence des sentiments | 情感矛盾性 | 主体面对所爱、所敬之人同时存在相反情感倾向。 |
| identification à l’agresseur | 同攻击者认同 | 主体通过占据攻击者的位置来形成防御；第六课指出，仓促的俄狄浦斯解释可能把主体推向这种中间解决。 |
| aphanisis | 欲望消失（琼斯）/ 消隐、使之消失（拉康） | 琼斯以主体恐惧自身欲望消失来解释阉割恐惧；拉康反转这项因果关系，并依语境把该词用于对象或阳具被“变没”，最终把欲望顶点定位为主体而非欲望的消隐。 |
| signifiant phallus | 阳具能指 | 男人和女人同欲望的关系因相对于这一能指的不对称而根本不同。 |
| déplacement de l’objet | 对象的移置 | 不只是欲望更换对象；移置本身维持欲望的脆弱平衡，使满足受阻而欲望对象得以保留。 |
| rétention de l’objet | 对象的扣留 | 借肛门隐喻说明：对象被保留为欲望的抵押品，却不必成为主体实际享用的对象。 |
| objet comme gage / otage du désir | 作为欲望抵押品／人质的对象 | 主体可以拥有而不享用，让他人享用；对象由此支撑欲望的持续。 |
| valeur d’usage / valeur d’échange | 使用价值 / 交换价值 | 第六课把对象脱离需要场域的挥发，与其从使用价值过渡到交换价值联系起来。 |
| enfant désiré | 被欲望的孩子 | 自我理想占据主体曾体验为母亲欲望之效果的位置。 |
| transfert de l’affect sur l’objet | 情动向对象的转移 | 幻想把主体面对欲望时的恐惧与情动委托给自恋性对象。 |
| névrose de dépendance | 依赖性神经症 | 对后弗洛伊德分析把主体困难还原为索求依赖的一般趋向之命名；第七课对此提出批判。 |
| niveau quésitif / niveau votif | 求取层次 / 愿求层次 | 前者是需要经索求提问与呼唤的层次；后者是主体无意识愿望、所愿与欲望试图获得表达的层次。 |
| $S(\bar A)$ | 被划杠的大他者之能指 | 标示大他者同样受能指标记并在话语中有所欠缺，不存在一个能保证全部回应的完整大他者。 |
| objet de l’oblativité | 奉献性的对象 | 后弗洛伊德分析用来描述成熟对象关系的术语；第七课指出该观念会遮蔽主体在欲望中的省略。 |
| masochisme primordial | 原初受虐狂 | “我被父亲打”这一无法被回忆、却由分析必然建构的阶段；主体在被取消的边缘寻找自身实现。 |
| instrument / $\Phi$ | 工具 / $\Phi$ | 在“一个孩子挨打”的幻想里，主体既不稳定地位于施打者也不位于被打者，而同施打工具认同。 |
| phallus médiateur du désir | 作为欲望中介者的阳具 | 对阳具的欲望不只指竞争性地想拥有阴茎，而指欲望经由阳具能指得到中介。 |
| insignes de l’autre | 小他者的徽记 | 主体在象征性镜面中调节并与之认同的特征；由大写 $I$ 标记，并参与自我理想构成。 |
| miroir symbolique | 象征性镜子 | 不是儿童面前的实物镜子，而是主体相对于大他者、借词语与认同徽记定位自身的象征装置。 |
| donner ce qu’on n’a pas | 给予自己所没有的东西 | 第七课给出的爱之定义；将爱同欲望对象的占有和满足区分。 |
| phobie / objet phobique / objet contraphobique | 恐惧症 / 恐惧症对象 / 反恐惧症对象 | 恐惧症对象作为可作多种用途的能指，介入主体欲望与大他者欲望之间；不得与一般“害怕某物”混同。 |
| fading / fading du sujet | 消隐 / 主体消隐 | 主体在能指中无法把自己完整命名、在要求或对象面前隐去的结构位置；同琼斯所谓“欲望消失”严格区分。 |
| splitting du moi / splitting de l’objet | 自我分裂 / 对象分裂 | 后弗洛伊德对象关系理论的术语；本期将其与主体消隐相对照，不把两套问题合并。 |
| désir insatisfait / désir impossible | 未满足的欲望 / 不可能的欲望 | 前者标示癔症者维持欲望的方式，后者标示强迫症者支撑欲望的方式。 |
| deuil / Trauer | 哀悼 | 《哈姆雷特》讨论中的关键过程；对象须先作为对象构成，才谈得上经由哀悼重新取得。 |
| trou dans le réel | 实在中的洞 | 真正的丧失在实在中造成的洞；哀悼通过调动全部象征系统来应答它。 |
| objet (a) | 对象（a） | 幻想公式中支撑主体消隐的对象；不是需要的自然对应物，也不等同于经验中的完整对象。 |
| objet séparé | 分离对象 | 主体分割后留下、无法还原为索求对象的欲望对象之原初形式。 |
| coupure / intervalle | 切口 / 间隔 | 主体只能在能指链的切口与间隔中出现；幻想对象同样以切口形式取得结构。 |
| pas Un | 非一 | 欲望结构中被划杠主体的标记；不是一般意义上的简单否定，而是通向主体唯一性的入口。 |
| manque à être | 存在之欠缺 | 主体因能指作用而无法同自身存在重合；不是具体对象匮乏，也不是普通的“缺点”。 |
| non-demandable | 不可要求者 / 不可要求之物 | 无法在索求中提出、却构成欲望对象及欲望场域的不可还原部分。 |
| phallophanie | 阳具显现 | 分析经验中阳具以结构性方式显现；不是对解剖阴茎的直接展示。 |
| déclin du complexe d’Œdipe | 俄狄浦斯情结的消退 | 弗洛伊德文章标题及本期相关结构讨论的固定译名。 |
| objet partiel / objet total | 部分对象 / 完整对象 | 对象关系理论中的对举；本期批评用发展阶段的完整化来遮蔽欲望对象的切口结构。 |
| reality testing / épreuve de réalité | 现实检验 | 格洛弗论倒错与现实感时使用的术语；不等于一般常识意义上的“面对现实”。 |
| bon objet / mauvais objet interne | 好对象 / 内部坏对象 | 克莱因式投射、内摄与对象分裂中的术语；拉康据此追问对象如何首先作为能指发挥作用。 |
| fantasme pervers / perversion | 倒错幻想 / 倒错 | 两者不得混同；神经症中也可出现倒错幻想，但这不等于倒错的结构。 |
| passage à l’acte | 付诸行动 | 本期在倒错语境中指幻想在行动中的显露；普通“实施、行动”义仍按上下文处理。 |
| sublimation | 升华 | 驱力或欲望在文化与创造活动中的转向；不把它等同于欲望获得直接满足。 |
| désir de l’analyste | 分析家的欲望 | 结课处提出：主体作为欲望之欲望，在分析中最终会同分析家的欲望相对峙。 |
