# Lacan-Chinese-Translation-Project

**拉康中文开放翻译计划**

<img src="assets/16-9.png" alt="拉康中文开放翻译计划横幅" width="720">

拉康中文开放翻译计划以开放协作的方式整理、翻译、校订和维护雅克·拉康研讨班及相关文本，希望让中文读者能够直接阅读文本，也能够围绕具体分段参与翻译、注释、考证和修订。

- 在线阅读：[KotobaRin 言林](https://kotoba-rin.com/seminars/)
- 备用站点：[GitHub Pages](https://kotoba-rin.github.io/Lacan-Chinese-Translation-Project/index.html)
- 协作说明：[CONTRIBUTING.md](./CONTRIBUTING.md)
- 知识卡入口：[知识库/README.md](./知识库/README.md)

## 仓库内容

```text
texts/
  <seminar>/
    original/       # 法文原文，按课次保存
    translation/    # 中文译文，与原文分段对齐
    glossary.md     # 该研讨班术语表
    notes/          # 阅读笔记与专题材料
  index.md          # 在线版首页源文件
知识库/             # 可复用的概念、人物、文本与拓扑知识卡
scripts/
  build_from_texts.py
.obsidian/plugins/lacan-translation-helper/
plugin-doc/         # Obsidian 插件与分段 AI 的设计说明
```

`scripts/build_from_texts.py` 会把 `texts/`、阅读笔记和知识卡整理成 mdBook 所需的 `build/`，随后由 mdBook 生成 `book/`。这两个目录都是构建产物，不应手工编辑或提交。

项目整理和翻译的研讨班原始文本主要来自 [Staferla](http://staferla.free.fr/)。

## 阅读、编辑与对照

### 浏览器阅读

在线版提供研讨班目录、原文与译文对照、阅读笔记和知识卡反向链接。主站与备用站点使用同一套仓库内容构建。

### Obsidian 插件

仓库内置桌面端插件 `Lacan Translation Helper`，当前版本为 0.6.0。将仓库根目录作为 Obsidian Vault 打开，并在“第三方插件”中启用它，即可使用以下功能：

- 创建和补全译文骨架，并根据 `<!-- untranslated -->` 更新翻译进度。
- 在 Obsidian Bases 中按研讨班和课次浏览原文、译文与完成状态。
- 同步主仓库，并添加多个 fork 作为逐段对照版本。
- 在 Reader / Editer 模式之间切换：Reader 用主仓库内容对齐本地项目，Editer 保留当前编辑文件，只更新对照版本。
- 通过本机 Codex App Server 对选定分段进行只读解读；支持流式输出、多会话、Skill 方案和继续追问。

Reader 同步会覆盖当前项目内容。如需保留本地修改，请使用 Editer 模式、提交到自己的 fork，或先自行备份。插件同步依赖本机 Git CLI，且目前仅支持 Obsidian 桌面端。

分段 AI 默认在只读沙箱中运行，Apps、Plugins 和 MCP 默认关闭；它不会直接修改原文、译文、术语表或阅读笔记。“本地 Agent”表示进程和文件权限控制在本机，并不表示模型推理一定在本地完成。详细边界见[分段 AI 解读架构设计](./plugin-doc/segment-ai-interpretation-architecture.md)和[多会话与 Skill 升级设计](./plugin-doc/segment-ai-multi-session-architecture.md)。

## 分段、笔记与知识卡

每个原文分段都有稳定 ID，例如 `s8-01-0001`。原文与译文通过同一个 ID 对齐，评论、校订、Issue 和 Pull Request 也应尽量使用该 ID 指明讨论对象。维护文本时不要随意改动已有 ID。

当一个译文块合并对应多个原文分段时，使用紧跟在 `id` 后面的 `ids` 声明：

```markdown
<!-- id: s8-06-0058 -->
<!-- ids: s8-06-0058 s8-06-0059 -->

这里写 0058 和 0059 合并后的译文。
```

- 阅读笔记放在 `texts/<seminar>/notes/`，可以链接到具体分段；构建后，相关笔记会显示在译文段落旁。
- 知识卡放在 `知识库/`，卡片与分段之间的链接会生成双向入口。
- 源文件可以使用 Obsidian 常见的 LaTeX 和图片嵌入语法，构建脚本会将其转换为 mdBook 可渲染的格式。

## 本地构建与验证

在仓库根目录运行：

```bash
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_from_texts.py
mdbook build
```

如需本地预览，在构建完成后运行：

```bash
mdbook serve --open
```

修改 Obsidian 插件源码后，在插件目录验证构建产物：

```bash
cd .obsidian/plugins/lacan-translation-helper
npm install
npm run build:check
```

插件源码入口是 `src/main.js`，Obsidian 实际加载的是构建后的 `main.js`。更完整的目录规范、翻译格式、分支流程和提交约定见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 参与项目

欢迎通过 Issue 或 Pull Request 提交：

- 译文、原文分段、术语和格式的修订。
- 注释、导读、阅读笔记和知识卡补充。
- 关键术语、句法判断和段落理解的说明。
- 文本来源、版本差异、引文出处和相关背景的考证。
- 图片缺失、链接错误、构建异常或段落不清等问题。

较大的译文修改请说明理由，尤其是涉及关键术语、句法判断或版本差异时。也欢迎 fork 本项目并维护自己的版本；不同版本之间的逐段对照，本身就是项目希望保留的交流方式。不要让他人替代了你的话语。
