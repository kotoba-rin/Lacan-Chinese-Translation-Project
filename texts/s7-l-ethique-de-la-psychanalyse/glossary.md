# 翻译术语对照表

适用范围：`S7 L'éthique de la psychanalyse`

本表用于统一第七研讨班译文。正文以“统一中文译名”为准；备注用于区分近义词、普通义与本研讨班的特殊语境。其他研讨班术语表只作项目先例，不自动覆盖本表。

## 伦理学、欲望与精神分析

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| éthique / l'éthique | 伦理学 | 指伦理学说、伦理反思或本研讨班问题域；与 *morale*“道德”区分。形容词 *éthique* 依句法译“伦理的”。 |
| morale / la morale | 道德 | 指道德领域、道德规范或既有道德学说；不与 *éthique* 合并。形容词 *moral* 依句法译“道德的”。 |
| expérience morale | 道德经验 | 保留拉康对义务、罪责、行动评价与善之取向的综合指称。 |
| faute | 罪责 / 过错 | 涉及弗洛伊德的罪责宇宙、惩罚需要与原初弑父时优先译“罪责”；具体行为过失可译“过错”。 |
| sentiment de culpabilité | 罪疚感 | 与 *faute*“罪责”区分；不译成泛化的“内疚”。 |
| besoin de punition | 惩罚需要 | 弗洛伊德术语；保留 *besoin* 的“需要”层次。 |
| désir | 欲望 | 精神分析概念义统一译“欲望”。 |
| désir de l'Autre | 大他者的欲望 | 大写 A；保留“欲望属于谁／以谁为对象”的结构歧义，依上下文说明。 |
| céder sur son désir | 在自己的欲望上让步 | 第二十七课的核心伦理命题；不是“满足欲望”，也不是泛指改变愿望，而是主体背离承载自身行动的欲望。 |
| service des biens | 对诸善的服务 | 保留 *biens* 在伦理学“诸善”与经济性“财物”之间的回响；具体列举财产时仍按语境译“财物”。 |
| demande | 索求 / 要求 | 分析情境中的结构概念优先译“索求”；普通请求或具体要求按语境译“要求”。 |
| plaisir | 快乐 / 快感 | 理论名词与 *principe de plaisir* 相连时优先“快乐”；具体感受可译“快感”。与 *jouissance*“享乐”区分。 |
| jouissance | 享乐 | 不译“快感”；保留其超出快乐原则、可能与痛苦相连的概念范围。 |
| livre de chair | 一磅肉 | 第二十七课借《威尼斯商人》的表达说明：抵达欲望须以享乐为代价；不按字面泛译“肉的一磅”。 |
| principe de plaisir | 快乐原则 | 与 *principe de réalité*“现实原则”成对。 |
| principe de réalité | 现实原则 | 与 *principe de plaisir*“快乐原则”成对。 |
| homéostasie | 稳态 / 内稳态 | 指装置维持低张力或平衡的调节倾向；不把它等同于欲望本身。 |
| principe de Nirvâna | 涅槃原则 | 第十七、十八课的能量学概念；须同具有历史维度的“死亡驱力”区分。 |
| entropie | 熵 | 伯恩费尔德与费特尔贝格讨论中的热力学概念；不因同死亡驱力对读而心理化。 |
| pulsion | 驱力 | 不译“本能”。 |
| Trieb / Triebe | 驱力 | 德文术语；第七课借英语 *drive* 与法语 *dérive*“漂移”展开双关，正文保留原词。 |
| pulsion partielle | 部分驱力 | 保留弗洛伊德驱力理论中的“部分”性质。 |
| pulsion de mort / Todestrieb | 死亡驱力 | 仅在原文确为 *pulsion* 或 *Todestrieb* 时使用。 |
| instinct de mort | 死亡本能 | 仅在原文确为 *instinct* 时使用，不替换成“死亡驱力”。 |
| pulsion de destruction / destrudo | 破坏驱力 | 同“死亡驱力”相关却不自动等同；*destrudo* 首次出现保留原词。 |
| surmoi / Über-Ich | 超我 | 首次出现德文时保留 *Über-Ich*。 |
| fantasme | 幻想 | 不译“幻觉”。 |
| masochisme | 受虐狂 / 受虐性 | 指临床类型时译“受虐狂”，指经济作用或结构倾向时译“受虐性”。 |
| génitalisation | 生殖器化 | 指分析理论中欲望趋向所谓成熟生殖器组织的过程；保留拉康的批判语气。 |
| relation d'objet | 客体关系 | 沿用既有理论名称；一般 *objet* 仍译“对象”。 |
| objet partiel | 部分客体 | 指驱力与享乐结构中的部分性客体；不预设它必然重新整合为“完整客体”。 |
| érotique / une érotique | 爱欲的 / 爱欲学 | 作名词且指有待建立的系统研究时译“爱欲学”；指文学或经验维度时依句法译“爱欲维度”。 |
| Sublimierung / sublimation | 升华 | 涉及客体力比多、驱力目标与社会价值的复杂过程；不简化为“高尚化”。 |
| Fixierbarkeit | 可固着性 / 固着 | 指个人力比多历程中形成固着的能力或倾向；首次出现保留德文。 |
| Haftbarkeit | 承担 / 责任 | 第七课强调它不只指“持续”，还带有负责、被约束和承担的德语回响。 |
| Genitalprimat | 生殖器首位 | 不把驱力网络在其统辖下的组织误写成毫无矛盾的统一。 |
| Verschiebbarkeit | 可移置性 | 指力比多或符号能在不同通路间移动；与动作名词 *Verschiebung*“移置”相关。 |
| Surrogat / Surrogate | 替代物 | 升华与驱力满足语境；保留替代性，不直接等同于象征代理。 |
| Partiallust | 部分快乐 | 指生殖器力比多中仍持续运作的部分性快乐。 |
| Reaktionsbildung | 反向形成 | 弗洛伊德术语；说明社会性格的形成可依赖同驱力相对抗的防御构造。 |
| répression | 压制 | 与 *refoulement*“压抑”区分；不因涉及欲望而自动改译“压抑”。 |
| refoulement / Verdrängung | 压抑 | 弗洛伊德术语；与 *répression*“压制”区分。首次出现德文时保留 *Verdrängung*。 |
| praxis | 实践 | 保留它作为行动及分析操作的含义，不缩减为抽象“理论应用”。 |
| intempérance | 不节制 / 不能自制 | 亚里士多德语境须结合所引希腊词判断；*akolasia* 偏“不节制、放纵”，明知善却未能照做的论证可依上下文用“不能自制”。 |
| κάθαρσις / catharsis | 净化 | 同时保留医学“涤除”和仪式“洁净”的历史歧义；第二十七课进一步界定为欲望的净化。 |
| Hilflosigkeit | 无助 / 无依 | 弗洛伊德焦虑论中的原初无助；第二十六课指分析终点可能触及的绝对无所依凭。 |
| Être pour la mort | 向死而在 | 海德格尔式表达在悲剧拓扑中的用法；不缩成普通的“走向死亡”。 |
| μὴ φῦναι / mē phynai | 宁可不要出生 | 俄狄浦斯的最后界词；其中 *μὴ* 还联系陈述内容与言说行为的分裂，不只是一项普通否定。 |
| moralisches Entgegenkommen | 对道德要求的迁就 | 琼斯用语；拉康将它解释为借承担禁令来回避阉割的“道德托辞”。 |

## 语言、主体与三界

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| la Chose / das Ding | 原物 | S7 核心术语，指表象和意指网络不能吸收、在最初现实经验中作为陌异内核被隔离出来之物；首次出现保留德文。不得与 *die Sache* 合并，也不因后文涉及康德就逐处译“物自体”。 |
| ce qui du réel pâtit du signifiant | 实在中承受能指作用的东西 | 第九课对原物及“人”的关键界定；*pâtir* 保留承受、受制于的被动性质。 |
| die Sache | 事情 / 事物 | 指由语言支配的人类行动所产生、可被说明和论说的事情或事物；同 *das Ding*“原物”区分。 |
| Sachvorstellung | 事物表象（Sachvorstellung） | 保留它同 *die Sache* 的构词关系；在弗洛伊德“词表象／物表象”既有术语对举中，可依原文层次说明其与“物表象”的关系。 |
| Dingvorstellung | 原物表象（Dingvorstellung） | 拉康用来指出弗洛伊德此处没有采用的构词；不与 *Sachvorstellung* 互换。 |
| Vorstellung / Vorstellungen | 表象 | 弗洛伊德术语；首次密集出现时可保留德文，不泛化为“观念”。 |
| Vorstellungsrepräsentanz / Vorstellungsrepräsentanzen | 表象代表 | 指在无意识中代表驱力并按能指法则组织起来的表象；不改写成“表象的再现”。 |
| Wahrnehmungszeichen | 知觉符号 | 弗洛伊德《第52封信》中的第一套记载；首次出现保留德文。 |
| Gleichzeitigkeit | 同时性 | 指多个能指得以同时呈现的原初共时性。 |
| Verneinung | 否定 | 弗洛伊德术语；指遭压抑之物在话语中一面被呈现、一面遭否认的方式。 |
| Verwerfung | 拒斥 | 同精神病结构有关；不与 *Verdrängung*“压抑”或 *Verneinung*“否定”混同。 |
| Spaltung / splitting | 分裂 | 指主体、言说行为与陈述内容等层面的结构性分裂；不弱化为一般意见分歧。 |
| Unglauben | 不信 | 不是简单取消 *Glauben*“信”的维度，而是人同世界及其赖以存在的真理发生关系的一种特殊模式。 |
| Verurteilung | 判决 | 第五课中与无意识层面的充分表述相连；首次出现保留德文。 |
| signifiant | 能指 |  |
| signifié | 所指 |  |
| sujet | 主体 | 概念义统一译“主体”；普通“题目、议题”义按上下文处理。 |
| Autre / grand Autre | 大他者 | 大写 A 时使用；与普通 *autre*“他者／别人”区分。 |
| Autre de l'Autre | 大他者的大他者 | 指为大他者提供保证的位置；该位置不因实在中有某物占据它便获得额外保证。 |
| autre | 他者 / 别人 | 概念义译“他者”；日常人际语境可译“别人、另一个人”。 |
| Nom-du-Père | 父之名 | 拉康术语。第五课原稿另写 *Nom-de-Père*；译文以“父名”保留该次形式差别并加注，不静默统一。 |
| discours | 话语 | 与 *parole*“言语”区分；泛指一套论述时可依句法译“论说”。 |
| parole | 言语 | 指说话行为及其象征条件；与 *discours*“话语”区分。 |
| Fort / Da | 不在（Fort）/ 在那里（Da） | 保留德文以显示成对交替；不把它缩成普通的“走／来”。 |
| Geviert | 四方 | 海德格尔术语；第五课用以提示能指电池至少包含四分结构。 |
| anamorphose | 变形透视 | 通过特定视角让最初不可辨认的线条聚成可读图像；第十课用以说明艺术围绕空组织幻象。 |
| ἀτοπία / atopia | 无处可在 | 第十课谈巴洛克形式让某物在“无处”重新涌现；保留希腊文与转写。 |
| das Es / Es | 它 | 弗洛伊德第二拓扑术语；正文首次出现保留德文，强调其原初首要地位，不普通化为日常代词。 |
| Besetzung | 投注 | 精神能量对表象或通道的占据；与 *Bahnungen*“通道开辟”相连。 |
| extimité | 外密性 | 拉康构词；指原物既在主体最亲密的内部，又以根本外在性处于其中心。首次出现保留法文。 |
| Zielablenkung | 目标转移 | 升华论中指驱力或趋向偏离其原有目标；首次出现保留德文。 |
| Strebung | 趋向 | 弗洛伊德术语；第十一课同 *tendance*、*Trieb* 并列，不直接抹平为同一个词。 |
| Ichziel / Ichziele | 自我目的 | 伯恩费尔德升华论中，自我预先立定并可吸收里比多变化的目标。 |
| Ichtrieb / Ichtriebe | 自我驱力 | 弗洛伊德早期驱力理论中服务于自我保存的驱力；与性驱力区分。 |
| Libidoziel / Libidoziele | 力比多目的 | 第十二课讨论伯恩费尔德时，同 *Ichziele*“自我目的”、*Lustziele*“快乐目的”区分。 |
| Lustziel / Lustziele | 快乐目的 | 以快乐满足为取向的目的；同 *Ichziele*“自我目的”对举。 |
| Ichgerecht / ichgerecht | 符合自我的 | 指某项目的或活动同自我及其既有目的相符。 |
| Versagung | 拒绝 / 受挫 | 依语境可指外部拒绝、内部拒绝或满足落空；保留德文以免同 *Verneinung*“否定”混同。 |
| Bearbeitung | 加工 | 指自我对感情、白日梦或幻想所作的组织工作；*sekundäre Bearbeitung* 译“次级加工”。 |
| vacuole | 空泡 | 第十一课借组织学意象指能指系统中心被创出的空位；不是生物学实物论断。 |
| Domnei / Domna | 贵妇 / 宫廷爱情中的贵妇 | 奥克语宫廷爱情术语；*Domna* 指处于支配位置的贵妇，*Domnei* 依上下文保留原词。 |
| domnoyer | 侍奉贵妇、调情嬉戏 | *Domnei* 的动词形式；第十一课强调它同 *donner*“给予”只有能指回响，并非词源同一。 |
| Senhal | 隐名 | 宫廷爱情诗中不直呼贵妇姓名而使用的代称；正文首次出现保留原词。 |
| lauzengiers | 嫉妒者 / 诽谤者 | 普罗旺斯宫廷诗歌中阻隔恋人与贵妇的敌对者。 |
| Vorlust | 前快感 | 《性学三论》术语；宫廷爱情的悬置技术维持这种与快乐原则方向相逆的预备快感。 |
| amor interruptus | 中断之爱 | 第十一课用来概括宫廷爱情的克制与悬置技术。 |
| don de merci / réunion de merci | 恩许之赠 / 恩许的结合 | 宫廷爱情仪式的神秘终点；其具体实践内容在原讲稿中被明确说成无法确定。 |
| ex nihilo | 从无中 | 第九课以陶罐围绕空被塑造说明创造；不弱化为普通“从零开始”。 |
| Erscheinung | 显现 | 第八、九课谈客体或原物取得可见形式时使用；首次出现保留德文。 |
| Autre chose | 另一物 | 原物受到遮蔽时，在重新找到客体的结构中由“另一物”代表；保留同 *la Chose* 的词语呼应。 |
| Wohl | 安适 / 福祉 | 康德语境中指主体自身或邻人的经验性“好处、福祉”；第五课以后须同 *das Gute*“善本身”区分。 |
| das Gute / Gute | 善 / 善本身 | 康德语境中的实践理性对象；在第六课同 *Wohl*“安适、福祉”对举，不一律并作普通“好”。 |
| Sicherung | 保障 | 康德术语；指主体面对法则或社会秩序时所能获得的保证。首次出现保留德文。 |
| pathologisches Objekt | 病理性客体 | 康德语境中的 *pathologisch* 指受感性、激情制约，并非现代临床意义上的“病态”。 |
| πρῶτον ψεῦδος / proton pseudos | 第一个谎言 | 《纲要》关于艾玛病例的表述，拉康称作“癔症的第一个谎言”；正文依原稿字形保留希腊文。 |
| ἁμαρτία / hamartia | 罪 / 缺失 / 判断错误 | 第六课援引《罗马书》时强调“缺失、未能参与原物”；第二十二、二十三课的悲剧语境则指克瑞翁的失误或判断错误，须同 *ἄτη* 区分。 |
| ἄτη / Atē | ἄτη（灾毁界限） | 保留希腊词；在《安提戈涅》中指人不能长久越过、又由大他者场域承载的灾毁界限，不等同于 *hamartia*“判断错误”。 |
| Αἰδώς / Aidōs | 羞耻 | 第二十五课中守卫性结合核心、阻止直接把握的屏障。 |
| αὐτόνομος / autonomos | 自律者 / 依自身法则 | 《安提戈涅》中形容主人公同能指切割及家族 *ἄτη* 的独特关系；正文依句法处理。 |
| prochain | 邻人 | “爱你的邻人如同爱自己”及 *Nebenmensch* 语境；不得泛化成空间上普通的“附近的人”。 |
| Ichlibido | 自我力比多 | 与 *Objektlibido*“客体力比多”对举。 |
| Objektlibido | 客体力比多 | 与 *Ichlibido*“自我力比多”对举；弗洛伊德明确说升华涉及客体力比多。 |
| Ich-Ideal | 自我理想 | 与 *Ideal-Ich*“理想自我”区分。 |
| Ideal-Ich | 理想自我 | 与 *Ich-Ideal*“自我理想”区分。 |
| Real-Ich | 实在自我 | 《纲要》语境中的假设性组织；同 *Lust-Ich*“快乐自我”区分，不等同于三界中的实在界。 |
| Lust-Ich | 快乐自我 | 精神组织最初轮廓显现之处；其现象性质同表象代表系统的投注相连。 |
| affect-signal / Signal | 情感信号 / 信号 | 第八课强调情感不是能指，而具有约定性、可移置的信号功能；焦虑也被弗洛伊德归入信号。 |
| réaction thérapeutique négative | 负性治疗反应 | 弗洛伊德晚期问题；第八课借它说明主体可能偏爱恶意乃至死亡。 |
| Überschätzung | 对客体的过度评价 | 爱欲客体被赋予超常价值；第八课将它推进为“客体的升华”。 |
| idéalisation | 理想化 | 引入主体对客体的认同；与 *sublimation*“升华”区分。 |
| perversion | 倒错 | 与升华并置时，指欲望越过快乐原则通常界限的一种关系；不作日常道德谴责语。 |
| élever un objet à la dignité de la Chose | 把一个客体提升到原物的尊严 | 第八课给出的升华一般公式。 |
| amour courtois | 宫廷爱情 | 中世纪升华问题的核心历史形式；不泛译为普通“浪漫爱情”。 |
