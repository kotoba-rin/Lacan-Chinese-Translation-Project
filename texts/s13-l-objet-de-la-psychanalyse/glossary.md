# 翻译术语对照表

适用范围：`S13 L'objet de la psychanalyse`

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| L'objet de la psychanalyse | 精神分析的对象 | 本期标题；这里的“对象”同时牵涉科学对象的构成与对象(a)，不缩减为一般治疗对象。 |
| objet | 对象 | 普通认识论、欲望或语法语境均先保留“对象”；固定术语 *relation d'objet* 仍译“客体关系”。 |
| objet(a) / objet (a) / objet petit(a) | 对象(a) | 本期原文主要使用带括号的记法；进入公式时写作 $a$，不改写成经验对象。 |
| i(a) / i'(a) | 小他者的意象 / 小他者意象在大他者中的虚像 | 依光学图式区分镜像意象与经大他者定位的虚像；公式本身保持不译。 |
| sujet | 主体 | 概念义固定译“主体”；普通“题目、议题”义依语境处理。 |
| instance | 审级 / 作用层次 | 弗洛伊德—拉康概念语境优先译“审级”；普通“场合、请求、机构”等义依句法处理，不机械译成“实例”。 |
| sujet de la science | 科学的主体 | 指笛卡尔式科学开启所关联的主体位置，不译“科学家”。 |
| division du sujet / refente / Spaltung | 主体的分裂 / 裂分 / 分裂 | *refente* 强调再次裂开或结构性裂分；首次同德文并列时可写“裂分（*Spaltung*）”。 |
| Ichspaltung / clivage du moi | 自我裂分 | 弗洛伊德晚期概念；同主体层面的分裂相关，但不直接抹平二者层次。 |
| Je / moi / Ça | 我 / 自我 / 本我 | 保留拉康对言说的“我”、镜像自我与弗洛伊德“本我”的区分；非人格结构 *ça parle* 不机械译成本我。 |
| ça parle / ça écoute | 它在说话 / 它在听 | 保留非人格主语，不补成“无意识在表达／倾听”。 |
| savoir / connaissance | 知识 / 认识 | *savoir* 指同能指及无意识相连的知识；*connaissance* 指认识关系或已知内容。 |
| Wirklichkeit / Realität | 现实效力 / 现实性 | 第二课用前者指关系能够实现的效力，用后者指作为不可能者、决定共同失败的现实；正文首次出现保留德文。 |
| vérité / réalité | 真理 / 现实 | 真理的位置或功能不改写为日常“真相”；现实同实在界严格区分。 |
| division entre le savoir et la vérité | 知识与真理之间的分裂 | 本期起点之一；不把二者改写成互补的两种认知内容。 |
| cause matérielle / formelle / efficiente / finale | 质料因 / 形式因 / 动力因 / 目的因 | 沿用亚里士多德四因名称；拉康把真理同原因问题相连时保留其分类。 |
| signifiant / signifié / signification | 能指 / 所指 / 意指 | 不把 *signifiant* 译成“意义”；*signification* 指意指作用或形成的意指。 |
| sens / signification | 词义、含义 / 意指 | 两词明确并举时保留层次：*sens* 可指一个词可被理解的含义，*signification* 指由结构产生的意指作用；不一概译成“意义”。 |
| signe | 符号 / 征兆 | 同“能指”区分；症候语境可依上下文译“征兆”。 |
| trait unaire | 一元特征 | “1”作为欠缺留下的单一标记；不改写成一般性格特征。 |
| objet zéro | 零对象 | 弗雷格对数的逻辑奠基语境；不是数量为零的经验对象。 |
| scotomisation | 盲点化 | 第二课批评把结构性裂分安置到知觉盲点中的解释；不以它代替 *Spaltung*。 |
| Autre / grand Autre | 大他者 | 大写 A 的能指场所；与小写 *autre* 区分。 |
| autre / petit autre | 他者 / 小他者 | 镜像同类或公式中的小写 a 译“小他者”；普通句法依语境译“另一个／别人”。 |
| désir / demande / besoin | 欲望 / 索求、要求 / 需要 | 分析结构中的 *demande* 优先译“索求”；具体请求依语境译“要求”。 |
| fantasme | 幻想 | 不译“幻觉”；公式按原文写作 $\bar S \mathbin{\lozenge} a$。 |
| jouissance | 享乐 | 与 *plaisir*“快乐／快感”区分。 |
| pulsion | 驱力 | 不译“本能”；保留其回路及部分驱力性质。 |
| regard / œil / vision | 凝视 / 眼睛 / 视觉 | 凝视是对象(a)的功能，不等同于观看器官或视觉知觉。 |
| pulsion scopique | 窥视驱力 | 沿用项目既有译名；其结构同时包含观看与被观看的位置。 |
| voix | 声音 | 作为对象(a)时保留其对象功能，不化约为可听见的声响。 |
| Réel / Symbolique / Imaginaire | 实在界 / 象征界 / 想象界 | 作为三种语域时使用“界”；普通形容词依句法译“实在的／象征的／想象的”。 |
| phallus | 阳具 | 作为能指时不改写为生理解剖器官。 |
| privation / frustration / castration | 剥夺 / 挫折 / 阉割 | 保留三项缺失机制的结构区分。 |
| transfert / névrose de transfert | 转移 / 转移神经症 | *transfert* 不译“移情”；后者指分析情境中构成并运作的神经症。 |
| sujet supposé savoir | 被假定知道的主体 | 转移的结构性支点，不表示某人实际拥有全部知识。 |
| principe de réalité / réalité psychique | 现实原则 / 心理现实 | 前者与快乐原则成对；后者不可同实在界混同。 |
| représentation / Vorstellung | 表象 | 弗洛伊德语境首次出现德文时可保留原词；普通“呈现、再现”义依句法处理。 |
| représentant de la représentation / Vorstellungsrepräsentanz | 表象代表 | 指在无意识中代表驱力并依能指法则组织的代表项。 |
| Verleugnung / Verneinung / Verwerfung / Bejahung | 拒认 / 否定 / 拒斥 / 肯定 | 四项机制不得互换；首次密集出现时保留德文。 |
| bande de Mœbius | 莫比乌斯带 | 一面一边的拓扑曲面；不写成普通“环”。 |
| tore | 环面 | 同球面、莫比乌斯带及克莱因瓶区分。 |
| bouteille de Klein | 克莱因瓶 | 无定向闭曲面；保留其内外连续的结构功能。 |
| plan projectif | 射影平面 | 拓扑与透视语境使用数学术语“射影”，不译“投影计划”。 |
| cross-cap / mitre | 交叉帽 / 主教冠 | *cross-cap* 是射影平面的浸入模型；原文改称 *mitre* 时保留“主教冠”的形象。 |
| coupure / trou | 切割 / 孔洞 | 依拓扑操作译名；普通“裂口、空缺”义依上下文处理。 |
| perspective / tableau | 透视 / 画作、画面 | *tableau* 指具体绘画时译“画作”，指构图平面或呈现时译“画面”。 |
| point de fuite / ligne d'horizon / point-sujet | 消失点 / 地平线 / 主体点 | 本期对透视结构的固定表达；主体点不等同于观看者的经验眼睛。 |
| aphanisis / ἀφάνισις | 消隐 / 消失 | 概念名译“消隐”；普通释义仍可写“消失”，并辨明消隐的是欲望、对象还是主体。 |
| Entfremdung / aliénation | 异化 | 结构概念固定译“异化”；第二十三课围绕 *Entfremdung* 本身争论“陌生感／异化／身处异乡感／现实解体”等译法时，依各发言者立场保留差异。 |
| idéal du moi / moi idéal | 自我理想 / 理想自我 | 前者是象征性定位，后者偏向镜像理想形象。 |
| Nom-du-Père | 父之名 | 固定术语；保留连字符所标示的命名功能。 |
| praxis | 实践 | 指通过象征操作实在的分析行动，不缩减为理论的普通应用。 |

## 地形学、地形与拓扑学

| 外文 | 统一中文译名 | 备注 |
| --- | --- | --- |
| topique / première topique / seconde topique | 地形学／第一地形学／第二地形学 | 弗洛伊德元心理学的“精神地点”模型：第一地形学区分意识、前意识与无意识，第二地形学区分本我、自我与超我；所说地点不是脑部解剖位置。法语 *topique* 对应德语 *Topik*，英语文献通常把两套模型称作 *first / second topography*，不得同 *topologie*“拓扑学”混译。 |
| topologie / topologique | 拓扑学／拓扑学的 | 指连续变形下保持的邻接、边界、连通与切割等结构关系；拉康借莫比乌斯带、环面、克莱因瓶、交叉帽及结来处理主体结构。它不同于弗洛伊德 *topique* 的第一／第二地形学，也不只是精神装置的区域示意图。 |
| topographie | 地形／位置分布、位置描绘 | 普通法语可指具体空间、身体、政治版图或对象位置的描绘；须按上下文译，不因词形相近便自动并入 *topique*“地形学”或 *topologie*“拓扑学”。 |
